# SPVC改进项目

文档导航整理日期：2026年10月21日。

当前研究用DINO图像表示和物理状态到latent的代理替代生成图像前端，训练对应控制器，并研究图像与代理差异怎样进入概率安全分析。已得到前端替换、误差比较和原代码口径代理SBC结果，尚未完成图像闭环端到端安全证书。

## 从这里开始

1. **给导师看、先理解整体：** [训练流程与关键实验说明](训练流程与关键实验说明.md)。讲框架、数据流、R0/R1/R2、q/PPO、Transformer和关键正负结果。
2. **查看最新SBC工作：** [SBC路线澄清](docs/current/SBC证书路线澄清_SPVC与语义双路径方案对照.md)开头，以及[完整实验说明](docs/current/CP与SBC安全余量实验_逐步说明.md)第十八节。最新记录包含三个有限时域结构化候选，仍未获得可替换证书。
3. **按问题找文档：** [项目文档总目录](docs/README.md)。按导师汇报、主线技术、专题对照、历史记录、论文参考分类。

## 目录分工

- `docs/current/`：主线说明、专题实验和保留的阶段记录；具体用途以文档总目录为准，并非每份都是最新计划。
- `docs/archive/`：历史方案、旧汇报和已完成阶段手册，仅用于追溯。
- `docs/references/`：论文PDF、论文解读和早期改进建议。
- `artical-F122/results/`：实验结果与配置；不同模型、数据和评价范围不能混合引用。
