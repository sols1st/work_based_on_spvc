# SPVC 改进项目

项目沿用 SPVC 的视觉反馈控制与非负神经屏障表示，将 cGAN 前端换为 DINO 低维观测。AEBS、车道保持和五维弯道遇障制动采用**轨迹级 CP 感知误差校准与确定性鲁棒屏障证书**。CP 估计新轨迹的视觉误差全程落入包络的概率下界。验证器检查包络内的每个允许后继，由此推导登记模型在采样时刻避险的条件。原 SPVC 的随机屏障证书（SBC）使用后继屏障值的条件期望。

## 收益证明的一句话

- 原 cGAN 原生轨迹 q=1.9156 m/92 对 DINO q=0.4184 m/99，**部署系统更好，但不是同预算架构因果**；
- 400/10k/24k 同数据预算：**400 DINO 好；10k/24k 真实图 cGAN 头 q 更小；24k cGAN 覆盖更低**，无单向赢家；
- 联合 C 5 对种子无稳定收益；
- 车道共同半径 r_cert=0.12，0.16 失败。
