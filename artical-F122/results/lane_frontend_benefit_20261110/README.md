# 车道前端收益证明：阶段一/二结果包

2026-11-10。**固定 C 与联合 C 的 5 对训练种子配对先导。** 结论：联合 C 没有稳定收益；不能把“学习 C”作为已有贡献。这个包不包含原 SPVC 车道基线，也不证明整个前端替换优于原方法。

## 协议

- 5 个训练种子：20261109、20261111、20261112、20261113、20261114；
- 每对固定 C / 联合 C 共享：数据、冻结 DINO 特征、warm start、30 epoch 预算、batch/优化器/学习率、C 初始化旋转；
- 固定 C 的 C 固定为旋转 `C0=[[0.8660254,0.5],[-0.5,0.8660254]]`，视觉头同步旋转；联合 C 的 C 可训练、逐行归一化；
- 两个版本使用**同一组新外部条件种子**：校准 `202611100101`，留出 `202611100102`；初始状态、曲率、每条轨迹种子逐对一致；
- 每个版本各自重新渲染、DINO 推理、闭环生成轨迹，不复用另一版本的状态序列；
- 每个版本 199 条校准 + 100 条留出，80 步；冻结 q 后再采留出；
- 同一 actor、同一 SBC、同一验证器；证书在各自 q 下独立审计。

## 解释

这个批次是**C 组件消融**，不是整体前端替换的收益证明：

- 联合 C 的实现确实更新了 C（C 变化约 0.00138），但 C 仍非常接近初始旋转；
- q 差异方向不一致、幅度很小；覆盖差也不支持联合 C 更好；
- 静态误差也没有显示联合 C 优势；
- 因而不能写“学习 C 提高了可观测性/控制性能/证书获得率”；
- 也不能从这批结果写“新前端整体优于原 SPVC”：没有车道原方法 A-native/A-matched 基线，没有任务完成率/到达指标，也没有原 cGAN 的公平重训。

## 边界

- 5 个训练种子是小样本先导，不做显著性/总体优势声明；
- q 是归一化车道状态，物理半宽是 `0.85q m` 和 `0.30q rad`；
- 数值区间不是向外舍入的浮点证明；
- 只覆盖注册渲染器、三个曲率、80 步、名义分布；不是新相机/实车；
- 固定 C 是旋转坐标 C0，不是原始未旋转 `C=I`；它是同预算消融，不是原 SPVC 论文复现。
