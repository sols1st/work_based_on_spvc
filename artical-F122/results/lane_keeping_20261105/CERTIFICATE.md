# 车道保持 SBC 证书：LQR + 有界神经残差类

> **2026-11-07 更新：** 本文是 11 月 5 日的结构化证书分支，历史对照用；当前最新为原 PPO + AEBS 同类训练式神经 SBC + 轨迹级 CP 0.090093，见 `../lane_keeping_20261106_aebs_method_sbc_v1/` 与 `../lane_trajectory_cp_20261107_v1/`。


2026-11-05。**结论：在语义二维状态、三个注册曲率下，`LQR + ε·clamp(B(x),0,1)·tanh(残差网络)` 这一类神经策略通过了二次 SBC 的数值区间证书。**证书文件：`residual_sbc.json`；生成脚本：`Aebs/lane_keeping/certify_linear.py --residual-eps .5`。

**这不是 PPO 的证书，也不是视觉误差下的证书。**下面把对象、条件、范围和未覆盖部分写清楚。

## 1. 被证明的控制器类

```
u(x, κ) = clip( u_LQR(x, κ) + ε · clamp(B(x), 0, 1) · tanh(r_θ(x, κ)) )
B(x)    = x^T P x
```

- `u_LQR = -Kx + atan(Lκ)/φ_max`，`K` 为离散 LQR 增益。
- `P` 是线性化闭环的离散 Lyapunov 矩阵，缩放到初始盒子最大 `B=0.999`。
- `ε=0.5`，`r_θ` 是任意以 `tanh` 为输出的神经网络；证书不依赖它的权重，只依赖 `|tanh|≤1`。
- 训练后的残差网络只是这个类的一个成员；换权重、换种子、换隐藏层宽度，证书仍然成立（只要输出仍是 tanh）。

因此证书覆盖的是**一个神经策略类**，不是某个固定线性控制器。

## 2. 证书内容

| 项目 | 值 |
|---|---|
| 控制器类 | LQR + `0.5·B(x)·tanh` 残差类 |
| SBC | `B(x)=x^T P x`，`P` 正定，非负 |
| 初态盒 | `|e|≤0.25 m`，`|θ|≤0.06 rad` |
| 初态 `B` 区间上界 | **0.999**（要求 ≤1） |
| 子水平集 `S={B≤1}` | `|e|≤0.3074 m`，`|θ|≤0.2628 rad` |
| `S` 是否在车道内 | 是（安全阈值 0.85 m / 0.30 rad） |
| 曲率 | `κ ∈ {-0.01, 0, 0.01}`，逐个验证 |
| 递减条件 | 每个与 `S` 相交的格子：`max B(next) ≤ min B(current)` |
| 验证方法 | 自适应区间细分，起始 200×200，最大深度 12 |
| 结果 | **0 unresolved**；104,556 个严格格 + 7,218 个平衡点邻域格 |
| 平衡点邻域 | 仅 `B≤10^-6` 的格子使用 `10^-8` 数值容差；`B(0)=B(next(0))=0` |

证书的逻辑：初态 `B≤1`；在 `S={B≤1}` 上 `B` 不增；因此 `B` 永远不超过 1，状态永远留在 `S`；`S` 完全在车道内，所以不会越界。坏集可以取 `S` 的补集，不需要 `B≥20` 的车道边界条件。

## 3. 验证方法

- 对每个状态格子，精确计算二次型 `B` 的区间上下界（凸二次型在盒上的最小/最大值）。
- 控制器动作区间 = LQR 仿射区间 ± `ε·B_max`；这覆盖任意残差网络。
- 下一步状态区间用单调 `sin/tan` 端点。
- 格子与 `S` 相交（`B_min<1`）就检查；完全在 `S` 外（`B_min≥1`）忽略；严格递减的格子通过；否则一分为四，直到通过或达到深度 12。
- 这是**数值区间证书**，不是形式化浮点证明。
- 本地与服务器 `vt` 环境（Python 3.8 / torch 2.3.1）各自独立运行，结果一致：104,556 严格格、7,218 平衡点邻域格、0 unresolved（文件 `residual_sbc_server.json`）。

## 5. 明确不覆盖

- **不覆盖原始 PPO actor**：它的动作不受 `ε·B` 缩放，不能用这个证书。
- **不覆盖视觉观测误差**：证书使用真实 `(e,θ)`；图像闭环是行为证据，不是这个证书的一部分。
- **不覆盖连续曲率**：只验证三个注册曲率；曲率在区间内连续变化需要另加区间。
- **不是形式化浮点验证**：区间用 float64，平衡点邻域有 1e-8 容差。
- **不保证目标到达**：只保证留在 `S`，`S` 在车道内。
