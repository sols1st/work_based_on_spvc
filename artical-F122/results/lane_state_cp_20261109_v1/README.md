# 车道保持：状态相关 Bernstein CP 盒（试验）

2026-11-09。**这是一个 state-dependent CP 对照，不替换 0.090093 常量盒主结果。**

## 做法

- 状态归一化 `(e/0.85, θ/0.30)`；
- 用 2×2 系数、degree-1 张量 Bernstein `b(e,θ)`，在 199 条校准轨迹的逐步残差上拟合（非负系数，HiGHS）；
- 轨迹分数 `max_t max(|err_e|,|err_θ|) / b(e_t,θ_t)`，取第 190/199 个分数得到 `q=1.7290315773`；
- 状态相关半径：`r(e,θ)=min(q·b(e,θ), 0.0992)`；上限 0.0992 是为了用已有 SBC 在最大半径上的证书做集合包含。

## 结果

| 项目 | 状态相关盒 | 常量盒（主结果） |
|---|---:|---:|
| 平均半径 | **0.08888** | 0.090093 |
| 最大半径 | 0.0992 | 0.090093 |
| 校准覆盖 | 190/199 | 190/199 |
| 留出覆盖 | **93/100** | 95/100 |
| SBC 验证 | 在 0.0992 上通过（状态盒是子集） | 在 0.090093 上通过 |

状态盒的平均半径只比常量盒小约 1.3%，最大半径反而更大；留出覆盖从 95/100 降到 93/100。因此这是一个**负/边际结果**：在当前 2D 误差形状下，简单 degree-1 Bernstein 没有带来覆盖更好的紧盒。

## 统计说明

`b(e,θ)` 和 `q` 都在同一批 199 条校准轨迹上拟合/取分位；没有一个独立的“拟合集”。留出 100 条只用于评估，不参与拟合、cap 或 q 的选择。因此这里的 190/199 是构造覆盖，93/100 是留出经验覆盖；不能把它写成独立拟合后的 95% 保证。

## 范围

状态盒用 cap 0.0992 做集合包含；SBC 证书是对常量 0.0992 盒的完整验证，状态盒是其子集。CP 限冻结名义渲染轨迹分布；不是实车、新相机或任意固定初态的条件覆盖。若要把它做成主结果，需要重新设计误差形状（分量相关/曲率相关）并重新校准。
