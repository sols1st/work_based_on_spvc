五、用 Python 实际计算 𝛽
下面给出可以直接用于二维状态、三阶多项式的 CVXPY 实现。假设已经计算了状态矩阵 X 和相应
的感知残差 r。
import numpy as np
import cvxpy as cp
from sklearn.preprocessing import PolynomialFeatures

# X: shape = (N, 2), columns = [px, py]
# r: shape = (N,), DINO 投影的无穷范数残差
X = np.asarray(X, dtype=float)
r = np.asarray(r, dtype=float)




                                               6
VISION‑SLS ·状态相关误差界                                           技术说明



# 1. 建立完整三阶多项式基
poly = PolynomialFeatures(degree=3, include_bias=True)
M = poly.fit_transform(X)
N, p = M.shape

# 2. 定义优化变量
beta = cp.Variable(p)
xi = cp.Variable(N, nonneg=True)

# 3. 每个训练样本对应的误差包络
b = M @ beta

# 4. 超参数（示例，可通过验证集调整）
gamma = 1e‑4
mu = 20.0

# 5. 凸优化
objective = cp.Minimize(
    cp.sum(b) / N
    + gamma * cp.sum_squares(beta)
    + mu * cp.sum(xi) / N
)
constraints = [
    b + xi >= r,
    b >= 0
]

problem = cp.Problem(objective, constraints)
problem.solve(solver=cp.OSQP)

if problem.status not in ["optimal", "optimal_inaccurate"]:
    raise RuntimeError(problem.status)

beta_hat = beta.value
print("Learned coefficients:", beta_hat)

# 6. 新状态计算误差包络
x_new = np.array([[1.0, 2.0]])
m_new = poly.transform(x_new)

b0 = float((m_new @ beta_hat).item())
print("Predicted error envelope:", b0)

上述代码与论文式（31）具有相同的基本优化结构，但将目标按样本数归一化，并添加了训练样本
上的非负约束。它适合作为实现起点，并不包含整个状态域上的多项式非负性证明。
由于优化变量只有 𝛽 和松弛变量 𝜉 ，DINOv2 不需要在这个凸优化过程中反向传播。视觉编码器和
𝐶𝑟 应当先训练完成并固定。

  ‧ 𝛾 太大：多项式系数受到较强约束，可能欠拟合。
  ‧ 𝛾 太小：高阶系数可能较大，在训练区域之外容易出现不合理波动。

 ‧ 𝜇 太小：优化器倾向于使用较大的松弛变量，误差包络可能低估真实残差。
