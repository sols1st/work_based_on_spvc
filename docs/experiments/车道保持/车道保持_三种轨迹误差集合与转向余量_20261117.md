# 车道保持的配对实验：视觉误差的形状怎样改变可验证的转向余量

2026-11-17 在服务器 `vt` 环境运行。三组使用同一个冻结的 DINO 视觉前端、神经控制器、神经鲁棒屏障和逐步图像闭环。唯一的实验变量是如何用同一批轨迹构造感知误差集合。这项消融用于解释当前框架较保守的环节。原 SPVC 的生成前端及期望型 SBC 没有参与这三组比较。

## 一、相同的输入和任务

车以 4 m/s 行驶，采样周期 0.1 s，一条轨迹包含 80 次观测和 81 个状态。每条轨迹独立抽取初态和一个固定曲率。初始横向偏差在 ±0.25 m 内，初始航向偏差在 ±0.06 rad 内，曲率取 −0.01、0、+0.01 m⁻¹。相机、光照和无噪声渲染协议固定。真实状态归一化为 x=(横向偏差/0.85，航向偏差/0.30)，该二维向量就是本版的固定线性状态代理。图像通过冻结 DINO patch 特征与视觉投影输出 y，低维视觉代理误差为 η=y−x。

在已知曲率 κ 下，演员网络 π 输出截断在 [−1,1] 的归一化转向，物理前轮转角为该数值乘 0.45 rad。闭环使用图像动作 π(y,κ)，离线另外计算 π(x,κ)。两者差的绝对值 d=|π(y,κ)−π(x,κ)| 衡量视觉误差对当前控制命令的实际影响。d 使用冻结的完整非线性网络计算，包含动作限幅。

本实验复用此前的 [AEBS 与车道鲁棒综合权重](../跨实验对照/AEBS与车道_旧前端鲁棒综合_20261116.md)。新采集使用 float32 视觉网络、float64 冻结策略和动力学；三臂数值接口一致。旧数据只用于定标各分量尺度，未进入本轮校准和留出统计。

## 二、三种误差集合

先将旧版 199 条校准轨迹转作本轮的开发数据。对各条轨迹的全程最大绝对误差分别取经验 95% 分位数，冻结横向尺度 b₁=0.0983874、航向尺度 b₂=0.0645874（均为归一化坐标），以及动作尺度 a=0.254529（归一化转向）。尺度只控制集合的形状，正式覆盖由下一步的新轨迹校准提供。

| 组别 | 每个时刻的分数；轨迹分数取 80 步最大值 | 校准出 q 之后，验证器允许的误差 |
|---|---|---|
| 统一盒 | 两个视觉分量绝对值中的最大值 | 两个方向同一半宽 q |
| 分维盒 | D=max(\|η₁\|/b₁, \|η₂\|/b₂) | 分别使用半宽 qb₁、qb₂ |
| 视觉＋动作联合集合 | max(0.5D, d/a) | 两个视觉分量分别满足半宽 2qb₁、2qb₂，且同一后继产生的动作偏差 d≤qa |

系数 0.5 在采集前给定。联合集合允许单项视觉误差放宽，同时切掉会产生过大转向偏差的组合。每种方法只用**一个整轨迹分数**同时校准自己的全部限制。不同组 q 的尺度不同，原始 q 不宜作收益比较。[采集与评分代码](../../../artical-F122/Aebs/lane_contract_comparison/collect.py)

## 三、登记与验证方法

1. 先锁定前端、控制器和屏障的文件散列、评分规则、额外转向扰动网格和采样种子。重新采集 199 条校准轨迹；每组用自己的第 190 小分数作 q。保存三份阈值后再采集 100 条独立留出轨迹，三组共用这些轨迹。轨迹访问过的状态、行为成绩和 DINO 推理成本相同。
2. 在三个曲率上用同一个连续域仿射区间验证器检查初态 B≤1、危险区 B≥20、活跃区域每个允许后继 B 不增。视觉盒用每轴两段误差区间划分。对联合集合，同时计算 π(x+η,κ) 的区间和名义动作区间 π(x,κ)±qa，取交集。凡真实满足联合约束的动作都在交集中。在转向命令外另加登记的有界扰动并再次限幅；各臂用相同的检查预算。若找到正漂移点，使用合法的状态、视觉误差和额外转向扰动重新计算并保存见证。点违反不增仅否定这份屏障在该误差模型下的充分条件。
3. 另在正式 q 生成前锁定了转向偏差诊断。在同一个连续初态域上，对视觉造成的 |π(x+η,κ)−π(x,κ)| 求仿射区间上界，并保留能直接实现某个偏差数值的初态与视觉误差。下界来自具体点，上界覆盖原初态盒、所有三个曲率和完整误差集合。这可以分辨一个集合真正允许的动作偏差与验证器单方面给出的松界。[连续域检查](../../../artical-F122/Aebs/lane_contract_comparison/audit.py) · [动作偏差区间与见证](../../../artical-F122/Aebs/lane_contract_comparison/action_range.py)

## 四、实际结果

### 视觉误差会让前轮转错多少

下表的转向偏差随初态、曲率和集合内视觉误差变化。下界是一个具体可复现的允许组合真正达到的值，上界对全部允许组合同步成立。它们夹住各集合允许的最大偏差。每一行都按该组自身的覆盖规则独立解释。[阈值与半宽](../../../artical-F122/results/lane_contract_comparison_20261117_v1/contracts.json) · [动作上下界与可行点](../../../artical-F122/results/lane_contract_comparison_20261117_v1/action_range.json)

| 约束 | 归一化横向／航向误差半宽 | 同一策略在连续初态域上允许的最坏前轮转向偏差（rad） |
|---|---|---:|
| 统一盒 | 0.096823／0.096823 | [0.280931, 0.304368] |
| 分维盒 | 0.106795／0.070107 | [0.249405, 0.272812] |
| 视觉＋动作 | 0.198388／0.130234，且归一化动作偏差 ≤0.256615475 | [0.1154766, 0.1154770] |

例如，统一盒允许横向和航向两维误差都等于 −0.096822812。在直路上，某个具体初态的名义输出是 −0.310859；用带误差的观测则输出 +0.313433，前轮角因此偏差 0.280931 rad（约 16.10°）。这个扰动满足统一盒，未必在真实渲染中出现。联合集合在所有初态允许的最大偏差约 6.62°。用联合上界除以统一盒已经达到的下界，至少减小 **58.89%**；相对分维盒已经达到的下界至少减小 **53.69%**（向下保留两位）。这说明联合校准减少了验证器需要考虑的、对转向最不利的误差组合。三组运行的是同一个策略，其实际视觉转向没有变化。

### 同一份神经鲁棒屏障还能容忍多少额外转向扰动

连续域检查允许归一化动作额外变化 u，并将结果限幅，再输入车辆模型。表中 ±m 表示本次认证对每一步的所有 u∈[−m,m] 都成立。所有单位已经换成物理前轮转角。初始集的共同屏障上界为 0.214509，危险集的共同下界为 23.546546。

| 误差集合 | 预设粗网格最大通过 | 补充细分后最大通过 | 细分后首个未决点 | 最小已找到正漂移见证的幅值 |
|---|---:|---:|---:|---:|
| 统一盒 | ±0.0675 rad | ±0.0675 rad | ±0.06975 rad | ±0.072 rad |
| 分维盒 | ±0.0675 rad | ±0.0855 rad | ±0.08775 rad | ±0.090 rad |
| 视觉＋动作 | ±0.0675 rad | ±0.0855 rad | ±0.08775 rad | ±0.090 rad |

原登记的 0.05 步长给出相同的粗区间。看到这个结果后，我们用同一算法和原预算对三组的公共区间 (0.15, 0.20) 以 0.005 的归一化步长补充分析。已通过点对所有更小扰动都成立，已有见证在所有更大扰动下仍合法。“未决”指存在未判定盒，未用作证书或反例。分维盒和联合集合的最大已证幅值比统一盒大 **26.7%**。统一盒在 0.072 rad 已有正漂移点，而另外两组到 0.0855 rad 均通过，说明该差异包含真实的屏障条件差异。以各组实际满足该屏障条件的幅值上确界比较，提升至少 **18.75%**，无需假定未决点是否通过。联合集合相比分维盒的优势体现在上一表的转向偏差；本次余量扫描未分辨出两者的差异。[预设网格结果](../../../artical-F122/results/lane_contract_comparison_20261117_v1/verification.json) · [补充细网格结果](../../../artical-F122/results/lane_contract_comparison_20261117_v1/refinement.json)

统一盒的一个见证位于归一化状态 (0.444531, −0.283594) 和零曲率，取双分量正向盒边误差并额外施加 −0.072 rad 后，B 从 0.002021 增至 0.006770，直接违反一步不增。该转移本身没有驶出车道。分维和联合集合在 0.090 rad 的见证发生在同一状态，观测动作与名义动作相同，额外转角已足以让 B 从 19.996604 增至 20.001060；继续压缩视觉动作偏差也会面临这个与视觉无关的限制。

### 独立图像闭环与安全声明

100 条共用的新轨迹中，统一盒 93 条、分维盒 95 条、联合集合 97 条全程满足相应集合。统一盒与联合集合逐条配对，有 6 条只满足联合集合，2 条只满足统一盒。8 条不一致轨迹作双侧精确 McNemar 检验得到 p=0.289，样本不足以支持联合集合的总体覆盖率更高。三组共用实际驾驶轨迹，越界都是 0/100，80 步平均绝对横向偏差都是 0.03690 m。实测驾驶表现由冻结的图像策略决定。[独立留出统计](../../../artical-F122/results/lane_contract_comparison_20261117_v1/coverage.json)

本实验给出两层保证。

1. **误差受约束时的确定性安全。** 从登记初态出发，只要每一步的视觉误差满足选定集合，额外转向扰动不超过该行已证幅值，三个已验证曲率均可使用这份神经鲁棒屏障。起点 B≤0.214509；逐步不增使它保持在该值以下。若首次离开安全矩形，在当前动力学、限幅和步长下必落进已验证的危险外壳，而该处 B≥23.546546。两者不能同时成立。安全矩形定义为横向偏差绝对值不超过 0.85 m、航向偏差绝对值不超过 0.30 rad。证明范围是离散模型的采样时刻。验证使用 float64 连续区间传播及划分，未作有向舍入的机器证明。
2. **名义 80 步闭环的轨迹覆盖，以及审计接受与不安全的联合概率。** 对任意预先固定的一行，若新的完整轨迹与 199 条校准轨迹在冻结策略和登记模拟器分布下可交换，秩 190/200 给出至少 95% 的整轨迹边际覆盖。令 A 表示按这次新校准得到的集合审计通过。若 A 成立且新轨迹全程在集合内，第一层证明给出 80 步避险（名义额外扰动为零）。因此 P(A 且新轨迹不安全) ≤ 0.05。概率同时对随机校准样本和下一条轨迹取值。这里不承诺固定校准集、某个特定初态、变更后策略／渲染器或更长时域的 95% 条件覆盖。实际带额外转向扰动时，闭环访问分布可能改变；要给该分布同样的概率保证，仍需按该部署协议校准。三组各自的 95% 也不能直接解释成三个事件同时覆盖。

## 五、怎样复查

[冻结协议](../../../artical-F122/results/lane_contract_comparison_20261117_v1/protocol.json) 记录权重与训练外数据散列、固定光照和相机、轨迹种子、评分规则。协议中的 `date` 沿用 11 月 16 日基础采集器的版本日期，本轮实际采集于 11 月 17 日。新结果目录携带校准／留出轨迹、用于定标的旧轨迹以及冻结策略、投影和屏障的权重。[打包输入与结果](../../../artical-F122/results/lane_contract_comparison_20261117_v1) · [独立复核程序](../../../artical-F122/Aebs/lane_contract_comparison/check.py)

在项目的 `artical-F122` 目录中运行以下命令，第一条不需要 GPU 或 DINO 权重。它核对输入和结果散列，逐步重算闭环动力学、整轨迹覆盖和每个动作／屏障反例。第二条运行评分与动作区间逻辑的三个回归测试。

```bash
python -m Aebs.lane_contract_comparison.check results/lane_contract_comparison_20261117_v1
python -m unittest discover -s tests -p test_lane_contract_comparison.py
```

服务器保留了原始数据包、DINO 权重和旧版开发目录。重做图像采集时，新输出目录必须尚不存在。附加的转向偏差诊断使用独立登记文件，须在校准阈值生成前登记。以下命令在服务器的 `vt` 环境、`/root/work_based_on_spvc/artical-F122` 下运行；refine 为看到粗网格后做的补充分析。

```bash
out=results/lane_contract_reproduction
python -m Aebs.lane_contract_comparison.collect "$out" --device cuda:1 &
collect_pid=$!
while [ ! -s "$out/protocol.json" ] && kill -0 "$collect_pid" 2>/dev/null; do sleep 1; done
python -m Aebs.lane_contract_comparison.action_range "$out" --register
wait "$collect_pid"
python -m Aebs.lane_contract_comparison.audit "$out"
python -m Aebs.lane_contract_comparison.action_range "$out"
mkdir -p "$out/inputs"
cp -R results/lane_contract_comparison_20261117_v1/inputs/. "$out/inputs/"
python -m Aebs.lane_contract_comparison.refine "$out"
python -m Aebs.lane_contract_comparison.check "$out"
```
