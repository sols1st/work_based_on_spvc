# AEBS 同预算图像前端对比：从静态测距到闭环轨迹与鲁棒证书

2026-11-17，在服务器 `vt` 环境重新读取 CARLA 原图并运行，使用同一个已冻结的制动控制器和神经屏障。

**收益出现于小样本测距。** 学习前端只有 400 张总图像包时，在共同留出图像库上，真实图训练的 SPVC 灰度测距头换成 RGB DINO 后，单帧平均绝对误差从 1.224 m 降到 0.283 m，闭环轨迹误差半径从 4.502 m 降到 1.977 m。同样只给 DINO 看 32×32 灰度输入，仍得到 1.888 m 的轨迹半径。闭环停车结果与误差分开统计。共同库中灰度头的 100 条轨迹全部成功停车，RGB DINO 有 19 条提前停车，灰度 DINO 有 12 条不安全终止。10k 与 24k 预算下，测距对照换成 DINO 都没有得到更小的轨迹半径。[完整配对表](../../../artical-F122/results/aebs_matched_replay_20261117/paired_comparison.csv)

## 1. 两端比较的对象

| 名称 | 从图像到估计距离 | 控制和验证如何处理 |
|---|---|---|
| SPVC 灰度测距头（下称灰头） | 对 640×640 RGB 原图做 PIL 灰度转换与双三次缩放，得到 32×32 像素。沿用 SPVC 的 `SubNet(1024,256,64,1)`，在真实采集的图像上训练 100 轮，按开发集均方误差选权重 | 直接将实图测距结果送给共同控制器。这条对照没有调用 cGAN 生成器，也没有重现原论文预期漂移 SBC。比较对象准确写作“真实图训练的 SPVC 结构测距头” |
| RGB DINO | 同一张源图经缩放、标准化，送入冻结的预训练 DINOv2-S/14。取 384 维 CLS 特征，用小网络输出一个估计距离。400 和 10k 使用历史 250 轮预算实验权重，24k 使用历史完整 RGB 权重 | 使用相同的控制器、速度输入、停止规则、屏障和审计标准 |
| 400 灰度 DINO 消融 | 输入逐图验证与灰头的 32×32 灰度像素完全相同，重复成三通道，再缩放给 DINO，重新训练小网络 100 轮，按同一开发集误差选权重 | 控制图像信息量、下游轮数、开发与测试划分。仍保留预训练知识，网络结构、参数量和优化器学习率有差别 |

此处 VISION-SLS 式的**状态代理**为固定的线性距离读出，$C=[1,0]$。图像前端和代理都输出归一化标量，乘同一个 `3.18272066116333` 回到米。闭环拿到的是图像前端输出和实测车速。验证器拿到的是真实距离加一个有界误差。训练时可以看真实距离标签，在线控制不能直接看这个标签。该 AEBS 配置没有联合训练 $C$。同预算仅指本任务目标域图像数。DINO 的外部预训练、训练时长和部署成本另计。

## 2. 从源图到证书的步骤

1. **冻结图像划分和已训练部件。** 输入为同一采集中的 24,000 张静态 CARLA 图像及其距离、天气、前车颜色。400 包为 240/88/72 张训练/开发/测试。10k 为 6,000/2,000/2,000。24k 为 14,172/4,908/4,920。400、10k 在距离分箱内抽取，24k 沿用历史划分。复用每档灰头和 RGB DINO 已选权重。额外灰度 DINO 只用 400 包训练/开发，最佳为第 98 轮。共享控制器和屏障沿用已冻结的 AEBS 鲁棒综合版本，历史训练利用过 RGB 误差管与仿真状态，因此“400 张”描述前端目标域预算，不能用于声称整个后端也仅用 400 张完成开发。[预算划分](../../../artical-F122/Aebs/vision_sls/make_aebs_budget_protocol.py) · [灰度消融训练](../../../artical-F122/Aebs/experiments/matched_aebs_gray_dino.py)
2. **构建两种冻结回放库。** 严格库只使用各自总包中的测试图，可回答“本次总共只有这么多图时，能做出什么闭环”。共同库从 24k 测试图中剔除任何预算中前端训练或选择权重时用过的图，可回答“放在同一组地点和外观上，训练预算改变有什么效果”。所有 24,000 张源图重新生成 32×32 灰度像素并做 SHA-256，排除与禁用图片灰度像素完全相同的测试项。共同库余 3,229 张。严格库余 72、2,000、4,920 张。共同库对小预算是额外评测图像，计数时单列。历史测试图可能已用于项目过往报告，此次新采样的是随机轨迹。[建库代码](../../../artical-F122/Aebs/experiments/matched_aebs_library.py) · [源图、权重和前端输出指纹](../../../artical-F122/results/aebs_matched_replay_20261117/library/manifest.json)
3. **把相机输入接进闭环。** 一条轨迹先独立均匀抽 $d_0\in[15,16]$ m、$v_0\in[2.5,3]$ m/s，再从 4 种天气 × 3 种车色中均匀抽一个，整条轨迹保持此外观。每一步在该外观库里找采集距离最接近当前 $d_t$ 的图片，取该图的模型输出 $\hat d_t$，控制器据 $(\hat d_t,v_t)$ 输出制动，再以 0.05 s 更新距离与速度。各方法共享初始状态和外观，控制器输入造成的后续状态差异保留。进入 5–6 m、速度 ≤0.5 m/s 为目标停车。距离 ≤6 m 而速度 >0.5 m/s 为不安全终止，提前停、出域和 400 步超时分别记数。[回放与停车动力学](../../../artical-F122/Aebs/vision_sls/rollout.py) · [停止规则](../../../artical-F122/Aebs/system/outcomes.py)
4. **重新计算轨迹级 CP。** 用新的校准种子抽 199 个初态和外观，所有方法共享这组情形，各自演化 199 条闭环轨迹。对每条轨迹取整段运行最大绝对误差 $S=\max_{t<\tau}|\hat d_t-d_t|$，包含提前停车和不安全终止前的所有控制步。分数比较**当前物理距离**，所以“只能查到附近另一距离的图片”造成的误差已经算入。把 199 个分数排序，取第 $\lceil(199+1)0.95\rceil=190$ 小为 $q$。固定全部阈值后，再用另一种子生成 100 个配对留出情形，记录覆盖、成功、危险和每条轨迹的分数。每次实验一套固定模型。配对样本不是 100 次独立训练。[采样、评分及证书检查](../../../artical-F122/Aebs/experiments/matched_aebs_replay.py) · [所有 4,186 条运行记录](../../../artical-F122/results/aebs_matched_replay_20261117/episodes.csv)
5. **检查共同神经屏障。** 此屏障要求初集上 $B\le1$，危险集上 $B\ge20$，并对活跃域 $d\in(6,16]$ m、$v\in(10^{-6},3]$ m/s 内 $B(x)<20$ 的状态，以及所有 $|\hat d-d|\le q$ 的允许输入，满足 $B(x^+)\le B(x)$。过去固定 0.45 m 管的数值区间审计检查 782,400 个单元，初集最大 0、危险集最小 25.0394。对本次模型半径 ≤0.45 m，包络是已审计管的子集，核对控制器和屏障哈希、输入单位后可直接复用这个全称条件。对更大的管，显式搜索一个违反不增条件的状态和观测，找不到则运行同一数值区间验证器。表中每个“反例”都有具体的允许误差及正漂移记录。[父证书](../../../artical-F122/results/aebs_robust_synthesis_20261117_release/development_certificate.json) · [一条实际漂移反例](../../../artical-F122/results/aebs_matched_replay_20261117/paired/common__dino_400/audit.json)

### 400 张时，像素完全相同还能看到收益吗？

两种网络都只接收相同的灰度缩略图。共同库上，单帧 MAE 从 1.224 m 降到 0.326 m，轨迹 $q$ 从 4.5020 m 降到 1.8880 m（−58.1%）。100 对轨迹的最大误差全部下降，平均下降 2.696 m，配对 bootstrap 95% 区间为 [2.619, 2.771] m。但成功 100→88，危险 0→12，其中 **2 条发生危险时甚至全程都在新误差管内**。缩小后的管仍容许对该控制器不利的观测，验证器也确实找到了屏障正漂移反例。

严格 400 库中，同像素消融得到 $q$ 4.5018→4.0297 m，成功 50→67，危险 8→9，覆盖 96→98，两边都有屏障反例。此组可作为少目标域图像情况下预训练视觉表征的观察证据。一种子及预训练、网络结构、学习率差异限制了对单一因素的归因。[同像素汇总](../../../artical-F122/results/aebs_matched_replay_20261117/gray_paired/summary.json) · [相同测试图片上的逐图误差统计](../../../artical-F122/results/aebs_matched_replay_20261117/frame_errors.csv)

### 为什么 24k 的严格回放有时比 10k 差？

每个外观单独找最近的图。严格 400 的 72 张测试图分给 12 个外观，每组仅 4–8 张。在 100 个留出情形中，最大查图错位达到 4.860 m。严格 10k 测试图的距离通常较密，最大内部距离间隙是 0.536 m，两种控制轨迹的最大查图错位约 0.267 m。24k 的历史划分却让所有外观在约 6.4965 到 8.2533 m 之间出现 1.757 m 空档。例如真实距离在这段中点时，即便相机能完美读出库中图片的标注距离，也能相差约 0.878 m。共同库继承了这类空档。三个总包的测试库不嵌套，单看三个严格 $q$ 不能断言多训练图像一定让闭环变差。即使固定共同库，10k 和 24k 的灰头也确实测得更准。[分外观距离间隙](../../../artical-F122/results/aebs_matched_replay_20261117/library_geometry.csv) · [原始双协议数值](../../../artical-F122/results/aebs_matched_replay_20261117/paired/summary.json)

## 4. 最终安全保证与论文可写的范围

- **严格 10k 的两个前端**各自有 199 条校准数据得到的轨迹 CP 加上同一鲁棒屏障。若未来轨迹由相同冻结库、相同独立初始状态与外观分布、相同最近邻和制动规则产生，对一条新的可交换轨迹，轨迹级 CP 给予至少 95% 的**边际**整段覆盖。误差全程在管内时，神经屏障的数值区间核验支持停止系统避开规定危险集，记 A 为本次校准得到的误差管经审计接受，则在同一回放规律下，P(A 且新轨迹不安全) ≤ 0.05。对某次固定的已通过校准询问未来条件风险，需要独立估计或额外假设。此处依赖数值审计的浮点/数学网络模型，区间运算没有向外舍入。保证不包含“停车必定进入目标区间”。[10k 灰头审计](../../../artical-F122/results/aebs_matched_replay_20261117/paired/strict_10000__gray_10000/audit.json) · [10k DINO 审计](../../../artical-F122/results/aebs_matched_replay_20261117/paired/strict_10000__dino_10000/audit.json)
- **其他组合**仍然得到相同冻结回放规律下的边际误差覆盖，但共同屏障在各自误差管中有违反不增的允许扰动。举例，共同库 400 RGB DINO 中，在 $d=6.00001\,\mathrm m,v=0.2269\,\mathrm{m/s}$ 给出 +1.97669 m 允许观测误差，网络屏障增加 0.39143。此反例否定的是所选屏障在整个不确定集合上的证明条件。这个构造点是否由该图像库实际产生是另一件事。[漂移状态与误差](../../../artical-F122/results/aebs_matched_replay_20261117/paired/common__dino_400/audit.json)
- **统计适用域。** 同一图片可用于多条轨迹，因为这里的随机单位是独立抽取的初态和外观，图像查表是确定性环境的一部分。95% 是对校准样本和一条新轨迹的边际结论。固定一次已得到的阈值，100 条留出的经验覆盖可以只有 89/100。若事后从多种前端中挑选表现最好的一种，需另用独立轨迹做最终校准。逐天气、新渲染图像、真实车辆和新地图都超出了这里的边际结论。要提出新场景安全主张，需要新的采集与隔离的轨迹级校准和检验。

这组实验支持“小样本预算下，预训练视觉表征降低目标域测距误差，且可以在固定后端上直接检验这种改善能否转化为安全”。同场景下已经得到的 10k 证书是在两种测距头上共同成立。采用各自原生视觉链、控制器与证书的系统对比应单列，不宜把灰头消融表标为“原 SPVC 端到端基线”。

## 5. 重算入口

在服务器 `/root/work_based_on_spvc/artical-F122` 的 `vt` Python 下可重算。前三个入口需要服务器的图像、历史权重与冻结后端。完整重跑时使用一个新的输出目录，本次输出保存在 `results/aebs_matched_replay_20261117`。

```bash
root=results/aebs_matched_replay_repeat
python -m Aebs.experiments.matched_aebs_library "$root/library"
python -m Aebs.experiments.matched_aebs_replay "$root/library" "$root/paired"
python -m Aebs.experiments.matched_aebs_gray_dino "$root/library" "$root/gray400"
python -m Aebs.experiments.matched_aebs_replay "$root/library" "$root/gray_paired" --gray "$root/gray400"
python -m Aebs.experiments.summarize_matched_aebs "$root"
```

最后一个入口只需要 NumPy 和保存的实验结果。它核对每个阈值、每一组覆盖和停止计数、输入初态的配对、合同/审计及原始运行记录的文件指纹，并从记录重建四张 CSV。[重算与完整性检查](../../../artical-F122/Aebs/experiments/summarize_matched_aebs.py)
