# 收益证明总览：当前方案相对原 SPVC 到底好在哪里

更新：2026-11-11。详细实验、计划和结果包见文末链接；本页只保留结论、口径和边界。

## 1. 三类收益，不能混着说

| 层次 | 问题 | 当前回答 |
|---|---|---|
| **部署系统收益** | 新 DINO 系统相对已部署的原 cGAN 系统，误差/覆盖是否更好？ | 24k DINO q=0.4184 m、覆盖 99/100；原原生 cGAN q=1.9156 m、覆盖 92/100；行为都成功 |
| **同数据预算收益** | 同样 400/10k/24k 数据，谁更好？ | **交叉，无单向赢家**：400 DINO 好；10k/24k 真实图 cGAN 头 q 更小；24k cGAN 覆盖更低 |
| **组件收益（联合 C）** | 联合学习 C 是否独立带来提升？ | 5 对种子无稳定 q/覆盖收益，**不能作为独立贡献** |

## 2. 原 SPVC cGAN vs 新 DINO

| 口径 | cGAN | DINO |
|---|---:|---:|
| 原生生成图轨迹 q | 1.9156 m | — |
| 真实图 DINO 轨迹 q | — | **0.4184 m** |
| 留出覆盖 | 92/100 | **99/100** |
| 任务行为 | 100/100 | 4,800/4,800 |

这是**部署系统/具体检查点**对照：数据量、输入类型、控制器和预训练都不同，不能写成“DINO 架构全面胜出”。

## 3. 同数据预算 400 / 10k / 24k

cGAN 的 state_net 在真实 32×32 灰度图上训练；DINO 用 RGB；同一档内共用 test。

|  总包 |      cGAN realhead MAE / q / 覆盖 |           DINO MAE / q / 覆盖 | 结论                    |
| --: | ------------------------------: | --------------------------: | --------------------- |
| 400 |           0.694 / 4.169 / 71/72 |   **0.298 / 0.865 / 69/72** | DINO 胜                |
| 10k | **0.0085 / 0.0209 / 1894/2000** | 0.0205 / 0.0557 / 1893/2000 | cGAN q/MAE 胜          |
| 24k | **0.0247 / 0.0307 / 4382/4920** | 0.0874 / 0.2307 / 4592/4920 | cGAN q/MAE 胜；DINO 覆盖高 |

- 三档 test 不同，**不能画 scaling 曲线**；
- 24k cGAN q 更小但覆盖 89.1%，DINO 93.3%；q 和覆盖要一起报；
- 不能写“DINO 全面更好”，也不能写“cGAN 全面更好”。

## 4. 联合 C

5 对训练种子：

| 指标 | 固定 C | 联合 C |
|---|---:|---:|
| q 均值 | 0.085263 | 0.085699 |
| 覆盖均值 | 95.6% | 95.0% |
| 鲁棒屏障通过 | 5/5 | 5/5 |
| 联合 q 更小的对数 | — | 3/5 |

结论：联合 C 可行，但**没有稳定独立收益**。

## 5. 可认证半径

同一 lane actor/鲁棒屏障，固定 C/联合 C 共用扫描：

- 0.04–0.12 通过；0.16 失败；
- **r_cert=0.12**；
- 常量 q=0.090093、联合 q=0.084338，均有约 **1.42×** 半径余量；
- 0.14/0.15 未测，不能说 0.12 是理论上限。

## 6. 现在能写 / 不能写

**能写：**

- 24k 真实图 DINO 部署系统相对原 400 图 cGAN：轨迹 q 1.9156→0.4184 m，留出覆盖 92→99；
- 原 400 图预算下，DINO 的 MAE/q 优于真实图 cGAN 头；
- 5 对种子显示联合 C 无稳定收益；
- 共同半径 r_cert=0.12。

**不能写：**

- DINO 架构在所有数据预算下全面优于 cGAN；
- 联合 C 提供独立可观测性/安全收益；
- 原 cGAN 已被证明不安全；
- 新系统在实车/新相机上安全；
- 5.221 m 是原生 cGAN 的 q。
