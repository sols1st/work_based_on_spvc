# SBC、CBC、CBF 与 CP：概念、区别及当前实验的安全保证

日期：2026-11-16。用途：解释这些概念的含义、相互关系，以及为什么当前系统可以采用“轨迹 CP＋鲁棒神经屏障证书”的论证方式。

本文是概念与现有实现的说明，不启动训练、不改变代码，也不为任何实验新增通过结论。文中专门标注的例子是教学例子，不能当成实验结果。

先记住三句话：

1. **SBC 的“随机”，主要描述系统及其证明条件；训练完成的屏障函数 B 通常是固定函数。**
2. **CP 处理误差覆盖的概率，屏障证书处理允许误差下的系统安全。**
3. **当前车道程序检查所有允许后继的 B 不增，因此它在数学结构上采用了鲁棒屏障条件；整体视觉安全仍受 CP 的概率前提限制。**

**本项目的用语（2026-11-17）**　原 SPVC 的随机屏障证书（SBC）按扰动分布约束后继屏障值的期望，定理 2.2 在适用状态还要求正的下降裕度。本文将 AEBS、车道保持及五维弯道遇障制动中逐个约束允许后继的后端称为**确定性鲁棒屏障证书**。两类证书都可以使用训练后参数固定的神经函数 B。轨迹级 CP 给出视觉误差全程落在校准集合内的边际覆盖保证。[SPVC 原论文，定理 2.2](../references/720_file_Paper.pdf)

## 1. 从车道实验理解所有对象

### 1.1 真实状态、观察与控制动作

真实物理状态记作 z=(e,θ)：e 是车辆相对车道中心的横向偏差，单位米；θ 是车头方向相对道路方向的偏差，单位弧度。

当前代码的归一化状态为：

\[
x=(e/0.85,\theta/0.30).
\]

例如 e=0.17 m、θ=0.03 rad 时，x=(0.2,0.1)。归一化只改变数字和单位，不能增加观察信息。

实际视觉反馈有以下过程：

\[
I\longrightarrow\operatorname{DINO}(I)
\longrightarrow p_\vartheta(\operatorname{DINO}(I))=y
\longrightarrow\pi_y(y,\kappa)=u.
\]

I 是当前图像，pϑ 是训练好的低维视觉投影，y 是低维观察，κ 是本实验假设已知的道路曲率，u 是控制动作。控制器部署时不能读取真实 e、θ 来代替视觉。

### 1.2 状态代理是什么

状态代理用真实状态计算名义低维观察：

\[
h_\phi(x)=Cx\quad\text{或}\quad h_\phi(x)=\text{神经网络}(x).
\]

真实视觉输出一般不精确等于代理，差异为：

\[
\varepsilon=y-h_\phi(x).
\]

因此真实闭环写成：

\[
x_{t+1}=f\bigl(x_t,\pi_y(h_\phi(x_t)+\varepsilon_t,\kappa_t)\bigr).
\]

代理使验证器能够从状态推算一个名义观察；误差集合使验证器覆盖代理与实际视觉的差异。代理不是运行时的真实相机，也不意味着观察误差已经消失。

### 1.3 “安全”究竟是什么

车道任务的主要限制是横向偏差和航向误差不超过规定范围。抽象地，用 X₀ 表示允许初始状态集合，用 Xᵤ 表示危险集合，目标是轨迹从 X₀ 出发，在规定时域内不进入 Xᵤ。

安全、稳定和完成任务不同：安全是没有进入危险区域；稳定关心状态是否靠近某个平衡点或目标；任务完成还可能要求按时到达、保持速度或成功停车。一个停止不动的控制器可能满足某项安全要求，却没有完成任务。

## 2. 为什么需要屏障函数 B

可以把 B(x) 理解为一个用于证明的标量“刻度”。初始状态的刻度很低，危险状态的刻度很高，再要求沿允许轨迹刻度不增加，就能排除进入危险集。

常用的充分条件之一是：

\[
B(x)\le a\quad(x\in X_0),\qquad
B(x)\ge b\quad(x\in X_u),\qquad a<b,
\]

并对所有需要检查的后继要求：

\[
B(x_{t+1})\le B(x_t).
\]

当前部分实验采用 a=1、b=20。假设从初始状态出发，B(x₀)=0.6，则后续始终有 B(xₜ)≤0.6。若某一步进入危险集，又要求 B(xₜ)≥20，同一个数不可能同时≤0.6 且≥20，因此无法进入危险集。

这就是“初始低、危险高、沿轨迹不增”的矛盾证明。B 不需要真的等于碰撞概率，也不需要等于车辆到边界的几何距离；它只需满足相应证明条件。

证明域还要包含可能第一次越界的后继。若只检查下一状态仍在安全区内的情况，就漏掉了最需要排除的那一步。若任务到达目标后停止，还需要明确系统随后是否停止、进入安全吸收状态，或交给另一套已验证控制器。

传统屏障方法同时包含最坏情况和随机系统两条路线，具体条件随系统类型变化。[Prajna、Jadbabaie 与 Pappas 的屏障证书论文](https://web.mit.edu/~jadbabai/www/papers/TAC05-Barrier.pdf)

## 3. BC、SBC、CBC、CBF、NCBF 分别是什么

缩写不是统一的分类树，不同论文可能采用不同定义。阅读时要看系统、量词和不等式，不能只看名称。

| 名称 | 常见全称 | 主要强调什么 | 不应自动推断什么 |
|---|---|---|---|
| BC | Barrier Certificate | 用一个函数证明系统安全 | 不限定是线性、神经、随机还是确定性 |
| SBC | Stochastic Barrier Certificate | 针对随机演化建立概率安全界 | 不表示 B 的输出本身必须随机 |
| CBC | Control Barrier Certificate | 将控制选择纳入证书条件或综合过程 | 不表示系统一定没有随机性 |
| CBF | Control Barrier Function | 通过屏障条件刻画保持安全的可用控制动作 | 不表示已经实现在线安全滤波器 |
| NCBF | Neural Control Barrier Function | 用神经网络表示 CBF | 神经网络训练完成不等于条件已被验证 |
| 鲁棒屏障证书 | Robust Barrier Certificate | 对集合内全部允许扰动证明安全 | 不保证实际误差永远在集合内 |

CBC 可以用于随机系统，已有文献明确用 CBC 同时综合控制器与概率界。因此“SBC 是随机，CBC 就是确定性”的理解不准确。[Formal Synthesis of Stochastic Systems via Control Barrier Certificates](https://arxiv.org/abs/1905.04585)

## 4. SBC 的“随机”到底指什么

### 4.1 固定函数可以作用于随机状态

例如 B(x)=x² 是固定函数。如果 x 是一个随机变量，B(x) 的值会随 x 的随机取值变化，但函数规则并没有改变。

神经屏障也是一样：训练中的初始化和采样可以是随机的，训练后权重通常冻结。同一状态输入，在数学模型中得到同一个 B 值。把网络叫作 SBC，是因为它被用来满足随机系统的屏障条件。

### 4.2 典型随机屏障条件：期望不增

对随机系统 \(x_{t+1}=F(x_t,w_t)\)，一种基础形式要求：

\[
\mathbb E[B(x_{t+1})\mid\mathcal F_t]\le B(x_t).
\]

ℱₜ 表示到当前为止的状态、扰动等信息。在适当的马尔可夫和独立性条件下，可以简写为给定当前状态的条件期望。

这个条件允许某些实际后继的 B 增大，只要求按照真实条件分布加权后的平均值不增。加上非负性、可积性、初始和危险阈值等条件，可以利用非负超鞅的最大不等式界定进入危险集的概率。

例如，对符合全部条件的停止过程，若 B(x₀)≤a、危险处 B≥b，则常见基础形式给出危险到达概率上界 a/b。若 a=1、b=20，则为 0.05。带正漂移、有限时域或不同停止规则的定理会得到不同界，不能一律套 a/b。

这里的概率来自随机系统的屏障定理。它与“CP 覆盖 95%”不是同一个来源，也不应未经推导就相乘。

### 4.3 一个教学例子：期望不增不等于每次不增

当前 B=1，下一步有两种可能：90% 概率 B=0.5，10% 概率 B=5。其期望为：

\[
0.9\times0.5+0.1\times5=0.95\le1.
\]

因此这一状态的一步期望不增条件成立。但仍有 10% 的后继使 B 从 1 上升到 5。这个算例只解释“期望”的含义，不证明一个完整系统已经满足 SBC，也不能直接读出其碰撞概率。

## 5. 鲁棒屏障条件为什么更强

### 5.1 不对扰动平均，而是检查所有允许扰动

给定一个误差集合 E(x)，要求：

\[
B\bigl(f(x,\pi_y(h_\phi(x)+\varepsilon))\bigr)\le B(x),
\qquad\forall\varepsilon\in E(x).
\]

其含义是：集合内的任意误差，无论如何在时间上变化，只要每一步满足集合约束，都不能使 B 增加。不需要知道集合内各误差分别有多大概率。

在上一个教学例子中，如果允许集合同时包含产生 B=0.5 和 B=5 的扰动，那么鲁棒不增条件失败，因为存在一个允许后继使 B 增加。

### 5.2 鲁棒条件与期望条件的关系

如果真实条件分布的全部支持都在 E(x) 内，且集合内每个后继都满足不增，那么取期望后也不增。

关键是“全部支持都在集合内”。CP 给出高概率覆盖，并没有保证集合外概率为零。因此不能仅根据集合内最坏值，直接上界原始未截断分布的完整期望。

可以构造一个说明性算例：当前 B=1，95% 的误差使下一步 B=0.5，另外 5% 的集合外误差使下一步 B=1000。集合内都不增，但完整期望为：

\[
0.95\times0.5+0.05\times1000=50.475>1.
\]

所以“CP 覆盖 95%＋集合内不增”不能直接证明原系统的 SBC 期望条件。正确做法是保留覆盖事件，再证明这个事件蕴含安全。

### 5.3 强条件的代价

最坏情况条件可能更保守。常量误差盒还可能允许实际视觉不会产生的误差组合。例如远离危险边界时才出现的大误差，被全局盒允许到了危险边界附近，会使证书更难成立。

这并不表示 CP 或验证器做错了，而是误差抽象丢失了状态与误差之间的关系。状态相关集合、方向相关集合等设计可能减少保守性，但仍需独立校准和对应验证。

## 6. CBC 为什么不是简单把 SBC 改一个名字

### 6.1 固定控制器验证与控制器综合

固定策略 π 后，验证条件是：

\[
\forall x,\ \forall\varepsilon\in E(x):
B(f(x,\pi_y(h_\phi(x)+\varepsilon)))\le B(x).
\]

这里检查给定控制器是否安全。

在完全状态反馈的鲁棒控制综合中，一种相应的充分条件是：

\[
\forall x,\ \exists u\in U,\ \forall w\in W(x):
B(f(x,u,w))\le B(x).
\]

这里不仅寻找 B，还需要为每个状态找到一个对全部允许扰动都有效的动作，并实际实现相应控制律。存在控制器还可能需要额外的可选择性、连续性等条件；论文应说明具体设定。

CBC 常强调后一种控制存在性或综合任务，但具体定义应以所引用论文为准，不能把上面这一个式子当成所有 CBC 文献的唯一标准。

### 6.2 量词顺序为什么重要

“存在同一个动作，能应对所有扰动”是 \(\exists u\,\forall w\)。

“每个扰动都能找到一个动作”是 \(\forall w\,\exists u\)。

后者可能要求控制器提前知道尚未观测到的扰动，因而不一定可实现。不能在证明中悄悄交换它们。

### 6.3 视觉控制还多了一层信息限制

两个真实状态可能产生同一个观察 y。如果状态一要求向左、状态二要求向右，而控制器没有额外历史信息区分它们，就不能仅凭 y 同时选择两个动作。

输出反馈综合应寻找一个可执行的映射 πᵧ(y)，对所有与该观察一致的真实状态都满足相应条件。抽象地说，需要同一个 u(y) 应对兼容状态集合中的全部情况，而不是仅证明每个真实 x 各自存在动作。

当前实验通过直接验证实际使用的观察到动作策略，避免把“真实状态可得”的策略误当作视觉控制器。

因此可以研究鲁棒 CBC，但不能因为已经用了 CP，就认为控制器综合部分自动完成了。

## 7. CBF、NCBF 和在线安全滤波器是什么关系

CBF 经常使用带符号的安全函数 b(x)，例如安全区域写作：

\[
\mathcal C=\{x:b(x)\ge0\}.
\]

在连续时间系统 \(\dot x=f(x)+g(x)u\) 中，一个典型条件是：

\[
\nabla b(x)^\top(f(x)+g(x)u)\ge-\alpha_b(b(x)).
\]

α_b 是满足相应性质的增益函数，不是 CP 的失败概率 α。结合适当的正则性、可行性和控制实现条件，该类不等式用于保证安全集合的前向不变性，即从集合内部出发后一直留在集合里。[CBF 理论综述](https://arxiv.org/abs/1903.11199)

离散时间也有 CBF 条件，例如 \(b(x_{t+1})\ge(1-\gamma)b(x_t)\)，其中 0<γ≤1。它允许一定程度的安全余量减少，但仍保持 b 非负。不能把连续时间导数条件未经分析就用于离散采样系统。

若用神经网络表示 b，则通常称为 NCBF。若每一步求一个满足屏障约束、又尽量接近原动作的 u，就形成屏障安全滤波器，常采用优化问题实现；是否为凸二次规划取决于系统和约束结构。

当前保留的神经非负 B 与已训练策略，不等于运行时安装了这样的滤波器。文件中出现 CBF 名称或借用了求界函数，也不意味着系统已经执行在线动作修正。

符号习惯也不构成本质区别。例如可以对非负 B 定义 b=a−B；B≤a 对应 b≥0。但具体漂移条件、证明域和可用动作仍需核对，不能只改符号就继承另一篇论文的定理。

## 8. CP 到底输出了什么

CP 是 Conformal Prediction，通常译作保形预测。这里用它根据冻结模型的校准误差确定一个集合阈值，讨论新样本被覆盖的概率。

基本输入是冻结的模型、评分规则、校准样本及目标错误率 α。输出是分位数 q，以及由评分规则确定的预测／误差集合。CP 不负责证明动力学安全，也不负责选择制动或转向动作。

它通常不输出完整的条件噪声分布，不能把校准盒理解为盒内均匀分布，更不能把盒外概率直接设成零。[CP 基础综述](https://arxiv.org/abs/2107.07511)

### 8.1 帧级和轨迹级是不同的样本单位

帧级分数可以取 \(s_i=\|\hat x_i-x_i\|_\infty\)。帧级覆盖描述一张新图像的误差是否被覆盖。

轨迹级分数取：

\[
s_j=\max_{0\le t<T}\|\hat x_{j,t}-x_{j,t}\|_\infty.
\]

一条轨迹只有一个分数，覆盖它意味着所有注册时刻、所有被评分坐标同时满足误差界。轨迹内各帧可以高度相关；校准要求作用于完整轨迹样本的联合分布。

若假设每帧独立且每帧覆盖率恰为 95%，80 帧全部覆盖的概率仅为 \(0.95^{80}\approx1.65\%\)。这是解释两种事件差别的假设算例；真实闭环帧通常不独立，不能据此计算当前实验覆盖率。

### 8.2 校准分位数怎么计算

对 n 个校准轨迹分数排序，取：

\[
k=\lceil(n+1)(1-\alpha)\rceil,\qquad q=s_{(k)}.
\]

当 k>n 时采用无穷大阈值，而不能强行取有限最大值。当前 n=199、α=0.05 时 k=190。[项目分位数实现](../../artical-F122/Aebs/lane_keeping/cp.py)

### 8.3 边际覆盖是什么意思

在相应可交换性等假设下，保证是：

\[
\Pr(s_{\rm new}\le q(D_{\rm cal}))\ge1-\alpha.
\]

概率包含校准集 D_cal 和新轨迹的随机性。它不是对每一个初始状态、每一个天气都分别成立的相同条件覆盖率，也不是给定某一份具体校准集后，真实覆盖率必然恰好至少 95%。

交换性表示样本联合分布对排列不变；独立同分布是常用的充分条件。分布无关不表示没有采样前提，更不表示任意环境变化以后保证仍成立。

## 9. CP 与鲁棒屏障如何连接

定义全程误差覆盖事件：

\[
E=\{\forall t<T:\varepsilon_t\in\mathcal E(x_t)\}.
\]

再定义 S 为“规定时域内轨迹安全”。如果屏障验证完整建立了集合内安全，则：

\[
E\Longrightarrow S.
\]

其含义是：只要实际误差全程满足集合前提，这条轨迹就安全。它并不要求误差在集合内独立、均匀或服从某个已知分布。

如果在同一统计流程下证书成立，且轨迹 CP 给出 \(\Pr(E)\ge1-\alpha\)，则由 \(S^c\subseteq E^c\) 得到相应的边际安全界。这里没有第二次乘 95%，因为集合内安全层使用的是确定性的逻辑蕴含。

统计覆盖与模型控制保证的组合需要同时核对各自前提，不能仅根据一个分位数就得出系统级安全结论。[CP 在形式化验证与控制中的综述](https://arxiv.org/abs/2409.00536)

### 9.1 为什么发布选择必须单独说明

令 A 为“这次校准后的 q 使证书通过并被发布”。不论其他校准结果如何，只要对被接受情况有 \(A\cap E\Rightarrow S\)，则：

\[
\Pr(A\cap S^c)\le\Pr(E^c)\le\alpha.
\]

但这不能直接写成 \(\Pr(S^c\mid A)\le\alpha\)。形式上只能进一步得到 \(\Pr(S^c\mid A)\le\min(1,\alpha/\Pr(A))\)，且通常并不知道足够好的发布概率下界。

例如在所有重复运行中，恰好只发布覆盖较差的少数情况，整体“发布且失败”概率虽小，被发布子集的失败比例却可能很大。这说明边际概率与经过筛选后的条件概率不同。

模型反复调参、校准种子反复更换直到通过，也需要相应的选择校正或新的独立评估。前面关于 E⇒S 的推导不能自动处理这些额外选择。

### 9.2 想针对一个固定发布系统进一步审计怎么办

可以在系统、集合和阈值完全冻结以后，另采独立同分布轨迹，用二项统计给全程覆盖率或失败率建立置信界。覆盖目标与统计置信水平是两个不同数字，例如“以 99% 置信度确认覆盖率至少某个下界”。

这是一项额外的统计审计，不是普通 CP 边际保证的另一种写法。样本数、置信度及停止规则应预先确定；同一模型的多帧不能当成独立轨迹来扩大样本量。

## 10. 当前车道代码实际在检查什么

当前 [verify_learned.py](../../artical-F122/Aebs/lane_keeping/verify_learned.py) 把连续状态区域和允许误差集合划分成小盒，并对每一盒计算 B 与后继 B 的数值上下界。

核心思想是证明：

\[
\overline B_{\rm next}\le\underline B_{\rm current}.
\]

因为任意盒内实际点都有 \(B(x^+)\le\overline B_{\rm next}\)，且 \(\underline B_{\rm current}\le B(x)\)，上述比较足以得到 B(x⁺)≤B(x)。程序另有非负 B 的零平台处理：后继上界为零时，同样不会超过当前 B。

这属于对全部允许后继检查的鲁棒充分条件，不是在盒内抽样后取经验期望。即使文件和模型类仍使用 SBC 名称，也应按实际不等式解释证明。

初始 B≤1、危险 B≥20 以及相应活跃区域的后继不增必须共同成立。当前代码跳过 B 已经高于危险阈值的部分，是为了验证从低 B 初始状态出发所需的活跃区域；跳过依据本身需要有正确区间下界，不能据经验猜测某个区域不可达。

该条件证明了误差前提下的排危，不自动证明车辆跟踪精度、目标到达时间或任务成功率。

### 10.1 为什么“1 和 20”不自动等于 95% 概率

在满足某个随机屏障定理时，1/20 可能进入危险概率界。但在当前逐后继不增的证明里，1 和 20 首先只是把初始与危险分开的阈值。

若能对每个允许后继保证不增，危险值达到 20 与初始值不超过 1 已直接矛盾；并不是还剩下“集合内 5% 的危险概率”。此时视觉闭环的概率损失主要来自实际误差可能超出 CP 集合，而非自动再加一个 1/20。

同一组神经网络和阈值可以被不同证明方式使用，最终概率必须由实际采用的定理推导。

## 11. 线性和非线性代理下，误差集合如何对应

### 11.1 线性可逆代理

若 h(x)=Cx，控制接口为 \(\pi_y(y)=\pi_0(C^{-1}y)\)，定义解码误差：

\[
\delta=C^{-1}y-x.
\]

CP 校准 \(\max_t\|\delta_t\|_\infty\)，对应原始低维误差集合：

\[
\mathcal E_y=\{C\delta:\|\delta\|_\infty\le q\}.
\]

它一般是平行四边形。不能把原始 y 的每一维直接限制在 ±q，然后声称与解码盒完全相同。

### 11.2 可逆神经代理

若 hφ 可显式求逆，控制接口为 \(\pi_y(y)=\pi_0(h_\phi^{-1}(y))\)，定义：

\[
\delta=h_\phi^{-1}(y)-x,\qquad
\mathcal E_y(x)=\{h_\phi(x+\delta)-h_\phi(x):\|\delta\|_\infty\le q\}.
\]

对任意允许误差，都有：

\[
\pi_y(h_\phi(x)+\varepsilon)=\pi_0(x+\delta).
\]

这使语义状态误差盒验证器可以通过明确的坐标恒等式用于新系统。代理的非线性没有消失，而是同时出现在 h、其逆和实际误差集合中。

此等价关系要求模型与集合定义匹配。普通非可逆 MLP、近似逆网络或任意固定 latent 盒，不自动满足这一恒等式。实现中的舍入误差也需要按实际验证精度解释。

有关现有车道非线性版本的训练和实验记录，见 [完整实验文档](../experiments/车道保持/车道非线性神经代理_联合训练与完整验证_20261115.md)。这里不把其他版本的验证结果移用到当前任意新模型。

## 12. “现在有 CP，能否不用 SBC、改用 CBC”的准确回答

如果指的是“概率来源是否可以主要由 CP 提供，后端改用集合内确定性的鲁棒屏障证明”，答案是可以。这是一种合理的理论组织方式，当前车道已经采用了这一类强漂移检查。

如果指的是“用了 CP，随机性就全部消失，从而不用再考虑概率或不用验证控制器”，答案是否定的。CP 集合仍可能漏覆盖；还可能存在动力学噪声、执行器误差或部署分布变化，它们需要被相应模型和假设处理。

如果指的是“原期望式 SBC 可以不改变条件直接改称 CBC”，也不成立。期望条件、鲁棒条件、控制器存在性条件的含义不同，需要逐项核对。

| 拟采用的做法 | 是否合理 | 要补齐什么 |
|---|---|---|
| 轨迹 CP＋固定策略的鲁棒神经屏障验证 | 合理 | 集合正确、全域检查、概率连接与发布选择 |
| 轨迹 CP＋鲁棒 CBC 综合控制器 | 合理 | 可执行控制律、输出反馈信息限制、全扰动条件 |
| CP 后直接假定误差永远不出集合 | 不成立 | CP 本身不提供硬支持集保证 |
| 保留期望条件、只把文件名改成 CBC | 不能建立新结论 | 必须明确证明采用的数学条件 |
| 把训练好的神经 B 继续作为新证明的候选 | 合理 | 在新条件和新集合下重新验证 |

若希望保留当前神经屏障网络作为最终表示，并不妨碍采用鲁棒理论；“神经表示”和“随机／鲁棒证明方式”是两条独立维度。

## 13. 哪些情况下仍然值得采用随机屏障路线

如果扰动没有实用的有限硬界，但分布模型可信，可以考虑期望式随机屏障；如果最坏情况集合过度保守，而实际极端扰动很罕见，利用分布信息也可能帮助获得更实用的概率结论。

代价是需要正确的条件分布或可信的期望上界。仅有一组误差样本或一个 CP 分位数，不足以自动给出对所有状态成立的期望条件。无界尾部尤其需要处理，因为小概率也可能对期望贡献很大。

混合方法也可能存在，例如集合内鲁棒、集合外另界定代价或风险，再加动力学随机屏障。具体概率损失应从事件分解或适用定理推导；不能默认各层独立，也不能把所有 95% 随意相乘。

## 14. CP-NCBF 与当前框架的关系

[CP-NCBF](https://arxiv.org/abs/2503.17395v2) 把分割 CP 引入神经控制屏障的可信性分析。它提供了“校准与神经屏障约束结合”的研究思路。

当前主要是在实际视觉观察与状态代理之间建立残差集合，然后验证该集合下的闭环后继。校准对象与证明对象必须明确：视觉残差被覆盖，不等于屏障约束残差也已被校准；两者都不是控制性能保证。

因此可以说明受到 CP-NCBF 思想启发，但不能把它的全部定理直接移植到当前非负 B、离散动力学和视觉残差校准上。当前具体保证应由自己的事件与屏障条件推导。

## 15. 常见疑问逐项解释

**CP 已经 95% 了，为何还要求屏障条件？** 95% 描述误差是否落在集合内。即使每个误差都很小，不合适的控制器仍会把车开出车道。屏障负责证明允许误差不会导致危险。

**屏障已经通过，为何还有图像轨迹不在集合里？** 证书通过是“集合内的所有情况安全”。实际误差集合外的轨迹不满足该项证明前提；它可能仍安全，也可能危险。

**一条轨迹超出包络，是否就是失败碰撞？** 不是。它先意味着该轨迹未被这项误差覆盖事件包含。观察到安全不能补成证书覆盖，观察到漏覆盖也不等于已发生事故。

**100 条测试只有 93 条覆盖，CP 定理是不是错了？** 单次有限测试覆盖率有采样波动。要如实报告 93/100 及区间，并核查采样、模型选择和交换性；不能强行把它写成 95/100，也不能仅凭这个数字断言定理失效。

**CP 95% 是否意味着剩下 5% 必然事故？** 不是。漏覆盖只是证书前提未建立，未覆盖轨迹仍可能安全。

**正漂移见证是否说明不存在安全控制器？** 它只说明当前 B 在该状态与扰动下不满足所检查条件。若要证明给定控制器确实不安全，需要从合法初始状态出发、全程扰动合法、最终进入危险集的轨迹。要证明任何控制器都不可能，还需要更强的不可控性论证。

**未解决区间等于验证失败吗？** 它意味着尚未证明，可能是界太松或预算不足。不能当作通过，也不能当作已经发现真实危险。

**数值验证等于形式化浮点保证吗？** 连续盒验证比有限点测试强，但若使用普通浮点而没有严格舍入与完整计算栈分析，就应称连续域数值审计；不能自动升级为部署程序的完整形式化证明。

**CBC 一定比 SBC 容易求吗？** 没有普遍结论。最坏情况条件可能比期望条件更难满足，控制器综合也可能增加优化难度。

**80 步通过能保证以后永远安全吗？** 屏障数学条件若覆盖全部必要区域与时间，可以支持更长的条件安全；但 80 步轨迹 CP 只校准了注册时长的覆盖事件，不能据此声称无限时域概率安全。

## 16. 论文和汇报中建议怎样表述

对当前采用逐后继鲁棒检查的版本，建议称为：

> 我们采用轨迹级 CP 感知误差校准与确定性鲁棒屏障证书。在登记模型和时域内，从规定初态出发，只要实际视觉误差全程落在校准集合内，固定控制器的任何允许后继都满足屏障不增，轨迹便避开危险集。整条新轨迹满足误差前提的边际概率取决于校准协议和轨迹可交换性。

若同时综合了可执行的观察反馈控制器，可以进一步使用“鲁棒神经控制屏障证书”的名称，并写出控制策略及其信息约束。

项目中旧的类名、权重格式或文件名可以继续含 SBC，论文则应说明沿用了神经非负屏障表示，但当前主证明采用什么漂移条件。不要仅凭类名宣称已经完整复现原 SPVC 的随机定理，也不要因为后端采用鲁棒条件就声称与 SPVC 无关。

一份完整保证陈述至少说明：动力学和控制接口、初始与危险集合、误差集合与单位、采样分布、时长、屏障条件、数值验证范围、CP 的边际口径，以及是否根据结果选择发布。

| 符号／术语 | 本文含义 |
|---|---|
| x | 缩放后的真实系统状态，供离线建模与证明使用 |
| y | 实际图像经过 DINO 与投影得到的低维观察 |
| hφ(x) | 从状态预测名义观察的代理；可以是 Cx 或神经网络 |
| ε | 实际观察与代理的差 y−hφ(x) |
| δ | 实际解码观察与状态的差，例如 hφ⁻¹(y)−x |
| B(x) | 屏障证书函数，通常固定且非负 |
| b(x) | 本文解释 CBF 时使用的带符号安全函数 |
| πᵧ | 实际可执行的观察到动作控制律 |
| 条件期望 | 按给定当前信息后的分布，对随机后继作平均 |
| 超鞅 | 满足相应条件期望不增性质的随机过程 |
| 鲁棒 | 对规定集合内全部允许扰动都成立 |
| 支持集 | 分布可能取值的范围；高覆盖集合不等于全部支持 |
| 前向不变 | 从集合内部出发，未来一直留在集合内 |
| 轨迹覆盖事件 | 一条新轨迹在注册时域的全部误差均满足集合约束 |
| 边际保证 | 对校准集和新样本的共同随机性而言的保证 |
| 可交换性 | 样本联合分布不随排列顺序改变 |
