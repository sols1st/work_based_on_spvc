# CP 如何连接视觉代理、PPO 与神经 SBC

日期：2026-11-16。用途：解释当前框架中 CP 的具体位置、输入输出、与 SBC 的数学连接，以及 PPO 中实际用到和没有用到的部分。

本文以 **2026-11-15 已完成的非线性车道结果包**为具体例子，结合现有训练代码说明通用流程。不将后续计划中的控制器重训视为已经完成，也不替代其他版本按各自协议取得的结果。

最重要的结论是：**PPO 学习如何控制，CP 确定感知误差需要覆盖的集合，SBC 检查该集合内的全部允许扰动是否仍能保证安全。**最新非线性车道实验复用了旧控制器和神经 SBC，重新做了轨迹 CP 和新集合下的 SBC 验证；新 CP 半径没有参与这一轮 PPO 或 SBC 的重新训练。

## 1. 先把整个流程放在一起

```text
开发和训练
    图像与状态数据 → 学习视觉投影、状态代理
    任务环境／开发误差模型 → PPO 学习控制器
    候选控制器／设计误差集合 → 学习神经 SBC，验证与反例反馈
                         ↓
              冻结最终前端与实际控制器
                         ↓
正式校准
    新图像闭环轨迹 → 逐帧观察误差 → 每条轨迹一个最大误差分数
                         ↓
              CP 排序分位数 → 冻结误差集合
                         ↓
最终验证
    当前控制器＋当前神经 SBC＋正式误差集合 → 连续域数值审计
                         ↓
独立留出
    分别评估整轨迹覆盖率、越界情况和控制表现
```

这是逻辑上的组织方式。具体程序可以在阈值冻结后先采留出再做验证，或先验证再采留出，前提是没有利用留出结果调整阈值、前端或控制器。最新非线性车道程序先采留出，随后审计 SBC。

**正式 CP 必须对应最终冻结的实际闭环。**开发阶段用于训练的误差半径，可以来自开发数据或预先规定的设计范围；它不自动等于最后那份具有明确统计前提的正式 CP 合同。

## 2. 各个对象分别是什么

| 对象 | 当前车道例子 | 输入 | 输出 | 主要作用 |
|---|---|---|---|---|
| 真实物理状态 z | 横向偏差 e、航向误差 θ | 仿真动力学 | 下一步物理状态 | 描述车真正在哪里、朝哪里 |
| 归一化状态 x | (e/0.85, θ/0.30) | 物理状态 | 两个无量纲坐标 | 统一网络与验证使用的尺度 |
| 视觉投影 pθ | DINO patch 特征后的网络 | 当前图像的特征 | 二维低维观察 y | 将图像变成控制可用的信息 |
| 状态代理 hφ | 以前是 Cx，现在可为可逆神经网络 | 归一化状态 x | 名义观察 hφ(x) | 提供可用于模型分析的状态—观察关系 |
| 解码器 D | 当前为显式 hφ⁻¹ | 实际低维观察 y | 状态估计 x̂ | 适配原控制器的输入语义 |
| 控制器 π | PPO 得到的神经网络 | x̂ 和已知曲率 κ | 转向动作 | 完成车道控制任务 |
| 神经 SBC B | 非负神经屏障函数 | 分析中的状态 x | 非负标量 | 用屏障条件证明不会进入危险区域 |
| CP 阈值 q | 轨迹分数的有限样本分位数 | 独立校准轨迹的分数 | 一个半径与误差集合 | 给感知不确定性提供统计覆盖依据 |

实际部署的图像分支不读取真实 e 和 θ。真实状态用于离线学习、仿真、误差计算和安全证明。当前曲率作为已知辅助量输入；它的误差没有在本轮 CP 中另外校准。

B 并不一定在运行时参与动作计算。当前已完成的非线性车道版本没有在线安全过滤器，动作来自视觉解码后的神经控制器；B 主要用于离线证明。

## 3. 为什么要在视觉和代理之间放 CP

实际图像产生的观察为：

\[
y_t=p_\theta(\operatorname{DINO}(I_t)).
\]

代理产生的名义观察为 hφ(xt)。二者之间有差：

\[
\varepsilon_t=y_t-h_\phi(x_t).
\]

假如验证器直接把 y=hφ(x) 当成精确等式，就会漏掉实际图像带来的偏差。名义模型通过，不代表实际视觉反馈也通过。

CP 不会消除 ε，也不会修正每一帧预测。它利用独立校准数据确定一个集合，使新的同分布轨迹在明确条件下以规定的边际概率落入该集合。SBC 再针对集合内的误差做控制验证。

因此两者分工为：

\[
\text{CP：这个集合能以什么概率覆盖实际误差？}
\]

\[
\text{SBC：误差在这个集合内时，闭环是否安全？}
\]

## 4. 当前实际校准的是哪一种误差

### 4.1 原始低维误差与解码误差不同

当前非线性车道控制为：

\[
\hat x_t=h_\phi^{-1}(y_t),\qquad u_t=\pi(\hat x_t,\kappa).
\]

定义解码后的有效误差：

\[
\delta_t=\hat x_t-x_t=h_\phi^{-1}(y_t)-x_t.
\]

**当前 CP 校准 δ，而不是直接给原始 ε 的每个分量套同一个 q。**这样选择是为了使误差度量与原语义控制器的输入一致。

对于线性可逆代理 h(x)=Cx，δ=C⁻¹(y−Cx)。对于当前非线性代理，需要使用真正的 h⁻¹，不能继续用 C⁻¹代替。

### 4.2 它仍然覆盖实际视觉与代理之间的误差

从 δ 的定义可得 y=hφ(x+δ)，所以：

\[
\varepsilon=h_\phi(x+\delta)-h_\phi(x).
\]

若 ||δ||∞≤q，则原始低维误差属于：

\[
\boxed{\mathcal E_y(x)=
\{h_\phi(x+\delta)-h_\phi(x):\|\delta\|_\infty\le q\}.}
\]

因此只是选择了更适合控制与验证的坐标来描述误差，没有忽略 y−hφ(x)。当前代码还保存了实际 latent 和原始残差，便于审计。

在线性情形中，这个集合是 {Cδ:||δ||∞≤q}；非线性情形中，它会随状态变化，边界可以是弯曲的。将它写成固定的 ε∈[−q,q]²，会改变被保证的集合，不能直接套用当前证书。

### 4.3 单位如何理解

当前 q 为归一化状态坐标下的无量纲半径。||δ||∞≤q 等价于同时满足：

\[
|\hat e-e|\le0.85q\ \mathrm m,\qquad
|\hat\theta-\theta|\le0.30q\ \mathrm{rad}.
\]

不能把 q 直接称为“米”，也不能把航向误差和距离误差未经缩放就比较大小。AEBS 的对应版本通常最终换算成距离的米制误差，解释时应使用它自己的尺度和接口。

## 5. 轨迹级 CP 如何一步一步计算

### 第一步：冻结需要校准的系统

冻结视觉投影、状态代理、解码器、实际控制器、推理配置、动力学和采样规则。若模型一边校准一边更新，校准分数就不再对应同一个固定系统。

最新例子固定了原控制器和神经 B，以原初始盒、三种曲率和名义渲染条件采集图像闭环。每一步根据本方法自己的当前状态重新渲染并推理，不复用其他控制器走出来的图像轨迹。

### 第二步：每条轨迹产生一个分数

每条轨迹 80 步，第 j 条轨迹的分数为：

\[
\boxed{s_j=\max_{0\le t<80}\|\delta_{j,t}\|_\infty.}
\]

它同时取两个观察坐标和全部时刻中的最大值。平均误差不是这里的校准对象。

举例：某轨迹大多数帧误差为 0.02，只有一帧达到 0.12，则轨迹分数至少为 0.12。不能因为这一帧占比小就将它忽略。若 q=0.09，该轨迹就不算“全程误差被覆盖”。

### 第三步：排序后取有限样本分位数

对 n 个校准分数排序，取：

\[
k=\lceil(n+1)(1-\alpha)\rceil,\qquad q=s_{(k)}.
\]

当 k>n 时，标准带无穷大补点的规则返回无穷大，不能擅自将 k 截断成 n 后继续声称相同覆盖率。当前 n=199、α=0.05，因此 k=190。

最新非线性车道的结果为：

\[
q=0.08753797876881117.
\]

对应横向约 0.074407 米、航向约 0.026261 弧度的解码误差范围。

### 第四步：冻结阈值，再做留出评估

校准得到 q 后，不再为了让 SBC 通过或让测试覆盖率好看而缩小、放大或重选 q。独立留出用于检查实际表现，不参与选择阈值。

最新实验校准覆盖 190/199，独立留出覆盖 96/100。校准上的覆盖比例与选取第 190 小分数密切相关，不能把它当成独立测试证据。

## 6. CP 的概率到底是什么意思

在模型与评分函数固定，校准轨迹分数和新轨迹分数满足可交换性等前提下，分割 CP 给出：

\[
\Pr\!\left(\max_{t<80}\|\delta_{\mathrm{new},t}\|_\infty\le q\right)
\ge1-\alpha.
\]

这里的概率同时涉及校准数据和新轨迹的随机性，是边际保证。CP 的有限样本分位数与边际覆盖依据见 [Angelopoulos 与 Bates 的综述](https://arxiv.org/abs/2107.07511)。

“轨迹分数可交换”可以通俗理解为：不同完整轨迹按同一冻结机制生成，没有系统性地挑选或删除某些轨迹。独立同分布是常用充分条件；轨迹内的连续帧可以存在时间相关性。

需要区分以下说法：

| 说法 | 当前是否支持 |
|---|---|
| 新完整轨迹的误差事件具有规定的边际覆盖 | 在所述统计前提下支持 |
| 每个固定初始状态都具有相同覆盖概率 | 普通分割 CP 不直接提供 |
| 任意一次已经得到的校准集都保证真实覆盖率≥95% | 不是普通边际 CP 的含义 |
| 每次抽 100 条留出就必有至少 95 条覆盖 | 不保证；有限样本会波动 |
| 换相机、天气、控制器、时长后自动沿用旧保证 | 不支持，需重新分析与校准 |

### 为什么不能用单帧 95% 替代整轨迹 95%

单帧覆盖只描述一个时刻；运行很多步以后，至少一次超界的概率可能更大。即使每帧覆盖率很高，也可能有多条轨迹各出现一次漏覆盖。当前对完整轨迹的最大分数做校准，就是为了直接对应“这段 80 步中全部误差均在集合内”的事件。

## 7. CP 具体怎样进入神经 SBC 的验证

### 7.1 q 改变了需要检查的后继集合

CP 的输出并不是一个要输入 B 的额外特征。B 的输入仍是状态 x。进入验证器的是 q 和由它定义的允许误差集合。

控制器的实际输入写成 x+δ 后，需要考虑：

\[
\mathcal F_q(x,\kappa)=
\{f(x,\pi(x+\delta,\kappa)):\|\delta\|_\infty\le q\}.
\]

为简化记号，f 在这里已经包含归一化状态与物理动力学之间的转换，以及动作尺度转换。

对于非线性代理，原始表达式是 π(h⁻¹(h(x)+ε),κ)。按照第 4 节的集合定义，对每个允许 ε 都存在 δ，使：

\[
\pi(h^{-1}(h(x)+\varepsilon),\kappa)=\pi(x+\delta,\kappa).
\]

这是当前验证器能够继续检查解码误差盒的理由。它依赖显式可逆代理、实际使用的逆映射，以及与之匹配的误差集合；不是对任意非线性 MLP 都成立的简化。

### 7.2 当前 SBC 检查三组条件

对初始集 X₀、危险集 Xᵤ 和规定的活跃状态域，检查：

\[
B(x)\le1\quad(x\in X_0),\qquad
B(x)\ge20\quad(x\in X_u),
\]

\[
\boxed{B(f(x,\pi(x+\delta,\kappa)))\le B(x)
\quad\text{对所有允许 }\delta\text{ 和注册曲率成立}.}
\]

初始／危险条件没有因为 CP 改成“95% 的点满足”。漂移条件也不是“95% 的扰动满足”：**在给定误差集合内，验证目标是全部允许扰动。**概率只出现在真实视觉误差是否落入这个集合的统计层。

### 7.3 为什么这些条件能排除危险

若轨迹初始 B≤1，且每一步实际误差在集合内，就能逐步推出：

\[
B(x_t)\le B(x_{t-1})\le\cdots\le B(x_0)\le1.
\]

假设它后来进入危险集，则按危险条件又必须 B≥20。一个数不能既≤1又≥20，所以不会发生这种危险到达。

证明必须覆盖可能的首次越界后继，不能只检查“下一步还在安全域内部”的状态。它证明的是安全，并不自动证明任务完成、轨迹收敛或任意长时间稳定。

### 7.4 程序怎样检查全部误差

程序将状态域和 [−q,q]² 误差域划分为小盒，用网络界传播和动力学界计算允许后继的范围，再估计 B 的上、下界。典型充分条件是下一状态的 B 上界不超过当前状态的 B 下界。

暂时无法判定的盒继续细分；发现具体点违反条件时保存见证；达到预算后仍不能判断的区域记为“未解决”。初始、危险和全部注册曲率的检查都完成、没有未解决区域，才记为通过。

代码中明确把 CP 输出传为验证器的 `--radius q`，而不是使用旧默认值 0.08。当前状态为 `passed_numerical`，不等同于整个 IEEE 浮点执行过程的形式化证明。

## 8. CP 是否进入 SBC 的训练

### 8.1 通用训练接口可以使用误差半径

现有神经 SBC 训练入口接收 `radius`。给定候选控制器和该半径，它计算允许误差下的后继范围，学习满足初始分离、危险分离和不增条件的 B。

可以用下面的示意损失理解：

\[
L_B=\lambda_0 L_0+\lambda_u L_u+\lambda_d L_d,
\]

\[
L_0\sim[B(x_0)-1]_+,\quad
L_u\sim[20-B(x_u)]_+,
\]

\[
L_d\sim\left[
\sup_{\|\delta\|_\infty\le r}
B(f(x,\pi(x+\delta)))-B(x)
\right]_+.
\]

这些是表达训练意图的示意式。实际代码包含平方惩罚、原始输出头裕量、采样与后继界等处理，不是逐字采用上述公式。

如果 r 来自开发阶段的 CP，CP 就通过训练所需覆盖的扰动集合影响 SBC。但 r 也可能只是人为设定的设计半径；参数叫 `radius` 并不能证明它有正式 CP 来源。训练损失小、采样检查通过，都仍需要最终连续域审计。

### 8.2 11 月 15 日非线性版本实际没有重训 B

这份结果包使用旧 B，其元数据记录训练半径为 0.08。新系统正式 CP 得到 q≈0.087538 后，重新在这个更大的半径下验证该 B，结果通过。

因此准确表述是：**新 CP 进入了本次最终 SBC 验证，没有进入本次 SBC 重训，因为这次没有更新 B。**旧 B 能证明新集合并不矛盾；训练时使用的范围不必是它实际能够证明的最大范围。

## 9. PPO 中有没有用 CP

### 9.1 现有代码提供两种 PPO 训练模式

| 模式 | 提供给 PPO 的观察 | 误差集合如何参与 |
|---|---|---|
| semantic | 真实归一化状态和曲率 | 不通过观察误差模型参与 |
| noisy | 归一化状态＋误差样本，再加曲率 | 从误差模型文件读取 r，在盒内采样 |

noisy 模式中：

\[
\tilde x_t=x_t+\eta_t,\qquad
\eta_t\sim\operatorname{Uniform}([-r,r]^2).
\]

PPO 根据这些有扰动的观察与环境交互，学习提高期望回报。如果 r 来自有效的校准，可以说 CP 间接影响训练环境。

但是 CP 只给集合覆盖，不会推出真实视觉误差在集合内均匀分布。均匀采样是人为选择的训练方案，不能把它当成 CP 的误差分布结论。

### 9.2 PPO 优化公式本身没有新 CP 项

现有训练调用标准 PPO，CP 不直接作为分位数约束或显式安全约束加入 PPO 损失。PPO 通过有限次采样提高平均任务表现，不能据此证明集合内每一个扰动都安全。

有时任务奖励含有越界惩罚；这也不会自动变成全域安全证明。最后仍由 SBC 审计检查允许误差下的全部后继。

### 9.3 复用的历史 actor 与本次新 q 要分开

历史 actor 的记录显示：noisy 模式、80,000 步，误差文件路径为 `/tmp/lane_cp_cons.json`。这证明当时使用了误差模型，但单凭现有这条路径记录，不能重建其全部校准来源，也不能把它等同于今天的新轨迹 CP。

11 月 15 日非线性实验复用了这个 actor，没有重新执行 PPO，所以新 q≈0.087538 没有参与那次 PPO 训练。本次实际新增加的是视觉／代理联合学习、非线性逆接口、新轨迹 CP 和新集合下的验证。

### 9.4 SBC 反馈更新 actor 与 PPO 重训也不同

代码另有 `refine_actor.py`：冻结 B，利用允许误差下的 B 增长惩罚、行为保持约束等更新 actor。这是一个基于梯度的控制器修正阶段，不应仅因为修改了 PPO 导出的网络就称为重新运行 PPO。

它会改变实际控制行为，所以修改后既要重新验证，也要为最终视觉闭环重新准备正式校准。最新非线性结果包没有执行这个修正阶段。

| 项目 | 11 月 15 日非线性车道结果 |
|---|---|
| 新训练的对象 | 视觉投影、C、可逆非线性耦合网络 |
| PPO actor | 复用，未重新训练 |
| 神经 SBC 权重 | 复用，未重新训练 |

| 留出观测到的越界 | 0/100 |

这里有两种不同统计：100 条都没有越界，是控制行为的实测结果；96 条全程误差被集合覆盖，是证书前提的实测结果。剩下的 4 条虽然没有越界，但不能算作这份误差合同下逐轨迹保证覆盖的案例。

它证明现有非线性前端能够衔接当前控制器并获得新的条件证书，不证明重新训练整套方法会取得同样结果，也不证明非线性模型优于线性模型。

## 11. CP 与 SBC 最后怎样组合成安全结论

记 E 为“新轨迹全程误差均落入校准集合”，U 为“在注册时域内进入危险区域”。完整鲁棒 SBC 条件成立时，有：

\[
E\Longrightarrow U^c.
\]

CP 在相应条件下提供 Pr(E)≥1−α。如何表述安全概率，还要考虑证书是否根据校准结果选择性接受。

若 A 表示“本次校准结果下证书被接受并发布”，在统计前提和验证正确性成立时，可由集合关系得到：

\[
A\cap U\subseteq E^c,
\qquad \Pr(A\cap U)\le\alpha.
\]

这不能直接改写成 Pr(U｜A)≤α。对“已经发布的固定系统”的高置信度覆盖要求，需要单独设计审计或采用相应统计方法，不能混用边际与条件概率。

另外，不存在“CP 95%×SBC 95%”这一步。当前 SBC 使用逐后继不增条件，提供的是误差前提成立时的确定性数学安全论证；它没有另给一个独立的 95%。若换用原论文的其他随机漂移定理，需要核对其假设与概率公式，不能直接移植。

## 12. 如果后续重训 PPO 和 SBC，合理顺序是什么

以下是建议流程，不表示这些新训练已经执行：

1. **开发阶段拟合前端和代理。**用训练／开发数据确定模型、解码接口和任务配置。
2. **确定开发误差模型。**可以用开发数据拟合误差集合或规定设计半径，供控制和 B 学习使用。
3. **重新训练 PPO。**可选噪声观察训练、实际图像训练等方式，明确各自代价；如果使用误差集合，只将它视为训练策略。
4. **训练神经 SBC。**在候选控制器下学习初始、危险和鲁棒后继条件，使用开发验证与反例反馈修正。
5. **冻结最终实际闭环。**视觉投影、代理、解码器和控制器都固定。
6. **用未使用的完整轨迹做正式 CP。**依据最终控制器实际访问的状态与图像计算 q。
7. **在正式集合下做最终 SBC 审计。**能否通过按实际结果记录，不能通过修改正式 q 来迎合证书。
8. **独立留出评价。**覆盖率、任务性能、危险事件和成本分别报告。

如果第 7 步失败后继续修改控制器，闭环分布改变，要回到开发阶段，为最终系统重新采集正式校准数据；不能直接沿用旧控制器轨迹的普通 CP 保证。若只修改 B 而不改任何动作映射，轨迹分布并不会因此改变，但证书选择、开发使用和发布概率仍要准确说明，留出不能被反复用来挑选候选。

## 14. 常见误解速查

| 疑问 | 准确解释 |
|---|---|
| CP 是不是让视觉预测更准？ | 校准本身不改变前端权重，它量化预测与代理的差异 |
| CP 的 q 是不是 B 的输入？ | 当前不是；q 决定 B 必须应对的后继范围 |
| SBC 只需检查 95% 的扰动吗？ | 当前目标是允许集合内全部扰动；95% 出现在集合覆盖的统计层 |
| PPO 加了误差就自动安全吗？ | 有限随机训练没有全域保证，还需 SBC 验证 |
| 误差在盒内是否说明它均匀分布？ | 不说明；均匀采样是 PPO 的人为训练策略 |
| CP 覆盖失败是否一定越界？ | 不一定，只是该条件证书的误差前提没有全程成立 |
| 新 q 比旧训练半径大，旧 B 是否必然失效？ | 不必然；用新 q 完整重验证后才能判断 |
| 换了前端，旧 CP 能否直接继续用？ | 一般不能，最终观察与闭环分布可能改变 |
| 改 B 与改控制器对校准影响一样吗？ | 不一样；仅 B 变化不改动作，控制器变化会改变实际轨迹 |
| 这份证书是否证明目标一定达到？ | 当前解释是安全；任务完成、收敛需另有条件或证据 |
