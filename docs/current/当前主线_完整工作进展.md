# SPVC改进项目完整工作与实验报告

更新时间：2026年10月14日。面向导师汇报与第一次接触项目的读者。

本文覆盖从原SPVC复现到最新五步MFNBC联合实验的全部主要路线，包括成功、失败、工程修复、数据采集、表示学习、控制训练、屏障检查、QP和CP。最新状态不是“所有模块都放在同一条成功流水线里”，而是“有一个保留的DINO最小替换基线，旁边有多条明确区分版本的研究分支”。

## 0 阅读方法和最新结论

### 0.1 最重要的五句话

1. 我们已把原SPVC的“物理状态生成图片”前端替换为“真实图像经DINO得到latent、物理距离经小网络得到同类latent”的双路径。原SBC、PPO交替训练及旧验证器口径保留，最终保存模型复查通过原代码阈值。
2. 两条新路径的平均一致性明显改善。相同开发图片上，新系统的图像距离MAE约0.166米，旧链约2.668米；代理—图像动作造成的下一速度平均偏差约0.00604米/秒，旧链约0.07496米/秒。
3. 控制任务已有正面表现，但“有限起点成功”“原代码报告95.62%”“真实图像闭环有可靠安全证书”是三个不同结论。第三个结论目前尚未成立。
4. 最新MFNBC分支真正实现了屏障学习和PPO安全反馈，也实现了旧约束保留与五步训练。但目前没有优于原控制器或普通PPO的验证安全收益；全部新联合候选不替换原模型。
5. 当前最缺的不是再接一个网络，而是把图像—代理差异的未来覆盖、必要状态域的屏障条件，以及模型版本和终止语义连接成可信证明。

## 1 我们研究的任务是什么

### 1.1 一个具体例子

车以2.75米/秒接近前方障碍物，距离15.5米。系统每0.05秒观察一次画面和速度，决定刹车或加速。希望它最终在规定距离内低速到达，而不是过早停住、一直磨蹭，或进入危险区时仍很快。

这不是完整自动驾驶：当前没有多车交互、车道保持、复杂转向或真实轮胎模型。研究对象是一个便于核对方法的自动紧急制动任务，英文缩写AEBS。

### 1.2 物理状态和动作

物理状态是两个数：

- d：到障碍物的距离，单位米。
- v：当前速度，单位米/秒。

动作a限制在[-3,3]。当前项目正数表示制动，负数表示加速。这与某些参考代码“负数刹车”的约定不同，不能直接照搬符号。

一步更新为：

```text
d_next = d - 0.05 × v
v_next = clip(v - 0.05 × clip(a,-3,3), 0,3)
```

clip就是把数值限制在给定范围内。例如动作5实际执行为3，速度算成3.1实际记为3。

本步的距离更新只使用当前速度，没有本步动作。因此，同状态的两条输入路径即使动作不同，一步下一距离仍相同；下一速度才可能不同。连续多步以后，距离当然也可能分岔。

### 1.3 初始范围和结束条件

通常从d为15～16米、v为2.5～3米/秒开始。最长400步，约20秒。

| 结局 | 中文含义 |
|---|---|
| success | 在目标距离[5,6]米内，速度不超过0.5米/秒 |
| unsafe | 距离不大于6米，同时速度大于0.5米/秒 |
| stopped_safe_outside_goal | 已停止但没有达到目标 |
| out_of_domain | 离开当前定义的状态范围 |
| timeout | 到400步仍没有其他终局 |

unsafe是实验定义的危险事件，不天然等于CARLA碰撞传感器报警或实体撞车。只报unsafe=0可能掩盖100% timeout，所以必须同时报任务完成情况。

### 1.4 为什么有两种归一化距离

网络通常喜欢大小相近的输入，因此距离会除以一个尺度。

- 原VT屏障坐标使用尺度3.18272066116333米。
- 当前R2表示坐标使用尺度3.161912679672241米。

两个尺度接近但不相同。d=10米时，两个归一化值不完全一样。适配器必须显式换算，不能把一个网络输出的归一化数直接塞给另一个网络。

归一化不代表距离单位变了，也不代表DINO部署输入被压成一维距离。

### 1.5 CARLA在这里实际做什么

当前多数实验中，CARLA负责提供图像，物理状态由上面的AEBS公式推进。全屏截图、图片库回放和解析状态更新要分别理解。

- 图片库回放：从已有图片里查一张，不会实时渲染对应新状态。
- 在线截图回合：每步取当时的CARLA画面，但车辆状态仍可能由解析公式驱动。
- 真实CARLA车辆动力学：需要实际施加油门/刹车并读取实车状态，本主线没有因此取得完整保证。

因此，雨天图片已经考虑了雨天“看起来不同”；它没有自动考虑湿路面摩擦变差。

## 2 原SPVC怎样工作以及我们想改什么

### 2.1 原方法的两条路径

真实输入链为：

```text
真实图片 → 旧图片处理/状态估计 → 原PPO → 动作 → 下一状态
```

用于分析的代理链为：

```text
物理状态和环境隐变量 → cGAN生成小图 → 旧状态估计/可验证代理 → PPO → 下一状态
```

cGAN可以理解为“按距离等条件画出一张像观测的小图”。代理是为了在大量物理状态上快速产生控制器输入，不是车辆动力学本身。

当前仓库的一个实际生成器是监督训练的MLP生成模型。不能仅因目录叫cGAN，就假定它完全等于论文中所有对抗训练设置。

### 2.2 SBC在原方法里的作用

SBC是随机屏障证书的缩写。用一个函数B给物理状态分配数值：初始区域较低，危险区域较高，安全演化中下一步B的期望应满足规定下降条件。

可以把它想成“用于证明系统行为的标尺”，不是PPO直接执行的刹车命令，也不天然是事故概率。

论文的保证依赖B非负、初始和unsafe区域界，以及在理论要求的安全状态上成立的动态期望条件。原论文Theorem 2.2要求检查的域不能任意替换成仅靠近unsafe阈值的一条窄带。

### 2.3 原方法怎样考虑环境差异

原论文把不同环境相对参考环境造成的闭环下一状态差写为Δs，并假设它服从与当前状态无关的固定分布μ。控制器更新后，还需要重新估计对应扰动分布。

通俗地说，先问“同一物理状态换了画面，控制器会把下一步带到哪里”，再把这种变化放入随机系统模型。

这说明原论文并非完全不考虑图像误差；但“用样本估计一个分布”与“证明未来真实误差服从这个分布”不是同一件事。

### 2.4 当前仓库实现需要单列的限制

代码检查中发现或记录了：

- 部分Lipschitz补偿项硬编码，不能直接当完整理论常数。
- 训练使用的噪声与验证积分噪声口径不同。
- learner与verifier的概率目标不同。
- 某些反例精化默认未开启。
- 旧区间接口的取值曾被当作上界，但审计中它与下角点普通值一致。
- 动态检查实际筛掉了大量网格点。
- 容许非零违反，且以总网格数作分母。

这些观察针对本项目当前提供的代码。不能据此直接说原论文定理错误，也不能推广成作者所有版本都有同样问题。

### 2.5 改进的核心动机

原代理要求“生成图片尽量像，再从图片读出控制信息”。我们的新代理直接要求“控制器读取的低维表示尽量一致”。

它有机会减少图像重建这层不必要工作。但减少一层网络不会自动消除误差，也不会自动得到新安全定理。

## 3 当前保留基线的完整架构

### 3.1 部署图像路径

```text
真实RGB
  → 冻结DINOv2-S/14
  → 384维特征
  → 训练过的投影网络
  → 32维图像latent
  → 拼接当前速度，形成33维输入
  → PPO
  → 动作裁剪
  → AEBS下一物理状态
  → 下一次观察
```

32维latent就是32个网络学习的内部数字，不是32米、32个手工距离，也不是32种固定物理量。目标是保留控制所需信息，弱化无关外观差异。

### 3.2 代理路径

```text
物理距离d
  → 按R2尺度归一化
  → q网络
  → 32维代理latent
  → 同一个PPO，加上相同速度
  → 动作
  → 下一状态
```

q不是强化学习Q函数。它是“距离到latent”的小网络，主要用于离线训练、网格计算和安全分析，不是部署时绕过摄像头读取真距离的模块。

当前q只接收距离，而建议中的更一般形式是q(x,η)，可包含更多物理状态和环境变量。我们实现的是AEBS的简化版本，尚未验证跨任务通用性。

### 3.3 各模块的实际结构

| 模块 | 结构或规模 | 在当前基线中的职责 |
|---|---|---|
| DINOv2-S/14 | 22056576个参数，输出384维 | 预训练视觉骨干，完全冻结 |
| Projection | 384→128 ReLU→32 | 把通用视觉特征变成任务表示 |
| 辅助decoder | 32→32 ReLU→1 | 检查表示能否恢复距离，训练/诊断使用 |
| q | 1→64 ReLU→64 ReLU→32 | 用物理距离生成代理表示 |
| PPO actor | 当前SB3 MLP，33维输入，两层64维Tanh隐藏层 | 决定动作均值；训练时还有动作分布 |
| PPO value网络 | 估计未来奖励 | 支持PPO训练，不是安全证书 |
| 原SBC | 2→16→8→1，旧实现非负输出 | 作用于物理状态，不读DINO图像 |
| 新NBC分支 | 2→64 Tanh→64 Tanh→1 | 有符号安全候选和RL反馈，不替代旧B |

辅助decoder没有插在latent与PPO之间。部署控制器仍直接读32维latent＋速度，因此不是“又改回一维距离头”。

原SBC代码的square_output命名容易误导：相关版本实际用了Softplus非负输出，不是所有版本都真的做平方。历史signed/unsigned变体要按各自配置理解。

### 3.4 冻结和训练是什么意思

冻结就是不更新该网络权重。DINO冻结不等于整个系统冻结：projection、q和PPO在各自阶段曾经训练。

当前联合实验冻结DINO、projection和q，只更新PPO与候选NBC。原SBC仍保留，不参加这一新分支的优化。

### 3.5 最新联合分支的数据流

```text
训练图片库和当前物理状态
  → 图像latent与速度
  → 完整PPO随机采样动作
  → 裁剪后的实际动作
  → 原解析AEBS后继
  → NBC单步或五步违规
  → 概率比安全损失更新PPO
  → 新轨迹＋旧转移训练NBC
  → 训练侧保留检查
  → 不合格NBC提议回退
```

NBC在这里参与离线训练，不是运行时硬过滤动作。即使安全损失参与反向传播，也不表示它已形成数学安全保证。

### 3.6 已形成和未形成的部分

已形成：表示、控制器、原SPVC接入、保存pair检查、精确误差对照、环境动作集合计算、NBC训练和联合反馈接口。

未形成：当前最终图像路径对应的独立误差覆盖契约、可信连续必要域证明、真实车辆动力学误差覆盖、合格的联合NBC、最终未触碰test评价。

## 4 关键术语的白话说明

### 4.1 训练相关

| 术语 | 白话解释 |
|---|---|
| epoch | 把一套训练样本过一遍；不是车辆跑一个回合 |
| step或timesteps | 与环境交互的一步，或表示网络的一次参数更新，需看上下文 |
| batch | 一次拿来计算损失的一小批样本 |
| loss | 当前做得不好的程度，越小通常越好，但不等于事故概率 |
| learning rate | 每次参数调整的力度；过大可能把原能力破坏 |
| gradient | 告诉参数往哪边调的信号 |
| checkpoint | 保存的模型；不是一个安全认证标签 |
| warm start | 从旧权重继续训练 |
| distillation | 用教师动作教学生模仿，不等于新的PPO交互训练 |
| replay | 重用旧数据；NBC可以回放旧转移，PPO概率更新不能把旧数据伪称当前采样 |
| on-policy | 数据确实来自当前采样策略，而非另一套策略的历史动作 |
| retention | 学新东西时保护旧能力；本项目有失败提议回退 |
| early stop | 满足停止规则就停，不是程序卡住 |
| seed | 随机过程的固定起点。本项目主要用7，没有靠换种子挑最好结果 |

PPO同时学动作与奖励价值。历史SPVC微调主要更新actor均值；这不自动保存完整PPO的价值网络、探索方差和优化器状态。

### 4.2 误差指标

- MAE：绝对误差平均。10次各差0.1米，MAE就是0.1米。
- RMSE：先平方再平均再开方，对少数大错更敏感。
- bias：带正负的平均误差；正负会抵消，所以不能只看它。
- P95：这批样本里95%的误差不超过的值，剩余5%可能更坏。
- max：这批样本观察到的最大误差，不是未来全部误差的严格上界。
- 相对latent误差：表示差除以表示本身的变化尺度，不是安全失败率。
- coverage：真实量落入预测范围的比例；要说明是样本覆盖、总体统计覆盖还是逐状态覆盖。

例如“相对latent误差7.63%”不是“事故概率7.63%”；“样本最大误差0.24”也不是“未来误差永远小于0.24”。

### 4.3 屏障相关

SBC B通常非负，用初始低、危险高及条件期望关系推导概率结论。NBC C允许负值，用C≤0作为候选安全区，危险区要求C>0。

两类函数数值不同，不能把B的概率公式直接套给C。C=-1比C=-0.2是否“更安全”，也不能脱离区域和动态条件随便解释。

“候选”是还在检查的函数；“证书”是相关条件真正成立后的结论。神经网络文件叫barrier.pt不说明已经获得证书。

### 4.4 QP和slack

QP即二次规划：在动作范围和一些约束下，选一个尽量接近PPO原动作的动作。

slack是松弛量，可理解为“这次允许借多少约束欠账”。若本来要求某残差≤0，加slack后允许残差≤slack，slack>0说明硬要求被放松了。

因此，QP“求出了一个解”与“原安全条件被满足”不同。正slack频繁出现，不能把该层称为始终执行硬安全约束的层。

### 4.5 CP的两个百分比

“99%覆盖、99%置信”不是重复说同一件事。

覆盖描述未来同分布样本有多大比例落在范围内；置信描述校准数据能够支持这项覆盖声明的可靠程度。有限独立轨迹、模型冻结、采样协议不变是重要前提。

单步99%不自动变成400步99%。每一步都可能漏一点，整条回合的风险会积累。

### 4.6 四种旧语义压力模式

| 模式 | 实际做法 | 不能误解成 |
|---|---|---|
| exact | 给控制器准确语义距离 | 摄像头估计已经无误差 |
| uniform | 每步在允许误差区间均匀抽一个误差 | 真实图像误差就是均匀分布 |
| random_boundary | 每步随机选区间正端或负端 | 两种真实天气 |
| worst_endpoint | 按该测试的规则选最不利端点 | 连续整个误差区间已被严格验证 |

端点测试是否真是最坏，要看策略和条件是否具有相应单调性；不能默认所有非线性网络最坏值都在端点。

### 6.5 20000步混合误差微调

配置：50%精确输入、25%区间内均匀、25%端点；再加轻量模仿蒸馏。seed7，20000环境步；蒸馏2个epoch、4096网格标签。每种模式200个评估回合。

| 模式 | baseline unsafe | robust unsafe | baseline return | robust return |
|---|---:|---:|---:|---:|
| exact | 0% | 0% | 405.817 | 282.814 |
| uniform | 1% | 21.5% | 405.485 | 280.708 |
| random boundary | 17% | 28% | 400.651 | 278.523 |
| worst endpoint | 100% | 100% | 241.775 | 165.364 |

### 6.6 感知误差和过程误差的分离

旧03_uncertainty用4×4状态格，每格256个状态、每状态16个感知误差，得到每格4096个转移，速度差支持约[-0.149398,+0.115774]。

后来确认这主要是“图像误差→动作差→后继差”，不能在动作已经按图像变化以后，再当独立过程噪声加一次。

新03_process_uncertainty只比较当前解析模拟器预测与实际同动作转移，16格每格256个样本残差全0。

结论：当前解析模型没有独立过程残差，不意味着真实车辆、路面或传感器没有噪声。重复计入同一误差会把验证变得过度保守。

## 7 阶段二 自由神经SBC的多种失败尝试

### 7.1 共用做法

训练一个B(d,v)，希望初始低、unsafe高，并在允许误差的后继上满足下降。用80×80物理状态网格检查，输出违反数、最差余量、最差状态和区域值。

余量为“当前B减去最坏下一B，再减所需下降量”。余量负表示条件未满足。最差值比均值更能暴露一小块危险区域。

不同版本改变了终止、危险、可恢复域，所以分母不同。不能把975比2886小就直接说安全改进了三倍。

这里有数学规格、实现语义和优化三个层面的原因，不能把全部失败简单归结成“神经网络不行”或“训练轮数不够”。

## 8 阶段三 Safety filter 教师和不依赖filter的学生

### 8.1 第一版filter

filter根据物理制动能力与感知范围修正PPO动作。它像一个在PPO之后把关的规则层。

旧一次实验unsafe由uniform4%→0%、random boundary12.5%→0%、worst endpoint100%→0%，但回报大幅下降，出现停滞。因此“没有进入unsafe”并不代表好控制器。

### 8.2 四个版本的配对比较

每种旧误差模式200个回合，比较原PPO、全局最大半径filter、观测分箱filter和防停滞filter。防停滞的英文是anti-stall。

| 模式 | 原PPO成功 | 全局filter成功/超时 | 分箱filter成功/超时 | anti-stall成功/unsafe/超时 |
|---|---:|---|---|---|
| exact | 100% | 100% / 0% | 100% / 0% | 100% / 0% / 0% |
| uniform | 96% | 75.5% / 24.5% | 90% / 10% | 100% / 0% / 0% |
| random boundary | 86.5% | 0% / 100% | 0% / 100% | 100% / 0% / 0% |
| worst endpoint | 0% | 100% / 0% | 100% / 0% | 100% / 0% / 0% |

anti-stall平均步数约202.5、205.2、196.9、118.2。动作干预率仍约79%～100%，说明结果依赖规则层，不是原PPO本身已学会。

### 8.3 第一次蒸馏失败

目的：让一个PPO actor学会教师动作，运行时不再使用filter。

配置：128×128物理网格，16384训练标签，80轮，batch512，lr=.0003。给少制动、低速区额外权重。

结果：教师动作MAE=.356864，最大差2.496832；四种模式全部timeout=100%。

原因线索：低速处一点过制动，长时间积累后可能一直无法到达目标。平均动作误差不能代表闭环任务是否完成。

### 8.4 第二版蒸馏

配置：32768标签，300轮，batch512，lr=.0003，少制动权重2、低速权重20，加强低速临界标签与恢复动作。

结果：动作MAE=.105696，最大差2.209528；四种模式全部success=100%、unsafe=0、timeout=0，平均步数约189.8、188.6、183.4、123.2。

这时运行时确实只有学生PPO，没有filter。standalone就是“可以独立运行，不需教师每步改动作”。

注意：它是教师动作蒸馏，不是全程靠普通PPO自己发现安全控制。该路线后来因手工物理结构依赖而不作为当前主线。

## 9 阶段四 粗网格反例修复 连续区间检查和有限状态SBC

### 9.1 LP第一次失败

对6400个网格状态建立80045条屏障约束，求解器HiGHS报告infeasible，同时没有一步最坏unsafe后继。

诊断指出，网格插值/终止边界可能把同一点同时要求B=0和unsafe高值。这种约束矛盾不能靠优化器找到解，也不能据此说物理上不存在安全控制器。

### 9.2 连续停车距离和离散停车距离

手工利用AEBS公式算最大制动下需要多少距离，定义“还来得及刹住”的可恢复区域。

连续公式曾把8个rollout unsafe点判为可恢复；改成实际0.05秒步长的离散计算后，可恢复5419、不可恢复269，可恢复但rollout unsafe=0，排除了14个连续公式偏乐观的边界点。

这个计算在二维制动任务里很方便，但对高维复杂任务不容易手工推导。因此用户要求放弃其作为新方法核心，当前主线不依赖它。

### 9.3 粗网格100%通过为什么不够

05_certificate_transfer_check：4483状态，每状态33个语义输入，共147939组合，教师和学生均没有违反，最小后继余量约0.003987米。

随后在d=[6,8]米、v=[2,3]米/秒加密201×201网格，每状态129个语义点，共2405334组合，发现约19个学生反例。粗网格漏掉极窄边界，不是“安全了以后又变不安全”。

### 9.4 高速修复和低速遗忘

这些结果属于一维语义与手工制动教师路线，不属于当前DINO的安全成果。

### 9.5 IBP和split-IBP如何工作

IBP是区间传播：输入不是一个点，而是一小盒范围，逐层算出网络输出可能落在哪里。它检查盒中的连续输入，而不是只抽几个点。

普通区间可能过宽。例如一整段语义距离放在一个盒里，网络输出下界很低，证明不了足够制动。split-IBP把语义输入分小段，各自求界后合起来，减少过度保守。

| 序号 | 范围/设置 | 结果 |
|---|---|---|
| 09 | 局部d=[6,8]、v=[2,3]，普通IBP | 未决15001，区域未决面积0.72% |
| 10 | 同局部，语义16段 | 未决0，程序报告局部动作条件通过 |
| 11 | d=[5,16]、v=[.5,3]全域 | 未决703 |
| 12 | 修正低速离散阈值 | 未决627 |
| 13 | 单独低速修复后 | 未决1831 |
| 14 | 双边界回放 | 未决248 |
| 15 | 语义64段 | 未决135 |
| 16 | 语义256段、状态细分深度9 | 3624格被评估，2002格证成，未决0 |

16版本面积85.53%为检查的可恢复证成部分，14.47%为物理不可恢复部分。不能说“全矩形100%都安全”；证明对象是所述可恢复状态与契约内输入的动作条件。

现有实现使用普通浮点界，不要将程序状态夸大成独立证明助手认证。最终概率还要有整条轨迹感知契约覆盖。

### 9.6 有限状态SBC

利用上述动作闭合证据，把状态抽象成R可恢复、T安全终止、U危险/不可恢复三类。LP得到B(R)=0、B(T)=0、B(U)=1，条件失败界beta=0，最大LP残差0。

白话：在指定模型和误差契约内，若不会从R跳到U，就能给这个三类系统一个简单屏障。

这不是原自由神经SBC终于训练成功，也不是“真实车辆事故概率为0”。它依赖手工物理集合、契约内观测和零过程残差，后来作为历史条件性对照保留。

## 10 阶段五 只替换语义前端 回到原SPVC后端

### 10.1 为什么回到这一版本

用户希望最小改动，先证明不用cGAN前端也能接回原SBC流程。因此不继续改验证强度或手工可恢复集，只替换真实图像输入的语义编码器及代理前端。

该版本不是当前32维DINO，而是前面的一维语义encoder。

### 10.2 最初失败

一次100轮运行有9/10000硬违反，初始上界约14.0486高于unsafe下界11.3076，没有可用区域分离读数。

旧代码把不超过0.1%的违反视为动态检查通过，所以9/10000=0.09%会打印“Decrease condition fulfilled”。这不等于零违反，也不等于同时满足其他证书条件。

### 10.3 增加迭代和保存正确pair

续训到503轮左右出现0/10000。一次循环内部区域值对应读数约87.934%，随后完整区域复查得到初始1.12208、unsafe20.4728、全域下界.347388，旧读数96.151%。

关键工程修改：达到零违反和目标读数时，停止在下一次PPO更新之前，保存与该次检查对应的PPO/SBC。

“之前有0违反，最后却保存8违反”的问题可能来自后续又更新了模型，而不是0违反记录自动覆盖了最终checkpoint。保存身份问题和证书强度问题要分开。

## 11 阶段六 可微QP联合训练和其局限

### 11.1 从两篇论文借了什么

BarrierNet提供“把可优化的安全约束层接到神经控制器后”的结构；Opt-ODENet强调安全投影与连续轨迹训练的结合。二者的连续时间CBF并不等于原SPVC的离散随机SBC。

本项目第一版只借用可微QP结构，没有实现完整Neural ODE、连续时间高阶CBF或作者全部方法。

### 11.2 QP的输入和目标

PPO给名义动作，SBC给一个动作相关条件，QP选尽量接近名义动作的可执行动作。不是“SBC先输出刹车动作”。

目标近似为：

```text
min 0.5 × (a - a_nom)^2 + 0.5 × rho × slack^2
同时满足动作范围和线性化SBC约束，slack ≥ 0
```

SBC下一值一般不是动作的线性函数，所以先在名义动作附近线性化。可微表示训练信号能通过QP解影响前面的网络；不表示这条近似约束一定是真安全条件。

### 11.3 Q1接口诊断

128状态、100个扰动格中心：QP干预46.09%，正slack1.56%，最大slack.060072，名义与QP中点违反均2；原旧“上界”违反均3。

后来定位：59个动作改变中57个只是把原动作裁剪到合法范围，只有2个超过普通clip；128状态没有一个落在当时原验证窄带。不能把46.09%都说成真正安全修正。

改为实际受检区域29状态后，中点违反7，旧检查却0。这促成区间实现审计。

### 11.4 区间审计与细分

同一29状态：旧实现正残差0、修正区间8、中点7。旧输出与下角点普通值最大差0，不能把它继续叫可靠上界。

完整旧模型复查：10000网格实际筛到21状态，修正界有1个硬违反。

该点d对应约11.215米、v≈2.985，改合法动作扫描也没显著降低粗IBP残差，但噪声格细分后：

| 噪声格 | 修正IBP残差 | 中点残差 |
|---|---:|---:|
| 10×10 | +1.971630 | -1.972052 |
| 20×20 | +.020401 | -1.975042 |
| 40×40 | -.974934 | -1.975809 |
| 80×80 | -1.475124 | -1.976002 |

这说明该点的粗界失败主要有保守性因素；不能据此说完整域已经验证。用户随后选择保留原SPVC代码口径，完整修正后端并未作为当前最小基线替换。

### 11.5 QP在环训练的四类结果

| 实验 | 配置 | 旧网格输出 | 20起点PPO/QP闭环 |
|---|---|---|---|
| 固定旧语义-SPVC＋QP | 不训练 | 不作新证明 | 双方全unsafe |
| QP joint smoke | 512状态，SBC/P各1轮 | 0/10000 | 双方全unsafe |
| QP joint full | 10000状态，SBC10轮/P1轮 | 1/10000 | 双方全unsafe，约69.7步 |
| 仅rho改10000 | 不重训 | 不改变核心结果 | 动作和结局未改善 |

正式一轮的SBC与actor参数确实变化，QP梯度测试也通过，所以是“训练实现成功，但安全效果失败”，不能称作没运行。

扫描118个轨迹状态、每点61动作，其中63个正slack状态未找到满足同一条件的扫描动作。这不是连续动作不可行的完整证明，但已说明只加大slack惩罚没有充分依据。

### 11.6 控制器初始化和学习率修复

原预训练PPO同20起点全成功；旧SPVC续训PPO却全unsafe。新QP入口增加从原PPO初始化、显式降低actor学习率的选项。

| 设置 | 训练配置 | 结果 |
|---|---|---|
| 原PPO初始化，lr=.05 | 512状态，各1轮 | PPO/QP全unsafe |
| 原PPO初始化，lr=.0001 | 512状态，各1轮 | 双方20/20成功 |
| 原PPO初始化，lr=.0001 | 10000状态，SBC10/P1轮 | 旧网格0/10000，双方20/20成功 |

完整小学习率版QP干预超过普通裁剪约4.16%，正slack约35.07%，最大5.512706。原PPO本来就成功，QP没有明确额外安全收益。

该版本改变了初始化和学习率，不能作为“只加QP，其他全部不变”的严格消融。

### 11.7 为何QP经常不满足条件

旧动态检查只看一条很窄的B值带，QP却在整条轨迹施加该条件。

成功的新PPO三条轨迹260步中仅2步落入旧带，90个正slack抽样点仅2点在带内；有限动作扫描只有3点找到可行解。

因此“旧网格通过”不能说明QP约束对全部轨迹都可行。把带外QP直接关掉也可能只是让它几乎不工作，不是新的安全方法。

## 12 阶段七 语义控制器的CP和全面评估

### 12.1 准确语义的轨迹CP

冻结小学习率PPO/QP；初始距离均匀15～16米、速度均匀2.5～3米/秒，确定性AEBS，H=400。

先59校准＋20测试作95/95 smoke，后459校准＋200独立测试作99/99登记实验。

准确语义下双方校准459/459成功、测试200/200成功；PPO分数阈值-.076305373，QP-.073926447；输出置信度.990079。

它是该输入/动力学/初始分布下的有限时域统计结论，不覆盖实际新摄像头、过程噪声或无限时间。

### 12.2 均匀契约误差CP失败

保持同模型，只在每步区间里均匀抽语义误差。正式结果：

- PPO：校准443成功/16unsafe，测试194成功/6unsafe，q_hat=+.024503191。
- PPO＋QP：校准443/16，测试192/8，q_hat=+.025823199。

阈值为正，未达到预设安全目标。QP没有改善。第二距离箱异常导致半径2.776米，是此压力模型的重要来源；均匀重抽全箱不等于真实图像误差频率。

### 12.3 最近图像重放CP通过

每步从旧400图里按距离找最近图片，先运行语义encoder，再PPO/QP。

双方459校准、200测试全部成功；PPO阈值-.077554999，QP-.083473600。结论局限于有限旧图片库回放分布，不代表所有未来图像。

### 12.4 不用CP的全面经验对照

目的：确认20起点不是偶然，并测试更强误差。

配置：32×32=1024个初始格中心、每回合400步，5种观察模式、2控制器，共10240条模拟轨迹；配对随机模式使用同一误差序列。

| 模式 | PPO成功/unsafe | PPO＋QP成功/unsafe | QP干预 | 正slack |
|---|---|---|---:|---:|
| exact | 1024 / 0 | 1024 / 0 | 4.23% | 35.02% |
| dataset-nearest | 1024 / 0 | 1024 / 0 | 4.55% | 32.09% |

## 13 阶段八 从一维语义转向DINO双路径

### 13.1 semantic＋latent建议到底要求什么

建议的核心不是“把DINO接上就结束”，而是三件事：

1. 表示保留控制所需信息，不必重建整张高维图片。
2. 相同物理状态在不同外观下，表示尽量一致。
3. 剩余图像—代理差异有明确覆盖范围，再进入安全验证。

建议允许三种误差接口：latent集合、动作集合，或物理下一状态残差集合。最终安全性质仍定义在物理状态，而非“latent看起来接近”。

当前前两项有实验改善；第三项的可靠覆盖与证明仍未闭合。建议文档里的概率公式也需要明确边际、条件和轨迹覆盖，不能直接套用普通CP作为逐状态条件概率。

### 13.2 初始DINO表示实验

旧400图先转RGB、放大到224×224，以冻结DINOv2-S/14提384维特征，再学384→128→32投影、辅助距离decoder和q。

结果：辅助距离MAE约.1951米、RMSE约.2954米；q每坐标latent RMSE约.27191；8图前向两路径均输出[8,32]，runtime_output_is_distance=false。

放大32×32图片不会创造新细节；DINO完全冻结不代表384维特征自动适合制动任务，仍需投影和控制训练。

### 13.3 三个20万步PPO对照

每种训练20万步、seed7，评估20×20=400初始点：

| PPO训练输入 | 评估q路径 | 评估旧图片库路径 |
|---|---|---|
| 只用q | 100%成功 | 9.5%成功，90.5%目标外停止 |
| 只用图像latent | 100%unsafe | 100%成功 |
| 每回合50% q、50%图像 | 100%成功 | 100%成功 |

它证明两条latent虽然同维度，坐标差仍会造成训练—运行不一致。混合输入缓解了该有限库问题，未证明新的图片也有效。

随后旧表示下原SPVC SBC打印0/10000、旧概率读数95.977%。这是历史q代理基线，不是当前R2最终模型读数。

### 13.4 真正留出图片库的失败

旧混合PPO：q成功100%，train图片成功70.75%、unsafe29.25%，validation库成功0%、unsafe100%。

再只用train库训练一个PPO：q与train都100%成功，validation库仍100%unsafe。

validation库最近图片最大距离错配约1.778894米，明显大于train库约.391834米。若实际距离7米，拿来一张约8.8米图片，控制器可能认为障碍还远。这不是单纯“验证图片图像质量差”。

representation_is_newly_heldout=false还提醒，表示或历史策略可能已见过旧图片；不能把这次叫全新独立test。

### 13.5 去掉查图误差的单步诊断

对每张图片自己的距离标签配速度，分别输入两条latent，直接算一步后继。

旧模型train6300组合，动作MAE=.183695、最大4.278715；validation2400组合，MAE=.163265、最大2.374193；validation图像独有unsafe1、双方unsafe94。

意义：查图误差不能解释全部行为差；精确匹配后仍有图像/代理差异。94是检查组合，不是94回合事故。

### 13.6 顺序拟合与联合拟合A/B

A先学图像投影，再让q追随；B让投影、q和辅助decoder共同学习，DINO冻结、PPO/SBC不改，不看test。

| 验证指标 | A顺序 | B联合 |
|---|---:|---:|
| latent RMSE | .256620 | .093820 |
| 相对latent RMSE | 45.1398% | 19.6262% |
| 残差L2 P95 | 1.856734 | .956814 |
| 图像距离RMSE | .524770米 | .419987米 |
| 远状态分离违反比例 | 14.7615% | 33.6760% |

B一致性改善，但状态分离指标变差，物理辅助距离RMSE也约.06816→.09967米。不能只优化“两条路径靠近”而忽视不同状态仍可区分。

### 13.7 B表示下重新训练PPO

20万步请求量，SB3实际按整批跑200704步；seed7。新表示坐标变了，不能复用旧PPO输入权重当作未变控制器。

这是表示与新控制器兼容性的正面开发结果，SBC尚未随之重新认证。

## 14 阶段九 保持原截图方式扩充24000张数据

### 14.1 为什么前面两种采集方案被放弃

曾采用Town10、camera.rgb、多锚点或不同截图框。用户看到近距离车辆大小和构图与原实验不同，要求不要改变采集方法。

传感器预览还遇到“actual camera/target pose不符”。先tick再读同帧状态等修复后，30张预览完整采集并通过manifest检查；这只是该预览路线跑通，不是最终正式数据来源。

最后以CARLA机器上的spvc_carla.py为基准，保留原观察者移动和桌面全屏截图，只扩充距离、天气、颜色和记录。

保存PNG、真实距离、距离组、天气、颜色、采集配置、清单、完成数和错误记录。新目录避免覆盖旧数据，未发现错误时不擅自删除图片。

图像文件完整不代表画面没有桌面遮挡，因此自动审计之外有视觉抽查。用户已确认本次图片正常。

|---|---:|---:|

审计24000张均能解码，decode_errors=0、near_constant=0、跨split重复组0。

白话：如果同距离红车在训练、蓝车在测试，测试可能只是换颜色，并不考察新距离。分组减少这种泄漏，但邻近距离仍相关，不能声称所有样本独立。

### 14.5 H5特征缓存

只给train＋validation的19080张提384维冻结DINO特征，CUDA约192.09秒；test_encoded=0、test_evaluated=false。

同步保存行号、文件名、标签、split、图片指纹和DINO版本，防止特征第100行配错距离第101行。partial文件不能当完整缓存使用。

## 15 阶段十 扩展数据上的R0 R1 R2表示学习

### 15.1 R0与R1的公平比较边界

R0只用晴天红车train1181张；R1用全部train14172张。两组验证均4908张，结构相同、seed7、联合9250次更新，随后400次q拟合。

各自归一化统计仅用各自train子集。H5没有合成增强视图，所以没有伪造旧增强损失；共用图像/物理辅助重建、latent配对、状态分离与输出正则。

模型选择：验证图像距离RMSE/尺度＋.2×相对latent RMSE。validation参与选择，不能叫未触碰最终test。

全批q阶段R1处理更多样本，虽然更新数相同，计算成本不是严格相同。主要比较数据覆盖作用，不声称只是网络架构造成全部差异。

## 16 阶段十一 R1和R2的PPO以及失效定位

### 16.1 R1新PPO配置

冻结R1，从头训练33维PPO。请求20万步，实际200704步，CPU、seed7。每回合50% q、50%train图片；图像回合随机均匀选12外观之一，整回合保持该外观。

不能简单在24000张里argmin取第一张：同距离并列12外观，若总取首行，实际上只学了一种外观。

评估q和每种外观，各400个相同20×20初始点；不对稀疏validation图片库作有误导风险的最近邻完整回合评价。

### 16.2 R1回放结果和精确单步结果

q及大部分外观400/400成功；阴天浅灰391/400、unsafe9，阴天红399/400、unsafe1。12外观合计4800回合，10次unsafe。

平均查图距离误差约.049～.050米，最大.378378米。精确匹配本图标签后：

### 16.3 最近邻错配诊断

阴天失败约在7.50米时查到7.752753米图片，关键动作少制动约2.06～2.45；按图片实际标签作反事实比较后仍有约.58～.89动作差。

不能据“阴天误差较大、阴天回放失败”就认定阴天颜色是唯一根因。

### 16.4 插值回放对照

冻结R1表示和PPO，用前后距离图片latent插值代替最近一张，旧4800回合unsafe10→0。

它诊断了检索错配的影响，但插值依赖已知真实距离标签，不是实际摄像头部署时自动获得的功能，也不是新的感知安全保证。

### 16.5 R1经验残差PPO

配置：冻结R1、20万步、seed7；50%图像、25% q、25%经验残差校正q。残差来自train本图latent-q，长度裁剪到train P95=.222080，回合缩放Uniform[0,1]。

train精确动作MAE由.025295变为.028644，最大差1.864548→1.653424，图像独有unsafe3→1；validation MAE约.132145、最大3.501269。

部分失败和尾部改善，平均动作差并非全部改善。train P95裁剪会舍掉较大尾部，所以这不是误差契约。

### 16.6 R2重新训练控制器

冻结R2，仍20万步请求、200704实际、seed7、50% q/50%外观固定train回放。q和12外观各400起点全部成功。

精确配对train动作MAE约.019848、validation约.119587；train图像独有unsafe0，双方unsafe5328，validation图像独有unsafe0。

## 17 阶段十二 在线截图轨迹与下一状态误差校准

### 17.1 错误协议Town10失败

首次459轨迹使用Town10HD_Opt与camera.rgb，偏离训练全屏截图协议。出现182次unsafe，轨迹最大下一速度误差达到.3米/秒。

该批保留为协议变化后的失败诊断，不能当当前原协议校准结果，也不能只因为后面成功就删除这批失败记录。

### 17.2 恢复原SPVC全屏截图的30条开发回合

冻结第09步R2控制器与表示，按原截图方式每步采集。30条全success，共2456步。

图像/q动作MAE=.179964、最大2.728690；反向饱和0，动作离线重放最大差约4.3511e-6。轨迹最大下一速度残差中位数.078326米/秒、P95=.113134、最大.136435。

这说明开发闭环跑通，但30回合不是高置信可靠性实验。动作最大差约2.73仍存在；速度裁剪会使动作差与后继差不线性对应。

### 17.3 独立轨迹残差契约

新采459条登记轨迹，H=400，目标失覆盖epsilon=.01、置信失败beta=.01。冻结对应R2表示和第09步PPO，按每条轨迹最大后继速度差评分。

得到q_hat=.150685468米/秒，输出置信度.990079。距离残差盒[0,0]，速度对称盒约[-.150685,+.150685]。

459来自预设统计样本量，不是随意选大数字。若以样本最大分数定阈值，独立同分布前提下，覆盖99%的置信下界为1-.99^459≈.990079。

q_hat描述两条输入路径诱导的后继差，不是“概率15%”，也不说明安全。校准协议、时间范围、分数公式和策略身份改变后，需要重新校准。

## 18 阶段十三 CP全局残差盒及动作分箱为何失败

### 18.1 全局CP盒鲁棒SBC

配置：固定第09步PPO、R2、上述契约；200轮、20000训练状态、4096区域样本、batch512、lr=.001；每状态5个残差样本，初始目标.01、unsafe目标1、下降权重100、区域权重20、top-k .1。

100×100采样检查中，非终止下降状态8910，违反8884；初始违反5942、最大.012174；unsafe违反1651、最小.619658；最差动态余量-.050335。

结果不是“只差一点就通过”。先区分优化失败与规格本身不可行。

### 18.2 三种固定残差压力测试

从400个登记初始点出发，最多400步：

| 每步残差 | 安全终止 | unsafe |
|---|---:|---:|
| -q_hat | 400 | 0 |
| 0 | 400 | 0 |
| +q_hat | 0 | 400 |

首个反例从[15米,2.5米/秒]出发，第61步到[5.884981米,3米/秒]，PPO前一步已最大制动3。

最大制动每步减速.15米/秒；误差盒却允许每步加回.150685。这个抽象可以不断抵消刹车，所以在这个最坏规格下，相关屏障要求无法成立。

它否定的是“极值可每步任意持续重复”的规格，不是说真实459轨迹都unsafe，也不是否定原SPVC的期望型SBC。

### 18.3 动作条件分箱

把459轨迹的37882步按动作分12箱，希望把全局最大误差与最大制动区分。

结果：最大制动箱[2.5,3]的正残差仍.147900537；用每箱正端点持续施加，400初始点仍全部unsafe。

这说明只按动作分箱仍丢掉了状态与时间关联。不断再切距离/速度箱又会变成对已看过的459轨迹拟合，不可继续称同一批数据为独立校准。

## 19 阶段十四 真实轨迹场景SBC和轨迹CP

### 19.1 与参考scenario论文的关系

读过并获取了Training with Hard Constraints相关代码。参考文章的场景方法包含特定硬约束、参数化和PAC前提，不能把任何“用场景样本训练神经网”都称为复现其定理。

我们实际的train_trajectory_scenario_sbc是对整网软损失的开发训练，不是作者最后一层LP方案的完整移植。

### 19.2 数据和共用条件

旧459轨迹降为开发数据，按整条回合分367训练、92验证，避免同一回合前后步骤跨split。

训练29970个相邻转移、验证7453个；初始B≤.01，unsafe B≥1，观测转移尽量不增加。安全终止后继按停止过程值处理。

相邻记录可能没有最后执行动作的后继，所以解释时须核对末步和outcome。新NBC采样后来专门保存了真实终止后继，不能倒写为这批旧轨迹已经没有该风险。

### 19.3 三个版本

| 项目 | v1 | v2安全占用 | v3边界加强 |
|---|---:|---:|---:|
| train动态违反 | 29901/29970 | 1730/29970 | 498/29970 |
| validation动态违反 | 7434/7453 | 458/7453 | 131/7453 |
| validation最小动态余量 | -.014336 | -.000349 | -.000066 |
| 初始网格违反 | 945 | 0 | 0 |

v1只约束起点低、危险高，B仍可沿安全轨迹慢慢升高。

v2新增“已知安全轨迹上B保持低值”的损失：200轮、batch512、8192区域样本、lr=.001，下降权重100、安全占用50、区域100。

v3同200轮与lr，下降权重500、区域200，安全占用50；内部初始目标.005、unsafe内部目标1.2，重点采v=.5001/.501/.505/.51附近unsafe边界，避免贴着成功阈值的漏分离。

区域分开了，但131个动态违反仍未消失。小于万分之一的数值幅度也不能擅自当0，尚未证明全是浮点误差。

### 19.4 冻结v3后新轨迹CP

新459条轨迹，冻结旧PPO与v3，预先登记后评分：

```text
score = B(initial) + sum positive increments - 1
```

停止语义：安全终止赋B=0，unsafe赋B=1。若一条完整轨迹到unsafe，初值与正增量总和至少能达到1，因此该分数不可能负。

结果：459/459 success；score中位数-.999996638、P95=-.999907858、最大-.999807990；q_hat=-.999807990。保守400×最大单步增量评分阈值也负，为-.947394616。

输出positive increment最大.000131513是单条轨迹的最大一步正增量，不能误写成该轨迹正增量总和。

### 19.5 这个pass意味着什么

在冻结、独立同分布、完整停止轨迹、未挑数据等前提成立时，支持登记分布下400步安全事件的统计结论。它不证明神经B满足原SPVC全域条件期望，不是无限时域或所有地图保证。

459条全成功本身也能作直接二项统计，必须对照说明屏障分数额外提供什么价值，而不能只靠“用了SBC＋CP”这个名字声称更强。

这套统计结果绑定旧第09步PPO和v3。minimal actor和最新联合PPO改变后，不可继承其阈值。

### 20.5 与原SPVC相同和不同的地方

相同：后端训练/损失/区域网格/噪声/旧筛选与容许违反口径。

不同：DINO图像latent与q代理latent，33维PPO输入和对应新权重；实际图像误差分布没有因为沿用后端而自动等于旧噪声分布。

准确成果是“最小前端替换成功接回原工程并得到同口径正面读数”，不是“真实图像保障已与原论文理论等价”。

## 21 阶段十六 在同图像同状态证明代理平均误差较小

### 21.1 为什么不能把两个原生误差直接比较

像素RMSE与latent RMSE坐标、维度、单位不同。拿.039像素误差与.0475 latent误差比大小，就像拿温度与长度比较，结论无意义。

因此做了两个互补实验：物理单位下的距离/后继差；同一冻结任务表示空间下的代理差。

### 21.2 物理单位比较配置

4908张validation、147240个非终止图片/速度组合；同PNG、同真实d/v、同dt与终止规则。没有训练、test、最近邻查图或完整rollout。

旧链是仓库基础PPO＋旧生成器/state_net；新链是minimal最终actor＋R2。两套PPO维数不同，比较的是各系统内部代理相对真实输入的偏差，不是共用同一PPO权重的架构消融。

cGAN两种输入制式[0,1]与[-1,1]均检查；生成隐变量固定z=0和均匀随机MC，随机32次不挑最佳图。

### 21.3 平均距离与下一速度结果

主口径为旧真实图[0,1]＋随机生成MC：

|---|---:|---:|---|
| 真实图像距离MAE | 2.667726米 | .165559米 | 对真实标签更准，平均降93.79% |

## 23 阶段十八 真正接入Model-Free NBC单步学习

### 23.1 借鉴内容与动机

Model-Free Safe Reinforcement Learning Through Neural Barrier Certificate提供三类机制：用转移样本学屏障，组合短多步不变性，用动作概率比把安全信号送入PPO。

本项目“Model-Free”的准确含义是屏障/策略安全学习不需要通过车辆动力学求导。样本仍由已知解析AEBS生成，不是世界真的没有模型。

原论文讨论神经近似可能破坏安全条件，不应把它理解成用Adam学完就有无条件保证。

### 23.2 新NBC的条件

C允许负值，以C≤0作候选区，初始C≤-.01，unsafe C≥+.01；单步要求：

```text
C(next) ≤ .9 × C(current)
训练时再留epsilon=.01余量
```

例：C=-1，下一C=-.95可以满足-.95≤-.9。它允许负值在界内向0靠近，不像固定每步严格下降那样惩罚一切上升。

初始/unsafe任务标签直接来自原定义，不用手工停车距离或TTC可恢复标签。

### 23.3 首轮离线训练

数据：固定最终actor造成的图像后继，不用q后继替代；train742320、validation294480，训练中有10629个unsafe后继。

结构2→64→64→1 Tanh隐藏层，线性有符号输出；200轮、Adam lr=.001、batch8192、seed7、λ=.1、ε=.01。初始/unsafe训练32×32，检查41×41。

损失是初始、unsafe、单步违规三个平均hinge。hinge就是低于/高于门槛时才计罚，满足时为0。

约158.05秒后初始/unsafe零违反；train原始动态246/742320、边界越过6；validation13863/294480=4.70762%、越过1009，最差-.180871。

结论：样本学习有效，泛化动态条件未合格，不是证书。

### 23.4 最差10%加权第二轮

从首轮NBC继续，120轮，只把动态损失改为一半均值、一半最差10%均值；模型、数据、λ/ε不变，约104.74秒。

train违反246→21、越过6→0；validation违反13863→13001，但越过1009→2324，最差-.180871→-.287532。

候选区比例也变：train57.93%→53.39%，validation53.83%→52.38%。集合更小不保证更好，不能只按总违反数减少就宣布安全改善。

第二轮不采用；后面的联合试验从首轮较稳定NBC出发。


## 24 阶段十九 首次PPO和NBC联合更新

### 24.1 初始化为什么不是直接恢复原PPO训练

minimal保存的actor包含均值和q，不是完整SB3 PPO训练状态。新分支把最终SPVC均值放进第09步完整PPO，继承其奖励价值网络和探索方差，重新建立优化器。

64个观测上初始确定性动作与最终actor一致，差为0；但这不表示价值网络、探索方差和优化器也都是原SPVC续训时的状态。

继承高斯动作标准差约1.417513，随机动作经常超出[-3,3]，由环境clip。该探索只在模拟器做，不能直接搬到实体车。

### 24.2 在策略采样和日志

训练从任务初始区域随机起步；一回合固定一个train外观；每2048步采一批、共4批8192步。查图最大距离差约.378105米。

必须同时保存：

| 字段 | 为什么需要 |
|---|---|
| observation | PPO当时真的读到什么 |
| 原始采样动作 | 高斯策略实际抽出的数 |
| old log-prob | 当时动作概率，用来做PPO比例 |
| 裁剪后的执行动作 | 真正进入模拟器的动作 |
| reward与PPO bootstrap后的reward | 区分原奖励和截断时价值补偿 |
| 当前/真实下一物理状态 | 不拿自动reset的下一回合起点冒充后继 |
| episode id、terminated、truncated | 区分回合和停止原因 |
| 图片行号、外观、距离gap | 可追溯感知输入与错配 |
| 采样完整策略、评分NBC | 可复现该轮概率和风险评分 |

为什么原始动作不能换成clip后的动作算概率：高斯抽5与抽3是两个不同事件，哪怕都执行3。用执行3的密度代替抽5的密度，会算错PPO概率比。

### 24.3 安全损失如何影响动作

先冻结该批采样前的C，算g=relu(C_next-.9C_current+.01)。g是该转移训练条件没满足多少，不是事故概率。

把g居中/标准化，乘动作概率比exp(new_log_prob-old_log_prob)，与PPO奖励损失一起优化。直观上提高相对低违规动作的概率，降低相对高违规动作概率。

无需对解析车辆公式反向求导：g当作记录好的标签，梯度通过动作概率分布进入actor。

安全系数从.05起，按批平均违规递增、上限1；这是项目简化，不是严格复现原作者全部乘子优化。

### 24.4 首次配置和结果

PPO lr=.00001、n_steps2048、batch256、每批4epoch、gamma=.99、GAE=.95、clip=.2、target KL=.01；NBC lr=.0003，每批PPO更新后才拟合转移10次。DINO/q冻结、seed7、无CP/QP/test。

训练和主要评估约15.57秒。same12外观×3×3初始点=108确定性回放，更新前后全成功；回报20.940843→20.938536，步数76.3519→77.2870。

固定首轮C的精确验证违反13863→14616，C候选边界越过1009→1059。训练端安全梯度四轮均非零、actor参数确实改变，证明接线有效；不代表效果有效。

### 24.5 最终新C退化

41×41区域检查初始正值错误0，unsafe非正值错误16，unsafe最小C=-.169136。最终策略/最终C自身验证动态违反19559，但此数不能与原固定C下13863当同一标尺直接比改善。

随机训练109个已结束回合94success、15unsafe；确定性评估108全成功不能掩盖随机探索危险。

每批平均g下降，但评分C和采样策略不断变，不能据此说真实风险下降。

## 25 阶段二十 防止NBC遗忘和普通PPO对照

### 25.1 只修正这一件事

新轨迹太少时，C可能为满足新转移把旧unsafe区域拉低。保留修正由三个配套部分组成：

1. 每NBC优化抽2048旧train转移，新/旧动态hinge各一半。
2. 区域损失除了平均还罚最大错误，让少数边界点不能被大多数正确点冲淡。
3. 检查不合格就恢复NBC权重与Adam动量；PPO不回退。

旧数据用于NBC监督，不拿旧动作概率冒充PPO当前数据。

### 25.2 门槛如何设置

固定16384旧train转移和81×81初始/unsafe网格，只用训练信息。起始参考原始动态违反7、边界越过1、epsilon hinge均值1.12830e-5。

候选要求：

- 初始与unsafe区域保留epsilon=.01裕量。
- 旧hinge均值不超过固定参考加1e-6数值容差。
- 旧动态违反和旧C边界越过不增加。
- 所有检查值有限。

这是“不得明显遗忘”的开发门槛，不是旧NBC已经安全：参考本来仍有违反。

### 25.3 两组对照

04_joint_retained：安全反馈开启。

### 25.4 为什么最终C仍是旧权重

每次新提议的区域已经分开，但旧guard动态违反7→26～29，均值约1.1283e-5→6.65e-5～7.05e-5，所以四次全拒绝。

## 26 阶段二十一 短多步MFNBC和状态覆盖诊断

### 26.1 为什么看未来五步

一动作当下还没违规，几步后却可能危险。只看一步的训练信号可能出现太晚。官方MFNBC代码有多步收缩式和累计epsilon余量，因此本轮固定1～5步，不做步数搜索。

五步只约.25秒，不是预测完整400步，也不能提前识别所有危险。

### 26.2 从旧有序轨迹先分析

04保留联合的8192步、13个unsafe终止，使用当时归档的评分NBC，不改任何网络。

单步g>0样本1383；五步加权g>0样本2306，增加923。

13次unsafe之前1～4步共52个“事件—提前步”检查位置，单步正违规14、五步27，新增13。它说明部分警告确实变早，但仍有25个位置没有正信号。这52个位置不是52个独立unsafe事件。

### 26.3 公式和一个白话例子

令rho=.9；第k步的hinge是：

```text
relu(C(state_after_k_steps)
     - rho^k × C(current)
     + .01 × (1-rho^k)/.1)
```

累计裕量来自连续k步收缩要求。k=1时就是上一轮条件；k=5时累计训练裕量约.040951。

按.99^(k-1)加权1～5步，除以实际可用权重和。该“只按可用未来归一化”是本项目适配，不是完整照搬官方固定分母代码。

例：当前动作后一步C仍没跨训练门槛，第四步却违反，那么这条记录会给当前动作一个正成本，让PPO有机会提前改变概率。

### 26.4 终止掩码为何重要

同回合的后继才能组成窗口。unsafe最后动作的实际后继不能丢，但终止后reset起点不能接在窗口末尾。

- 窗口可在terminated或truncated那一步结束。
- 不跨到下一episode。
- 不跨rollout边界编造尚未采的状态。
- 不足5步时使用已经真实记录的步数，不补零假装未来安全。
- 旧散点仍只做单步NBC回放，不把相邻图片数组当轨迹。

原始y_t与下一个x_t在同回合逐点一致，最大差0；解析物理重算误差约4.7684e-7。

| 固定C动态违反/294480 | 14583 | 14617 | 14508 |

五步比单步多34个违反，比对照多109个，比原控制器多754个。没有安全改善。

安全关闭的五步影子组与上一轮普通PPO最终全部策略张量完全相同，说明仅改变影子NBC窗口没有暗中改变PPO抽样或训练随机状态。

### 26.7 训练覆盖能解释全部失败吗

把五步训练访问状态按d每.25米、v每.25米/秒粗分格，8192步访问91格。验证294480组合中247632落在未访问粗格。

固定C的14617个违反里4206在未访问格，10411在访问过的格。C≤0内也有9809个违反，其中7732在访问过的粗格。

因此，“所有失败只是训练没到过那里”不成立。相反，粗格里至少访问过一个点也不能证明见过该精确距离、速度和外观。该统计支持进一步检查覆盖，但不是唯一根因证明。

两个代表点：

- d≈7.677678米、v=3，余量约-.130750，当前C≈+.093502，本来就不在C≤0内。
- d≈6.501502米、v≈1.55，余量约-.123673，C≈-.023334，在候选区内，确实是应关注的候选闭合问题。

把C>0点和C≤0点的违反分开，才能避免对全部物理状态强行施加同一种安全解释。

### 26.8 终止反馈也存在不一致线索

对07训练日志只读核对：

| 实际终局 | 事件数 | 终止动作单步/五步正违规 |
|---|---:|---:|
| success | 94 | 37 |
| unsafe | 15 | 7 |
| 其他 | 0 | 0 |

也就是说37次成功末步仍被屏障收缩条件罚了，而8次unsafe末步没有正hinge。

这不说明程序把结局标签记录错；说明“当前C收缩hinge”不是实际unsafe事件的完美分类器。C>0区域中即使下降，也可能仍unsafe；安全终止的C值也未必满足继续运行状态的收缩式。

目前窗口边界和真实末状态记录正确，但停止任务的损失语义还需要分析。不能因为用了正确mask就声称整个风险目标已正确。

### 26.9 本轮结论和停止理由

已实现：短多步梯度链和掩码，发现更多提前警告，完成同预算对照和只读覆盖/末步诊断。

未实现：合格NBC对新策略适应、安全优于普通PPO、误差覆盖和连续证书。

本轮不继续加步数、强度、随机种子或放宽检查门槛；原minimal控制器和SBC不变。下一次更有信息量的工作是核对安全终止/unsafe终止如何进入训练反馈，以及候选区内动态违反和当前策略是否一致，而非再次盲目堆训练。

## 27 为什么目前还没有完整安全保证

### 27.1 有三类问题 不是一个问题

1. 输入覆盖：未来真实图像会不会产生超出验证范围的latent或动作？
2. 控制与屏障：范围内所有可能后继，是否满足相应安全条件？
3. 数值与域：格间状态、终止、出域、真实动力学及概率模型，是否与推导一致？

只降低latent平均误差主要改善第一类的经验难度；只加NBC主要帮助生成控制/屏障候选；原网格通过只提供某实现范围的检查。它们不能各自代替另外两类。

### 27.2 NBC怎样才可能成为证书

最简单确定性版本需要：

- 初始状态全部在C≤0里。
- 所有真正unsafe状态在C>0里。
- 在应保持安全的区域内，执行允许动作后的状态仍留在C≤0。
- 终止和出域有明确处理。
- 对声称的连续状态和输入范围确实证明，不只训练样本。

若进一步用C_next≤.9C且当前C≤0，就可递推C_next≤0。但当前即使初始/unsafe有限网格分开，动态仍存在大量违反，所以递推链断了。

### 27.3 原SBC与NBC不能相互继承概率

原B非负，结论依赖区域阈值和条件期望；新C有正负，核心是不变候选区。把C简单加一个常数变非负，不会自动满足旧B的期望式和概率读数。

原95.62%读数、旧CP99%、新NBC区域0违反不能加起来或相乘得到“更高安全率”。

### 27.4 图片误差要怎样纳入验证

可以做latent契约，也可以直接做执行动作契约：

```text
e_a = clipped_image_action - clipped_q_action
e_a ∈ [lower(d,v),upper(d,v)]
image_action ∈ clip(q_action + error_interval,-3,3)
```

然后验证整个动作范围诱导的后继，不只名义q动作。如果采用原SBC，检查相应噪声期望；若采用NBC，检查合适域内的候选区闭合。

契约不是简单min/max表：要明确模型、状态/环境范围、采样方法、未来覆盖口径和时间范围。已有观测包络按构造覆盖旧样本，不等于新图像一定覆盖。

### 27.5 为什么CP不能直接填入每个状态

普通split CP通常给总体边际覆盖。它不自动给“给定当前历史，每一步都以99%被覆盖”。

如果用逐历史条件概率去上界屏障期望，还需相应条件覆盖、契约外B界，以及感知事件与过程噪声关联的处理。不能把已有总体CP阈值直接填入这种公式。

若选择整条轨迹最大误差评分，可支持登记分布下的轨迹覆盖。它同样不是每个初始点或任意天气的全称保证。

### 27.6 一个可行但尚未完成的证明链

```text
模型与协议冻结
  → 独立数据证明整轨迹误差覆盖
  → 契约内全部允许动作/后继满足可靠屏障条件
  → 必要连续状态域和停止/出域处理成立
  → 明确时间范围与环境分布的安全结论
```

在确定性模型正确、契约内有逐路径安全证明时，可把整轨迹失覆盖概率转成风险界。当前这些前提未同时成立，不能宣称已经得到该结论。

如果不做统计校准，也可以设定明确的确定性图像扰动范围并作鲁棒证明；范围与真实性同样要交代。CP是可选工具，不是唯一合法方法。

### 27.7 三种环境误差必须分开

| 类型 | 现有实验是否包含 |
|---|---|
| 天气、光照、颜色造成图像不同 | 已采12外观，进入表示、动作和记录后继 |
| 同状态图像与q代理不一致 | 已测量、已有包络开发和NBC训练；未来覆盖未完成 |
| 摩擦、延迟、执行器误差等车辆过程变化 | 未由当前图片数据建立实测过程契约 |

相同误差不能既算动作集合又作为独立噪声加一次。反过来，过程残差0也不说明真实路面没有误差。

## 30 下一步应怎样走

### 30.1 不继续重复的方向

不继续靠放宽epsilon、缩窄检查域或改分母制造通过；不重复全局正残差盒；不把完整动作范围当当前B支持；不拿已开发数据反复校准到pass。

不继续把“PPO已100%成功”当新安全训练一定会提高任务成功率。基线在该初始小网格已经接近天花板，真正要改善的是危险边界、分布外误差或证明覆盖。

### 30.2 训练改进的最小下一步

先核对末步：

- 成功已经停止时，是否还应当满足继续运动状态的收缩要求？
- unsafe终止是否需要明确失败监督，而不是只看C是否上升？
- C>0区域的收缩得分是否被误当真实低风险？
- 接口能否在保留旧约束的同时生成与新策略兼容的C？

先用保存轨迹作诊断，不先加新数据或训练轮数。之后只改一个损失语义，再与同预算普通PPO比较。任何终止处理变化都需作为新算法配置明确记录，不能称“其他完全不变”。

### 30.3 误差保证的最小下一步

冻结表现较好的minimal控制器，不把失败联合候选当正式对象。用开发数据建立状态相关、非对称动作误差候选，先检查能否同时包住图像动作并保有屏障可行性。

有可行候选后再冻结、采新独立轨迹校准；不能先大量正式采集，后面又改策略/集合使数据失去独立校准用途。

连续验证须处理动作集合随状态变化，不能仅继承q路径旧K补偿。域外、停止和过程模型也须登记。

### 30.4 最终独立评价

方案冻结后再编码/使用test。若先根据test失败改模型，test就变成开发数据，需另留最终评价。

正式报告至少包括每外观任务表现、双路径误差尾部、查图距离差、契约覆盖、屏障违规与验证域、运行耗时及模型身份。不可只报总体平均。

### 30.5 关于可发表性

当前可展示的数据/表示/代理一致性优势与失败诊断具有研究价值，但“能发表”不能由接了DINO或MFNBC来保证。可主张的新贡献需要公平旧基线、独立评价、清楚的适用范围，及至少一个完整论证闭合的安全结论。

最合理的论文故事不是把所有历史分支拼成巨大成功框架，而是选择一条主线：低维双路径表示降低代理偏差，明确误差抽象如何进入控制与验证，再证明或统计校准所声称的范围。MFNBC可作为训练机制或对照，其现阶段负结果应诚实保留。

## 34 给导师汇报时可直接使用的表达

### 34.1 两分钟版本

我们最开始尝试让原SPVC不再生成图像，而直接使用控制需要的语义；随后根据建议采用冻结DINO和32维latent。真实图像与物理状态各有一条进入同一控制器的路径，前者用于运行，后者便于安全分析。

目前收集并审计了24000张原协议图片，包含四种天气和三种颜色。多外观和同距离组训练把双路径验证相对误差从约79%降到7.63%。在同一批开发图片上，新系统的当前距离误差和图像/代理下一速度平均偏差都明显低于旧cGAN链，且已接回原SBC/PPO后端并通过旧代码检查口径。

我们还尝试了QP、CP、不同神经屏障以及MFNBC联合训练。它们并不是全部成功，也不是全部现在在用。最近MFNBC的单步、保留修正和五步反馈都真正运行了，能把安全信号传给PPO，但还没有优于原控制器的安全验证表现，所以没有替换基线。

现在的主要缺口是：未来真实图像与代理的差异要有可信覆盖；覆盖范围里的控制和屏障条件要在合适状态域成立。下一步先解决训练信号与终止事件的匹配，再选择一个可行误差契约与验证对象，避免继续无依据加轮数。

### 34.2 导师问是不是已经有安全保证

可答：已有原工程口径和若干历史条件/统计结果，但当前DINO最终图像闭环的完整保证尚未建立。原95.62%是旧实现读数；旧轨迹CP绑定旧策略；MFNBC目前仍是未通过的候选训练。

### 34.3 导师问MFNBC有没有实际用进去

可答：用了单步屏障、动作概率比反馈、短多步累计裕量，并保存了真正在策略的完整动作概率和终止后继。没有照搬全部TensorFlow/Ray框架，乘子和部分窗口归一化是项目简化。效果暂时没有提升，因此报告了对照和失败，不把“接上了”当“成功了”。

### 34.4 导师问为何不直接采用早期手工证书

可答：二维制动能算停车距离，历史条件性检查也有正面结果；但方法依赖任务物理公式，通用性不足。现在把它留作对照，主线改为学习表示与误差抽象，屏障的最终保证仍需补齐。

### 34.5 导师问新代理是否真的更准

可答：在同4908图和相同状态下，距离与后继速度的平均误差明显更小；共同任务空间代理距离也更小。但控制器、训练数据和输入制式不同，不能当独立架构因果实验；最坏下一速度误差还有恶化，所以仍需误差尾部覆盖。
