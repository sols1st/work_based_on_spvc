# 联合学习视觉投影与 C：实验步骤、适配和结果

更新：2026-11-10。本轮在原结果旁新增独立版本，不覆盖固定 C 前端、原控制器或原 SBC。**三种前端均已实际联合训练；RGB 与车道的新条件 SBC 数值审计已通过，灰度新集合未通过；不能继承旧证书。**跨版本完整比较见 [AEBS与车道全版本汇总](AEBS与车道实验全版本汇总_步骤原理结果与观测样例_20261109.md)。

## 1. 这一次究竟改了什么

以前的车道前端直接预测归一化横向偏差和航向误差，等价于固定 `C=I`；AEBS 直接预测归一化距离，固定 `C=[1,0]`。本轮改成两条分支：

```text
图像 I → 冻结 DINO → 可训练视觉投影 pθ → 低维向量 y
真实状态 x → 可训练、逐行归一化的 C → 名义低维向量 Cx
                                      ↓
                      训练时匹配 y 与 Cx
                      冻结后校准 y−Cx 的误差
                                      ↓
                 控制接口适配 → 新轨迹 CP → 神经 SBC 重验证
```

真实状态只用于训练、校准和验证，部署的视觉分支不读取真实位置。车道曲率和 AEBS 速度仍按原实验设定作为额外已知量输入控制器。

参考原实现：`VISION-SLS/perception_utils/networks.py` 的 `SupervisedDinoObservability` 将 `C` 注册为可训练参数；`VISION-SLS/expe/hardware/train_observability.py` 的 `loss_uni` 使用

\[
\bar C_i=C_i/\|C_i\|_2,\qquad
L(\theta,C)=\frac1N\sum_i\|p_\theta(\operatorname{DINO}(I_i))-\bar Cx_i\|_2.
\]

本轮使用这条实际启用的匹配目标。原文件中 Gramian 可观测性正则被注释，本轮也没有启用它。**不能因此声称已经实现完整 VISION-SLS 的 SLS 控制综合或原论文全部可观测性设计。**车道保留适合空间位置识别的 patch 空间读出网络，AEBS 保留 CLS 特征 MLP，因此是按原理做任务适配，而非逐层复制原网络。

## 2. 车道：每一步的输入与输出

### 第一步：准备冻结特征与状态

- 输入：3,600 张 192×192 道路渲染图，以及横向偏差 `e`、航向误差 `θ`；每张图已有冻结 DINOv2-S/14 的 256×384 patch 特征。
- 状态归一化：`x=(e/0.85, θ/0.30)`；两维安全域为 `[-1,1]²`。
- 划分：2,160 训练、540 验证、540 静态校准预留、360 静态测试。后两部分不参与选择 C。
- 输出：固定特征、状态和数据划分。后续真正的**轨迹级 CP 使用重新生成的闭环轨迹**，不把这 540 张独立图片当成轨迹校准。

### 第二步：同时优化视觉投影与 C

输入是冻结特征和训练状态。保留已有视觉头作为 warm start，初始 C 设为旋转矩阵：

\[
C_0=\begin{bmatrix}0.8660254&0.5\\-0.5&0.8660254\end{bmatrix}.
\]

为了让起点对应原预测，把视觉头最后一层同步变换到这个坐标系。**这一步旋转本身不算“学到了 C”。**之后将视觉参数与未归一化 C 一起放入优化器，执行 30 个 epoch；每步重新逐行归一化 C，记录梯度与矩阵变化。

用验证集的解码状态误差选择检查点，并事先规定条件数不能超过 10。条件数描述矩阵逆运算对误差的放大：接近 1 较稳定，很大意味着两行接近重复、难以还原状态。逐行单位范数只能阻止零行，**不能单独阻止两行塌缩成同一个方向**。

实际选择第 29 个 epoch，得到：

\[
C=\begin{bmatrix}0.86586398&0.50027955\\-0.49891353&0.86665177\end{bmatrix}.
\]

- 与初始化的 Frobenius 距离：0.00129498，且 C 梯度非零。
- 视觉参数变化 L2：0.732333。
- 最小奇异值约 0.999211，条件数 1.001578。

因此两部分确实共同更新，但 C 的变化较小，不能夸大成“自动发现了一个完全不同的观测结构”。

输出：`joint_observation.pt`、训练协议、每轮历史、静态预测和报告。代码见 [车道联合训练](../../artical-F122/Aebs/lane_keeping/train_joint_observation.py)、[模型与接口](../../artical-F122/Aebs/lane_keeping/joint_observation.py)。

### 第三步：适配原控制器，不偷换输入含义

原控制器接收 `(估计 e/0.85, 估计 θ/0.30, 曲率)`。新视觉头输出的是 y，不能直接把 y 当作这两个状态坐标。

本轮使用显式接口：

\[
\pi_{\rm new}(y,\kappa)=\pi_{\rm old}(C^{-1}y,\kappa).
\]

输入：视觉低维向量、冻结 C、已知曲率。输出：原范围内的转向动作。这是**控制器坐标适配，没有新一轮 PPO 训练**；名义状态下 `C⁻¹Cx=x`，所以保持原名义控制行为。视觉误差仍然真实影响动作，不是用真实状态替代视觉。

这个方案要求 C 可逆。若将车道两维状态压成一维，仅靠这个接口就无法恢复状态，需要历史观测器或另一套控制设计，不能直接套用本轮结果。

### 第四步：先冻结，再生成新闭环轨迹

输入：冻结后的新前端、原语义控制器、C 的逆接口、原渲染器与动力学。

协议在采集前落盘并记录模型和源代码哈希：199 条校准轨迹、100 条随后采集的留出轨迹，各 80 步；初始状态独立均匀采样于原初始盒，曲率从 `{-0.01,0,0.01}` 均匀抽取，并在每条轨迹内固定。相机、光照和无噪声设定沿用原名义实验。

**每一步重新根据当前状态渲染图像，再运行 DINO 和新视觉投影。**这不是拿旧闭环图像轨迹重新打分。失败或越界轨迹也保留，不能删除后再算 CP。

输出包含真实状态、原始 latent、解码观测、动作、误差和每条轨迹的图像摘要。

### 第五步：在明确的误差坐标中做轨迹 CP

原始 latent 误差是 `r=y−Cx`。本轮选取冻结的度量：

\[
s_j=\max_{t<80}\|C^{-1}p_\theta(I_{j,t})-x_{j,t}\|_\infty.
\]

在实数代数下，它等于 `max_t ||C⁻¹r_t||∞`。每条轨迹只产生一个分数，因此允许轨迹内任意时间相关性；需要交换性的是不同完整轨迹的分数。

199 条校准分数取第 `ceil((199+1)×0.95)=190` 小值为 q，不裁剪、不为了通过 SBC 人为缩小。先保存 q，再采集 100 条留出轨迹。

这对应原 latent 空间的集合：

\[
\mathcal E_y=\{C\delta:\|\delta\|_\infty\le q\}.
\]

它通常是平行四边形，**不是原 latent 每一维都取 ±q 的轴对齐盒**。程序同时保存原始误差和解码误差，报告两种写法因浮点运算产生的差异。未给出向外舍入的浮点实现证明。

### 第六步：在新 q 下重新验证原神经 SBC

输入：原神经 SBC、原语义控制器、新 q，以及接口关系。

\[
\pi_{\rm new}(Cx+C\delta,\kappa)=\pi_{\rm old}(x+\delta,\kappa).
\]

因此原连续盒验证器可以检查 `||δ||∞≤q`；这是明确的实数坐标等价关系。新报告绑定 C、视觉检查点、控制器、SBC 和新 CP 合同，不能只贴旧验证结果。

若出现正漂移见证，表示**当前这个 SBC**无法证明新误差集合；不自动表示实际轨迹一定越界，也不表示所有其他 SBC 都不可能存在。若仅有未解决区间，表示数值界还不能作结论，不能写成通过。

## 3. AEBS：为什么需要单独适配

两种 AEBS 图片库只有距离标签。若只用一维状态 d 并把标量 C 归一化，C 几乎只能取 ±1，无法作为有意义的连续联合学习实验。

本轮沿用 AEBS 原来的两维状态 `x=(d/S,v)`，学习 1×2 矩阵 `C=(C_d,C_v)`，图像头仍只输出一维 y。**没有伪造“采集到了速度标签”的说法。**我们明确采用静态图片库假设 `I=I(d,外观)`：对同一张图片配辅助速度 `0、1.5、3 m/s`，训练目标为：

\[
y\approx C_d d/S+C_vv.
\]

同一图片不能同时给出不同 y，损失会推动不可从单帧图片识别的速度项变小。它是对当前静态观测模型的适配，不能用于声称动态模糊、连续视频或真实相机中的速度可观测性。

部署时：

\[
\hat d/S=(y-C_vv_{\rm measured})/C_d.
\]

加上实测速度后，整体观测矩阵是 `[[C_d,C_v],[0,1]]`，只要 C_d 不接近零就可以还原两维控制输入。程序要求 `|C_d|≥0.2`。

训练、控制适配、CP 依次为：

1. 输入原 DINO CLS 特征、距离标签和声明的辅助速度，联合优化视觉 MLP 与 C。
2. 固定训练预算，用训练内部的开发划分选检查点；该内部划分可能已被 warm-start 旧模型见过，不能叫全新盲测。原校准/测试图片不参与本轮检查点选择。
3. 图像库中的 `observation` 保存原始 y；控制时使用上面的速度解码公式。
4. 固定新图像库预测和控制接口，重新采样 199 条校准与 100 条留出初始状态，按外观组固定整条轨迹回放。
5. 分数取全程最大物理误差 `|S(y−C_d d/S−C_vv)/C_d|`，包括最近邻取图与实际状态不一致的误差。
6. 用新米制半径重新验证相同语义控制器与对应神经 SBC；记录连接到新前端的代数关系。

灰度前端的视觉 S=3.2378063202 m，旧 SBC 的状态尺度是 3.1827206612 m；两者不混用。RGB 两个尺度均为 3.1827206612 m。

AEBS 这里仍是**固定图片库回放**，不是在线运行 CARLA 后得到新图像。新轨迹是新的闭环状态/动作序列，并非新的相机采集。

实现：[AEBS 联合模型](../../artical-F122/Aebs/vision_sls/joint_observation.py)、[联合训练](../../artical-F122/Aebs/vision_sls/train_joint_observation.py)、[新回放 CP 与验证连接](../../artical-F122/Aebs/vision_sls/joint_replay_cp.py)、[原图＋实测速度部署接口](../../artical-F122/Aebs/vision_sls/joint_deploy.py)。有原图部署入口不等于已经验证新相机数据的分布。

## 4. 结果与对照

### 4.1 前端训练已经完成

| 实验 | 选中 epoch | 学到的 C | 结论 |
|---|---:|---|---|
| 车道 | 29 / 30 | 见上方 2×2 矩阵 | 两分支实际更新，C 可逆 |
| RGB AEBS | 39 / 60 | `[1.0, -0.0000084382]` | 静态图片模型下速度项趋近零 |
| 灰度 AEBS v2 | 507 / 1000 | `[0.99999809, 0.00193068]` | 两分支实际更新；仍存在图片误差长尾 |

灰度 v1 的 300 个 epoch 结束时，C 的速度项仍约 0.0745、开发误差仍在下降，因此在 CP 之前增加训练预算做 v2；v1 保留。没有根据轨迹校准或留出覆盖率选择这次延长训练。

### 4.2 同预算车道消融：目前不能宣称联合 C 优于固定 C

| 设置 | 静态测试横向 MAE | 静态测试航向 MAE | 最大归一化坐标误差 |
|---|---:|---:|---:|
| 原视觉头 | 约 0.02111 m | 约 0.005884 rad | 见原报告 |
| 额外训练 30 epoch，固定初始旋转 C | 0.017918 m | 0.005139 rad | 0.118784 |
| 额外训练 30 epoch，联合 C | 0.018018 m | 0.005140 rad | 0.114197 |

固定 C 与联合 C 的平均误差非常接近，固定 C 甚至略好；联合 C 在这一次测试的最大误差较小。**这是单种子结果，不足以证明统计显著优势，更不能把相对原视觉头的全部改善归因于 C 的联合学习。**消融不用于切换已经冻结并开始采集的联合 C 主实验。

从原理上也要克制：本轮车道 C 是可逆的 2×2 矩阵，控制前又经过 C⁻¹，因此名义作用主要是换一个观测坐标系；视觉头和 C 之间还存在共同旋转等不唯一性。仅仅得到一个非单位矩阵不能构成“学习到更好可观测性”的证据。本轮确认了联合训练、误差集合和原 SPVC 验证接口能够衔接；后续若主张性能贡献，应增加多种子、真正降维/部分可观测设置，或预先规定的可观测性/控制相关训练目标，并使用新的校准与留出数据验证。

## 5. 最后能得到什么安全保证

需要两层条件同时成立：

1. **统计层：**前端、C、控制器、评分函数和采样协议在校准前固定，完整轨迹分数满足交换性，轨迹 CP 给出一条新的同分布轨迹全程落在误差集合中的边际概率至少 95%。这不是“对每个固定初始状态都至少 95%”，也不是“给定某一次校准样本后一定达到 95%”。
2. **控制层：**对所用误差集合内的所有允许后继，非负神经 SBC 满足初始 B≤1、危险 B≥20、活跃过程 B 不增，并覆盖可能的首次越界后继。沿满足误差前提的轨迹，B 从不超过 1，不能到达要求 B≥20 的危险集。这里使用比期望漂移更强的逐后继不增检查。

两层连接后，才可讨论注册分布与注册时长下的边际安全表述。它不是把“CP 95%”和“SBC 95%”简单相乘；本轮区间检查对应的是误差前提成立时的逐后继安全。

还必须说明**证书发布的选择问题**：如果只在某次校准结果使 SBC 通过时才发布，直接得到的是 `P(发布且不安全)≤0.05`，不能未经分析就改写成 `P(不安全 | 已发布)≤0.05`。反复调整前端、误差度量或筛选校准集直到通过，也不能继续沿用同一次 CP 的名义覆盖。本轮保持新校准后的前端和阈值冻结，失败项照实保留。

这沿用 SPVC 的“名义低维观测＋误差集合＋神经非负 SBC＋连续域验证”路线，但使用适配后的停止过程/不增条件，不声称原论文严格下降参数和原实现原样不动。数值验证没有向外舍入，结论限定为数学网络的连续域数值审计，不是完整 IEEE 浮点形式化证明。

**车道**只覆盖注册的道路渲染、相机、曲率集合和 80 步；**AEBS**只覆盖冻结图片库及注册最近邻回放分布和停止规则。天气、相机、道路、控制器或 C 改动后，需要重新校准并检查。一个实验未通过，不撤回其他旧版本按各自合同获得的结论。
