本文服务于一个明确目标：把 SPVC 的原视觉前端替换为“DINO 特征、低维视觉投影、状态到低维观察的代理”，覆盖实际视觉观察与代理之间的误差，并保留神经控制器和神经非负 SBC 的安全验证路线。最终要回答：**这种替换相对原方法到底带来了什么收益，收益来自哪里，有什么理论和实验依据？**

建议优先争取的论文结论是：在同样的任务、安全覆盖要求和实验预算下，新视觉观察抽象降低了控制与验证必须处理的有效感知不确定性，从而提高获得证书的比例，或扩大可认证的工作范围，同时保持任务性能。上述内容是待检验的主张，不是预定的实验结果。

联合学习 C 是一个独立的消融问题。即使联合 C 没有明显优于固定 C，也不自动否定整个前端替换方案；但不能继续把“学习 C 的独立收益”作为已经得到的贡献。

## 1. 先区分三种不同的证明任务

| 任务 | 通俗含义 | 需要交付的证据 | 单靠什么还不够 |
|---|---|---|---|
| 方法正确性 | 替换之后，证书确实对应实际视觉闭环 | 观察接口等价关系、误差集合、SBC 条件、概率假设、实现审计 | 某次仿真没有碰撞 |
| 整体收益 | 相同任务下，新方法比原 SPVC 更有用 | 公平基线、多次重复、证书与任务指标 | 新方法自己通过一次 |
| 组件贡献 | 提升究竟来自 DINO、训练预算、C，还是误差集合设计 | 每次只改变一个主要因素的消融 | 不同版本各挑最好的一次 |

“证明方法有效”和“证明方法优于基线”是两件事。正确性可以通过推导与验证建立；普遍优于原方法不能从网络结构直接推出，要通过规定任务上的实验支持。

也不能把“覆盖代理误差”本身全部写成新贡献：原 SPVC 已有代理与不确定性处理的思想。新工作应具体说明观察抽象、误差校准方式、验证接口及其效果有哪些改进。原方法的口径以项目中的 [SPVC 原论文](../references/720_file_Paper.pdf) 和对应实现为准。

## 3. 收益需要在哪个坐标里比较

### 3.1 区分真实状态、归一化状态和低维向量

为避免单位混乱，本文用 z 表示物理状态，用 x 表示送入模型的归一化或已明确缩放的状态。

车道当前有：

\[
z=(e,\theta),\qquad x=(e/0.85,\theta/0.30).
\]

低维观察为：

\[
y=p_\theta(\operatorname{DINO}(I)),\qquad y_{\rm nominal}=Cx.
\]

原始低维残差为 \(\varepsilon_y=y-Cx\)。当前车道控制器真正使用的误差为：

\[
\delta=C^{-1}y-x=C^{-1}\varepsilon_y.
\]

所以当前 q 是归一化状态坐标的无量纲半径。若 \(\|\delta\|_\infty\le q\)，对应的物理误差界分别是 \(0.85q\) 米和 \(0.30q\) 弧度。报告不能把 q 直接当成米，也不能把米和弧度的误差直接相加。

AEBS 的一维视觉残差通过 C 和速度接口解码后，统一转换成距离误差，单位是米。不同前端的视觉归一化尺度与 SBC 的状态尺度要分别记录。

### 3.2 为什么不能只比较原始低维误差

如果把视觉输出和代理同时乘以 0.1，原始残差也会缩小为原来的 0.1 倍，但控制前除回来以后，预测、动作和安全性可能完全不变。

更一般地，对任意可逆矩阵 T，设：

\[
p'=Tp,\qquad C'=TC.
\]

则：

\[
(C')^{-1}p'=C^{-1}p,
\qquad
(C')^{-1}(p'-C'x)=C^{-1}(p-Cx).
\]

这是直接的代数恒等式。对于当前采用逆变换的控制接口，两种表示可以产生完全相同的动作和 CP 分数。逐行归一化 C 能排除部分缩放自由度，但并不能消除所有等价表示。

因此本计划比较的是解码后的有效误差和真实闭环结果。联合训练 C 可能改善训练过程、误差方向或控制相关表示，但这些都不能由“C 变了”直接推出。

## 4. 需要整理成论文命题的理论部分

本节是针对当前框架拟整理的命题与证明思路。它们不是已经证明“新方法必然优于旧方法”的定理，也不代替实现中的数值审计。

### 4.1 命题一：代理误差集合覆盖实际视觉输入

固定前端、C、控制器和状态定义。若在某一步有：

\[
\varepsilon_y=p_\theta(\operatorname{DINO}(I))-Cx\in\mathcal E_y(x),
\]

那么实际后继：

\[
x^+=f\bigl(x,\pi(p_\theta(\operatorname{DINO}(I)))\bigr)
\]

属于验证器需要检查的后继集合：

\[
\mathcal F(x)=\{f(x,\pi(Cx+\varepsilon)): \varepsilon\in\mathcal E_y(x)\}.
\]

证明只需要代入 \(p_\theta(\operatorname{DINO}(I))=Cx+\varepsilon_y\)。如果模型还包含动力学扰动，后继集合也必须覆盖它；不能只覆盖视觉误差，却对未建模动力学误差作保证。

这说明验证代理有意义的原因：不是假设代理和实际视觉完全一样，而是把它们的差异显式纳入后继集合。

当前车道取：

\[
\mathcal E_y(x)=\{C\delta:\|\delta\|_\infty\le q\},
\quad
\pi_y(y,\kappa)=\pi_0(C^{-1}y,\kappa),
\]

于是 \(\pi_y(Cx+C\delta,\kappa)=\pi_0(x+\delta,\kappa)\)。低维空间中的集合通常是平行四边形，不应误写成每维都取 ±q 的轴对齐盒。

### 4.2 命题二：更小的允许后继集合不会破坏已有鲁棒证书

更一般、也更方便跨表示比较的条件是：对同一个状态 x，新旧闭环抽象的后继满足：

\[
\mathcal F_{\rm new}(x)\subseteq\mathcal F_{\rm old}(x).
\]

若同一个 B 已对旧集合证明 \(B(x^+)\le B(x)\)，则对新集合当然仍成立，因为新集合中每一个后继都已经被旧检查覆盖。初始集、危险集及其 B 条件必须相同。

当动力学、名义观察和控制接口都相同时，\(\mathcal E_{\rm new}(x)\subseteq\mathcal E_{\rm old}(x)\) 是上述后继包含关系的一个充分条件。C 或控制器改变后，不能只比较低维集合体积，就声称满足包含关系。

通俗例子：一个证书已经应对了距离估计 ±0.5 米的全部误差，那么它也能应对 ±0.3 米；但若同时换了控制器，或者换了“米”的含义，就需要重新检查。

本命题支持“较紧的有效误差集合有利于证书可行性”，不支持以下过度推论：

- 平均误差更小就一定有更小的 CP 集合；轨迹最大误差可能受长尾支配。
- 集合体积更小就一定被旧集合包含；方向和形状也很重要。
- 验证一定更快；细分策略与数值松弛会影响运行时间。
- 当前验证失败就证明不存在其他控制器或 SBC。

### 4.3 命题三：误差事件成立时，逐后继 SBC 条件保证安全

设初始集为 \(X_0\)，危险集为 \(X_u\)，在完整的适用状态域上有：

\[
B(x)\le a\quad(x\in X_0),\qquad
B(x)\ge b\quad(x\in X_u),\qquad a<b.
\]

当前实验常采用 a=1、b=20。再假设对每一个允许的活跃状态及允许后继，都有 \(B(x^+)\le B(x)\)。

若真实轨迹全程误差落在集合内，命题一保证每一步实际后继都属于验证集合。递推得到 \(B(x_t)\le B(x_0)\le a\)。如果某一步进入危险集，又必须有 \(B(x_t)\ge b>a\)，矛盾，因此不会进入危险集。

这里必须包含“可能第一次越界的后继”，不能只验证仍留在安全区域内部的下一状态。证明域、终止规则及终止后的处理也必须完整：若到达目标后停止推理，要明确系统也停止、进入可证明安全的吸收状态，还是继续由另一套控制规则接管。

这一论证证明安全，不自动证明按时到达目标。当前逐后继不增条件比期望漂移条件更强；不能直接套用原随机屏障的概率公式而不核对前提。

### 4.4 命题四：轨迹 CP 与条件安全的连接

冻结评分规则，给每条完整轨迹一个分数。当前车道使用：

\[
s_j=\max_{0\le t<T}\|C^{-1}y_{j,t}-x_{j,t}\|_\infty.
\]

对 n 条校准轨迹，令 \(k=\lceil(n+1)(1-\alpha)\rceil\)。当 k≤n 时，q 为第 k 小的校准分数；当 k>n 时，采用无穷大阈值，不能强行改成有限最大值。n=199、α=0.05 时 k=190。

在冻结模型和评分函数、校准与新轨迹分数可交换等条件下，分割 CP 给出新轨迹 \(s_{\rm new}\le q\) 的边际概率至少为 \(1-\alpha\)。轨迹内部可以相关；需要适当随机化和可交换性的是完整轨迹之间的采样。基础依据见 [CP 综述](https://arxiv.org/abs/2107.07511)，控制与验证中的使用边界可参考 [Formal Verification and Control with Conformal Prediction](https://arxiv.org/abs/2409.00536)。

如果对相应集合的鲁棒证书成立，命题三把“误差被覆盖”连接到“轨迹安全”。但发布选择必须单独处理：令 A 表示这次校准后证书被接受，则在上述有效性前提下可得到：

\[
\Pr(A\cap\{\text{不安全}\})\le\Pr(s_{\rm new}>q)\le\alpha.
\]

这不是 \(\Pr(\text{不安全}\mid A)\le\alpha\)。例如只公布恰好获得很小 q 的运行，会改变被公布结果的分布。不能反复挑选模型、校准种子或样本，直到通过后还直接沿用普通 CP 的名义保证。

主实验保留所有预登记运行及其失败结果，准确报告边际 CP 和条件 SBC。若论文要求对某个已经冻结发布的系统给出高置信度覆盖下界，可另设独立审计：固定系统和已经验证的半径 r，采集独立同分布轨迹，用二项分布的单侧置信下界审计 \(\Pr(s\le r)\)。这是额外的统计证据，与 CP 的边际结论不同；样本量和置信水平应事前确定，不能一边看下界一边随意停止。

## 5. 收益指标及其正确解释

### 5.1 主指标

| 指标 | 计算与输入 | 要回答的问题 | 解释限制 |
|---|---|---|---|
| 有效校准半径 q | 相同评分函数、时长和 α 下的新轨迹 CP | 真实闭环需要覆盖多大的观察误差 | 不能跨单位、度量直接比；更小不自动等于更好 |
| 完整证书通过比例 | 通过的预登记运行数／所有预登记运行数 | 同预算下能多稳定地获得证书 | 必须把失败和超时留在分母中 |
| 已验证容许半径 r_cert | 固定控制器、B、任务，在预登记半径点完成验证 | 当前候选能容忍多少不确定性 | 是已知下界，不一定是真正最大半径 |
| 容忍余量 M | 同一误差集合族下 r_cert/q | 实际误差需求离已验证能力还有多远 | q>0 才定义；形状不同不能直接相除 |
| 可认证工作范围 | 预先给定初始集／速度配置中的通过情况 | 新方法能否支持更难的任务条件 | 改动任务后重新检查动力学和校准分布 |

一个示意：旧前端 q=0.12，新前端 q=0.08，同一控制器与 B 已验证 r=0.10，则新前端落入已验证的容忍范围，旧前端尚未获得这项覆盖。数字仅用于说明，不是本项目新结果。

特别注意：在当前车道固定语义控制器、固定 B、共同解码盒的比较中，验证问题只由 q 等参数决定。若给固定 C 和联合 C 相同 q，二者后端实际是同一个验证问题，r_cert 理应相同。此时收益只能来自实际需要的 q 改善，不能另算一次“C 让验证器更强”的收益。

### 5.2 控制性能与计算成本

同时记录任务完成率、碰撞／越界率、超时率、完成时间，以及车道横向误差与转向变化、AEBS 停车距离和制动行为。成功、危险、未完成应按注册规则清楚区分；覆盖失败是另一维度，可以发生在成功轨迹上。

在不会碰撞但永远不完成任务的情况下，不能宣称控制整体更好。安全证明也不能代替到达目标的证明或经验完成率。

计算成本拆成：前端训练、控制器与 SBC 训练、轨迹采集与 CP、连续域验证、运行时单帧推理。记录机器、设备、线程、峰值内存／显存、总耗时和推理中位数／高分位延迟。缓存特征的训练时间不包含在线 DINO 的代价，二者必须分开。

### 5.3 诊断指标

静态 MAE、RMSE、95/99 分位误差、最大误差、C 的条件数、不同状态位置上的误差分布有助于解释原因，但不替代主指标。最大误差要注明样本数量；样本越多，看到更大的最大值并不奇怪。

CP 留出覆盖率与二项置信区间用于检查数据表现。93/100 或 91/100 不能写成“实测达到 95%”；有限样本低于 95% 也不单独证明 CP 定理失效，应结合区间、协议和跨运行证据分析。

## 6. 两组对照分别回答什么问题

### 6.1 对照一：尽量固定控制后端，隔离前端收益

| 编号 | 前端与代理 | 控制器／SBC | 主要用途 |
|---|---|---|---|
| A-native | 原 SPVC 的原方法链路 | 原生设置，严格标注 | 保留原方法的端到端基线 |
| A-matched | 能实现共同语义接口的原前端，配相同误差审计口径 | 与 B、C 相同 | 尽量隔离前端替换的收益；这是受控适配基线 |
| B | DINO＋视觉投影＋固定 C | 固定同一个语义控制器和神经 B | 新前端的基本版本 |
| C | DINO＋视觉投影＋联合学习 C | 固定同一个语义控制器和神经 B | 学习 C 的额外贡献 |
| D，可选 | 与 C 同一前端，改为训练期拟合的状态相关误差几何 | 控制后端尽量不变 | 集合形状的额外贡献 |

当前优先只做 B 与 C。原 cGAN 是否能在车道上提供语义一致、预算合理的基线，需要先核查；不能把 AEBS 的旧 cGAN 检查点直接拿来当车道基线。如果无法构造 A-matched，就保留 A-native 的整体比较，并明确它不能单独隔离前端因素。

原方法本身的保证口径与统一审计口径应分别列出。给原方法加上新的轨迹 CP 后，它已经是一个用于控制变量的适配版本，不能再称为未经修改的原论文复现。

### 6.2 对照二：允许各自训练，比较完整方法的能力

各版本使用同样的动力学、观察数据预算、控制信息、目标和危险集，独立训练控制器与神经 SBC。控制器容量、SBC 容量、环境交互步数、反例反馈轮数、超参数搜索次数和验证时限应相同，或明确给出预算曲线。

该实验回答“整套方法是否更容易得到实用的安全控制器”。它不能直接说明全部提升来自视觉前端；归因仍依赖对照一。

最后用于正式轨迹 CP 的控制器必须已经冻结。若验证失败后利用反例继续更新控制器，则新的闭环分布改变，必须进入新的开发轮次，并为最后选定模型重新准备未使用的校准与测试数据。只更换 B 而不改变控制动作不会改变轨迹分布，但证书选择与发布仍按第 4.4 节解释。

## 7. 数据与公平性协议

### 7.1 数据分成不同用途

| 数据 | 用途 | 能否据此调整模型 |
|---|---|---|
| 前端训练集 | 更新视觉头、C，拟合状态误差尺度 | 可以 |
| 开发／验证集 | 选检查点、超参数、控制与验证预算 | 可以，但结果属于开发表现 |
| 正式轨迹校准集 | 计算冻结评分函数的 CP 阈值 | 不再用它选择前端、控制器或误差形状 |
| 正式盲测轨迹 | 评估覆盖、控制性能和统计差异 | 不可以；看过后用于修改则变成开发数据 |

原有测试与留出数据已经被多轮查看，应视为历史回归证据。新阶段正式结论使用新的随机流和完整轨迹。若要声称新场景泛化，还应按采集轨迹、场景、天气或资产来源分组划分，避免相邻帧或同一图片变体同时出现在训练和盲测中。

### 7.2 配对比较如何进行

同一对 B、C 采用同样的训练划分、warm start、训练随机种子、初始状态以及外部环境随机条件。这样差异更容易归因于是否学习 C。

但是后续状态、动作和图像必须由各自闭环产生。不能让 C 使用 B 已经行驶出来的图片轨迹，然后称为 C 的真实闭环评估。

配对依赖显式的初始状态／环境清单，不能仅靠传入同一个 seed。不同算法消耗随机数的次数可能不同；环境噪声应按“轨迹编号、时间步、随机因素”管理，避免随机流错位。校准与留出使用不同的随机流；方法之间可以共享外部条件以实现配对。

### 7.3 必须冻结的项目

冻结记录至少包括：数据及划分、图像预处理、DINO 权重、视觉投影、C、状态尺度、控制器、动力学、危险集、初始分布、曲率／速度配置、时长、终止规则、CP 分数、α、误差尺度拟合规则、采样种子、验证算法与预算。

使用文件哈希绑定。模型和源码都应归档。冻结只是保证流程一致，不会自动建立新相机数据与已有图片库的交换性。

### 7.4 预算一致究竟指什么

固定 C 与联合 C 应保持相同训练图像、特征缓存、视觉头结构、初始化、batch、优化器、学习率、epoch 上限和检查点选择规则。两者选择不同 epoch 可以接受，因为使用同一开发选择规则；不能事后为较差版本额外挑一套规则。

DINO 预训练资源与原 cGAN 的预训练资源不相同，应披露。公平的下游训练预算不意味着基础模型的预训练总成本相同。旧 400 图 cGAN 与新 24k 图前端的历史比较只能说明这些具体检查点的表现，不能单独证明架构优势。

## 8. 阶段一：补齐固定 C 与联合 C 的闭环试验

目的：先确认当前已有检查点之间的差别是否能延伸到 CP 和证书。这是流程先导实验，不能只凭这一对检查点写最终优势结论。

| 步骤 | 输入 | 具体操作 | 输出 | 验收条件 |
|---|---|---|---|---|
| 1. 绑定模型 | 已有 B、C 检查点、同一 actor、同一神经 B | 核对哈希、尺度、C 可逆性和实际控制输入 | 模型与接口清单 | 没有使用真实位置绕过视觉 |
| 2. 固定新协议 | 当前车道动力学与采样设定 | 保持 80 步、α=0.05、原初始盒与三种曲率，生成共同外部条件清单 | 新协议与配对编号 | 校准和留出随机流独立 |
| 3. 分别采集校准 | 两个冻结闭环、各 199 条外部条件 | 每步实际渲染、DINO 推理、控制和状态更新 | 两套轨迹、latent、动作、误差和分数 | 失败轨迹保留；未复用另一闭环的状态序列 |
| 4. 分别计算 q | 两组 199 个轨迹分数 | 各取第 190 小分数并冻结 | 两份 CP 合同 | 不截断 q，不筛除长尾 |
| 5. SBC 审计 | 同一 actor、B，各自 q | 相同连续域验证器、初始参数、精度与时限 | 验证报告、见证或未解决区域 | 通过必须满足全部条件且无未解决区域 |
| 6. 独立留出 | 各自冻结系统与 q，各 100 条配对条件 | 各自生成新的闭环轨迹 | 覆盖、越界、控制表现、置信区间 | 原始结果完整，测试后不改阈值 |
| 7. 汇总差异 | 两套完整结果 | 比较 q、证书状态、控制指标和耗时 | 一张对照表和诊断图 | 结论仅限这一对检查点 |

原联合 C 的已有 199/100 结果继续保留为历史证据。新的配对先导应给两组使用同一批新外部条件，避免只给固定 C 新采样，却拿另一随机批次的联合结果来归因。

如果出现提前终止，必须按注册停止过程处理。车道以检查的 80 步后继为准；AEBS 若安全停止后进入吸收状态，要明确分数如何延拓。危险终止不能删掉，渲染或文件损坏造成的基础设施失败也应单独留痕，不能只保留成功采集的轨迹。

## 9. 阶段二：多种子重复与统计比较

### 9.1 规模与执行顺序

先导完成并冻结正式协议后，建议先做 5 对训练种子，每对包含固定 C 和联合 C。每个版本各做 199 条校准与 100 条新留出；这是可行性与跨种子一致性评估，不承诺具有足够统计功效证明很小的改善。

如果需要更精确的控制成功率或罕见失败估计，可在正式采样前将每版本留出规模定为 500 条，或依据先导差异进行样本量设计。是否扩样依据预定的精度／资源规则，不以“显著了没有”为临时停止条件。

按 5 对、2 个版本、299 条、每条 80 步计算，上限约为 239,200 次图像观察推理，不包含额外的运行时测量和任务难度扫描。先测一小批端到端速度，估算资源后再排队；这不是已开始的服务器任务。

### 9.2 统计单位与配对分析

- 前端训练方法之间的总体差异，以训练种子为主要重复单位；不能把同一个模型的几万帧当成几万个独立训练实验。
- 覆盖率和成功率的基本观测单位是轨迹，不是帧。轨迹内连续帧高度相关。
- 每个训练种子内比较配对外部条件下的轨迹表现；跨种子先形成每对差值，再汇总。
- q 的差异主要报告跨种子配对差值、分布与不确定性。若对校准数据重采样估计不确定性，应按完整轨迹重采样并重算分位数；这只是统计分析，不替换已冻结的部署阈值。
- 成功／失败可报告配对不一致次数及恰当的配对检验；连续指标可使用轨迹与种子层级的重采样分析。只有 5 对种子时，图示和区间比强行宣称显著更重要。

每个运行的覆盖率报告实际分子分母与二项置信区间。不同模型具有不同覆盖概率时，不能把所有帧或所有异质模型的轨迹简单合并成一个二项样本，掩盖模型间差异。

### 9.3 预登记主指标

对固定 C 与联合 C 的首轮对比，建议主指标为共同坐标下的 q 差异，同时把控制完成表现作为必须报告的约束指标。证书通过比例和容忍余量作为直接关联安全验证的结果。

对于“整个新方法相对原 SPVC”的正式比较，建议主指标改为相同预算下的证书通过比例，或预登记难度网格中的通过范围。不要实验结束后从几十个指标里挑唯一变好的一个当主结论。

是否具有实际价值，还需要预先确定最小改善幅度或控制性能可接受退化幅度。阈值应根据任务意义与先导噪声确定，然后冻结；不能把任何极小数值差都称为实质收益。

## 10. 阶段三：扫描已验证容忍范围与任务难度

### 10.1 先扫描误差半径，保持任务不变

固定 actor、B、动力学、初始集、危险集和验证配置，选定一组归一化半径，例如 0.04、0.06、0.08、0.10、0.12、0.16，另外包含实际 q。该网格是建议开发起点，正式版在看新对照结果前冻结。

对每个半径独立记录：通过、存在实际见证、未解决、超时或运行错误。取通过点中的最大值作为已验证容许半径 r_cert。没有通过点时记“未建立”，不能伪造为已经验证的零半径。

当前候选的真实鲁棒条件对嵌套半径具有单调性，但有限预算验证器的“是否及时给出通过”不一定表现为严格单调。不能把一次未解决当成真实边界，再盲目二分宣称找到最大值。

在相同语义 actor、B 和盒集合下，B 与 C 共用这份容忍扫描即可；无需重复同一数学问题，再把重复运行的时间差当成算法提升。

### 10.2 扩大可认证初始范围

从当前初始盒出发，用参数 ρ 定义一组嵌套初始盒，始终限制在合法状态域内，其他任务条件保持不变。比较各方法在同一 ρ 下的证书结果。

每当初始采样分布改变，真实闭环访问的状态分布也会变，不能默认沿用旧 q。可以对每个预登记初始分布独立校准，或者预先设计统一的混合分布并明确保证只针对该混合分布。混合分布下的边际保证不自动变成对每一个子区域的保证。

扩大初始集还需要重新检查初始 B 上界；不能只复用漂移验证。若仅旧 B 的初始上界失败，应明确这是当前候选证书的限制，而不是任务一定不可安全控制。

### 10.3 改变速度是更高成本的第二层实验

车道提高速度会改变动力学和控制难度。每个速度点必须同步用于仿真、控制接口、校准与验证；必要时按同预算重新训练控制器和 B。

当前部分参数位于代码常量中，因此速度扫描需要先改造成显式配置并校验所有模块一致读取。不能只在渲染器或仿真中改变速度而复用旧动力学证书。

对于多个速度点分别获得的保证，不能未经处理声称整个连续速度区间或同时所有场景都满足同一个概率下界。连续范围需要对应的连续域验证，统计多重声明也要明确范围。

## 11. 阶段四：RGB AEBS 复现与原 SPVC 基线

### 11.1 RGB AEBS 的固定 C 与联合 C

保留当前冻结图片库、外观组、最近邻取图规则和实测速度假设；配对初始状态和外观组，重新生成各自闭环。固定 C 与联合 C 使用同一 RGB 输入和相同视觉训练预算，再接相同语义控制器与 B 做首轮比较。

输入为原图或经过来源校验的冻结 DINO 特征、距离标签、声明的辅助速度、原控制器与 B。输出为各自的训练检查点、物理距离残差、轨迹 CP 合同及证书报告。

辅助速度 0、1.5、3 m/s 是静态图片模型下的训练设计，不是相机测得的速度标签。同一图片不随这些辅助速度改变，C 的速度项趋近零不构成“从图像学会估计速度”的证据。

原固定 C 版本 q≈0.41836 m、联合版本 q≈0.39452 m 来自不同采样；留出覆盖也不同。它们可以作为现象记录，不能直接宣布联合 C 带来确定改善。

### 11.2 原 cGAN 的公平基线

先核查原方法需要的数据与生成／感知接口，再决定以下两种呈现：

1. 历史检查点比较：保留原有数据量和模型，明确它是历史系统迁移表现，不用于架构因果结论。
2. 匹配训练预算比较：尽量使用同一批允许训练数据、同样的测试分组、相同调参次数和控制任务，训练原方法前端并运行完整审计。

若原方法包含多步网络而新方法只需要一个视觉头，应比较两条完整部署链路；不能只给原方法挑一个误差最大的中间模块。无法复现的部分如实说明，不用弱化实现来制造优势。

灰度与 RGB 的颜色消融，应先固定源图像、分辨率和后续处理，只改变颜色通道。现有“32×32 灰度”对“较高分辨率 RGB”同时改变颜色与输入信息量，不能把差异全部归因于颜色。

### 11.3 结果范围

当前 AEBS 支持的是冻结真实图像库的闭环回放分布。新的状态轨迹不等于新采集图片。若后续要声称适用于新 CARLA 图像、不同相机或真实车辆，需要相应的新采集与独立校准／评估协议；不在当前固定库收益实验中默认成立。

## 12. 阶段五：只有基础对照清楚后，再优化误差几何和训练目标

### 12.1 状态相关误差集合

全局常量 q 会把某些状态附近的极端误差允许到所有状态上。一个合理改进是训练期拟合正的尺度 b(x)，再以 \(\max_t\|\delta_t\|_\infty/b(x_t)\) 做轨迹 CP，形成 \(\|\delta\|_\infty\le q b(x)\)。

输入是训练／开发残差和真实状态；输出是冻结尺度函数、独立校准 q 和实际状态相关集合。验收要求：b(x) 在证明域为正，训练与正式校准分开，验证器直接验证该集合；不能为了让证书通过再人为加一个未校准的上限。

该集合主要用于离线验证：证明时可把 x 作为数学变量。若要在部署时根据 b(x) 动态调整控制而真实状态不可得，还需要额外的状态估计与保守评估，不能直接读取真实 x。

收益要与同样校准样本预算的常量集合比较。平均半径小但某些关键状态半径大，仍可能更难验证；集合形状不是越复杂越好。

### 12.2 控制相关的方向与训练损失

有些观察方向的误差更容易引起危险动作。可以在训练／开发阶段学习固定的加权度量，或者增加对动作变化、B 的后继增长的惩罚，让视觉模型更多关注控制敏感的误差。

它们是候选优化方向，不是现有实现或现成保证。度量必须非退化、尺度受约束，并在校准前冻结；降低损失仍要通过独立 CP 和完整 SBC 审计确认。

特别要防止把权重压到接近零、丢弃困难状态，或降低任务性能来获得“更小误差”。建议把这类方法作为新的 D 版本，与基础 C 版本分开，不在第一轮对照里同时更改多个因素。

### 12.3 灰度失败案例如何利用

保留造成长尾的原图、误差、访问轨迹和验证见证，分开检查：图像质量与标签、预测尾部、常量集合在未观测状态上的保守性、控制器对误差的敏感性、B 的表达与训练。

不能因某张图片让 q 很大就删除它，再称同一任务已解决。若确认标签或文件损坏并修复，需给出客观质量依据、版本记录，重新划分适用数据和校准；不能按预测误差大小决定保留哪些图片。

当前正漂移见证只否定当前 B 的对应条件。若需要证明控制器本身无法在该集合下安全，应展示从合法初始集出发、每一步误差均在集合内且确实到达危险集的完整轨迹；一个任意状态的一步 B 增长并不足够。

## 15. 验收标准与不同结果对应的论文结论

### 15.1 阶段完成不等于必须获得正收益

| 阶段 | 完成标准 | 不满足时如何处理 |
|---|---|---|
| 理论与接口 | 坐标、误差集合、后继、安全事件和适用域一致 | 先修接口，不能用错误口径继续刷实验 |
| 单对闭环 | 固定／联合各有完整新轨迹 CP、验证、留出和失败记录 | 修采集或报告，保留原始失败 |
| 多种子 | 预登记运行清单全部有结果或明确未完成原因 | 补齐缺失运行，不只留最好种子 |
| 容忍与难度 | 相同任务网格、相同预算、完整状态分类 | 无法判定的点单独标出 |
| 原方法基线 | 原生与受控适配口径区分，数据／预算透明 | 降低主张范围，不称已经证明优于原 SPVC |
| 论文证据包 | 表图、原始记录、哈希、保证前提能对应 | 不从日志片段拼凑最终通过结论 |

### 15.2 结果如何解释

| 可能结果 | 可以写的结论 | 下一步 |
|---|---|---|
| 新前端比原链路有更小有效 q，且更常通过，任务性能保持 | 支持前端替换对安全可认证性的改进 | 在第二场景复现，并补总成本 |
| 固定 C 与联合 C 没有稳定差异 | 联合训练可行，但独立性能贡献未建立 | 保留消融；主贡献放在整体观察抽象与误差衔接 |
| q 变小，但所有方法原本都通过且控制相近 | 只证明更大的误差余量，不证明证书获得率提高 | 做预登记难度扩展，检查是否转化为工作范围 |
| 静态 MAE 更好，轨迹 q 更差 | 长尾或闭环访问分布抵消了平均精度提升 | 检查困难状态，改进训练或集合形状 |
| 证书通过但任务完成率下降 | 安全验证有进展，整体控制收益不足 | 重新研究控制目标，不能只报安全数字 |
| 平均运行更快但 DINO 在线超出控制周期 | 离线成本改善不等于部署可用 | 压缩／缓存等设计需另行评估和重新校准 |
| 全部合理对照均无优势 | 当前组合缺乏所主张的性能收益证据 | 如实缩小论文主张，或引入新的控制相关方法后再评价 |

当前目标是得到可信答案，不是无限调整直到某一组图看起来有优势。每次方法变化都记录为新版本，保留已完成的失败和无显著差异结果。

## 16. 最终安全保证与论文表述边界

完成上述实验后，安全结论仍由三个部分构成：

1. 数学层：在声明的动力学和误差集合内，完整的 SBC 条件推出轨迹安全。
2. 统计层：在冻结模型、注册轨迹分布和相应可交换性条件下，轨迹 CP 控制新轨迹误差未被覆盖的边际概率；发布选择与跨场景声明按第 4.4、10.3 节处理。
3. 实现层：代码与合同一致、原图输入和单位正确、连续域检查完成。当前验证未给出向外舍入的浮点实现证明，因此结果称为条件 SBC 的连续域数值审计通过，不能升级为全计算栈形式化保证。

它不自动覆盖任意天气、任意相机、任意更长时域、未建模动力学或未登记速度，也不自动证明目标必达。需要拓展时，明确增加相应模型、数据和验证。

如果实验支持，可以使用这样的论文结果表述模板：

> 在所考察任务、统一轨迹覆盖目标和匹配的下游训练／验证预算下，所提出的低维视觉观察抽象降低了有效感知误差集合的规模，并改善了神经 SBC 的可认证工作范围；这些结论由配对多种子对照支持。理论部分说明代理误差集合如何把实际视觉闭环纳入 SBC 验证，并明确轨迹校准与条件安全结论的连接。

“降低了”“改善了”“支持”只有在相应结果完成后才能写进论文。学习 C 若没有独立收益，不在这段话中额外声称它提高了可观测性或控制性能。

## 17. 理论来源与本计划中的用途

| 来源 | 本计划借鉴什么 | 不直接继承什么 |
|---|---|---|
| [项目中的 SPVC 原论文](../references/720_file_Paper.pdf) | 视觉代理、不确定性、神经控制器和屏障证书的整体研究路线 | 不默认当前不增条件、停止过程与原论文每个定理完全相同 |
| [VISION-SLS](https://arxiv.org/abs/2604.24894) | 从预训练视觉特征学习低维观察，与状态代理匹配，处理观察不确定性 | 当前没有实现其完整 SLS 控制综合；论文中的优势不是本项目的结果 |
| [CP 基础综述](https://arxiv.org/abs/2107.07511) | 分割校准、有限样本分位数、边际覆盖及其前提 | 不提供任意分布偏移、任意模型选择后的条件保证 |
| [Formal Verification and Control with Conformal Prediction](https://arxiv.org/abs/2409.00536) | 统计不确定性与控制／验证连接时的整体分析视角 | 不代替本实验的数据交换性和具体 SBC 条件审计 |
| [CP-NCBF](https://arxiv.org/abs/2503.17395v2) | 将校准思想用于神经屏障可信性，关注不确定性与安全区域保守性 | 不把其有符号 NCBF 直接等同于当前非负 SBC；本文不是其定理的直接复现 |
| 本文第 3、4 节的代数和集合推导 | 坐标变换不变性、后继包含、逐后继安全归纳 | 这些基本关系不是“新方法必然更好”的创新性定理 |

与 VISION-SLS 和 CP-NCBF 的关系应写成具体设计来源，而不是把两篇文章的名称相加作为创新证明。论文价值仍需要可复现的观察接口、保证链条、方法设计与公平收益证据共同支持。

## 18. 术语速查与第一批执行清单

| 术语 | 在本计划中的意思 |
|---|---|
| 代理 | 用状态计算名义低维观察的模型，此处为 Cx；不是替代真实相机输入 |
| 有效误差 | 经过实际控制接口后真正影响控制的观察误差；当前车道是 C⁻¹y−x |
| 消融 | 固定其他条件，只改变一个组件，以判断该组件有没有贡献 |
| 配对实验 | 两个方法共享初始条件等外部因素，但各自生成闭环轨迹 |
| 交换性 | 完整样本的联合分布在置换顺序后不变；独立同分布是常用的充分条件 |
| 边际覆盖 | 对校准数据和新样本的联合随机性而言的覆盖概率；不是每个状态都满足相同概率 |
| 条件安全 | 误差确实在允许集合内等前提成立时，证明轨迹不会进入危险集 |
| 已验证容许半径 | 当前控制器和证书已成功覆盖的误差范围，不是已经知道的理论极限 |
| 正漂移见证 | 一个允许后继使 B 增加，反驳当前不增条件；不必然是一次真实碰撞 |
| 未解决区间 | 验证器尚不能判断的区域；不等于通过，也不等于已经找到反例 |
| 盲测 | 在模型和规则确定后才查看的最终评价；已据此调参的数据不再是盲测 |
| 发布选择 | 只发布满足某个结果条件的运行；可能改变条件概率，须单独处理 |
