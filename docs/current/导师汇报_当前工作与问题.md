# DINO双路径感知与安全控制研究进展汇报

汇报日期：2026年10月14日

## 一 当前在做什么

本项目以SPVC为基础，研究如何用更简单、误差更小的视觉表示替代原来的图像生成代理，并将真实图像与代理之间的差异纳入控制器的安全分析。

原SPVC的思路是：实际运行时，控制器根据摄像头图像做决策；离线分析时，根据物理状态生成一张替代图像，再计算控制动作和安全条件。两条路径之间存在差异，因此代理分析的结论能否用于真实图像路径，是需要处理的关键问题。

我们的修改是：不再生成整张替代图像，而是让真实图像和物理状态分别产生同一种低维表示，再交给同一个控制器。这样可以减少生成图像、压缩图像和重新估计状态带来的多层误差。

当前进度可以概括为：**前端替换和控制流程已经跑通，平均代理误差明显减小；原SPVC后端的同口径检查已有正面结果，但真实图像闭环的可靠安全保证尚未完成。最近正在尝试把屏障条件直接加入强化学习训练，接口已实现，暂时没有得到安全改善。**

这里需要区分两个问题：

1. 系统是否能完成控制任务，新的代理是否比旧代理更准确。
2. 是否可以证明，在明确的场景和误差范围内，真实图像控制系统具有所声称的安全性。

第一个问题已有实验支持，第二个问题是当前主线的主要难点。

## 二 研究任务和成功标准

### 车辆需要做什么

当前任务是自动紧急制动。车辆向前方障碍物运动，控制器根据观测和车速决定加速或制动，使车辆到达目标距离附近时已经足够慢。

实验中的物理状态包含两个数：车辆到障碍物的距离，以及当前速度。控制器输出一个动作，范围为−3到+3；在本项目中，正值表示制动，负值表示加速。

原任务初始范围为距离15至16米、速度2.5至3米/秒。目标是到达距离5至6米的区域时，速度不超过0.5米/秒。进入距离不超过6米的区域但速度仍高于0.5米/秒，记为不安全。

所以，日志里的“不安全”是任务定义的危险状态，不必然是CARLA中已经发生了实体碰撞。提前停在目标外、超过时间限制、离开规定状态范围，也分别记录，不能一概算成功。

### 图像与动力学分别来自哪里

图像在CARLA中按原采集方式获得；当前多数训练和验证使用原AEBS解析动力学计算车辆下一状态。也就是说，我们已经使用了真实采集的场景图像，但不能把图片库实验等同于完整CARLA车辆动力学实验，更不能等同于实车验证。

在解析模型中，每步时间为0.05秒。当前速度决定下一步距离，制动动作决定下一步速度。天气和颜色目前通过图像影响控制动作，不是自动改变模型中的轮胎摩擦或制动能力。

## 三 当前框架怎样工作

### 实际图像路径

```text
摄像头图像
    → 冻结的预训练DINO视觉网络
    → 可训练的低维投影网络
    → 32维图像表示
    → 与当前速度拼接
    → PPO控制器
    → 执行动作
    → 车辆下一状态
```

DINO是预训练视觉网络，本项目不重新训练它的主体。它先把图像转换成384个特征数，再通过投影网络得到32个数，供控制器使用。

这32个数称为latent，可以理解为“压缩后的任务信息”。它们不是32个手工指定的物理变量，也不是把图像变成一个距离数。控制器直接使用这32维表示和速度，不经过一维距离预测头。

训练中确实有一个辅助距离预测模块，但它用于约束和检查表示是否保留距离信息，不是运行时控制器的输入通道。

### 离线代理路径

```text
物理距离
    → 小型代理网络q
    → 32维代理表示
    → 与相同速度拼接
    → 同一个PPO控制器
    → 计算下一状态和安全条件
```

代理网络q的作用是：已知物理距离时，不生成图片，直接生成控制器需要的内部表示。这里的q不是强化学习中的Q函数。

例如，同一距离的晴天红车图像、雨天蓝车图像，会得到不同的视觉特征。我们希望它们经过投影后，与该距离产生的代理表示尽量接近。两条路径越接近，离线代理对实际图像控制的代表性越好。

但代理网络当前只接收距离，不包含完整天气变量或复杂场景状态。这是针对当前任务的实现，还没有证明能够直接推广到任意驾驶任务。

### 安全模块分为保留基线和研究分支

**保留基线**使用DINO双路径前端，后面仍接原SPVC的PPO、SBC训练及旧验证流程。SBC是一个作用于距离和速度的函数，用于检查初始区域、危险区域和状态转移是否满足安全相关条件。

**最新研究分支**参考Model-Free NBC方法，学习另一个屏障函数，并把它给出的违规信号加入PPO训练。这一分支还在实验中，没有替换保留基线。

新屏障不是运行时动作过滤器。它目前通过训练损失影响控制器，不是在每次输出动作后强制修改动作。当前主线也没有把QP、CP和safety filter全部串起来运行；这些属于前期尝试过的不同分支。

## 五 数据扩充和表示对齐取得的效果

### 数据如何构成

扩充数据保留了原来的图像采集方式，主要增加距离和外观覆盖：2000条距离采样，配合4种天气和3种颜色，共24000张图像。

按距离块分组划分，而不是逐张随机打散。同一距离块的不同颜色、天气和重复图像放在同一集合，减少“训练集已经见过同距离，只在验证集换了颜色”的泄漏。

| 集合 | 图像数量 | 当前用途 |
|---|---:|---|
| 训练集 | 14172 | 表示与控制学习 |
| 验证集 | 4908 | 开发诊断和模型选择 |
| 测试集 | 4920 | 留作方案冻结后的最终评价，目前未编码和评价 |

全部24000张图片通过了解码审计，没有发现跨集合重复组。视觉质量也经过确认。

### 为什么不仅增加图片 还增加对齐训练

早期只训练少量单一外观时，代理表示可以很准确，但真实图像表示在新距离、新外观上偏差很大。控制器在代理路径上成功，并不意味着换成图像路径也成功。

因此进行了两步改进：先使用所有训练外观，再把同距离的12种外观共同拉向相近的表示。这样不仅让图像路径接近物理代理，也减少同距离不同天气、颜色之间的变化。

| 验证指标 | 单一外观训练 | 全部外观训练 | 再加同距离外观对齐 |
|---|---:|---:|---:|
| 双路径相对表示误差 | 78.89% | 8.70% | 7.63% |
| 图像距离平均绝对误差 | 1.753米 | 0.186米 | 0.166米 |
| 图像距离均方根误差 | 2.067米 | 0.240米 | 0.214米 |

“相对表示误差”是两条路径的差异相对于表示自身变化幅度的大小，不是失败概率。例如7.63%不能解释为系统有7.63%的不安全概率。

这些结果说明，增加外观覆盖和同距离对齐，确实改善了表示一致性；不是简单多跑几轮PPO就能替代的工作。

不过，最后一版的最大表示误差仍比前一版略大。当前改进主要体现在平均和大部分样本，不是每一个样本都更好。

## 六 新前端是否比原cGAN代理更准确

这是目前最明确的正面成果之一。为避免不同数据造成假象，比较使用相同的4908张验证图像、相同物理状态以及相同解析动力学。

### 用米和米每秒衡量

| 测量对象 | 原cGAN相关链条 | 当前DINO链条 | 解释 |
|---|---:|---:|---|
| 真实图像的距离平均绝对误差 | 2.668米 | 0.166米 | 当前视觉表示保留距离信息更准确 |
| 代理距离平均绝对误差 | 0.1445米 | 0.00412米 | 已知距离生成代理后，距离信息损失更小 |
| 两路径导致的下一速度平均偏差 | 0.07496米/秒 | 0.00604米/秒 | 代理动作与实际图像动作造成的物理后继更接近 |

图像距离平均误差下降约93.8%，下一速度平均偏差下降约91.9%。天气、颜色分组下的平均指标也有改善，不只是晴天总体平均改善。

这里“下一速度偏差”比较的是：同一系统的图像动作和代理动作，在相同当前状态下造成的下一速度差。它不是对实车下一速度的预测误差。

旧链使用仓库已有基础PPO，新链使用最终DINO控制器。因此这是两套系统各自内部的代理偏差比较，不是保持同一控制器权重不动的纯前端消融，也不是已经确认的原论文最终checkpoint对照。

### 在同一个表示空间中比较

像素误差和latent误差单位不同，不能直接比数值大小。因此另做了共同表示空间实验：将真实图像和cGAN生成图像都送入同一个冻结评价网络，再与DINO物理代理比较。

采用随机生成输入的主口径时，DINO平均差异为0.0475，cGAN为0.9562，平均下降约95.0%。该结果支持“新代理更贴近当前任务所需的表示”。

但评价网络参与过本项目任务训练，且旧图像存在低分辨率和灰度化，比较会受这些因素影响。不能把全部差距归因于cGAN生成器，也不能将95%解释成任意场景的通用优势。

### 安全分析最需要注意的尾部

平均偏差减小了，但下一速度的最大偏差从约0.215米/秒增至0.236米/秒。也就是说，新系统的大多数情况更准确，少量最差情况仍需处理。

**这就是当前不能从平均误差下降直接推出安全保证的原因。安全分析必须考虑少量大误差，而不是只看平均值。**

## 七 原SPVC后端目前得到什么结果

最小替换版本去掉cGAN和旧图像状态网络，保留原后端训练、噪声设置、网格筛选和容许违反规则。最终保存的控制器与SBC已重新一起检查，模型与结果能够对应。

主要结果是：

| 项目 | 最终保存模型复查结果 |
|---|---:|
| 总网格规模 | 10000个状态 |
| 原代码筛选后实际检查状态 | 82个 |
| 硬违反数 | 1个 |
| 原代码容许违反阈值 | 不超过总网格的0.1% |
| 当前按代码分母计算 | 1/10000，即0.01%，通过旧阈值 |
| 原代码安全到达概率读数 | 约95.62% |

可以汇报的结论是：**DINO前端成功接入原SPVC工程，最终保存模型通过了原代码同口径检查，并得到正面的概率读数。**

这里仍有两项限制。第一，原代码不是对10000个状态全部做同样的下降检查，而是筛选一个屏障相关区域；实际带内1/82约为1.22%，不能把1/10000说成全域零违反。第二，检查主要沿物理状态到代理latent的路径进行，实际图像与代理的差异还没有完整纳入保证。

因此，95.62%应作为原代码口径读数报告，不能直接宣称真实图像闭环已经具有95.62%的可靠安全保证。

## 八 现在为什么研究Model-Free NBC联合训练

前面的工作主要解决“代理更准”和“接回原方法”，但剩余图像误差仍可能改变动作。仅让两条latent接近，还不一定能让控制器对这些差异足够稳健。

因此参考Model-Free NBC论文，尝试让控制器在训练时就认识到哪些动作会违反安全条件，而不是只追求完成任务的奖励。

### 屏障给控制器什么信号

新屏障函数记为C。它给每个距离、速度状态打一个分数：C不大于0的区域是网络提出的安全候选区域，已知危险区域应当具有正分数。

训练同时要求状态转移满足一个收缩条件。白话理解是：控制器不能只让当前状态看起来安全，还应该让下一状态留在合适的区域内，并留出一定余量。

当某个动作不满足这一条件时，产生一个违规得分。PPO除优化任务奖励外，还尝试降低高违规动作被选择的概率。它不要求对车辆动力学直接求导，梯度通过策略的动作概率进入网络。

这是对参考论文机制的项目适配，不是完整复现其全部算法或理论。学习出来的神经网络也必须接受检查，不能因为加入了安全损失就自动称为安全控制器。

### 当前已经做了哪些实验

先使用真实图像路径对应的转移样本训练C，再进行三类联合实验：

1. **单步联合训练**：当前动作的下一状态违反越大，训练时越受惩罚。
2. **加入旧约束保留**：学习新轨迹时同时回放旧数据；如果新C损害旧检查结果，就恢复旧C。
3. **五步联合训练**：不只看下一步，还看当前动作之后短期轨迹的变化，尝试提前发现风险。

另外设置同预算的普通PPO对照，不使用屏障安全反馈，避免把普通继续训练造成的变化误认为安全方法的贡献。

## 九 最新联合实验的配置和结果

### 实验怎样配置

最新每组训练8192步，分4批，每批2048步。PPO学习率为0.00001，使用相同初始策略和seed。表示网络全部冻结，只更新控制器和候选屏障。每组约16秒，是用于定位问题的小预算实验，不是充分收敛后的大规模性能结论。

训练使用图片库回放，每回合固定一种天气和颜色，并按当前距离查找训练图像。主要任务评价使用12种外观和9个共同初始状态，共108个确定性回合。

另用4908张验证图像与60个非终止速度组合，形成294480个精确图像和状态组合，检查动态条件。这个数量不是294480次独立车辆回合。

为了公平比较不同控制器，动态违规统一由同一个冻结的首轮屏障判断。否则一个新屏障把自己变得宽松，也会看起来“违规变少”，但并不代表物理上更安全。

### 结果怎样

| 指标 | 原控制器不再训练 | 单步联合并保留旧约束 | 五步联合并保留旧约束 | 普通PPO对照 |
|---|---:|---:|---:|---:|
| 确定性回放成功 | 108/108 | 108/108 | 108/108 | 108/108 |
| 同组回放不安全或超时 | 0 | 0 | 0 | 0 |
| 固定屏障下动态违反 | 13863 | 14583 | 14617 | 14508 |
| 从候选安全区跨出的组合 | 1009 | 1056 | 1060 | 1049 |
| 被保留的新屏障更新 | 不更新 | 0/4 | 0/4 | 0/4 |

这组结果说明：控制任务表现保持了，但安全条件没有改善。五步方法比普通PPO多109个动态违反，也比不继续训练的原控制器差。

五步方法在旧轨迹分析中确实增加了一些风险提前提示；但“信号更多”不等于“训练效果更好”。目前不能把这一分支当作成功改进，也没有用它覆盖原模型。

首次没有保留机制的联合实验还使16个危险检查状态落入新屏障自己的候选安全区。保留机制阻止了这类退化，但后续四次新屏障更新都被退回，表明“保护旧结果”和“适应新策略”尚未同时实现。

### 为什么108次成功 仍然说没有安全改善

108次评价集中在原任务初始范围，使用确定性动作；原控制器在这里已经全成功，因此成功率很难再提高。

安全检查还包含不同中间状态和靠近危险边界的状态。一个策略可以从规定起点顺利完成，却不能满足更广状态范围的屏障条件。

训练时PPO还会随机探索，最新五步组109个已结束训练回合中有15个不安全。它与确定性评价不是同一实验设置，两者应分别报告。

## 十 当前真正遇到的问题

### 问题一 平均误差更小 但未来大误差的覆盖尚未解决

天气和颜色引起的差异已经进入采集数据、表示训练和图像动作诊断，并非完全没有考虑环境因素。

但“观察过这些天气”不等于“未来所有图像误差都被安全分析覆盖”。现在缺的是一个能够合理包含未来图像动作差异、同时又不让安全条件无法满足的误差范围。

拟合过一个状态相关动作误差区间网络。训练样本覆盖约99.18%，验证样本约90.93%；原窄带验证覆盖约85.17%。漏覆盖仍明显，不能当作可靠契约。

若允许任意动作−3至+3，虽然一定包含实际动作，但当前屏障又无法验证。区间太窄会漏掉真实动作，太宽会无法证明，这是误差建模的核心矛盾。

### 问题二 神经屏障的分数与真实失败事件尚未完全一致

最新保存轨迹中，94个成功终局有37个末步受到正违规惩罚；15个不安全终局只有7个末步受到正违规惩罚。

这不说明终局标签记录错了，而是说明当前屏障收缩得分并不是失败事件的准确替代。已经安全停止的状态，可能不应继续按“还要往前运行”的条件惩罚；危险区域里的分数即使下降，也不意味着已经安全。

这是下一步需要优先检查的线索，但尚不能认定它就是联合训练失败的唯一原因。

### 问题三 新策略和屏障一起学习 容易彼此迁就或遗忘

策略变化会产生新转移，屏障需要适应；但屏障可能通过改变自己的区域，降低训练损失，却破坏原来的危险区域或旧转移条件。

保留机制能拒绝退化的屏障，却不能保证存在一个新屏障同时满足所有要求。当前0/4次更新被接受，正是这个问题的表现，而不是新屏障已经训练成功。

### 问题四 原方法检查通过与实际图像保证之间仍有缺口

沿用原SPVC后端，不等于实际感知差异自动满足原假设。现有结果主要是特定代理、特定网格和原代码筛选规则下的结果。

要形成真实图像闭环保证，还要说明图像误差覆盖、必要状态范围的屏障条件、连续状态之间的补偿，以及停止或离开验证范围时怎样处理。

### 问题五 动力学和泛化范围仍有限

当前主要使用解析AEBS动力学，尚未覆盖真实车辆制动偏差、路面变化和传感器延迟。数据也集中在当前任务及采集协议，不能声称跨地图、跨任务或现实场景通用安全。

## 十一 前期失败路线给了哪些结论

| 路线 | 观察到的结果 | 为什么不继续作为当前主线 |
|---|---|---|
| 自由神经SBC反复加权和改输出 | 部分损失变小，但区域和动态条件难以同时合格 | 不能靠训练损失下降代替证书检查 |
| 全局CP残差盒 | 正向最大残差连续施加时，400个起点全部进入危险状态 | 把轨迹误差扩成每步任意扰动过度保守，连最大制动也无法抵消 |
| 仅按动作分箱缩小残差 | 正残差压力仍使400个起点全部失败 | 动作条件不足以保留误差的时序和状态结构 |
| Safety filter加蒸馏及手工可恢复集 | 有成功闭环和条件性验证结果 | 依赖当前任务物理结构，不符合后续更通用的主线目标 |
| QP可微层 | 接口和联合训练曾跑通，结果依赖初始化、屏障和软约束 | QP不能修复不可行或错误的安全条件，当前没有保留在主线中 |
| NBC最差样本加权 | 训练违规下降，验证候选区越界反而增加 | 只追求少数损失指标，会掩盖集合退化 |

旧轨迹CP也曾得到正面统计结果，但对应的是当时冻结的策略、屏障和采样协议。控制器或评分规则变化后，不能直接沿用旧数字作为新系统保证。

这些尝试的价值是排除了几种看似简单、实际上会造成不可行或指标误导的做法。当前不准备把它们全部拼进一个更复杂的系统。

## 十二 下一步怎么推进

### 第一步 先解决训练反馈与停止任务的关系

先分析现有保存轨迹，不立即增加采集量或训练轮数。重点区分安全成功、不安全结束、超时和仍在运行的转移，核对这些事件应该怎样进入屏障损失。

随后只改变一项明确的终止反馈处理，再与相同预算的普通PPO比较。检验它是否减少候选安全区内的动态违反和越界，而不是只降低训练损失。

这一项是新的算法适配，不能表述为完全没有改变原方法。

### 第二步 为保留基线建立可行的图像误差范围

继续保留表现较好的minimal控制器，先用开发数据构造状态相关、允许正负方向不同的动作误差范围。

开发阶段同时检查两个问题：它是否足够覆盖图像动作，以及在这个范围内屏障条件是否仍可能成立。不能只调到检查通过，却漏掉真实图像动作。

若得到可行候选，再冻结模型与误差规则，用新独立轨迹做正式校准。独立数据是指没有参与模型训练或误差规则选择的数据；否则覆盖结论容易乐观。

### 第三步 补必要状态范围与连续误差分析

在误差范围可行后，检查安全条件所需的状态域，并处理网格之间的连续状态和误差变化。不能把原代理路径的网格补偿直接当作新增动作误差已经被覆盖。

如果最终只能得到某分布、某时间范围内的统计安全结论，就按该范围报告，不将其升级为全场景形式化保证。

### 第四步 冻结方案后再使用测试集

最后使用保留的4920张测试图像，以及匹配任务的闭环评估。结果同时报告各天气和颜色的任务表现、平均和尾部误差、覆盖率、屏障违反、适用范围及模型版本。

若联合安全训练在同预算对照下仍没有优势，就保留为负结果，不继续单纯加大训练量。项目的正面成果仍可围绕双路径代理改进和明确边界的安全分析展开。

## 十三 当前完成度和希望讨论的重点

| 研究环节 | 当前状态 |
|---|---|
| DINO双路径前端与数据流程 | 已完成并有稳定实验结果 |
| 表示一致性改善 | 已完成平均与分组开发对照，尾部仍有问题 |
| 新表示控制器及原SPVC后端接入 | 已完成，最终保存模型通过原代码阈值 |
| 相比旧代理的平均偏差优势 | 已有配对数据支持，仍需更严格原基线和最终测试 |
| 图像差异进入环境动作诊断 | 已实现，但没有可靠未来覆盖保证 |
| NBC和PPO联合训练 | 接口与对照已完成，暂未得到安全收益 |
| 真实图像闭环安全保证 | 尚未完成 |
| 未触碰测试集最终评价 | 尚未开展，等待方案冻结 |

希望与导师重点讨论：论文主线是否聚焦于“低维双路径替代生成代理，降低偏差，并明确误差如何进入安全分析”；Model-Free NBC作为改善训练的研究分支，而不是在尚无收益时直接作为主要成功贡献。

理论目标也需要明确：是追求指定误差集合内的条件性屏障保证，还是指定场景分布和时间范围内的统计保证。两者需要不同的数据和证明，不能只根据哪个数字好看来选择表述。

## 十四 汇报结论

本阶段不是仅替换一个视觉网络，而是完成了数据扩充、双路径表示学习、控制器重训、原SPVC后端接入、保存模型复查及新旧代理配对比较。结果表明，新前端显著减少了平均表示和物理后继偏差，控制闭环在已评价的初始范围内能够完成任务。

当前主要困难是：少量大感知误差仍没有可靠覆盖，屏障训练条件与实际终局事件尚未完全一致，新策略与屏障共同学习也没有带来验证安全改善。因此，下一阶段应集中补齐误差覆盖与安全推理链，并先修正有证据支持的训练语义问题，而不是继续堆模块或只增加训练轮数。

### 关键术语速查

| 名称 | 在本项目中的含义 |
|---|---|
| DINO | 已预训练的视觉特征提取网络，主体冻结 |
| latent | 网络学习的32维压缩表示，供控制器直接使用 |
| 双路径 | 真实图像产生表示与物理距离产生代理表示，两者共用控制器 |
| PPO | 根据任务奖励学习动作的强化学习算法 |
| SBC | 原SPVC使用的随机屏障函数，条件成立时用于安全概率分析 |
| NBC | 新分支使用的神经屏障，提出候选安全区域并提供训练反馈 |
| 屏障违反 | 不满足指定函数不等式，不等同于已经碰撞 |
| 候选安全区 | 网络认为可能安全的区域，仍需检验它是否能保持安全 |
| 动态条件 | 检查从当前状态到下一状态时，屏障关系是否满足要求 |
| 契约 | 有明确适用范围和覆盖依据的误差约定，不只是观察到的最大误差 |
| CP | 用独立样本校准统计覆盖的方法，结论依赖采样与评分条件 |
| QP | 在约束下求合适动作的优化问题，约束不可行时也不能凭空保证安全 |
| 验证集 | 用于开发诊断和选择方案的数据，不是最终独立评价 |
| 尾部误差 | 少量最差样本中的大误差，往往比平均值更影响安全 |
| 闭环 | 观察、决策、执行、得到下一状态，再观察的连续过程 |
