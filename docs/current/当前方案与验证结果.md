# 当前方案与验证结果

更新日期：2026-10-29。当前实验场景为 **AEBS 自动紧急制动**。本页是最新主线总览；过去的双路径、停车场及 CP 阶段报告统一从[历史归档](../archive/README.md)查阅。

## 当前方案

```text
图像 → 冻结 DINOv2 → 一维 VISION-SLS 观测 → 拼接实测车速 → PPO → 制动动作
                                  ↓ 离线误差建模与训练验证
                         状态相关 CP 包络 + 非负 SBC
```

部署使用 SBC 反馈训练后的 PPO。SBC 保持非负屏障、初始集不超过 1、不安全集至少 20 的条件，以及对应的 95% 目标；隐藏层仍为 `[2,16,8,1]`、tanh。适配版采用非负 ReLU 输出和停车后吸收的非增条件。该适配与旧 Softplus、每步严格下降 0.1 的配置有区别，不能写成旧配置原样通过。

以下数字来自已保存模型包的[结果汇总](../../artical-F122/results/vision_sls_spvc_sbc_pass_20261029/summary.json)，本次文档整理没有重跑实验。

准确结论是 **限定模型下的连续状态域数值区间检查通过**。CP 路径要求观测位于给定包络内，边际 CP 覆盖率本身不能建立逐状态的支持集假设；固定图片回放路径直接检查冻结图片库。当前未声明新场景图像安全、实时 CARLA 保证或 IEEE 浮点执行的形式证明。任务到达统计和 SBC 安全条件也应分别引用。
