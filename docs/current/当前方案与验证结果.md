# 当前方案与验证结果

文档更新：2026-11-04。实验结果分别截至 AEBS 的 2026-10-29 发布版、停车场的 2026-11-03 结果包。本页是统一状态入口；详细流程见[完整步骤文档](./VISION-SLS_SPVC_SBC当前框架_步骤原理实验与安全保证_20261029.md)，全部资料见[文档导航](../README.md)。本次整理没有重新训练或增加实验次数。

## 两个实验的区别

| 项目 | AEBS | 停车场 |
|---|---|---|
| 任务 | 自动紧急制动 | 四维车辆绕障停车 |
| 感知 | DINO-S → 一维观测，拼接实测速度 | DINO-G → 三维观测，延迟观测器估计状态 |
| 控制 | 经 SBC 反馈训练的 PPO 直接输出动作 | 参考规划＋LQR＋残差 PPO 建议，再经过在线区间后备检查 |
| 感知误差使用 | 状态相关 CP 参考包络；另检查固定图片回放 | 新采集的按起点组启动 CP；启动后安全集合仅按动力学传播 |
| SBC | AEBS 非负网络、停止过程不增条件 | 几何 ReLU 分支＋有界学习头＋时钟的结构化神经 SBC |
| 验证对象 | AEBS 指定连续域及相应观测模型 | 新受保护闭环的增广可达不变域 |

两者都采用非负 SBC，但控制器、数据和证明域不同。AEBS 不在线修改动作的表述，不适用于停车场；停车场的新证书也不使旧无后备控制器通过。

## 停车场：最新受保护闭环与神经 SBC

首次理解本实验，可先读[旧证书矛盾的逐步解释](./停车场神经SBC_构造证明与实验_20261103.md#contradiction-explained)：SBC 是证明分数，车速越界使状态被归入危险，两者之间的推理在该节逐步展开。

依据：[冻结结果包](../../artical-F122/results/vision_sls_parking_20261103_neural_sbc_certificate_v1/README.md)、[证书及逐场景审计](../../artical-F122/results/vision_sls_parking_20261103_neural_sbc_certificate_v1/certificate.json)、[证明专题](./停车场神经SBC_构造证明与实验_20261103.md)。

```text
启动图像 + 目标 → 全部兼容初态盒子 + 跟踪参考 + 安全后备
后续图像 → 延迟观测器 → LQR + PPO 建议
                           ↓
                  全部盒子及后备后缀检查 → 实际动作
```

| 检查 | 结果 |
|---|---|
| 连续初始化域 | 原 15 个起点各状态分量 ±0.02；联合制动及各自参考的盒子检查通过 |
| 神经 SBC 条件 | 初始 ≤0.305、危险 ≥20、有效非终端每步变化 ≤−0.005 |
| 原中心 / 新扰动图像闭环 | 各 15/15 成功，均零碰撞、零越界 |
| 归档独立重算 | 30/30 通过，930 个状态时刻、900 个转移 |
| 独立启动 CP 数据 | 975 次启动采集；审计覆盖 233/240，中心覆盖 15/15 |
| 旧反例误差规律回归 | 4/4 安全到达 |
| 极端后续观测回归 | 15/15 安全、14/15 到达；场景 7 未到达 |
| 软件及跨环境核查 | 本地和服务器 CPU 各 59 项通过，独立证书重算通过 |

**条件模型安全：**在注册的 RK4 模型、零过程扰动、30 步时域、初态盒子和正确运行的后备检查下，启动 CP 覆盖真实误差便蕴含后续路径安全。神经下降条件在已经证明初始化可进入且转移闭合的增广域上成立，没有验证任意拼接的八维安全状态与观测器状态。

**统计连接：**预先指定起点组，在相同独立均匀启动协议、冻结视觉和渲染条件下，split CP 的启动覆盖可连接为单次新实验至少 95% 的边缘模型安全保证。概率同时包含校准集和新启动样本的随机性；不是固定校准文件下每个初态 95%，也不是 15 次实验同时安全的 95%。审计覆盖比例不是安全概率，不能把两个 95% 相乘。

**边界与代价：**不覆盖此前 ±0.04 完整初态域、非零过程扰动、采样间整车无碰撞、无限时域或实车保证。安全不等于必然到达。原起点与扰动组分别有 137/450、193/450 步修改建议动作，当前不宣称硬实时。网络保留旧学习参数，但图像轨迹上学习头接近零，证明主要依赖结构与后备不变性，不能归因于自由神经训练独自完成全域证明。
