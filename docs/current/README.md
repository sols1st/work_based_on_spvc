## 最新结论，引用前先看

- **AEBS 单位修复：**旧 RGB 合同把归一化 q=0.07249 直接当米，实际只验证 ±0.07249 m；正确半径是 0.230725 m。旧 SBC 在正确半径下有 212 个正漂移见证，**旧 tube 通过结论撤回**。
- **原 10/29 灰度实现：**400 张 32×32 灰度图、状态相关 CP、配套 SBC；4,971,398 区间 0/0、1441/1441。它是历史小数据包，不能与 24k test 横比，详见[前端对比 §1.1](AEBS前端对比_cGAN_灰度_真实RGB_20261108.md)。
- **AEBS 当前证书：**冻结回放分布轨迹 CP 半径 **0.4183585684 m**；新训练非负 SBC 在 292,024 个区间上 **0 见证/0 未解决**，初始 0、危险下界 25.213636。
- **AEBS 运行时：**冻结真实图片库最近邻回放，不是 cGAN 根据状态生成图像；CP 是 `d̂−d` 的 1D latent 残差，包含最近邻查图误差。
- **AEBS 状态相关 CP 变体：**参考 10/29 的 Bernstein `b0(d)`；`C` 仍固定 `[1,0]`，只学误差尺度，不是联合学习新前端；平均半径 0.3217 m、最大 0.720 m，留出覆盖 92/100；同一 SBC v2 在 41,070 个区间上 0/0 通过。它不替换常量 CP 发布包，因为覆盖更低。
- **车道当前证书：**2D latent `(ê,θ̂)−(e,θ)`，轨迹 CP 0.0900931580；SBC 审计 0/0。
- **车道状态相关盒试验：已撤回。** 代码/报告不一致，留出分数误用校准残差；不能作为 CP 或安全结论。当前主结果仍是常量 0.090093 盒。
- **cGAN/灰度对比：**cGAN 旧检查点 2.747 m、CP 5.221 m；灰度 DINO 0.1017 m、0.2656 m；真实 RGB 0.0874 m、0.2307 m。cGAN 旧检查点不是同预算重训，不能写成架构因果。

- **原 SPVC cGAN 对照：**原生 cGAN 轨迹 q=**1.9156 m**、留出 **92/100**；新 DINO q=**0.4184 m**、留出 **99/100**；两边行为都成功（100/100 vs 4800/4800）。收益在误差包络/覆盖，不是任务成功率；**不是同预算架构胜负**：400 图同 actor 对照 cGAN q=1.9156 小于 DINO-400 q=4.0205。24k DINO 的优势主要来自数据规模。[误差对照](SPVC前端替换_收益证明_原SPVC_cGAN误差对照_20261110.md)。
- **前端 C 组件收益：**5 对训练种子配对中，固定 C / 联合 C 各 5/5 通过数值 SBC；联合 C q 均值 0.085699、固定 0.085263，留出覆盖 95.0% 对 95.6%，3/5 对联合更小。**没有稳定收益，不能作为独立贡献**；整体前端替换相对原 SPVC 的收益仍未建立。[阶段结果](SPVC前端替换_收益证明_阶段一至二结果_20261110.md)。
- **车道状态相关修复 v2：**99 拟合＋100 校准，无 cap；原留出回归 93/100。直接验证实际状态集合，本地/服务器均通过，13,000 区间、0/0；旧 v1 继续撤回。[修复步骤与结果](../../artical-F122/results/lane_state_cp_20261109_repaired_v2/README.md)。这次状态包络修复没有联合学习 C；后续独立增加的联合前端实验见上方新专题，不能混用证书。
