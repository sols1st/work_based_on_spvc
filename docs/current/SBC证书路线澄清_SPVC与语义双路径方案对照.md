# 还能不能得到SBC证书：原SPVC、语义双路径建议与当前方案的完整对照

更新：2026-10-09。本文依据本地论文、当前代码和用户回传结果编写；没有启动新实验。文中“建议”“待验证”不是已经实现或已经证明的结论。

## 1. 先回答最重要的问题

**不是“换成DINO以后就不能得到SBC证书了”，而是“当前R2图像闭环还没有得到有效的端到端SBC证书”。**

现在有三个不同的问题，不能合成一句“成功了”或者“失败了”：

1. **代理控制系统能否训练出SBC？** 可以继续尝试。原SPVC式的训练入口已经存在，但目前没有足够的新结果证明R2已经成功。
2. **代理系统的SBC能否覆盖真实图像路径？** 不能自动覆盖。两条latent路径不完全相同，需要额外的误差传递论证。
3. **已经尝试的全局CP残差盒是否可行？** 对当前固定控制器、当前动力学和“盒中所有残差序列都必须安全”的要求，已找到反例。这条具体规格不可行，不代表所有随机SBC方法不可行。

因此，推荐保留DINO、双路径latent和PPO，停止盲目微调最近的轨迹SBC软损失；先做清楚原SPVC基线，再研究“代理证书如何转移到图像控制系统”。不需要因为一次残差盒失败，就放弃全部工作。

### 1.1 当前结论清单

- [x] DINO双路径表示与PPO已经可运行，并有明确的开发集改进。
- [x] 原SPVC截图协议下30条在线开发轨迹全部成功。

- [ ] 轨迹SBC v3的下降条件通过：尚未通过，验证转移仍有131/7453违反。

## 2. 先把几个容易混淆的概念分开

### 2.1 SBC不是控制器，而是控制器的“安全论证函数”

PPO根据观测输出动作。SBC通常是一个函数 `B(x)`，给物理状态一个数。

可以把它理解为“用于数学论证的风险刻度”，但它的值不天然等于真实事故概率。需要满足一整组条件，才能推出概率界。

一个常见的归一化版本是：

- 所有相关状态上 `B(x) >= 0`；
- 初始区域上 `B(x) <= b0`，其中 `b0 < 1`；
- 不安全区域上 `B(x) >= 1`；
- 在规定的非终止区域，下一步的**条件期望**不超过当前值。

直觉是：系统一开始位于低刻度，危险状态位于高刻度，若风险刻度在正确的随机模型下平均不增加，就可以限制碰到危险区域的概率。

**只把安全样本训练成接近0、不安全样本训练成大于1，还不够。** 这可能只是一个分类器，没有满足连接相邻时间状态的动态条件。

### 2.2 三种“下降”要求不是同一件事

| 要求 | 通俗解释 | 特点 |
|---|---|---|
| 条件期望下降 | 给定当前状态或历史，按真实建模的随机分布平均，下一步风险不增加 | 随机SBC的核心；允许某些具体转移上升 |
| 每个观测转移都下降 | 保存的每一对相邻状态都不能上升 | 比对这些样本取平均更强，但只看有限数据，仍不能代表所有状态 |
| 每个允许误差都下降 | 对误差集合中的全部选择，包括最不利选择，都不能上升 | 鲁棒条件；可能比真实系统严格得多 |

最近的实验从原SPVC的第一种要求，先走到了第三种，再走到了第二种。这是**验证对象和约束发生了变化**，不只是换了训练算法。

### 2.3 CP提供覆盖，不自动提供安全

CP可以回答：“在同样的采样协议下，一条新轨迹的误差落在这个范围内的概率有多高？”

它不会自动回答：“控制器面对这个范围里的误差，一定不会撞车吗？”

需要两段论证：

```text
误差覆盖成立 ── 加上 ── 被覆盖的误差不会破坏安全
                         ↓
                  才能推出安全结论
```

我们已有的CP阈值完成了其中一类统计覆盖工作；全局盒压力测试失败，说明后半段没有接上。

### 2.4 “没出事故”不等于“完成任务”

安全性通常关心是否进入不安全集合。成功到达目标还需要任务完成条件。一直停着可能安全，但不一定完成任务；超时不能默认为成功。

下文若写“安全概率”，不自动包含“400步内成功到达目标的概率”。必须分别报告success、unsafe、timeout等结果。

## 3. 原SPVC究竟怎么得到SBC证书

### 3.1 论文、代码与旧实验结果需要分开

用户称为SPVC的论文 `720_file_Paper.pdf`，正文将框架称为 **SafePVC**。本文沿用项目习惯称SPVC。

论文里的定理、仓库的具体数值实现、某次训练输出的概率，是三个层次：

- 定理告诉我们：假设和不等式成立时可以推出什么。
- 实现负责检查这些条件，必须保证上下界方向、噪声积分、连续状态覆盖等正确。
- 输出日志记录某个模型在该实现下的结果，不能超出前两个层次的适用范围。

旧语义前端曾输出 `96.151%`，属于当时的模型和legacy检查器，不能直接迁移到现在的R2 DINO模型。

### 3.2 原文的模型结构

简化后为：

```text
状态、环境因素 → 图像生成/近似感知模型 → 控制器 → 动力学 → 下一状态
                         ↓
                构造可验证的闭环近似
                         ↓
                SBC训练＋期望条件验证
```

原文先用cGAN描述观测，再构建较小的近似感知网络，使后续验证可以计算。它不是直接对任意真实世界图像进行无条件证明。

原文将环境变化造成的闭环下一状态差写成 `Δs`，并在Assumption 1中假设其服从一个**不依赖当前状态的固定分布**。这是其随机抽象的假设，不是仅凭采集数据就自动得到的事实。

### 3.3 原文核心是期望，不是每一步最坏误差

Theorem 2.2使用的一种尺度是：

\[
B(s)\geq 0,\qquad B(s)\leq 1\;(s\in S_0),\qquad
B(s)\geq \frac{1}{1-p}\;(s\in S_u).
\]

同时在定理指定的安全子区域要求：

\[
\mathbb E_{\Delta s\sim\mu}
[B(\widetilde F(s,\Delta s))]+\varepsilon\leq B(s).
\]

其中 `μ` 是建模的扰动分布，`ε>0` 是下降裕量，`p` 是想保证的安全概率下界。原文还有具体区域与闭环假设，不能只摘这一行公式使用。

重要区别：**平均风险下降，不意味着每一次随机转移都下降。** 原文允许某些低概率扰动导致风险升高，只要整体满足定理要求。

原文还通过状态离散化、区间界和Lipschitz补偿处理网格之间的连续状态，并非“网格上大多数点通过就自然证明整个连续域”。

### 3.4 为什么不能把原代码通过当作所有问题都解决

本项目之前的检查发现：legacy区间实现与修正实现会给出不同结果；原代码的硬违反比例阈值还允许不超过0.1%的违反。

因此可以保留原代码用于公平复现，但论文中应分开报告：

1. 原始实现下是否通过；
2. 理论所需的全部条件是否经过可信检查。

本地实现问题不能直接推导成“原论文数学定理错误”；反过来，原论文有定理也不能保证任何本地日志就是有效证书。

## 4. semantic+latent建议PDF真正建议了什么

这份PDF是设计建议，不是一篇已经为当前代码完成证明的定理论文。

### 4.1 它的核心是两条路径共用一个安全相关的低维表示

```text
部署路径：图像 → 冻结DINO → 小投影网络 → z_img ─┐
                                                ├→ 同一个控制器 → 动力学
验证路径：物理状态x、环境因素η → 小代理q → z_q ─┘
```

大DINO负责图像表示，不直接进入高成本形式验证；小代理网络负责让验证在可处理的物理状态空间中进行。

建议中的安全语义不是强制变成一个距离标量。它可以是多维latent，同时利用距离等安全相关物理量作为训练辅助监督。当前运行时仍是32维latent加速度进入PPO。

### 4.2 建议要求的三件事

1. **安全信息保留**：latent必须保留决定控制的关键因素，不能为了对齐把所有输入都压成同一个向量。
2. **外观不变性**：同一物理状态的不同天气、颜色图像，应产生尽量一致的安全表示。
3. **误差覆盖与传播**：图像路径和小代理仍有差别，必须将差别纳入证书。

我们已经做了前两件的大量工程工作，也校准了第三件中的一种误差；但还没有完成第三件到最终安全定理的闭合。

### 4.3 PDF不只允许latent误差，也允许动作或下一状态误差

建议先后讨论了：

- latent差：`z_img - z_q`；
- 动作差：`π(z_img) - π(z_q)`；
- 下一状态差：`f(x,π(z_img)) - f(x,π(z_q))`。

因此，我们使用下一速度残差，并没有背离建议的基本方向。问题在于后来把它压成**全局、对称、各步可以任意重复取极值的盒**，损失了很多结构。

建议中的状态相关集合 `Eα(x)` 和当前一个全局标量 `q_hat` 并不是同一个精细程度的模型。动作分箱失败也不代表所有状态条件模型都失败，只说明当前动作分箱仍不够。

### 4.4 建议PDF里的覆盖公式也需要补齐假设

PDF讨论了类似下式的想法：

\[
(1-\alpha)\sup_{z\in Z_\alpha(x)}B(f(x,\pi(z)))
+\alpha B_{\max}\leq B(x)-\varepsilon.
\]

它的含义是：大部分概率落在契约内，少部分契约外情况用一个最坏风险上界处理。

但要把它用作逐状态SBC条件，至少需要：

- 给定当前状态/历史后，契约内的条件概率确实不低于 `1-α`；
- 契约外后继确有适用的 `B_max`，包括出域情况；
- 随机环境的时间相关性与模型一致。

**普通的边际CP覆盖不能直接代替逐状态条件覆盖。** 某些少见但危险的状态可能覆盖很差，即使总体覆盖率很高。轨迹级覆盖也不能不加证明地塞进每一步的条件期望公式。

这不是否定建议，而是说明它提出的是研究框架，落地时需要我们补上这些条件。

## 5. 当前实现与两份材料的差别

| 维度 | 原SPVC理论框架 | semantic+latent建议 | 当前R2及最近实验 |
|---|---|---|---|
| 图像前端 | 生成/近似感知链条 | 冻结视觉模型＋低维投影 | 冻结DINO＋32维投影 |
| 可验证感知代理 | 小型感知近似 | `q(x,η)`，或不变表示下的 `q(x)` | 目前q只输入归一化距离；速度单独送PPO |
| 部署控制 | 感知输出送控制器 | 图像latent送控制器 | 图像latent＋速度送PPO |
| 感知不确定性 | 固定分布随机闭环扰动假设 | latent/动作/下一状态契约 | 已校准轨迹最大下一速度残差 |
| 证书动态条件 | 条件期望下降 | 鲁棒或概率加权条件，需具体定理 | 全局盒最坏条件失败；之后改成观测逐步下降 |
| 连续状态覆盖 | 网格＋界传播＋Lipschitz补偿 | 由小网络和误差集支持验证 | 最近轨迹SBC仅有有限样本/网格诊断 |
| 时间范围 | 原定理讨论无限时间安全 | 取决于最终采用的证明 | CP校准协议目前为400步 |
| 起点范围 | 定理对规定初始集合中的每个起点 | 取决于证明 | 当前轨迹统计首先针对登记起点分布 |
| 当前能声称的结论 | 假设与验证条件成立时的概率界 | 尚需实现与证明的设计 | 开发性能改善、残差覆盖；没有端到端证书 |

尤其要注意：**每个起点都成立**与**从某个起点分布抽取一条轨迹时大概率成立**不是同一种保证。

## 6. 最近到底哪里失败了

### 6.1 全局CP盒：不是简单的训练不收敛

| 实验 | 结果 | 可以得出的结论 |
|---|---|---|
| 全局盒SBC训练 | 8884/8910下降违反 | 当前训练没有找到合格证书 |
| 恒定零/负残差测试 | 各400/400安全终止 | 这两类特定序列没有找到失败 |
| 恒定正 `q_hat` 测试 | 400/400进入不安全区 | 盒内确有不安全序列，当前路径级鲁棒规格不可行 |
| 动作分箱正残差测试 | 400/400进入不安全区 | 仅按动作区间收紧仍不足 |

反例直觉很直接：最大制动在一个 `0.05 s` 步长内使名义速度降低 `0.15 m/s`，全局盒却允许每一步再加上 `0.150685468 m/s`。于是抽象模型允许“始终刹不下来”的序列。

这条序列不需要真实发生，只要它被鲁棒集合允许，就会破坏“集合内所有序列都安全”的证书要求。

但它不证明：

- 真实图像控制器一定会这样行驶；
- 这条序列在真实环境下有正的或足够大的概率；
- 原SPVC的期望型SBC不存在。

### 6.2 轨迹SBC：区域分开了，动态条件还没过

| 版本 | 验证转移下降违反 | 不安全区网格违反 | 判断 |
|---|---:|---:|---|
| v1 | 7434/7453，约99.75% | 77 | 区域和转移条件都未通过 |
| v2：安全占用低值 | 458/7453，约6.15% | 5 | 明显改善，仍未通过 |
| v3：补不安全边界 | 131/7453，约1.76% | 0 | 区域分离改善，仍不是证书 |

v3验证最坏下降裕量约 `-6.57×10^-5`。绝对值小不等于已经证明是浮点误差；不能随意调大容忍阈值把它改成“通过”。

更重要的是，安全占用值大量接近0，说明网络可能主要学到了“轨迹附近给很小值、不安全区给大值”。这种形状有用，但不能替代条件期望下降和连续域验证。

### 6.3 数据转移提取还有一个要先核对的缺口

当前 `train_trajectory_scenario_sbc.py` 用保存状态的相邻两行构造转移，即 `states[:-1] → states[1:]`。

采集逻辑保存动作前状态，执行一步后若终止便退出，因此最后一个动作产生的终止后继不一定作为下一行保存。直接相邻配对会漏掉每条轨迹的最后一步。

这意味着：“提取出来的转移里没有unsafe后继”不能直接推出“原轨迹没有unsafe结果”。需要用保存的实际图像动作和一致的动力学重建末步，核对保存的outcome、时间索引、有效行和连续性。

本次是文档审计，没有修改训练代码；该问题应在下一轮任何证书训练或校准之前处理。

## 7. 为什么不建议直接用CP把v3的剩余违反包起来就宣布SBC成功

已经写出的一个分数是：

\[
S(\tau)=B(x_0)+\sum_t[B(x_{t+1})-B(x_t)]_+-1.
\]

代码还将安全终止处的值置0，不安全处置1。对于完整且连续一致的停止轨迹，不安全会导致该分数非负。因此，冻结模型以后，用独立轨迹校准并得到严格负的阈值，确实可能支持一种有限时域、同分布的统计安全结论。

**问题不是这种事件推理必然无效，而是它不能自动证明训练出的神经B是原SPVC意义的SBC。**

考虑一个没有学到任何动力学的函数：安全时为0，危险时为1。它也能构造出类似的安全/失败分数。若方法最终只靠新轨迹是否出现失败，那么SBC是否真正提供额外价值就值得质疑。

作为对照，若固定策略的459条独立同分布完整轨迹全都无失败，仅用零失败二项统计，在99%置信度下就有安全概率下界：

\[
p_{\mathrm{safe}}\geq 0.01^{1/459}\approx 0.990017.
\]

这是条件性的统计例子，不是声称当前已完成新的独立测试。它说明：如果同样要收集459条无失败轨迹，必须解释神经SBC相比直接事件统计多带来了什么。

结论：该CP分数可作为统计评估备选，但不能把“分数覆盖”命名成“原SPVC式SBC已经验证”。也不应为了得到好看的置信度而忽略这一区别。

## 8. 下一步建议：两条证书路线，先明确目标再选

### 8.1 路线A：保留原SPVC的随机SBC目标

这是最接近“还要像原SPVC一样得到SBC”的路线。

**第一步是已经存在的最小替换基线：**

```text
距离 → q latent → PPO → 原SPVC动力学/噪声 → 原SBC训练与VT检查
```

运行入口是 `Aebs.dino_latent.run_spvc`，已有说明见[原版SPVC最小替换实验](R2_DINO原版SPVC最小替换实验.md)。本次不再另写一个重复训练器。

这个基线回答“R2代理控制系统能不能沿用原方法训练出候选SBC”。它不自动覆盖图像latent误差，也不掩盖legacy验证器已知的审计限制。

**第二步才是完整图像系统的随机证书：**

1. 给出真实图像闭环适用的条件随机模型，而不是任意固定一个均匀分布。
2. 处理天气、颜色等在轨迹内持续存在的环境变量：可把必要因素加入状态，或明确使用带历史的条件分布。
3. 估计并可信上界 `E[B(x_next)|当前状态/历史]`。
4. 验证非负、初始、不安全和动态条件，补足网格之间的连续状态覆盖。
5. 证明近似模型与图像闭环之间的误差不会使这些条件失效。

在概率1%的轨迹集合之外不受约束的400步CP结论，不能直接升级为所有状态、无限时域的条件漂移界。这里是路线A真正困难的研究环节。

**可行性判断：仍值得做，但不能承诺一定成功。** 其难点不是DINO本身，而是随机模型、证书优化和可信验证三者必须对应同一个闭环。

### 8.2 路线B：代理屏障＋安全相关误差预算的有限时域转移

这是一个建议研究的替代目标，尚未实现和实测。它保留屏障函数，但不冒充原文无限时域随机SBC定理。

核心变化：不再问“两条latent差了多少”，而问“这点差别让屏障风险上升了多少”。

在**同一个实际状态** `x_t` 上比较两条路径：

\[
F_q(x_t)=f(x_t,\pi(z_q(x_t))),\qquad
F_I(x_t)=f(x_t,\pi(z_{img,t})).
\]

定义非负的风险增量：

\[
r_t=[B(F_I(x_t))-B(F_q(x_t))]_+.
\]

解释：图像误差即使很大，只要没把系统推向更高风险，就不按同样幅度惩罚；只累计对屏障不利的部分。这里比较的不是两个分别跑远了的状态，而是实际同一状态上的两种动作后继。

#### 一个可检查的充分条件，而不是已经获得的结论

先考虑当前确定性AEBS名义动力学，要求真的证明：

\[
B(F_q(x))-B(x)\leq c,\quad c\geq0,
\]

并证明初始 `B<=b0`、不安全 `B>=1`，以及所需区域有效。令整条轨迹的预算为：

\[
R_H=\sum_{t<\min(H,T)} r_t,
\]

其中 `T` 是按预先定义的安全终止/失败规则停止的时刻，进入失败的最后一步必须包含。则对停止前的各时刻，有：

\[
B(x_t)\leq b_0+Hc+R_H.
\]

所以，如果冻结全部模型后，用独立完整轨迹得到 `R_H<=Q` 的有效覆盖，并且

\[
\boxed{b_0+Hc+Q<1},
\]

那么在该覆盖事件上，轨迹无法达到 `B>=1` 的不安全集合。

这一推导来自逐步累加：名义变化最多c，图像路径额外增加最多r。它的前提可以逐项核对，不需要把普通边际CP硬解释成逐状态条件CP。

#### 必须明确的限制

- 这是400步等固定时域、登记分布上的安全转移目标，不是原SPVC对每个初始点的无限时域保证。
- 这里要求名义变化的逐点上界，**不能拿一个仅有期望下降的SBC直接代入**。若名义系统本身随机，需要另行推导随机版本。
- 名义变化界c若太大，`Hc`会耗尽全部预算；所以该方案也可能失败。
- B在不安全区的高值必须真实成立，不能只在评分时把神经输出强行改成1并当作验证结果。
- 出验证域必须单独证明不会发生，或计为失败并纳入屏障条件；不能直接删掉出域样本。
- 安全终止后不再讨论动作，需要与任务定义一致；不能把普通低速状态随意宣布为终止。
- CP保证依赖完整轨迹的采样假设与冻结规则。更新PPO、q或B之后，都必须重新处理校准有效性。
- 此方法能否比直接统计更有价值，需要实验比较，不能提前声称减少样本量或保证更强。

#### 和失败的全局盒有什么区别

全局盒把某处最大的速度误差允许在每一步重复；这里使用一条真实轨迹上的**累计风险影响**。天气等时间相关性保留在整条轨迹分数里，而不需要假装逐步独立。

它仍可能保守，但至少避免了“误差出现在哪里不重要，只要最大就每步叠加”的抽象方式。

### 8.3 当前优先顺序

**先路线A的最小替换基线与数据审计；不要立即再采459条数据。**

然后与导师明确二选一：

- 必须保留原SPVC式随机SBC结论：投入条件随机模型与期望验证，不把轨迹CP当替代证明。
- 接受有限时域概率安全作为新目标：先在开发集检查路线B预算是否有希望，再做独立校准。

两条路线可以共用DINO、q、PPO和屏障训练技术，但最终定理与论文表述必须分开。不是“先做简单版，最后把名字改成强保证”。

## 9. scenario-based论文的方法还能怎么用

《Training with Hard Constraints: Learning Neural Certificates and Controllers for SDEs》的scenario方法，将固定特征后的证书最后一层训练写成线性规划，并分析约束在采样分布下的PAC满足性质。它不是普通的全网络Adam软惩罚训练，也不直接等于任意轨迹的安全概率。[原文第3.2节](https://arxiv.org/html/2602.23526v1#S3.SS2)

借鉴到本项目可以考虑：

\[
B_w(x)=w^T\phi(x)+b,
\]

先训练特征网络 `φ`，然后固定它。在固定控制器、固定后继模型下，初始/不安全/转移条件对最后一层参数w、b成为线性约束，用LP求可行解。

这仍是神经屏障，只是最后一层不再靠软损失碰运气。它与以前给每个网格点单独放一个自由变量的有限状态LP不同。

需要注意：

1. 输出再接平方或softplus后，不能继续宣称同一问题还是线性规划。
2. 非负性必须单独保证，不能只满足初始与不安全边界。
3. 特征网络用哪些数据选出来、LP使用哪些独立场景，必须符合所引用定理的数据假设。
4. 有限样本LP可行，只说明这些约束可行；连续域或PAC结论需要额外条件。
5. 原文是连续时间SDE，本项目是离散AEBS，须改写为离散转移条件，不能照搬生成元公式。
6. LP不可行只能否定这套固定特征、约束和样本下的可行性，不能证明所有SBC都不存在。

因此它适合用来改善“怎么训练B”，但不能单独解决“B证明的是哪个系统、哪一种安全”。

## 10. 后续实施计划与停止条件

### 第一步：修正数据与结论口径，不新增模型

- [ ] 核对每条轨迹的最后一步，重建实际后继并与outcome一致。
- [ ] 检查时间连续性、动作限幅、单位、终止顺序、有效掩码、NaN及模型哈希。
- [ ] 区分CARLA图像渲染与车辆状态更新：当前状态按解析AEBS动力学更新，不能写成已经验证了CARLA真实车辆物理。
- [ ] 将旧459条明确标为已用于开发，不再对调整后的评分器宣称它是未触碰校准集。

产物：数据审计报告。若发现末步缺失或标签冲突，先修数据链，不继续训练掩盖问题。

### 第二步：完成R2＋原SPVC的对照基线

- [ ] 使用已有 `run_spvc`，记录SBC、PPO、q、原噪声设置和最终checkpoint的对应关系。
- [ ] 分别记录原实现阈值、零违反检查、区域界与概率输出，不能只看最后一行概率。
- [ ] 对训练后更新的PPO重新评估图像路径；旧PPO的图像结果和CP阈值不能直接沿用。
- [ ] 保存“忠实原实现”与“可信验证审计”的差异，不把二者混写。

产物：回答代理系统基线是否成功。若失败，区分约束不可行、优化不足、界过松，不无限叠加损失。

### 第三步：做一个证书转移可行性小实验

若选择路线B，先固定一组候选B、q、PPO，在旧开发轨迹上计算 `r_t`、`R_H` 以及预算余量 `1-b0-Hc-Q_dev`。`Q_dev`只能叫开发统计，不叫正式CP阈值。

- [ ] 名义变化界不是只在轨迹样本上看过，而有明确的连续域验证计划。
- [ ] 记录预算大值来自哪些状态、外观、时刻，而不是只看平均latent误差。
- [ ] 若预算明显不够，优先训练降低风险相关误差/改善控制器，而不是直接加校准数据。

停止条件：若名义条件本身不可行，或转移预算长期大于安全间隔，暂停路线B；不能删掉坏轨迹或缩小宣称范围而不明确说明。

### 第四步：再考虑训练算法改进

在目标明确后，比较现有软损失与固定特征最后一层LP。保持同一控制器、同一安全定义和同一数据划分，避免把换模型、换域、换阈值的效果混在一起。

若需要更新PPO，优先增加安全相关的双路径动作/屏障一致性训练，而不是只追求平均latent距离最小。新PPO也要重新评估控制效果，不能只优化证书损失。

### 第五步：最后才进行正式校准与论文实验

- [ ] 冻结表示、PPO、屏障、评分函数、H、初始/环境分布和通过条件。
- [ ] 使用与开发数据独立、无轨迹重叠的新采集；不同文件哈希本身不证明独立。
- [ ] 完成事先选定的统计校准与最终测试，失败则如实报告。
- [ ] 与原SPVC基线、仅代理不覆盖误差、全局盒、直接事件统计进行比较。

不承诺固定459条适用于所有新方案。它对应此前特定的最大次序统计量、误差概率与置信度选择；场景LP的样本量还取决于其自身条件和有效决策维度。

## 11. 能不能写成学术论文

有研究价值，但目前不适合把贡献写成“已经提出并验证了一套端到端安全保证方法”。

更有说服力的研究问题是：

> 如何用低维安全表示构建可验证代理，并将代理控制系统的证书以明确、不过度保守的方式转移到冻结视觉模型驱动的闭环系统？

可以形成的贡献需要实际完成：

1. 安全相关双路径表示，而不只是把cGAN替换成DINO。
2. 解释并解决全局误差盒在控制验证中的过度保守问题。
3. 一个假设、时域、分布范围都明确的转移定理。
4. 可信实现与实验，证明比仅看成功率、直接统计、单纯latent对齐有额外价值。

不能作为充分创新性的说法是：“使用了DINO＋PPO＋SBC＋CP，所以是新方法。”相关模块及组合方向已有研究。例如CP-NCBF已经研究将CP用于神经控制屏障构造，不能把“CP与屏障结合”本身作为新的首创点。[CP-NCBF原文](https://arxiv.org/abs/2503.17395)

本文没有完成新颖性检索，也不保证某个方向不会与别人重复或能够录用。论文可行性取决于理论缺口能否补上、效果是否优于适当基线，以及结果能否在不只一个非常特化场景中复现。

## 12. 可以直接向导师这样解释

> 我们没有证明DINO方案不能获得SBC。当前已经完成多外观数据、双路径表示和PPO，并得到图像路径与代理路径的轨迹误差覆盖。失败的是把这个误差压成一个全局区间，要求它在每一步任意取最坏值也安全；这比原SPVC的期望下降更强，已有反例说明当前规格不成立。
>
> 后来直接用轨迹训练屏障，虽然区域分离已经改善，但动态条件没有全部通过，而且有限轨迹通过也不等于原SPVC的连续域随机证书。下一步先完成R2在原SPVC中的代理基线，确认能否得到候选SBC，再明确处理图像到代理的证书转移。
>
> 如果坚持原文同等级的随机SBC，需要补条件随机模型和期望验证；如果接受有限时域目标，可以研究基于屏障风险增量的轨迹误差预算。两者都能保留当前DINO双路径，但不能混淆保证强度，也不能把CP覆盖直接叫成安全证明。
