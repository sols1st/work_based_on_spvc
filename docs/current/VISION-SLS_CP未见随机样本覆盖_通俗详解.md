# CP 原理与实验效果：为什么用、怎样算、加入以后得到什么

更新日期：2026 年 10 月 27 日。

这份说明只讲一件事：**图像测量会有误差，怎样用 CP 给这些误差划出一个有统计依据的范围，再检查它能否包住没参与算界的新随机样本。**

CP 是 Conformal Prediction 的简称，通常译为“保形预测”。名字不必先记住；本文会从“看误差、排大小、定范围”三个动作解释它。

本次讨论保持原来使用的机器人控制器和随机采样方式不变，比较的是视觉误差能否落在范围内。文中的真实数字来自已保存的停车场和无人机仿真，本次没有重跑控制实验或改变模型。

## 先看四个问题的直接回答

| 你关心的问题 | 本文的回答 |
|---|---|
| 为什么要用 CP？ | 学出来的误差范围可能在新样本上偏小。我们需要按一个明确的覆盖目标，用独立数据决定该怎样调整范围。 |
| CP 的原理是什么？ | 每次运行算出“需要把初步范围乘多少才够”，把这些数排序；按照未来样本在排序中出现的位置，选择与目标对应的倍率。 |
| 加入后得到什么？ | 一个可计算的新误差界，以及在规定条件下对新随机运行的覆盖结论；模型、倍率和计算依据都能保存下来。 |
| 实验效果怎么样？ | 同一批新随机轨迹，停车场全程覆盖由 13/42 提高到 41/42；无人机由 4/30 提高到 29/30。 |

阅读顺序可以按表中四个问题来：先读第 1—3 节理解目的、原理和产物，再读第 4—5 节的完整手算过程，第 6—9 节看实验效果和结论范围。程序细节与文件位置集中在附录。

## 1. 为什么需要 CP：学出一个函数以后，还缺什么

### 1.1 我们有两个不同的问题

第一个问题是：**哪个位置或姿态的视觉误差大，哪个地方小？**

可以用已有数据学一个函数。例如它在 A 处给出 0.04，在 B 处给出 0.06，在 C 处给出 0.08。这个函数学的是误差随状态变化的规律。

第二个问题是：**用这些数作为范围，能包住多少未来的新误差？**

即使第一个问题做得不错，也不能直接回答第二个问题。看下面的教学数据：

| 状态 | 函数给出的初步范围 | 新样本的实际误差 | 结果 |
|---|---:|---:|---|
| A | 0.04 | 0.048 | 超界，初步范围偏小 |
| B | 0.06 | 0.090 | 超界，初步范围偏小 |
| C | 0.08 | 0.064 | 在范围内 |

这个函数仍然可能学到了一部分空间规律，但我们还需要检查它有没有普遍留少了空间。**本次给初步函数加入 CP，就是为了处理这个后续问题。**

### 1.2 为什么训练时看起来不错还不够

函数是根据第一批数据调出来的，它自然更容易适合这些已经看过的样本。以后再出现一批图像，误差可能超过训练时看到的大小。

可以把它想成学生反复练过一套题：练习题成绩好，不能直接当作新试卷的成绩。我们需要另外一批题来检查并调整自己的判断，还需要新的试卷来评价最后效果。

CP 把这些职责分开：**学规律的数据、决定调整量的数据、最后评价的数据分别使用。**

### 1.3 为什么不直接把所有范围随便放大两倍

这样做可能提高覆盖，但还有两个问题：

- 为什么是两倍，而不是 1.1 倍或 3 倍？它与“希望覆盖 95% 的完整运行”之间是什么关系？
- 如果范围扩大得过多，后续控制就可能需要预留过多空间，一些本来能完成的任务也会更难安排。

本次选择 CP 的理由是，它给出了**数据量、覆盖目标和排序位置之间的明确规则**。倍率从另一批独立数据中算出来，有可说明的概率依据。

这里也要保留一个区别：CP 按覆盖目标选择倍率，并不证明得到的范围是所有可能方法中最小的。初步函数质量不好时，CP 算出的范围仍可能很宽。

### 1.4 我们希望加入 CP 后改善什么

希望改善的是：**在初步函数固定后，用另外的数据调整它，让同一种采样方式产生的新运行更经常被完整覆盖，并能够说明这个覆盖目标的由来。**

本轮预先选择的目标是 95%。这意味着关注“一次新运行的全部观测能否都被包住”，后面会一步步解释。网络输出本身的准确程度，在这个统计校准步骤中保持原样。

## 2. CP 的原理：为什么排序能对还没出现的样本有帮助

### 2.1 先把一次完整运行变成一个可比较的数

假设初步函数在某个时刻给出的范围是 0.04，实际误差却为 0.06。两者相除得到：

$$0.06/0.04=1.5.$$

它告诉我们：这一步需要把初步范围乘到至少 1.5，才能刚好覆盖实际误差。

一次运行里会有很多时刻。假设三步各需要 0.8、1.2、1.5 倍，那整次运行需要的统一倍率就是最大的 **1.5**。只要倍率达到 1.5，这三步就都能被包住。

于是，我们不用直接比较几十张图像，而是让每条完整运行提供一个“所需最大倍率”。

### 2.2 新运行和旧运行，必须来自相符的产生方式

想象有 20 条完整运行，它们都按相同的固定规则产生，使用同一套已经固定的初步函数。哪一条被叫作“校准运行”、哪一条被留作“新运行”，不会让它的误差天生更大。

这就是排序原理需要的关键。把校准数据与新数据一起考虑时，被留下的那条新运行，不会总是更容易排在最坏的一端。

论文常用“交换性”描述这种顺序不让某条样本变得特殊的性质。实际中，独立地按同一种规则采集运行，是使这个条件成立的常见做法。后文会用日常说法说明条件，正文不要求先掌握这个术语。

### 2.3 为什么 19 条校准运行可以对应 95% 的目标

继续考虑刚才的 20 条运行，其中 19 条用于算界，另外 1 条作为新运行。

若没有并列的分数，且这些运行满足上一段的数据条件，那么在把校准和新运行的随机性一起考虑时，新运行排在第 1、第 2、……第 20 位的机会相同。

我们用那 19 条校准运行中的最大所需倍率作为最终倍率。

- 新运行若排在前 19 位，其分数不会超过校准最大值，就能被覆盖。
- 新运行若刚好排第 20 位，它比那 19 条都更难覆盖，才会超界。

在这个简单情形下：

$$\text{超界概率}=1/20=5\%,\qquad
\text{覆盖概率}=19/20=95\%.$$

![CP 排序原理：新运行在二十个位置中的哪一个](/Users/johann/project/work_based_on_spvc/docs/assets/vision_sls_cp/cp_rank_principle_20_positions.png)

图中是帮助理解原理的假想排序，不是实验结果。实际计算时只使用那 19 条校准运行；我们并没有提前读取未来运行的误差。

**所以，CP 对未来样本的依据来自“未来样本在共同排序中的位置”。** 它不需要提前看见未来误差的具体数值。

### 2.4 更多数据时，也可以按目标选位置

实际停车场有 40 条校准运行，再加未来的一条，共对应 41 个可能位置。按 95% 目标，CP 选择校准分数中的第 39 小；在相应条件下，得到不低于 39/41≈95.12% 的总体覆盖下界。

因此，实际公式里会出现“校准数量加 1”，而不是只对已经看到的样本直接乘一个 95%。第 5 节给出完整的排序计算。

并列分数使用“误差等于界也算覆盖”的比较时，只会使这个规则更保守，不削弱所说的下界。

### 2.5 为什么这件事不要求先猜误差服从哪条曲线

上述想法主要利用样本之间的排序关系，不要求先假定真实误差一定符合某种特定数学曲线。这对复杂图像误差很有吸引力：误差可能不对称，也可能偶尔突然变大。

但数据产生条件仍然重要。如果未来运行来自完全不同的任务，或者换了模型、控制器和采样方式，排序中“新运行不特别偏向最坏一端”的依据就需要重新检查。

还要注意，理论把“随机抽校准数据，再产生新运行”作为一个整体来看。它没有承诺每一份已经抽好的校准数据，都必然算出一条单独达到 95% 的界。第 9 节会进一步解释这个范围。

## 3. 加入 CP 后，具体能得到什么

### 3.1 得到一个可以代入状态计算的新函数

本文使用的版本先有一个正的初步尺度 h，再由 CP 算出一个倍率 q，最后得到：

$$\boxed{b(x)=q\times h(x).}$$

这句话可以读成：**来到状态 x，就查出原来预留的误差空间，再乘上独立数据给出的调整倍率。**

例如教学数据中 h=0.064，q=1.25，则最终误差界为 0.08。原来误差大的地方仍可以有较大的界，原来误差小的地方仍可以有较小的界。

### 3.2 得到每个观测分量的明确范围

教学假设：参考读数是 [1.10，0.90，0.40]，最终误差界是 0.08。则它定义的视觉读数范围为：

| 分量 | 参考读数 | 允许的视觉读数范围 |
|---|---:|---|
| 第 1 个 | 1.10 | 1.02 到 1.18 |
| 第 2 个 | 0.90 | 0.82 到 0.98 |
| 第 3 个 | 0.40 | 0.32 到 0.48 |

如果三个分量都在各自范围内，这次观测就被覆盖。一次运行中所有使用的观测都被覆盖，才叫整次运行完整覆盖。

因此，“CP 输出一个误差界”不只是一句抽象说法，而是能转成这样逐项检查的范围。这里的数值属于网络输出的尺度，不直接代表厘米或米。

### 3.3 得到与目标对应的统计结论

当模型固定，校准运行与未来运行满足所需数据条件时，按本方法选出的倍率可以为**一次新随机运行的全部观测同时被覆盖**提供有限样本的概率依据。

本轮目标为 95%。对应的结论是：**在规定条件下，随机采集校准数据、算出界并再产生新运行的整个过程中，全程覆盖概率至少为 95%。** 这里同时考虑了校准数据和新运行的随机性。

依据来自第 2 节的排序规则；第三批测试则帮助我们检查固定候选在实际记录中的表现。理论条件和实测成绩需要一起说明。

### 3.4 得到可以保存和复核的一组结果

| 产物 | 它有什么用 |
|---|---|
| 初步函数 h | 说明不同状态原本预留多少误差空间 |
| 调整倍率 q | 说明独立数据要求整体怎样调整 |
| 最终函数 b | 以后可以直接按状态计算误差界 |
| 校准分数及排序位置 | 可以重算倍率，知道它的来源 |
| 新样本的覆盖记录 | 可以看哪些运行通过、哪些观测超界 |

这些结果比单独说“取一个差不多的误差上限”更容易检查和复现。

### 3.5 同时明确这次改善发生在哪里

在本专题的前后比较中：

| 项目 | CP 前后是否改变 |
|---|---|
| 网络对图像的输出 | 不变 |
| 每张图像的实际误差 | 不变 |
| 同一批机器人轨迹和动作 | 不变 |
| 用来包住误差的范围 | 按独立校准结果调整 |
| 判断被覆盖的观测和运行次数 | 随范围调整而改变 |

**本次得到的是更有依据、在新随机数据上覆盖更好的误差范围。** 范围变宽是有代价的，后续控制可能需要留更多空间；不能把覆盖提高直接读成网络更准确或控制更安全。

## 4. 真正开始算之前：先弄懂“误差”和“新随机样本”

### 4.1 把视觉读数与参考读数相减

#### 4.1.1 先想象一个容易理解的测量

假设一把电子尺测量桌子长度。真实长度为 1.00，电子尺显示 1.03，误差就是 0.03。

如果提前声明“误差不超过 0.05”，这次测量就在范围内；如果电子尺显示 1.08，误差为 0.08，就超出了这个范围。

我们希望声明的范围既有依据，又尽量不大。范围设得无限大当然能包含一切，但没有使用价值；设得过小，则会经常漏掉真实误差。

VISION-SLS 中要处理的也是这种“测量读数偏差”，只是网络输出有多个数，且其含义不直接等于桌长或物理位置。

#### 4.1.2 在实际实验中，一张图像对应两组数

对同一张图像，先得到：

- **视觉读数**：图像经过已经训练好的网络，得到的几个低维数字。
- **参考读数**：利用这张图像对应的真实状态，通过已经固定的参考读数计算规则 C 算出的数字。

停车场每组有 3 个数字，无人机每组有 5 个数字。视觉读数与参考读数的含义和尺度相匹配，所以可以逐项相减。

下面是教学例子：

| 分量 | 视觉读数 | 参考读数 | 相减后的误差 | 误差绝对值 |
|---|---:|---:|---:|---:|
| 第 1 个 | 1.12 | 1.10 | +0.02 | 0.02 |
| 第 2 个 | 0.85 | 0.90 | −0.05 | 0.05 |
| 第 3 个 | 0.43 | 0.40 | +0.03 | 0.03 |

本方案用其中最大的绝对值表示这一次观测的误差大小：

$$r=\max(0.02,0.05,0.03)=0.05.$$

数学上叫作无穷范数，但在这里先记住它的操作即可：**相减，取绝对值，再取最大。** 后面的拟合、CP 计算和测试都使用同一种操作。

#### 4.1.3 什么叫“覆盖”

假设给这次观测的误差界为 0.06：

$$\text{实际误差 }0.05\le\text{误差界 }0.06.$$

我们就说这次观测被覆盖了。因为最大的分量误差也不超过 0.06，所以三个分量都落在 ±0.06 的范围内。

若界为 0.04，这次就未覆盖。**覆盖是一个大小比较，不代表网络读数被修改或误差被消除了。**

这里比较的是网络输出的这组数字。0.05 不能直接说成小车位置偏了 5 厘米。

### 4.2 明确什么样的新运行属于本次讨论

#### 4.2.1 没参与算界，才叫这里的“没见过”

先使用一些数据学函数、算倍率，之后再生成另一批运行。这批新运行没有参与前面的拟合和算倍率，它们就是这里的未见样本。

“没见过”不表示事后也不知道真实误差。验证时仍要有真实状态，才能计算参考读数并判断有没有覆盖。

本轮是仿真，程序能记录真实状态。测试真值用来评分，没有拿它回头调整已经固定的误差界。也不能由此理解成实际部署时随时都知道真实状态。

#### 4.2.2 随机不等于任意改变一切

本专题讨论的随机性是：在规定好的场景、控制器、初始条件设置、图像处理和扰动采样方式下，再抽取新的随机扰动，生成新的运行。

例如，同一套停车场实验再运行一次，扰动不同，走过的细节和看到的图像也可能不同。这是同一种机制下的新样本。

如果换成另一套控制器、另一种遮挡机制或另一座完全不同的停车场，样本产生方式就变了，不能仅凭“以前没见过”三个字就直接使用原来的统计结论。

#### 4.2.3 实际实现必须先把图像和状态对齐

计算误差时，参考读数必须来自**生成这张图像的状态**。

教学例子：机器人已经从位置 1.0 走到 1.2，但当前收到的是位置 1.0 时拍的图。如果网络正确读出 1.0，却拿它减当前 1.2，就会凭空制造一个误差。

本轮程序按原执行代码的图像延迟对齐状态，停车场还处理了视觉与规划坐标的平移。然后才进行“视觉读数减参考读数”。这一步在 CP 排序之前完成，否则后面校准的是错位误差。

## 5. 从数据到最终误差界：六个步骤全部展开

下面使用同一个教学例子走完全过程。先用第一批数据学初步尺度，第二批独立数据算倍率，第三批独立数据评价最终结果。表格中的教学数值只为手算，实际实验数字在第 6 节另列。

### 5.1 先分开三批数据

可以把它理解成学习、调整标准、正式考试三个阶段。

| 数据 | 用来做什么 | 结束后留下什么 |
|---|---|---|
| 第一批：学形状 | 学习哪些位置或姿态误差大，哪些地方误差小 | 一个初步误差尺度函数 |
| 第二批：算倍率 | 检查初步函数在新运行上低估多少 | 一个统一倍率 |
| 第三批：独立检查 | 用固定函数和倍率，评价新的运行 | 实测覆盖次数与比例 |

常见名称分别是训练集、校准集、测试集。这里只要记住各自职责，不必先记术语。

为什么不全部用同一批？因为一个函数可能特别适合它已经看过的数据。在同一批上拟合再打分，很难说明它对后来数据怎么样。第二批必须与拟合过程分开；第三批则不能参与决定模型和倍率。

如果看了第三批发现不好，再改函数或调参数，这批数据就成为开发数据了。之后还要有新的独立评价数据。

### 5.2 用第一批数据学初步尺度 h

#### 5.2.1 它给的是初步尺度

我们把这个函数记作 h。它的输入是图像对应的状态，输出是一个正数：

$$h(\text{状态})=\text{该状态下的初步误差尺度}.$$

例如：

| 状态 | 初步尺度 h |
|---|---:|
| A | 0.04 |
| B | 0.06 |
| C | 0.08 |

意思是模型认为 C 处需要留的误差空间比 A 处大，不表示已经证明所有未来误差都分别小于这些数。

实际代码用多项式拟合状态与误差的关系。停车场输入二维位置、三阶多项式；无人机输入五个位置/姿态相关状态分量、四阶多项式。拟合使用第一批数据，拟合完成后固定参数。

#### 5.2.2 为什么代码里还有一个最小正数

实际先拟合函数 b0，再定义：

$$h(x)=\max\{0.001,b_0(x)\}.$$

这里 x 表示状态。取最大值，是为了使后面除以 h 时不会除零或除负数。它不意味着真实误差一定小于 0.001。

从这里开始，网络、参考读数计算规则 C、初步函数及其输入处理方式都固定。CP 接下来调整的是倍率，不会在这个步骤重新训练视觉网络。

### 5.3 在第二批数据上算每条运行需要的最大倍率

#### 5.3.1 每一次观测先算一个比值

计算：

$$\text{所需倍率}=\frac{\text{实际误差大小}}{\text{初步尺度}}=\frac r h.$$

这个比值可以直接读成“要把原尺度乘多少，才能包住这次误差”：

| 实际误差 r | 初步尺度 h | r/h | 怎么理解 |
|---:|---:|---:|---|
| 0.032 | 0.04 | 0.8 | 原尺度已经够大 |
| 0.072 | 0.06 | 1.2 | 需要乘到至少 1.2 才够 |
| 0.080 | 0.08 | 1.0 | 刚好够大 |

#### 5.3.2 一次完整运行只留下一个数

假设一次教学运行只有上表这三次观测。要让它**全程**都被覆盖，统一倍率至少需要多大？

$$\max(0.8,1.2,1.0)=1.2.$$

所以，这次运行只向 CP 提供一个数：**1.2**。

它代表“为了覆盖这次运行中的所有观测，所需的最大倍率”。后面将这个数称作该条运行的分数。

停车场实际一次有 30 次观测，无人机一次有 35 次。处理方式完全相同：先逐次算 r/h，再取该次运行最大的一个。

```text
一条停车轨迹的30次图像观测
        ↓ 各自计算误差与初步尺度
30个“误差/尺度”比值
        ↓ 取最大的
这条轨迹的1个分数
```

#### 5.3.3 为什么不能直接把所有图像混在一起排序

因为我们想评价的是“一次完整运行有没有全部覆盖”。一条轨迹里的图像还有时间关联，不能因为存了 30 张，就把它们当成 30 次彼此独立的完整运行。

因此停车场 40 条校准运行虽然有 1200 次观测，最终排序的是 **40 个轨迹分数**，不是 1200 个帧分数。

用一条轨迹的最大值，可以直接把“所有步骤都覆盖”变成“这条轨迹的分数没有超过最终倍率”。这也是本方案选择这种计算方式的原因。

### 5.4 把倍率排序，按目标选择一个数

#### 5.4.1 先规定自己想覆盖多少

本轮选择 95% 作为目标。直观上，我们希望同一种机制下的一次新运行，其全部观测同时被误差界覆盖的概率达到至少 95%。

这个目标是算界前设定的，不是看到测试比例后再决定的。它也不表示一条轨迹允许 5% 的帧超界。

#### 5.4.2 一个完整的 19 条运行教学例子

假设第二批共有 19 次完整运行，每次已经按上一节算出一个最大倍率。排序后得到：

```text
0.55, 0.60, 0.65, 0.70, 0.75,
0.80, 0.85, 0.90, 0.92, 0.94,
0.96, 0.98, 1.00, 1.02, 1.05,
1.10, 1.15, 1.20, 1.25
```

使用 CP 的有限样本排序规则：

$$\text{取第几小}=\left\lceil(\text{校准运行数}+1)\times\text{目标覆盖率}\right\rceil.$$

这里的向上取整，可以理解成：结果若不是整数，就进到下一个整数。

代入 19 次运行、目标 95%：

$$\left\lceil(19+1)\times0.95\right\rceil=19.$$

所以取排序后第 19 个数：

$$\boxed{q=1.25.}$$

这个 q 就是以后统一使用的倍率。前一节那条分数 1.2 的运行也包含在教学列表中；因为 1.2≤1.25，它的所有步骤都能被最终界覆盖。

#### 5.4.3 真实停车场为什么取第 39 个

实际停车场有 40 条校准轨迹，目标 95%：

$$\left\lceil(40+1)\times0.95\right\rceil
=\lceil38.95\rceil=39.$$

因此取从小到大第 39 个。它恰好是倒数第二个，不是第 38 个，也不是自动取最大值。

无人机有 60 条：

$$\left\lceil61\times0.95\right\rceil=58.$$

程序的排序位置从 0 开始，所以数学上的第 39 个对应代码数组下标 38。这只是下标约定，不是另一套统计方法。

#### 5.4.4 为什么公式里要加 1

因为排序规则考虑的对象还包括接下来的一条新运行。19 条校准加 1 条新运行，对应第 2 节图中的 20 个位置；40 条校准加 1 条新运行，对应 41 个位置。

“加 1”就是把这个未来样本纳入概率计算。因此规则不是只检查已经看到的数据覆盖了多少，还为尚未出现的那一条考虑了排序位置。

这一步的依据仍是第 2 节说明的数据条件：函数固定，校准运行与未来运行按相符规则产生。改变整个任务机制后，仅换一个随机种子不能使原来的结论自动适用。

#### 5.4.5 数量不够时，程序不能硬给有限界

例如只有 10 条校准运行，却要求 95%：

$$\lceil11\times0.95\rceil=11.$$

第 11 个数不存在。按本方法约定，此时返回无限大的界，而不是悄悄改取第 10 个并继续宣称原目标。

95% 目标的有限界最低需要 19 条校准运行。这只是排序规则的最低门槛，不代表 19 条就足以稳定描绘复杂场景的所有误差。

### 5.5 将初步尺度乘上选出的倍率

公式只有一行：

$$\boxed{\text{最终误差界}=\text{倍率}\times\text{初步尺度},\qquad b(x)=q\,h(x).}$$

教学倍率 q=1.25 时：

| 状态 | 初步尺度 h | 最终误差界 b=1.25h |
|---|---:|---:|
| A | 0.04 | 0.05 |
| B | 0.06 | 0.075 |
| C | 0.08 | 0.10 |

CP 用同一个倍率调整不同状态的尺度，所以原来“这里大、那里小”的空间关系仍然保留。

如果教学尺度函数为：

$$h(s)=0.04+0.02s,$$

未来某状态 s=1.2 时：

$$h(1.2)=0.064,\qquad b(1.2)=1.25\times0.064=0.08.$$

**这个 0.08 是函数与校准倍率算出来的，不是提前指定一个数后就自动获得覆盖依据。** 此处 s 只是用于手算的一维状态，不是实际停车场全部状态。

![教学例子：拟合尺度与排序倍率](/Users/johann/project/work_based_on_spvc/docs/assets/vision_sls_cp/cp_worked_example.png)

图中是教学数据，与本节例子一致。左图说明原尺度乘 1.25 后得到新误差界；右图说明这个 1.25 来自 19 个完整运行分数的排序。

倍率也可能小于 1：如果初步尺度本来太保守，校准后可能缩小。本轮两个实际倍率都大于 1，所以本轮观察到的是扩大误差界。

### 5.6 拿第三批新运行检查，不再改变界

#### 5.6.1 一次新运行怎么判定

继续使用教学倍率 1.25，假设新运行有三次观测：

| 时刻 | 初步尺度 | 最终界 | 实际误差 | 是否覆盖 |
|---|---:|---:|---:|---|
| 1 | 0.04 | 0.05 | 0.045 | 是 |
| 2 | 0.06 | 0.075 | 0.070 | 是 |
| 3 | 0.08 | 0.10 | 0.095 | 是 |

三次全覆盖，这条运行记 1 次完整覆盖。

如果第二步的实际误差变为 0.076，超过 0.075，即使其他两次仍覆盖，这条运行也记作未完整覆盖。

测试时要接受这一次失败，不能看到了 0.076 就把界改成 0.077，然后继续把同一批数据叫作独立测试。

#### 5.6.2 两个覆盖率，不能混着读

假设有 4 次新运行，每次 5 次观测：

| 运行 | 被覆盖观测数 | 全部 5 次都覆盖吗 |
|---|---:|---|
| A | 5/5 | 是 |
| B | 4/5 | 否 |
| C | 5/5 | 是 |
| D | 3/5 | 否 |

- 按观测数算：17/20=85%，这是逐点覆盖率。
- 按完整运行算：2/4=50%，这是整轨迹覆盖率。

就像几份试卷：总题目正确率很高，不意味着很多份试卷能全部答对。本方案以整条运行的最大倍率来算 CP，主要关心的是后一个指标。

## 6. 实验效果：在同一批新随机轨迹上，覆盖提高了多少

先说明这张成绩单对应什么：视觉模型、原来固定使用的控制器、测试轨迹和实际误差均保持相同。比较的是本次新拟合的初步尺度 h，与 CP 调整后的 qh。

**这里的“校准前”专指新拟合函数 h 尚未乘 CP 倍率；它不是作者原代码全部误差模型成绩的统称。** 这份对照也不包含用新界重新设计控制器后的运行。

| 实验设置 | 停车场 | 无人机 |
|---|---:|---:|
| 一次运行的观测数 | 30 | 35 |
| 用于拟合的运行数 | 40 | 100 |
| 用于算倍率的独立运行数 | 40 | 60 |
| 本节独立随机测试运行数 | 42 | 30 |
| CP 调整倍率 q | 约 1.23264 | 约 1.18705 |
| 相对原尺度增加的空间 | 约 23.26% | 约 18.70% |

### 6.1 本次比较只改变误差界

我们拿第三批已经保存的原始轨迹，做两遍判断：

```text
第一遍：实际误差 ≤ 初步尺度 h 吗？
第二遍：实际误差 ≤ CP 最终界 q × h 吗？
```

两遍使用完全相同的轨迹、视觉输出、真实状态和实际残差。没有更换测试样本，也没有重新运行一个更容易的控制任务。

### 6.2 最关心的全程覆盖，改善很明显

| 场景 | 校准前整轨迹覆盖 | CP 后整轨迹覆盖 |
|---|---:|---:|
| 停车场，新随机测试 42 条 | **13/42，30.95%** | **41/42，97.62%** |
| 无人机，新随机测试 30 条 | **4/30，13.33%** | **29/30，96.67%** |

![同一批新随机轨迹在 CP 前后的完整覆盖](/Users/johann/project/work_based_on_spvc/docs/assets/vision_sls_cp/unseen_random_coverage_before_after.png)

图中虚线是预设目标。柱子是有限测试的实测比例，不能仅凭它们高于虚线，就认定真实覆盖概率必然超过 95%。两场景的结果支持在本轮固定参考策略及随机采样机制下，CP 校准起到了预期作用。

### 6.3 每一次观测的覆盖也提高了

| 场景 | 测试观测总数 | 校准前覆盖 | CP 后覆盖 |
|---|---:|---:|---:|
| 停车场 | 42×30=1260 | 1208/1260，95.87% | 1259/1260，99.92% |
| 无人机 | 30×35=1050 | 1001/1050，95.33% | 1049/1050，99.90% |

可以看到，校准前逐点覆盖已经在 95% 左右，但全程覆盖很低。原因是少数超界观测分散到了很多次运行中。

停车场校准前共有 52 次观测超界，影响了 29 条运行；校准后只剩 1 次观测超界，影响 1 条运行。

无人机校准前共有 49 次观测超界，影响了 26 条运行；校准后只剩 1 次观测超界，影响 1 条运行。

这正好说明了为什么要按“一条运行中的最大比值”来校准：即使只是少量步骤超界，也会让完整运行无法被覆盖。

### 6.4 放大约两成，为什么整轨迹比例会提高这么多

因为“全程是否覆盖”是一个门槛判断。

假设某次运行 30 步中有 29 步都在界内，只有一步需要倍率 1.10。倍率为 1 时整条不覆盖，倍率增加到 1.23 后整条就覆盖了。并不需要 30 步的误差都发生巨大变化。

如果很多运行的最大比值刚好集中在 1 到 1.23 之间，统一放大约两成，就可能使很多运行跨过这个门槛。本轮停车场校准前后从 13/42 到 41/42，就是在同样残差上发生的覆盖判定改变。

### 6.5 这个改善证明了什么

它直接支持：

- 初步尺度函数在这批随机测试中不足以经常包住全程误差；
- 在未参与算界的数据上，独立校准得到的倍率显著改善了完整覆盖；
- 此时没有把界放到无限大，而是使用了约 1.23、1.19 的有限倍率。

它没有说明视觉误差更小、机器人动作更好或任何条件下都不会超界。扩大误差范围使覆盖更容易，所以评价时还要关心界有多宽。CP 提供的是一套与覆盖目标对应的倍率选择规则，不是脱离范围大小只追求一个漂亮百分比。

## 7. 为什么没有覆盖到 100%：看两次真实超界

这是本轮数据里的真实观测，可以帮助理解“统计覆盖允许少量超界”。

### 7.1 停车场的那一次

在随机测试子集第 23 次运行、第 22 次观测时：

| 量 | 数值 |
|---|---:|
| 初步尺度 h | 0.07103637 |
| 校准倍率 q | 1.23263838 |
| 最终界 qh | 0.08756215 |
| 实际误差大小 r | 0.09132456 |

比较结果：

$$0.09132456>0.08756215.$$

这一次观测需要的倍率约为：

$$r/h\approx1.28560,$$

比已经固定的 1.23264 更大，所以它没被包住。这一帧使该条运行未能完整覆盖，因此结果为 41/42，而非 42/42。

### 7.2 无人机的那一次

在随机测试子集第 11 次运行、第 23 次观测时：

| 量 | 数值 |
|---|---:|
| 初步尺度 h | 0.04460025 |
| 校准倍率 q | 1.18704612 |
| 最终界 qh | 0.05294255 |
| 实际误差大小 r | 0.05453689 |

需要的倍率约为 1.22279，高于固定倍率 1.18705，因此该观测未覆盖，最终为 29/30 条完整覆盖。

这里使用从 1 开始的“第几次”方便阅读；原始数组下标从 0 开始，对应索引已保存在复核记录中。

### 7.3 为什么不把倍率再调大，让这两次也通过

可以把更保守的方案作为新的开发候选，但不能根据这两个测试失败点修改倍率，再把同一批数据当作未见测试来证明新方案。

本轮选择 95% 目标，并按照独立校准数据得到倍率。留下这些超界记录，才能如实评价这个已经固定的方案。

实际每场景的 50 条测试并非全部随机样本，还专门加入了一些按指定方向持续施加扰动的测试。例如停车场的一次测试会始终只沿某个状态分量的正方向或负方向施加规定扰动，而不是每一步随机抽取方向。

这些是刻意设置的压力情况，没有按校准集那种随机方式抽取，所以单独列出来。

| 场景 | 同机制随机测试的 CP 整轨迹覆盖 | 另外的压力测试覆盖 | 两者混合后的比例 |

<a id="meaning-95"></a>
## 9. 得到了 95% 的统计依据，可以说到哪一步

### 9.1 它给的是随机意义下的覆盖依据

通俗表述是：

> 模型固定、数据条件成立时，按规定方式生成校准运行并算出界，再生成一次新运行，CP 对这整个随机过程给出至少 95% 的全程误差覆盖依据。

要特别注意：换一批校准数据，算出的倍率也会变。标准 CP 控制的是包含这种随机性的总体覆盖，**不要求每一份已经抽到的校准数据算出的界，都单独具有至少 95% 的未来覆盖概率**。

它也不表示每个固定位置、每种遮挡或每个小分组都各有 95% 覆盖。某些较少出现的情况，覆盖可能更差。

### 9.2 为什么不是让每一个未见样本都通过

因为目标是统计覆盖，允许有尾部样本超界。要求未来每一种误差都不超界，需要更强的假设或其他验证，不能由普通 CP 的 95% 直接得到。

一次未覆盖不代表程序一定算错；反过来，多次未覆盖也不能一律说成“允许的 5%”。需要看它们来自什么机制、样本数量多少、是否持续偏离目标，以及模型和划分条件是否成立。

### 9.3 为什么测试结果不必刚好等于 95%

95% 是预先选定的目标；测试比例是有限次实际运行数出来的结果。它会受样本波动影响，可能是 94%、96%、98%，不会被算法强制固定为 95%。

例如停车场测试 42 条，完整覆盖 41 条就是 97.62%。这个结果与目标相符，但**不能单凭这 42 条就证明当前固定误差界的真实覆盖概率必然超过 95%**。

还要分清校准集与测试集。用 40 条校准分数的第 39 个算界，校准集通常至少覆盖 39/40=97.5%，这与排序规则直接相关；它不能代替第三批独立数据的成绩。

<a id="plain-explanation"></a>
## 10. 把目的、原理、实现与效果连起来讲一遍

假设有人问：“未来一次运行会遇到没见过的图像，你怎么知道误差范围该留多大？”

可以这样解释：

> 我们先用第一批数据，学出每个状态附近大概需要留多少误差空间。这个函数还只是一个初步判断。
>
> 然后保持它不动，另外运行一批数据。每个时刻都比较真实误差与初步判断，算出需要放大多少倍；一次运行只保留它最困难的那个时刻。
>
> 再把这些完整运行需要的倍率排好。按预先指定的95%目标和有限样本规则，选出一个统一倍率。以后每个状态的误差界，都用这个倍率乘原来的尺度。
>
> 最后用第三批、没有参与算界的随机运行检查。本轮固定参考策略下，停车场完整覆盖由13/42提高到41/42，无人机由4/30提高到29/30。说明这次校准确实改善了新随机运行上的覆盖。
>
> 这个结论有适用范围：模型固定、运行产生方式相符，并满足CP所需的数据条件。它允许少量超界，不承诺每个未来样本都通过，也不会把视觉网络的实际误差消除。

**这就是本专题中 CP 的作用：用独立数据决定误差范围该怎样调整，让范围对相应机制下的新随机运行有统计覆盖依据，并用另一批数据检查实际表现。**

## 附录 B. 程序实现与复核方法

需要看代码时再读本附录。理解正文的排序原理和实验效果，不要求先理解下面的数组操作。

### B.1 程序如何按步骤计算

先用日常语言写一遍程序顺序：

```text
读入已经拟合好的函数，后面不再改它
    ↓
读入新的校准运行及每一步的真实误差
    ↓
每一步算“误差/初步尺度”
    ↓
每条运行只保留最大的比值
    ↓
把这些最大比值从小到大排好
    ↓
按样本数和95%目标，取指定位置的数作为倍率
    ↓
保存倍率与原函数，得到最终误差界
    ↓
在第三批新运行上逐步检查，再逐条统计全程覆盖
```

#### B.1.1 与实际程序对应的简化代码

下面忽略文件读取和网络推理，只保留 CP 算术。`r_cal`、`h_cal` 的每一行是一条运行，每一列是一个观测时刻；测试数组也是相同含义。

```python
import math
import numpy as np

# r_cal：每步实际误差大小；h_cal：固定函数给出的正尺度
# 两者形状相同，例如停车场为 (40, 30)
assert r_cal.shape == h_cal.shape
assert np.all(h_cal > 0)

# 1. 每一步需要的倍率
ratios = r_cal / h_cal

# 2. 每条运行留下最大的倍率
scores = ratios.max(axis=1)

# 3. 按95%目标确定排序位置
n = len(scores)
k = math.ceil((n + 1) * 0.95)

# 4. 取倍率；样本不足时遵循无穷大约定
q = np.sort(scores)[k - 1] if k <= n else float("inf")

# 5. 在独立测试数据上用固定的q算界，不再调整q
test_bounds = q * h_test
covered = r_test <= test_bounds

# 6. 每个时刻都覆盖，这条运行才算完整覆盖
whole_run_covered = covered.all(axis=1)
print(whole_run_covered.sum(), "/", len(whole_run_covered))
```

真正程序还会检查协议中的轨迹数量、random_only 标志、种子、数据来源哈希和数值有效性，并保存每条轨迹分数。上面的代码演示的是计算逻辑，不包括全部工程检查。

#### B.1.2 为什么要把一整个模型保存下来

保存一个 q 不够，还需要保存它乘的是哪个函数，以及当时如何产生数据。

| 保存内容 | 原因 |
|---|---|
| 初步函数的系数、输入变量、特征顺序 | 保证能算出同一个 h |
| 输入的标准化参数 | 避免同一状态因预处理不同而得到不同尺度 |
| 最小正尺度 0.001 | 确保计算规则一致 |
| 倍率 q、目标 95%、运行数 n、排序位置 k | 说明界怎样得到 |
| 校准分数和数据哈希 | 方便重算与追溯 |
| 每条运行的步数和采样协议 | 明确这个覆盖结论针对什么运行 |

本轮这些内容保存在各场景 `doc_cp_model.json`、`doc_cp_scores.npz` 和 `protocol.json` 中。

### B.2 本次怎样从原始数据重算

本次讲解前，从保存的原始数组重新做了以下核对：

1. 用真实图像观测、对齐后的状态和 C 重算误差向量，与原记录比较一致。
2. 用已保存的系数重新计算 h，确认最终界确实为 qh。
3. 从校准轨迹重新算每条最大比值，排序后得到相同 q。
4. 在同一批测试残差上分别比较 h 和 qh，得到前后覆盖次数。
5. 把随机与压力子集分开，核对随机部分只有一条轨迹、一个观测超界。
6. 与既有报告中的固定参考策略测试指标交叉核对。

实际程序允许 1e−8，也就是 0.00000001 的比较余量，以免计算机小数运算带来的极小差异影响边界判断。正文第 7 节两次真实超界的差值远大于这个余量，所以这些未覆盖判定不依赖这点极小的比较余量。

这些是旧数据的独立重算，没有据此调整模型或 q。原实验时，这批测试没有参与该模型拟合或校准；现在它们已被看过，今后开发新的模型仍需要另外的最终测试数据。
