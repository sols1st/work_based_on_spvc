### Slide 3｜安全链条：CP + SBC 在做什么

**标题：** CP 管“误差有多大”，SBC 管“误差在包络内时是否安全”

**画面：** 横向 5 步流程，每步一个短句：

```text
图像 → DINO → y
状态 x → Cx
e = y − Cx
CP：q / q·b(x)  → 误差集合 E
SBC：B(x') ≤ B(x) 对所有 x'∈E
```

下面三个小框：

- **CP 95%：** 新轨迹的误差以约 95% 概率落在包络内（边缘覆盖，不是每个状态都 95%）。
- **SBC：** B≥0；初始 B≤1；危险 B≥20；包络内后继不增。
- **验证：** 连续域切盒，检查所有后继；0 实际反例 + 0 未解决才算通过。

**讲稿提示：** 用“雨伞”比喻：CP 是伞要多大；SBC 是伞内走路不能把风险分数抬高。

**不要放：** 太多公式；公式放备份 B1。

## 3. 备份页

### B1｜术语和公式

- CP：`rank=ceil((n+1)(1−α))`；n=199，α=.05，rank=190；不是 `np.quantile(.95)`。
- 轨迹 CP：`s_j=max_t |e_t|`；一条轨迹一个样本。
- 状态相关：`r(x)=q b(x)`，`score=max_t |e_t|/b(x_t)`。
- SBC：`B≥0`，初始 `B≤1`，危险 `B≥20`，包络内后继 `B'≤B`。
- 风险上界：`B0/20`，条件在误差包络内。
- 轨迹 CP 95% ≠ 每帧/每状态 95%；CP 95% ≠ 安全 95%。

### B2｜AEBS 全表

- 固定 C：q .418359，190/199，99/100，292,024 0/0，4,800/4,800。
- 状态相关：q mean .3217/max .7189，190/199，92/100，41,070 0/0。
- 旧 .2307 tube：单位错误，撤回。
- cGAN 原生 q1.9156/92；迁移 5.221/87.64；DINO400 4.0205/94。

### B3｜车道/状态 CP

## 5. 讲之前必须统一的口径

1. **原生 cGAN q = 1.9156 m**；5.221 m 是迁移，不是原生。
2. **24k DINO q = 0.4184 m**；不是 cGAN 原生 q。
3. **400 图同预算 cGAN q 更小**；不能写 DINO 架构全面胜。
4. **C 联合无独立收益**；不能写“学习 C 提高可观测性”。
5. **CP 95% ≠ 安全 95%**；SBC 是条件证书。
6. **行为成功 ≠ 证书通过**；机器人 24/24 但 28/32 盒内反例。
7. **所有结论限定**在保存图像/渲染图、注册分布、数值区间；不是实车/形式化浮点证明。
