## 前一轮修正：加入旧约束保留机制与普通PPO对照

### 本次只改什么，为什么这样改

前一轮出现16个unsafe区域错误，说明NBC只拟合少量新访问轨迹会破坏已有约束。本次针对这一点修改NBC更新，不改表示、q、奖励、解析动力学、PPO学习率/预算、探索方差或SPVC后端；不加入QP、CP、多步项、新数据和test。

新增`Aebs/dino_latent/nbc_retention.py`，由`train_joint_nbc_ppo.py --nbc-retention`调用：

1. 保留原742320个训练图像单步转移，每次NBC优化抽2048个旧转移；新/旧动态损失各占一半。旧样本只训练NBC，绝不冒充当前策略的PPO在策略样本。
2. 区域损失同时保留均值和最大违反，避免极少数unsafe点被平均值稀释；训练区域仍32×32。
3. 固定16384个旧训练转移和81×81初始/unsafe网格做保留检查。检查λ=0.1、ε=0.01余量，旧平均动态损失不得超过固定初始参考值加1e−6，旧原始违反数和C边界越过数不得增加。1e−6是计算容差，不是额外安全风险预算。
4. 每批仍尝试10次NBC优化；不满足检查就恢复该批之前NBC权重与Adam动量。**只回退NBC，不回退PPO。** 检查是训练侧有限样本保护，不是连续域证明。

固定保留样本由独立随机数生成器从train抽取，未读取validation/test标签进行模型保留；不会改变PPO随机采样序列。81网格包含最后41网格的检查位置，但这也不等于完整区域证明。初始参考在16384点上原始动态违反7、边界越过1、ε动态损失均值1.12830e−5：这些原有违反并未被消除，门槛只防止继续变差。

这三个组成部分是同一个“防止NBC遗忘”的工程修正，来自旧约束回放/候选保留动机，不冒称Model-Free NBC论文的新定理或作者原样算法。

### 必须说明：NBC四轮均未获准保留

两个新组的四次NBC候选都通过了区域余量检查，提议unsafe最小值约+0.092，而非上一轮负值错误。这显示新区域损失改善了候选区域分离。但是候选在旧训练保留点上的平均动态损失约6.65e−5～7.05e−5，比原参考1.1283e−5变差；原始违反从7增至26～29，均被门槛拒绝。

因此最终NBC与首轮预训练NBC的所有参数/固定缓冲区**逐张量完全相同**。模型文件哈希不同是因为记录了不同策略身份与元数据，不代表NBC学到了新权重。

**准确结论：我们实现并测试了“防止遗忘”的保护机制，区域错误16→0；但它靠拒绝所有候选保护旧NBC，没有完成NBC对新策略的成功适应。** PPO仍更新，其验证退化没有被这一保护机制阻止。不能把本轮称为成功的联合安全学习，也不能把原始未通过的NBC变成证书。

### 安全条件怎样影响PPO

每轮先收集2048步，存下完整策略的原始高斯采样动作与旧log-prob、实际裁剪动作、奖励、状态/后继、回合编号、终止标记、图片编号、外观和查图距离误差。真实末状态在自动reset之前记录；不把两个回合的状态相连。4轮合计8192步。

先固定该轮采样前的NBC，得到`g=relu(C(next)−0.9*C(current)+0.01)`。把g全批居中并缩放后作为**已脱离计算图的安全成本**，以`exp(new_log_prob−old_log_prob)*cost`加入PPO损失。直观地说：提高相对安全动作的概率，降低相对高违规动作的概率；不需要对车辆动力学求导。

PPO每轮4个epoch、batch256、lr=1e−5、KL门槛0.01；安全系数初值0.05，按本轮平均违规小幅递增并上限1。这个单步成本、全批归一化及有上限递增规则是**本项目的简化试验设置**，灵感来自Model-Free NBC第V节概率比反馈，不是原作者完整多步PPO-Barrier原样复现，也不是理论最优乘子。

PPO更新后，才用记录的真实后继更新NBC10次（lr=3e−4、λ=0.1、ε=0.01），避免屏障先改变自己的评分，把PPO的风险信号抹掉。DINO/q不参加更新。

### 先说清楚“接进去了什么”

此前`environment_nbc_20261013_001`名字含NBC，但当日实际是旧SBC与环境区间诊断，不是Model-Free NBC训练。**2026-10-14才新增并运行了论文第IV-B节的单步屏障学习部分。** 目前是离线NBC候选预训练，尚不是论文完整PPO-Barrier联合算法。

### 环境影响如何进入这次训练

固定当前最终actor，对每张真实图片自己的物理距离和60个非零速度，已有记录为：

`真实RGB → 冻结DINO/投影 → 图像latent → 最终actor → 裁剪动作 → 已记录AEBS下一状态`。

“Model-Free”在本轮的准确含义是：**屏障学习只用固定转移样本，不计算动力学导数。** 样本生成仍使用已有解析AEBS模拟器，不是实测CARLA车辆动力学。没有额外叠加旧固定均匀噪声，所以本轮也不等价于原SPVC的噪声证书。未来天气/图像误差覆盖仍未证明。

### NBC条件、损失和适配

新网络为2→64→64→1、tanh隐藏层、线性有符号输出，输入为物理状态的VT坐标`(d/3.182720661...,v)`，内部再固定归一化。与原Softplus非负SBC是不同候选，不能沿用原95.62%读数。

候选区域`C(x)≤0`；初始区要求负值，不安全区要求正值；单步条件：

`C(next) ≤ (1−λ)C(current)`，λ=0.1。

例如−1→−0.95虽然值变大，但仍满足−0.95≤−0.9；不会像固定下降要求那样机械惩罚所有上升。三个训练项：

- 初始区：`mean relu(C+ε)`。
- 不安全区：`mean relu(ε−C)`。
- 单步：`mean relu(C(next)−0.9*C(current)+ε)`。

ε=0.01用于防止恒等于0的屏障和提供训练余量，来自官方srlnbc正裕量实现的动机；本项目借鉴该形式，用PyTorch重写，不声称已迁移作者整个TensorFlow/Ray框架。

监督只使用已知任务区域：初始[15,16]m×[2.5,3]m/s；unsafe[5,6]m×(0.5,3]m/s。训练区域网格32×32，开发检查41×41（速度从0.5001开始避免把0.5的成功边界误标为unsafe）。这是已知安全事件标签，不是人工可恢复标签，也没有修改原VT矩形。区域网格检查不是连续区域证明。

### 1. 为什么不能直接拿两个原始误差比大小

32维latent的误差与32×32像素图的误差不在同一坐标系。即使除以维数，latent的数值尺度也可以随网络缩放而改变，所以“0.05比0.1小”本身没有比较意义。

新实验固定已经训练好的DINO和32维投影，不重新训练评价器。定义`E(I)=P((DINO(I)-训练均值)/训练标准差)`，所有图像使用相同预处理。对于同一真实图像I和其距离d：

| 数据 | 得到的共同空间向量 | 作用 |
|---|---|---|
| 真实RGB图像I | `z_real=E(I)` | 两种方法共同的参照 |
| DINO物理代理 | `z_q=q(d/距离标准差)` | 新方案的代理 |
| 原生成器图像G(d,z) | `z_G=E(G(d,z))` | 旧方案的代理转入同一个空间 |
| 真实图像按原方法降到32×32灰度 | `z_low=E(downsample(I))` | 观察分辨率、灰度及原预处理本身引入的差异 |

对每张图计算`新误差=||z_q-z_real||₂/√32`；对每次生成计算`旧误差=||z_G-z_real||₂/√32`。两者使用**同一个参照、坐标系和尺度**，才可以作配对比较。这里除以√32得到坐标均方根距离，并不是新的学习目标。

通俗解释：不再问“图片相差几个像素”和“latent相差几个数”谁更小，而是把两条代理都放到同一个已有的语义空间，再问谁更接近真实图像。

**必要限制**：这个32维评价空间是任务训练得到的，q本来就被训练去贴近它，所以它不是与两种方法独立的裁判。结果只能称为“冻结任务语义空间中的代理一致性”，不能只靠它证明新结构普遍优于图像生成。旧cGAN为32×32灰度，新方案为RGB前端，且训练数据规模不同；结果属于现有系统比较，不是排除所有混杂因素的架构消融。已有米、米/秒物理量对照应一起展示。

### 90%目标区域如何定义

新增独立的诊断口径，不覆盖第22步原窄带口径。先用带真实区间输入的IBP，对初始区和不安全区各自直接划分20×20小盒，计算初始上界a与不安全下界u。使用不平移的归一化`B_normalized=B/a`，90%目标对应原B阈值`a/(1-0.9)=10a`。只有`u>=10a`，区域分离才支持继续检查这个目标。否则直接记录区域分离不足，不把目标降低到“通过”为止。

在现有10000个点中，额外标记安全且`B<=10a`的点为`target_probability_scope`。原来的legacy_band、below_unsafe_safe、all_safe三个掩码保持不变。这只是论文式阈值对应的**候选代理检查区域**，不代表已验证所有连续状态；本步也没有利用终止区额外删点。没有减去有限网格的domain_min，避免把局部最小值误当成全局非负性依据。原类的`square_output=True`实际调用softplus，脚本保持原实现，没有换网络。

### 具体计算什么

1. 核对R2、旧PPO、第22步新actor/SBC及scope记录的哈希，检查距离单位和保存数组一致。
2. 统计旧三种区域及新增90%候选区域的违反位置。此处计数仍来自第22步legacy期望，不冒充全网格corrected结果。
3. 最多选12点：原窄带补偿最差点、90%区域硬违反最差点和补偿最差点，并补入空间上分散的问题点；同一点不重复。
4. 对每点依次计算10×10、20×20、40×40、80×80噪声小格。同步保留原实现值、中点近似、带真实区间输入的期望下界/上界。10×10结果必须复现第22步保存值，否则停止排查模型或代码差异。
5. 输出`residual=E[B(next)]-B(current)`，负数表示下降。若整个区间为正，数值结果支持该点确实上升；若上界为负，支持该点严格下降；区间跨0或非常接近0则仍未解决。`1e-5`仅用于诊断标签，不是新的安全容忍阈值。
6. 另记期望上界加原网格补偿、加训练epsilon=0.1后的残差。点上负残差不自动说明原训练间隔、网格补偿或全域条件都通过。

**当前R2 DINO双路径代理闭环已经达到本地沿用的SPVC实现的“非空窄带零硬违反”结果，并实现初始区与不安全区的屏障值分离；但尚未证明满足原论文定理的全部条件，也未通过本次实验建立实际图像闭环的端到端SBC保证。**

这里“与SPVC同口径”是指采用相同的训练机制、噪声设置和检查规则，不是所有模型、数据、输入维度和证明假设都完全相同。也不是已与原cGAN模型做完同预算的优劣对照。

### B. 与本地SPVC实现保持一致和发生变化的部分

| 比较项 | 本地原SPVC基线 | 当前第22步R2版本 | 结论边界 |
|---|---|---|---|
| 可验证前端 | 状态与环境变量经cGAN/感知近似链送控制器 | 物理距离经小代理q得到32维latent | 替换的是感知表示链，不是证明两条前端完全等价 |
| 实际图像路径 | 原感知链及其控制输入 | 图像→冻结DINO→R2投影→32维latent，与速度一起送PPO | 图像路径没有直接进入第22步状态网格验证 |
| 控制器 | 原感知输入对应的PPO | 适配32维latent＋速度的R2 PPO | 保留PPO方法与SPVC更新机制；不是原PPO的相同输入维度或相同权重 |
| SBC | 原神经SBC结构与训练方法 | 沿用原结构、平方输出、区域及下降损失 | 不使用第19步轨迹SBC权重 |
| 训练流程 | SBC与控制器交替更新 | 沿用原循环 | PPO可能被更新，不能直接继承旧PPO的统计保证 |
| 动力学和随机噪声 | 原AEBS与factor=0.05的均匀下一状态噪声 | 相同 | 此噪声不是第14步CP残差盒，也不自动覆盖实际DINO误差 |
| 状态网格 | 100×100 | 相同 | 10000为总网格数，不是窄带实际检查数 |
| 下降检查范围 | 归一化B位于不安全下界的95%～100%之间 | 相同，实际选中69点 | 是B值的窄带，不是物理距离固定的一条危险带 |
| 硬违反规则 | `expected-B>=0`计违反，使用原比例阈值 | 相同；本次0/69 | 硬检查通过不等于全部验证条件通过 |
| 网格补偿与区间计算 | 原局部梯度补偿及legacy区间实现 | 保留不变 | 原实现的已知审计限制也保留下来，不因复用而消失 |
| 距离单位 | 原数据std1归一化 | 原VT坐标保留，进入q前转换到R2尺度 | 必要的接口单位转换，不改变物理安全定义 |
| 额外诊断 | 本次不依赖其额外诊断 | 同一checkpoint上增加宽区域检查 | 只记录，不改变训练、停止条件或原硬判定 |

本次没有加入QP、安全过滤器、人工可恢复集或新的CP契约；也没有为了得到零违反进一步缩窄原95%～100%的带宽。

### C. “和原论文一样的保证”为什么还不能直接说

必须区分三个层次：

1. **原实现口径的实验结果：已有正面结果。** 窄带实际69点，硬违反0；区域界顺序正确。
2. **原论文定理所需的完整验证：尚未建立。** 原论文Theorem 2.2在规定的安全子水平区域要求期望下降，不是只检查不安全阈值下方最后5%的带。当前扩域诊断存在违反，且窄带补偿后也有1个违反。扩域诊断本身不是原定理的逐项完整实现，因此这里的结论是“证据尚不充分”，不是宣布原论文定理被推翻。
3. **从q代理到实际图像路径的转移：尚未由第22步证明。** `距离→q→PPO`和`图像→DINO/投影→PPO`共用控制器，但输入latent仍有差异。需要为相同最终控制器补上误差覆盖与安全传递论证。

期望下降意味着按指定噪声分布计算的下一步平均屏障值不增加；它不要求每次随机转移都下降。与此同时，不能因为采用期望而随意漏掉定理要求检查的状态。原方法假设、代码筛选、数值界是否有效，都应逐项核对。这一要求对原基线和改进方法相同，不是给DINO方案单方面增加标准。

### E. 第21步与第22步分别证明到哪里

- **第21步：** 459条轨迹均success，CP评分阈值为负。在完整性、事先冻结、独立同分布等条件经核验成立时，可支持登记分布及400步范围内的轨迹统计安全结论。它不是原神经B条件期望下降的验证。
- **第22步：** 使用原SPVC训练与legacy检查，对代理闭环得到窄带零硬违反及正确区域分离。它不使用第21步校准数据作为误差证明，也不自动得到真实图像闭环保证。
- **不能直接合并：** 不能把第21步的99%/99%与第22步的95.41%直接相乘、相加或任选其一作为“最终系统安全率”；需要先确认模型一致，再建立组合定理及各自假设。

### F. 可以直接放入汇报的总结段

> 我们在保持原SPVC训练机制、AEBS动力学、随机噪声和窄带硬检查规则不变的前提下，将原感知前端替换为冻结DINO与R2双路径latent表示。当前代理闭环在原窄带实际选中的69个网格点上实现零硬违反，初始区与不安全区屏障值成功分离。这说明当前方案能够达到原实现的窄带硬检查结果，并非在相同口径下无法训练出候选屏障。同一checkpoint扩大检查范围后出现违反，窄带补偿后也仍有1个违反，因此区域比率95.41%目前只作为数值指标，不能直接解释为已经证明的安全概率。后续需要核验原定理条件，并对最终PPO补充图像路径评估与代理误差转移，才能讨论原论文级别的端到端保证。

## 2. 完整数据流

部署图像路径：

```text

速度 ─────────────────────────────────────────────┘
```

原SPVC训练和VT网格路径：

```text
物理距离 → 冻结q_psi → 32维latent ┐

速度 ─────────────────────────────┘
                                      ↓
                         原人工均匀过程噪声
                                      ↓
                       原SBC训练与VT网格检查
```
