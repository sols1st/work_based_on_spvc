## 2. 与 AEBS 统一了什么，哪些仍然属于任务适配

直接复用的模型实现是 [Aebs/vision_sls/sbc_cp.py](../../artical-F122/Aebs/vision_sls/sbc_cp.py) 中的 NonnegativeSBC，而不是另写一个相似名字的网络。checkpoint 也使用 AEBS 的加载格式。

统一的核心流程是：

~~~text
PPO 任务预训练
  → 固定策略，训练非负 SBC
  → 连续域验证
      → 通过：冻结策略—SBC 配对
      → 区域条件失败：继续修复 SBC
      → 动态条件失败/未解决：反例或未解决状态反馈
          → 固定 SBC，小步更新策略，保护任务性能
          → 固定新策略，重新训练/验证 SBC
~~~

这是一套带提前终止条件的算法。已有策略配上有效证书后，就可以停止；不要求为了“看起来交替训练”而人为修改已通过的策略。

仍需适配的部分：

| 部分 | AEBS | 车道 |
|---|---|---|
| 状态 | 距离、速度 | 横向偏差 e、航向偏差 theta |
| 视觉观测 | 距离估计；速度另行测量 | 二维偏差估计；曲率作为已知输入 |
| 动作 | 制动 | 转向角 |
| 任务 | 制动并到达目标区域 | 持续保持车道，不越界 |
| 终止语义 | 停车/目标事件后的停止过程 | 当前模型中的持续车道保持；实验运行 80 步 |
| 误差集合 | 状态相关的一维视觉包络 | 当前为二维归一化全局误差盒 |
| 训练数值实现 | AEBS 区域与后继界、任务回退 | 车道区域与非线性后继界、任务回退 |

因此可以说“迁移了 AEBS 的核心方法，并复用其屏障网络”；不能说所有代码、损失权重和统计校准方法完全不变。车道新增的原始输出负裕度、输出层初始缩放都是训练数值处理；不修改最终 1/20/不增的验收条件。

## 3. 每一步具体怎样做

### 步骤 0：冻结问题和已有控制器

输入：11 月 5 日 PPO 权重、冻结的 patch-DINO 观测模型、车道动力学。

物理状态与归一化状态分别为：

$$s=(e,\theta),\qquad x=(e/0.85,\theta/0.30).$$

已知曲率取 −0.01、0、0.01；速度 4 米/秒，采样周期 0.1 秒，轴距 2.6 米，最大转角 0.45 弧度。初态仍为横向 ±0.25 米、航向 ±0.06 弧度，危险条件仍是超出横向 ±0.85 米或航向 ±0.30 弧度。

本轮没有重训视觉前端或重新做 PPO 预训练。已有 PPO 的记录为 80,000 步、观测误差扰动训练；其名称 ppo_image 不意味着当时每个 PPO 步骤都重新渲染和运行 DINO。

输出：固定的模型、误差接口和任务定义。actor 文件散列为 b412c6ed5298540cefb532b1e8e47b046f06fd37df1353b406a04d0957028de2。

### 步骤 1：准备训练状态和误差后继

输入：固定 PPO、归一化误差范围 [-0.08,0.08]²。

从安全状态矩形采样训练状态，补充初态出发的模型轨迹；初态与危险集合包含边界样本，避免只靠随机点漏掉边角。固定策略时，预先计算观测误差子盒经过策略和车辆模型后的后继盒。

这里学习的是：同一个真实状态 x，观测可能是 x+delta，因此策略可能输出一组动作，对应一组后继。训练损失约束后继盒，而不只约束一个随机误差样本。训练用状态仍是有限采样，最终要由连续域验证补足。

输出：训练状态、曲率、后继区间，以及初态和危险区域的训练样本。

### 步骤 2：训练与 AEBS 同类的自由神经 SBC

使用：

$$g_\psi(x)=W_3\tanh(W_2\tanh(W_1x+b_1)+b_2)+b_3,$$
$$B_\psi(x)=\operatorname{ReLU}(g_\psi(x)).$$

所有网络参数参与优化。非负性由 ReLU 保证，其余条件需要训练和验证，不能由网络名称保证。

训练约束包括：

1. 初态的 SBC 足够低；训练时进一步要求原始输出 g 为负，避免 ReLU 零区边缘太脆弱。
2. 危险区域的 SBC 足够高；训练目标取 25，给最终阈值 20 留出空间。
3. 活动区域内，允许误差导致的后继 SBC 不增。训练加入小裕度帮助优化，但验证不允许正漂移容差。
4. 安全模型轨迹上的训练项帮助学习低值区域，这些轨迹不是几何教师，也不是证明。

输出：一个学习得到的候选 SBC。发布种子 41 在第 2000 次优化检查达到开发检查标准；种子 42 在第 1750 次达到。不能把这两个数写成一般收敛保证。

### 步骤 3：连续状态域验证

验证器分别覆盖初态、危险集合和所有需要检查的安全状态。每个状态盒内的所有点都由区间界覆盖，不是仅检查盒子的中心。

动态检查过程为：

~~~text
真实状态盒 + 允许观测误差盒
  → 原 PPO 的动作区间
  → 非线性车辆动力学后继盒
  → 学习到的 SBC 后继上界
  → 与当前 SBC 下界比较
~~~

只有当前 SBC 下界严格大于 20 的盒子才被排除；其余盒子必须证明后继上界不超过当前下界。无法判断则细分；达到预算仍未解决，返回未通过，不改成容差放行。

主验证使用仿射相关界。发布候选同时使用普通逐层 IBP 复核。两者共享任务动力学和审计框架，不能称为完全无共享实现的两个形式验证器。

**为什么危险区域只检查到归一化 ±1.3？** 从安全矩形内任意状态出发，动作即使取最大限幅，一步后继的两个坐标绝对值也分别不超过约 1.1391 和 1.2611，因此必在 [-1.3,1.3]²。验证器在这个区域内覆盖全部越界状态。若首次越界发生，它必落在已检查的危险集合，足以完成首次离开安全域的反证。没有声称此 Tanh 网络在整个无限平面上的危险下界已经得到验证。

输出：与实际 actor、SBC 散列绑定的证书记录；若失败，分别保存实际点反例和未解决盒子的中心。未解决中心只是继续学习的开发样本，不能称为实际危险反例。

### 步骤 4：需要时，利用 SBC 反馈更新策略

这部分已实现并纳入统一入口：固定 SBC，对策略参数求导，降低后继屏障违例，并用原策略模仿项限制动作变化。

每个更新块之后，都在固定开发面板检查安全、平均横向偏差和动作振荡。退化时进行小步回退；仍不合格就恢复策略及优化器状态。更新后的策略必须重新验证，旧策略的证书不会自动转移。

**本轮两个主实验未触发这一步**，因为原 PPO 与学习到的 SBC 已在首次主审计通过。反馈梯度、冻结 SBC、性能退化检测、完整策略回滚均有回归测试，但本轮不把它们写成“已观察到的控制性能提升”。

输出：需要时产生新的候选策略；本轮输出仍为原策略。

### 步骤 5：重新加载、模型扰动与图像回归

固定发布包后，运行三组各 240 条、每条 80 步的模型误差轨迹，以及 12 条实际渲染图像轨迹。图像通过本机 DINOv2 和冻结投影头进入原 PPO，SBC 使用真实状态离线计算。

这些是开发回归：沿用已知图像场景及固定随机种子。重新运行不使它们变成未参与开发的独立测试集，也不产生新的 CP 统计保证。

## 5. 最后得到什么安全保证

以主验证为例，初态 B≤0.08583。假设每步观测误差在声明盒内，使用正确 PPO、当前离散动力学、零过程扰动和三个已知曲率，那么每个允许后继满足 B 不增。

如果某一时刻首次越界，该状态一定在已经检查的 [-1.3,1.3]² 危险部分，故 B≥23.65349。但由此前每步不增，又应有 B≤0.08583，矛盾。因此在这些模型假设和包络条件下不能越界。

这采用了比条件期望不增更强的逐后继约束。它是包络条件下的模型安全结论；不能把两个阈值相除后宣称现实图像具有某个无条件安全概率。CP 单帧边缘覆盖、全轨迹同时覆盖和误差支持集假设仍不是一回事。

数值验证用 float64，未实现完整向外舍入误差证明；部署 PPO 用 float32 的实际运行另有回归证据。本轮不声称硬件执行的完整形式证明、连续曲率区间、未知过程扰动、实车安全或任务性能必然改善。

## 6. 对论文定位的意义和剩余工作

现在可以报告：同一类低维视觉观测、误差包络、PPO、非负神经 SBC 训练与连续域验证流程，在 AEBS 和二维视觉车道任务中都有通过结果。车道证书由与 AEBS 相同网络类训练得到，不再只靠人工几何构造支撑第二个场景。

当前仍不能声称：

- 两个独立训练控制器都通过；这里两个种子只改变 SBC 的训练，同用一个 PPO。
- 策略—SBC 交替更新在车道上提高了成功率；主运行没有触发策略更新。
- 统一流程整体具有新的理论创新；同类训练验证循环不是仅凭移植就成为新理论。
- 已完成公平前端对照、多 PPO 种子、独立最终图像评估或轨迹级 CP 概率分析。

后续论文实验应预先固定不同 PPO 种子与训练预算、视觉前端和误差建模对照、是否加入策略反馈的消融，以及独立场景评估。此次完成的是方法一致性的关键一步，不是整篇论文全部证据。
