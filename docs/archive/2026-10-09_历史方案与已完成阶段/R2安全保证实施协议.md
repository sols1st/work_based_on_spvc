# R2安全保证实施协议

更新日期：2026-10-06。

## 当前结论

R2表示与R2-PPO已经冻结，但当前仍没有安全保证。`400/400`成功和精确配对`0`个单侧unsafe是开发评估，不是连续状态域证明，也没有统计覆盖结论。

本阶段沿用“semantic latent用于学习、physical-state disturbance用于最终证明”的建议。第一版不直接验证32维latent球，而校准两条控制路径造成的下一物理状态残差。

## 预登记保证范围

- 状态：`x=[distance_m,speed_mps]`，范围`[5,16]×[0,3]`。
- 不安全集合：`distance_m <= 6 and speed_mps > 0.5`。
- 每条轨迹最长400步，`dt=0.05 s`。
- 目标轨迹违反率`epsilon=0.01`，置信失败率`beta=0.01`。
- 校准单位：一条独立、同步的图像/状态轨迹，而不是一帧，也不是同一静态图像的重复速度配对。
- 由现有tolerance-rank口径，`epsilon=beta=0.01`至少需要459条独立校准轨迹；459条时使用最坏分数。
- R2、R2-PPO、DINO权重、动力学、分数、时域和数据分布在校准前冻结。

## 残差与分数

同一当前状态分别计算：

```text
x_next_image = f(x, PPO(projection(DINO(image)), speed))
x_next_q     = f(x, PPO(q(distance), speed))
delta_x      = x_next_image - x_next_q
```

每条轨迹的nonconformity score为400步内归一化`L_inf`残差的最大值。当前AEBS动力学中动作只影响下一步速度，因此两条路径的下一距离严格相同；第一版契约的距离残差固定为0，速度残差为conformal半径给出的对称区间。

## 独立轨迹采集

入口：`Aebs.connect.collect_r2_calibration_trajectories`。它连接专用、渲染开启的CARLA实例，不加载或切换地图；每条轨迹从`d∈[15,16] m、v∈[2.5,3] m/s`独立采样初始状态，从R2使用的4种天气和3种车色均匀抽样外观。每一步由同步CARLA RGB传感器生成图像，在线执行冻结DINO、R2 projection和R2-PPO，并用图像路径动作推进AEBS状态。q路径不参与数据采集，也不更新任何模型。

先在远端检查当前地图和spawn：

```bash
python -m Aebs.connect.collect_r2_calibration_trajectories \
  --inspect \
  --output-dir results/dino_expanded_v1/10_calibration_inspect
```

确认地图和`spawn-index=4`场景正确、世界中没有其他车辆/行人/传感器后，先运行2条烟雾轨迹到单独目录：

```bash
python -m Aebs.connect.collect_r2_calibration_trajectories \
  --expected-map <inspect输出的地图短名> \
  --episodes 2 \
  --output-dir results/dino_expanded_v1/10_calibration_smoke
```

烟雾采集不能用于正式校准。确认成功后重新启动空CARLA世界，并运行固定正式计划：

```bash
python -m Aebs.connect.collect_r2_calibration_trajectories \
  --expected-map <inspect输出的地图短名> \
  --episodes 459 \
  --horizon 400 \
  --seed 1701 \
  --output-dir results/dino_expanded_v1/10_calibration_trajectories
```

正式输出为`calibration_trajectories.h5`。失败或中断的目录不得续用或覆盖，必须换新目录完整重跑。

入口：`Aebs.dino_latent.calibrate_transition_contract`。输入H5必须满足：

- schema=`spvc_r2_online_calibration_trajectories_v1`；
- `split_role=calibration`；
- `independent_from_training=true`；
- `used_for_model_selection=false`；
- 与训练相同的冻结DINO权重哈希；
- 数据集`dino_features[N,400,384]`、`distance_m[N,400]`、`speed_mps[N,400]`、`valid[N,400]`和唯一`trajectory_id[N]`。

正式命令在独立轨迹H5准备完成后运行：

```bash
python -m Aebs.dino_latent.calibrate_transition_contract \
  --calibration-h5 results/dino_expanded_v1/10_calibration_trajectories/calibration_trajectories.h5 \
  --representation results/dino_expanded_v1/08_R2_group_alignment/dino_safety_latent.pt \
  --ppo-dir results/dino_expanded_v1/09_R2_ppo \
  --output-dir results/dino_expanded_v1/10_transition_contract
```

该入口不读取当前train/validation/test静态缓存。输出契约只证明登记分布下的轨迹级误差覆盖；在鲁棒SBC对契约内所有残差完成验证之前，它仍不是控制器安全证书。

## 后续验证条件

SBC验证器必须将标称转移替换为：

```text
x_next = f(x, PPO(q(distance),speed)) + delta_x
delta_x in calibrated physical residual box
```

并对连续状态单元及误差区间的所有组合证明初始条件、不安全集分离和barrier下降。旧`run_spvc.py`的固定过程噪声不能替代该视觉闭环残差；旧结果不能转移到R2。

若鲁棒SBC在契约内确定性成立，且轨迹级误差契约达到99%覆盖、99%置信度，才可在完全相同的登记分布和400步时域下给出相应概率安全陈述。独立测试只作最终检查，不参与阈值或模型选择。
