## 1. 两个实验的共同目标与主要区别

共同目标是：把图像变成控制器能使用的少量数值，并证明，在明确的模型和观测误差条件下，控制器不会把系统带进危险区域。

这需要完成三个相互关联、又不能混为一谈的工作：

- **感知学习**：图像能否给出有物理含义的低维观测？
- **控制学习**：根据观测，能否完成制动或车道保持任务？
- **安全验证**：面对声明范围内的全部允许误差，闭环是否满足安全条件？

感知平均误差小，不自动意味着控制安全；有限次任务成功，也不自动意味着连续状态范围内都安全。

| 项目 | AEBS | 车道保持 |
|---|---|---|
| 物理任务 | 接近前方目标，并在规定距离内把速度降下来 | 持续转向，使横向偏差和航向偏差不越界 |
| 真实状态 | 距离 d、速度 v | 横向偏差 e、航向偏差 θ |
| 从图像学习什么 | 一个数：归一化距离 | 两个数：归一化横向偏差和航向偏差 |
| 额外已知输入 | 实测速度，当前按无误差处理 | 道路曲率，当前按准确已知处理 |
| 图像来源 | 400 张已保存图像，闭环使用最近邻回放 | 简化道路渲染器，可随当前状态重新渲染 |
| DINO 特征 | 整张图像的 384 维 CLS 特征 | 保留空间位置的 16×16 patch 特征，每块 384 维 |
| 策略 | PPO，经 SBC 反馈继续微调 | 原图像/误差训练 PPO，本轮不改权重 |
| 最终神经 SBC | 训练得到的 Tanh 隐藏层＋ReLU 输出网络 | 根据几何模板构造的纯仿射/ReLU 网络 |
| 在线动作 | PPO 直接输出制动动作 | PPO 直接输出转向动作 |
| SBC 在哪里起作用 | 离线训练和验证 | 离线构造和验证 |
| 当前主要保证 | 误差包络内的条件模型安全；另有固定图片库回放模型的验证 | 每步二维误差在指定盒内的条件模型安全 |

两个实验都采用了 VISION-SLS 的“预训练视觉特征→低维观测→误差描述”思路。当前后端使用 PPO 与非负 SBC，没有把 VISION-SLS 的完整 SLS 控制合成算法整体移植过来。

## 2. 先理解 SBC：一个分数怎样变成安全保证

### 2.1 SBC 接收什么，输出什么

SBC 是 stochastic barrier certificate，即随机屏障证书。这里用 B(x) 表示。

- **输入**：仿真和离线分析中的真实状态 x。
- **输出**：一个非负分数 B(x)。
- **用途**：通过全区域约束和闭环转移约束，证明系统难以或不能进入危险区域。

B 的数值不是网络直接预测的“碰撞概率”。例如 B=0.4 不能直接解释成 40% 碰撞概率。

两个实验的在线控制器都不需要读取真实状态来计算 SBC。真实状态用于仿真标签、训练和离线验证；在线策略接收的是视觉观测及声明可用的其他测量。

### 2.2 为什么要同时检查三个条件

除 B≥0 外，核心条件为：

$$
\begin{aligned}
B(x_0)&\le1 &&\text{初始集合内},\\
B(x)&\ge20 &&\text{危险集合内},\\
B(x_{t+1})&\le B(x_t) &&\text{相关状态及全部允许后继}.
\end{aligned}
$$

第三行是本项目当前鲁棒检查采用的逐后继条件。它强于只要求条件期望不增：如果每一种允许后继都不增，那么支持在这些后继内的任意概率分布也不增。

**直观例子：**假设从初态出发 B=0，而且每一步 B 都不能增加，又必须非负，那么沿途只能一直等于 0。但危险状态要求 B 至少为 20，因此这样的轨迹不可能进入危险集合。

不能只把函数在初态写成 0 就宣布安全。还要证明：

1. 危险区的分数确实足够高；
2. 控制器执行动作后，所有允许后继仍满足不增；
3. 不会跳到未建模、未分析的状态而绕开这些条件。

### 2.3 阈值 1 和 20 与 95% 有什么关系

在非负屏障、初始上界、危险下界，以及实际闭环条件期望不增等数学前提成立时，非负超鞅的停止论证给出：

$$
\Pr\{\text{进入危险集}\}\le \frac{B(x_0)}{20}\le\frac1{20}=0.05.
$$

因此安全概率下界可以达到 95%。**这里的 95% 来自屏障阈值比，不是感知 CP 的 95% 直接变出来的。**

本项目两份最终报告的初始上界都是 0。在精确数学条件全部成立时，可以进一步推出相应模型内的零风险结论。但当前验证采用浮点数值区间计算，且图像过程有声明范围，所以报告应写“指定条件下的模型安全数值证据”，不能写成“现实车辆 100% 安全”。

### 2.4 为什么本次不用每步固定下降 0.1

假设 B 从最多 1 开始，每步都必须下降 0.1，那么超过 10 步便会要求 B 为负，与非负性冲突。停车后的吸收状态也不可能永远严格下降。

当前采用的是**不增**条件，并允许安全核心区域的 B 精确等于 0。AEBS 在原终止事件处停止；车道则检查安全核心在持续观测误差下仍能保持不变。训练中使用的小正裕度是寻找候选的工具，不能误写成零值状态也必须严格下降的最终定理条件。

## 3. 实验一：AEBS 自动紧急制动

### 3.1 步骤 A0：先固定物理任务、初始集合和失败标准

**输入：**原 AEBS 的距离、速度、制动动作及终止规则。

**具体做法：**把状态定义为 x=(d,v)，单位分别为米、米/秒，使用：

$$
\begin{aligned}
d_{t+1}&=d_t-0.05v_t,\\
v_{t+1}&=\operatorname{clip}(v_t-0.05a_t,0,3).
\end{aligned}
$$

动作 a∈[−3,3]，正数表示制动、负数表示加速。时间步长 0.05 秒。当前模型没有额外过程扰动；速度输入按准确测量处理。

| 对象 | 规定 |
|---|---|
| 建模状态范围 | d∈[5,16]，v∈[0,3] |
| 待保证初始集合 | d∈[15,16]，v∈[2.5,3] |
| 成功 | 5≤d≤6 且 v≤0.5 |
| 不安全事件 | d≤6 且 v>0.5 |
| 提前安全停车 | d>6 且 v≤10⁻⁶；安全但任务没有完成 |
| 经验测试上限 | 每条最多 400 步 |

SBC 的危险区域检查使用闭矩形 [5,6]×[0.5,3]，额外包含 v=0.5 的边界，比实际失败判定保守。

**输出：**一套固定的状态转移、初始域、成功和失败标准。后续训练、验证和测试引用同一套规则。

**为什么先做：**否则可能通过改变初始集合、终止判定或速度阈值，把不同任务的结果放在一起比较。

### 3.2 步骤 A1：整理图像与距离标签

**输入：**本地 [Downsampled.h5](../../artical-F122/Aebs/data/Downsampled.h5)，共 400 张 32×32 灰度图及对应距离标签。

**具体做法：**

1. 按图像内容分组，避免同一重复图像直接跨集合。
2. 划分 240 张训练、80 张验证、80 张测试图像。
3. 训练集用于学习视觉投影；验证集用于选视觉模型；原测试集用于留出评估，后来又拆出 40 张 CP 参考校准、40 张参考审计。
4. 保存划分索引、视觉输出和来源信息，使结果可追查。

**输出：**固定的数据划分，以及后续可复用的特征、观测和划分文件。

**当前限制：**这批图片在开发中经过反复诊断和比较。它们可以用于开发和固定库复核，但不能继续被描述成一批完全未使用、与未来新图像分布关系已经证明的最终独立数据。

### 3.3 步骤 A2：用冻结 DINO 提取特征

**输入：**原始图像。

**具体做法：**

1. 灰度复制成三通道；
2. 缩放到 224×224，按 ImageNet 均值和标准差归一化；
3. 输入冻结的 DINOv2 ViT-S/14；
4. 读取代表整张图像的 384 维 CLS 特征。

**输出：**每张图像对应一个 384 维特征向量。

**这里训练什么：**DINO 参数始终冻结。DINO 提供视觉表示，本身没有距离误差或安全保证。

### 3.4 步骤 A3：把特征压缩成一个可解释的观测

**输入：**384 维 DINO 特征，以及同一图像的真实距离标签。

**具体做法：**

1. 用训练集特征的均值和标准差做标准化；
2. 训练 384→128→128→1 投影网络，前两层后使用 GELU；
3. 让输出 y 接近 d/s_vis，固定观测矩阵 C=[1,0]；
4. Adam 学习率 0.001，batch 64，训练预算 250 epoch，按验证均方误差选择模型；保存的是第 243 个 epoch；
5. 训练损失为逐样本欧氏误差均值；输出一维时等价于绝对误差，不能写成训练采用 MSE。

视觉距离尺度 s_vis≈3.23780632 米。因此：

$$
y=p_\theta(\operatorname{DINO}(I)),\qquad \hat d=s_{\mathrm{vis}}y.
$$

**输出：**冻结视觉模型 observation.pt。它把图像变成一个有距离含义的数。

| 数据 | RMSE | MAE |
|---|---:|---:|
| 训练 240 张 | 0.08585 米 | 0.06578 米 |
| 验证 80 张 | 0.46765 米 | 0.15005 米 |
| 测试 80 张 | 0.16544 米 | 0.12927 米 |

验证集最大误差约 4.01 米，说明平均误差不能替代最坏情况分析。视觉模型冻结后，后面的策略和 SBC 更新不再修改它。

### 3.5 步骤 A4：先训练能完成任务的 PPO

**输入：**视觉观测 y、实测速度 v、AEBS 动力学和奖励。

**具体做法：**

1. PPO 输入 [y,v]，动作是制动量 a；
2. 策略为两层 64 单元 Tanh 网络后接动作层，输出限幅到 [−3,3]；
3. 预训练请求 30,000 个环境步，种子 7；
4. 训练 episode 混合名义观测 d/s_vis 和训练图片最近邻观测，使策略同时接触理想输入和实际视觉偏差；
5. 训练重置可以使用整个建模域；最终要求安全和任务表现的初始域仍是 [15,16]×[2.5,3]。

奖励鼓励接近目标，并处罚过快进入目标区域。提前停在较远位置并不算成功。

**输出：**具有任务能力的初始 PPO。

**为何还没有安全保证：**PPO 优化平均回报，不能排除没采到的危险状态，也不能自动覆盖视觉误差的所有可能值。

### 3.6 步骤 A5：拟合状态相关误差尺度，再做 CP 参考校准

**输入：**冻结视觉模型、图像距离标签，以及训练/参考校准划分。

**具体做法：**

第一步计算米制残差：

$$
r_i=|\hat d_i-d_i|.
$$

第二步在 240 个训练样本上拟合正的三次 Bernstein 多项式 b₀(d)。拟合让半径尽量小，同时用松弛变量容纳难样本；系数下限 0.01 保证整个 [5,16] 米范围内半径为正。

具体令 z=(d−5)/11，则：

$$
b_0(d)=\sum_{k=0}^{3}\beta_k {3\choose k}z^k(1-z)^{3-k}.
$$

优化目标为平均半径加 20 倍平均松弛量，约束 b₀(dᵢ)+ξᵢ≥rᵢ、ξᵢ≥0、βₖ≥0.01。当前系数约为 (0.05307643,0.16276348,0.31936965,0.16892113)。Bernstein 基函数非负且和为 1，所以半径为正；这种正性不等于所有未知图像都被覆盖。

第三步在 40 张参考校准图像上计算：

$$
s_i=\frac{r_i}{b_0(d_i)}.
$$

取 α=0.05，排序位置为 ceil(41×0.95)=39，得到 q≈2.522198953，最终参考包络：

$$
b_{\mathrm{CP}}(d)=q\,b_0(d),\qquad
y\in\left[\frac{d-b_{\mathrm{CP}}(d)}{s_{\mathrm{vis}}},
\frac{d+b_{\mathrm{CP}}(d)}{s_{\mathrm{vis}}}\right].
$$

**输出：**[perception_contract.json](../../artical-F122/results/vision_sls_spvc_sbc_pass_20261029/perception_contract.json)，记录半径函数、排序规则、来源和限制。

| 集合 | 覆盖 | 含义 |
|---|---:|---|
| 拟合训练集 | 240/240 | 当前训练样本的经验覆盖 |
| 参考校准 | 39/40 | 用来计算倍率的数据 |
| 参考审计 | 40/40 | 当前参考审计样本的经验覆盖 |

**这一步得到的是参考误差模型。**普通 CP 的单个新样本边际覆盖，需要评分规则固定、校准和未来样本可交换等前提；当前重复使用图片且未来采集关系尚未建立，所以没有获得真实新图像的完整 95% 统计连接。

### 3.7 步骤 A6：把感知误差通过策略传播到后继状态

**输入：**真实状态或状态盒、参考观测包络、当前 PPO。

**具体做法：**

~~~text
状态范围
→ 这一范围允许的视觉观测
→ PPO 可能输出的制动区间
→ 车辆下一步状态区间
→ SBC 后继分数上界
~~~

对固定状态，若 a∈[a_low,a_high]，则：

$$
v'\in[\operatorname{clip}(v-0.05a_{\mathrm{high}},0,3),
\operatorname{clip}(v-0.05a_{\mathrm{low}},0,3)].
$$

同一步 d′=d−0.05v 仍取决于当前真实速度；不同视觉观测先影响下一步速度，多步之后才累积成距离差。

**输出：**每个状态对应的允许后继集合外包络。

**为什么这样适配：**视觉误差进入的是控制器输入。把它直接当成距离和速度上的独立过程噪声，会得到另一套系统。

### 3.8 步骤 A7：训练非负神经 SBC，并与策略交替改进

**输入：**当前 PPO、误差包络、初始/危险区域、开发状态和失败见证。

**具体做法：**

1. 使用 2→16→8→1 网络，隐藏层 Tanh，最终输出 ReLU；
2. SBC 输入 [d/s_B,v]，其中 s_B≈3.18272066 米，与视觉尺度不同，必须显式换算；
3. 先训练初始区域低分、危险区域高分，并补齐矩形角点，特别是 (6,0.5) 边界；
4. 把当前策略下实际找到的危险前驱状态也作为高分训练样本；
5. 对安全进展状态训练零值平台，并惩罚后继上界超过当前分数；
6. 区域条件一旦成立，后续更新若破坏分离就回退，避免 SBC 退化成常数；
7. 固定 SBC，小步更新 actor，使策略减少屏障违例；再固定 actor，继续训练 SBC；
8. 将新发现的实际反例加入开发数据，重新训练、重新验证。

这里 ReLU 的作用是允许一片安全区域精确等于 0。它仍然是非负神经屏障。旧 Softplus 输出和严格下降配置没有原样保留。

**如何避免把策略练坏：**使用固定训练初态面板，更新前后比较任务表现；如果丢失已有成功或新增不安全轨迹，则恢复 actor 及优化器状态。最终 actor 微调学习率为 0.00003，并带模仿原策略的损失。

**历史结果说明为何要验证：**r13 在开发面板上已经零违例，但新的 65,536 状态检查发现 30 个违例，连续域检查又发现 158 个实际反例。它们反馈给 r14，最终发布 r14，而没有把 r13 当作成功。

**输出：**配对的最终 policy.pt 与 sbc.pt。训练只是寻找候选，下一步才判断是否通过。

### 3.9 步骤 A8：完成连续域数值区间验证

**输入：**冻结的策略、SBC、视觉观测和误差合同。

**具体做法：**检查整个初始矩形的 B 上界、整个危险矩形的 B 下界，以及相关活动域：

$$
d\in(6,16],\qquad v\in(10^{-6},3]
$$

内的闭环不增条件。不能只检查随机点。

对一个状态盒，线性层按权重正负传播上下界，Tanh/ReLU 利用单调性传播；不能证明就继续细分。若达到限额仍不能证明，记录“未解决”，不能按通过处理。

最终使用两种不同的观测模型：

**路径一：CP 参考包络。**覆盖包络内全部观测，把其经过 PPO 和车辆模型的后继纳入检查。成立前提是实际每步观测都属于该包络。

**路径二：固定 400 张图片回放。**真实距离只在离线回放中用于选最近邻图片，控制器接收该图片对应的视觉输出。验证器按相邻图片标签距离的中点切开区间，处理最近邻切换，包括边界两侧，不假设查图函数光滑。

| 检查 | 包络模型 | 固定 400 图回放 |

### 3.11 AEBS 在线运行时每一步到底做什么

~~~text
当前图像 I_t → DINO → 一维观测 y_t
                                   \
实测速度 v_t ------------------------→ PPO → 制动 a_t
                                                   ↓
                                      车辆更新到下一状态
~~~

SBC 和 CP 在离线阶段用于训练、建模和验证。当前主线在线不解 QP，也不由 SBC 修改动作。离线回放知道真实距离是为了查图；实际图像部署接口不需要真实距离。

### 3.12 AEBS 最后得到了什么安全保证

分两条写：

1. **包络路径：**在已声明的 AEBS 离散模型、准确速度、原初始域、零过程扰动、原终止吸收语义下，如果实际观测每步都在参考包络内，则数值区间检查支持相关闭环满足屏障条件，从而支持相应停止系统的模型安全论证。
2. **固定回放路径：**对冻结 400 图库及其确定性最近邻选择规则，直接纳入实际保存的视觉输出，包含可能超出参考包络的观测；获得该回放模型范围内的连续域安全数值证据。

第二条的优势是不用假定这 400 张图的实际误差全部在 CP 包络内；代价是结论绑定这份图库和查图规则。更换图库、仅使用 80 张图的另一个查询规则、换成实时相机后，不能直接继承它。

两条都不单独证明必然到达目标。1441/1441 是任务回归结果，不是目标可达性定理，也不是实车或新天气的无条件 95% 保证。

## 4. 实验二：车道保持

### 4.1 步骤 L0：固定二维车辆误差模型

**输入：**横向偏差 e、航向偏差 θ、道路曲率 κ、转向角 φ。

**具体做法：**固定速度 4 米/秒、轴距 2.6 米、步长 0.1 秒，使用当前代码的离散更新：

$$
\begin{aligned}
e_{t+1}&=e_t+4(0.1)\sin\theta_t,\\
\theta_{t+1}&=\theta_t+\frac{4(0.1)}{2.6}\tan\phi_t-4(0.1)\kappa_t.
\end{aligned}
$$

这是本实验采用的离散模型，不是任意速度、完整车辆侧向动力学或采样间连续安全的证明。

| 对象 | 当前规定 |
|---|---|
| 初始集合 | e∈[−0.25,0.25] 米，θ∈[−0.06,0.06] 弧度 |
| 安全阈值 | \|e\|≤0.85 米，\|θ\|≤0.30 弧度 |
| 实际失败判定 | 任一分量严格超过上述阈值 |
| 证书危险分离 | 包含达到阈值的边界，作保守检查 |
| 动作范围 | φ∈[−0.45,0.45] 弧度 |
| 道路曲率 | κ∈{−0.01,0,0.01} 米⁻¹，当前准确已知 |
| 任务时域 | 80 步，即 8 秒 |
| 过程扰动 | 当前证书取 0 |

**输出：**[core.py](../../artical-F122/Aebs/lane_keeping/core.py) 中固定的任务定义。

**版本说明：**本次证明保持已有的 4 米/秒任务；不能将结论用于更早的 8 米/秒配置。

### 4.2 步骤 L1：生成带真实状态标签的道路图像

**输入：**离线可知的 (e,θ)、曲率，以及渲染参数。

**具体做法：**

1. 用简化道路渲染器从当前状态产生 192×192 RGB 图像；
2. 在横向 [−0.8,0.8] 米、航向 [−0.25,0.25] 弧度范围内采样，加入中心和若干角点等结构化状态；
3. 保存图像、真实状态、曲率和场景编号；
4. 按场景编号划分训练、验证、校准、测试；
5. 当前 v2 记录有 60 个场景编号、每组 60 张图，共 3600 张。

| 划分 | 场景编号数 | 图像数 | 用途 |
|---|---:|---:|---|
| train | 36 | 2160 | 训练视觉头 |
| validation | 9 | 540 | 选择视觉头 |
| calibration | 9 | 540 | 计算 CP 半径 |
| test | 6 | 360 | 留出误差统计 |

**输出：**带标签的渲染数据，以及保存的 [scenes.json](../../artical-F122/results/lane_keeping_20261105/patch_perception_v2/scenes.json)。

**场景一词要准确理解：**当前 60 个编号使用相同名义光照、相机、无噪声、无遮挡设置，变化主要来自三个曲率和状态采样。不同编号不代表 60 种独立天气或摄像头；结构化状态还会重复。按编号划分本身也不能保证像素内容完全不重复，更不能自动建立未来真实图像的独立统计保证。

### 4.3 步骤 L2：保留 DINO 的空间信息，读取两个状态观测

**输入：**渲染道路图像和对应的 (e,θ) 标签。

**为何不用 AEBS 相同的 CLS 读出：**车道任务需要识别道路在图像中的细微左右位置和方向，整图摘要可能丢失这些空间信息，因此这里使用 patch 特征。

**具体做法：**

1. 将图像预处理后送入冻结的 DINOv2 ViT-S/14；
2. 保留 16×16 个 patch token，每个 384 维；
3. 用小型卷积头 384→64→64→1 产生空间打分；
4. 对打分做 softmax，得到各位置权重；
5. 用权重计算位置坐标的加权平均，即空间 soft-argmax；
6. 最后通过一个 2→2 线性层，输出两个归一化观测。

学习目标是：

$$
y=(\hat e/0.85,\ \hat\theta/0.30)\approx(e/0.85,\ \theta/0.30).
$$

训练头使用 Smooth L1 损失，β=0.02；预算 300 epoch，按验证 MSE 选择模型。DINO 冻结，只训练这个空间读出头。

**输出：**patch_projection.pt，一个图像到二维观测的冻结模型。

| 指标 | 横向误差 | 航向误差 |
|---|---:|---:|
| 测试集 MAE | 0.02111 米 | 0.005884 弧度 |
| 测试集 RMSE | 0.02771 米 | 0.008228 弧度 |
| 测试集最大绝对误差 | 0.08446 米 | 0.03628 弧度 |

证据：[感知指标](../../artical-F122/results/lane_keeping_20261105/patch_perception_v2/metrics.json)、[空间读出实现](../../artical-F122/Aebs/lane_keeping/patch_perception.py)。

### 4.4 步骤 L3：把二维视觉误差变成一个校准分数

**输入：**冻结视觉头、校准图像和真实状态标签。

**具体做法：**先计算归一化误差向量：

$$
\delta_i=y_i-(e_i/0.85,\theta_i/0.30).
$$

再取两个分量绝对值的最大值：

$$
s_i=\|\delta_i\|_\infty=\max(|\delta_{e,i}|,|\delta_{\theta,i}|).
$$

这使一个半径同时约束两个分量，避免把两个分别 95% 的边缘事件误当成联合 95%。

540 个校准分数中，取第 ceil(541×0.95)=514 个，得到：

$$
r_{\mathrm{CP}}=0.07203315198.
$$

对应物理半径约为横向 0.06123 米、航向 0.02161 弧度。

**输出：**[cp_patch_95.json](../../artical-F122/results/lane_keeping_20261106_neural_sbc_certificate_v1/cp_patch_95.json)。

实际记录：校准覆盖 514/540≈95.185%；测试覆盖 337/360≈93.611%。这些是样本覆盖比例，不是闭环安全概率。

### 4.5 步骤 L4：区分训练误差、CP 半径和证书半径

这里有三个不同数字，必须分开：

| 数值 | 在哪里用 | 准确含义 |
|---|---|---|
| 0.3 | 原 ppo_image 的噪声训练配置 | 用较宽均匀误差盒训练策略；不代表该范围已有安全证书 |
| 0.07203315 | patch 视觉头的 CP 文件 | 当前校准分数得到的半径；不直接给整条轨迹保证 |
| 0.08 | 本轮最终 SBC 连续区间验证 | 人为声明并通过检查的观测误差盒半径，比该 CP 数字稍宽 |

原 PPO 的 metrics.json 记录训练使用 /tmp/lane_cp_cons.json。本次读取该仍存在的配置，半径为 0.3，并明确注明它是保守工程包络，不是 95% split-CP 半径。临时路径不是可靠的长期工件；本节仅如实记录查到的训练来源，最终证书对象以冻结 actor 权重和散列为准。

**重要区别：**“策略在 0.3 噪声下训练过”不能推出“对全部 0.3 噪声均安全”。最终已经通过的证书范围是：

$$
\delta_e,\delta_\theta\in[-0.08,0.08].
$$

这对应物理观测误差：

$$
|\hat e-e|\le0.068\text{ 米},\qquad
|\hat\theta-\theta|\le0.024\text{ 弧度}.
$$

把 0.072 稍放宽到 0.08 增加了数值验证的误差范围，但没有自动生成更强的 CP 统计定理。

### 4.6 步骤 L5：训练能完成任务的 PPO

**输入：**归一化观测和准确已知曲率：

$$
o=(y_e,\ y_\theta,\ \kappa/0.01).
$$

**具体做法：**

1. 使用两层 64 单元 Tanh 网络，输出归一化动作 u；
2. 限幅 u∈[−1,1]，转成实际前轮角 φ=0.45u；
3. 原 ppo_image 采用 noisy 模式，训练请求 80,000 环境步，种子 7；
4. noisy 模式在真实归一化状态上加入均匀误差样本，训练时不需要每步重新运行渲染器和 DINO；
5. 每条训练任务保持曲率为三个注册值之一；奖励鼓励居中、航向对齐，并处罚过大转向和越界。

因此 ppo_image 的准确含义是“针对视觉观测语义和误差模型训练、再用真实图像观测评估的 PPO”，不能写成每一个训练步都直接用图像端到端训练。

**输出：**ppo_model.zip 和导出的 actor.pt。SBC 求解阶段保留这份 actor 的训练权重，不加 LQR 控制或在线过滤。

原指标文件记录了训练后的任务表现；本次结论主要引用修复加载器后的新回归，避免把旧加载错误影响下的评估混进来。

### 4.7 步骤 L6：先修复“验证的到底是不是原策略”

**输入：**原 SB3 模型、导出的 actor 和旧加载代码。

**发现的问题：**SB3 训练结构为：

~~~text
Linear → Tanh → Linear → Tanh → Action head → clip
~~~

旧加载器漏掉第二个 Tanh。Tanh 没有可训练参数，因此载入权重不会报错，但输出动作已经变了。

**具体做法：**修复网络重建，并将两个现有 PPO 与 SB3 原模型的确定性输出逐项对照。5000 个诊断样本里，旧结构和正确结构的归一化动作最大差约 0.09147，说明这不是无关紧要的格式问题。

另外，旧 LQR 分支的区间计算存在负反馈上下界写反、初始上界写死错误等问题。旧 passed 记录不继续作为证书证据；本轮验证原 PPO 的结果独立保存。

**输出：**与原 SB3 策略一致的 actor 加载路径，以及对应软件回归测试。

### 4.8 步骤 L7：构造能表达安全核心的 ReLU 神经 SBC

**输入：**原 PPO、归一化真实状态 x=(e/0.85,θ/0.30)、初始集合和危险阈值。

**具体做法：**

1. 从局部线性反馈的 Lyapunov 矩阵获得一个几何模板；
2. 按 32 个方向生成向量 aᵢ；
3. 用这些方向定义多面体尺度 V(x)；
4. 在 V≤1 的区域设置零值平台，在外部增大屏障分数：

$$
V(x)=\max_{i=1,\ldots,32}a_i^\top x,\qquad
B(x)=200\,\operatorname{ReLU}(V(x)-1).
$$

当前几何模板矩阵约为：

$$
P=\begin{bmatrix}
8.92381134&1.41175285\\
1.41175285&1.52388578
\end{bmatrix}.
$$

实现取 P=LLᵀ 的 Cholesky 分解，令角度 αᵢ=2πi/32，面向量按行向量 aᵢᵀ=(cos αᵢ,sin αᵢ)Lᵀ 生成。这样得到近似椭圆形的多面体尺度；是否适合原 PPO，仍由后面的完整动态检查决定。

因为：

$$
\max(a,b)=\operatorname{ReLU}(a-b)+b,
$$

最大值可由有限个仿射运算和 ReLU 实现，因此这是一份实际神经网络证书。

**为什么用零值平台：**有持续观测误差时，车可能在中心附近小幅运动，不必每一步严格接近原点。只要这些运动始终留在安全核心，安全就可以成立。平台允许这些状态的 B 都等于 0。

**LQR 在哪里出现：**它只用于生成证书形状。实际被验证的动作仍由原非线性 PPO 输出；不能把这里写成换用了 LQR 控制器。

**输出：**sbc.pt，保存 32 个面向量、平台和缩放参数。这是构造式神经证书；旧自由 Tanh SBC 并没有因此被证明训练成功。

### 4.9 步骤 L8：证明初始集合与危险集合被分开

**输入：**构造的 SBC、整个初始矩形、整个危险区域。

**具体做法与结果：**

1. V 是仿射函数最大值构成的凸函数，初始矩形内的最大值可由四角最大值控制；
2. 初始 V 上界约 0.99892643<1，因此整个初始集合 B=0；
3. 用非负面系数组合，构造坐标方向的支撑界，检查任一归一化坐标绝对值达到 1 时 V 的下界；
4. 得到危险 V 下界约 1.14041464，对应 B≥28.0829>20。

**输出：**初始和危险区域的数值几何分离界，以及可追查的面组合系数和残差。

这里无需抽样所有危险点来猜最低分数。几何组合用于约束连续集合，但其当前实现仍受浮点数值精度边界限制。

需要动态检查的 B≤20 等价于 V≤1.1，其坐标外包约为横向 ±0.33881 米、航向 ±0.28937 弧度，严格位于原安全矩形内。初始集合未缩小，原安全阈值也未放宽。

### 4.10 步骤 L9：在全部允许误差下检查动态不增

**输入：**原 PPO、ReLU SBC、归一化安全域、误差盒 ±0.08、三个曲率。

**具体做法：**

~~~text
真实状态盒 x
→ 加入二维误差盒 δ
→ 拼接准确已知曲率
→ 原 PPO 动作区间
→ 车辆后继状态盒
→ 后继 V/B 上界
→ 判断是否满足不增
~~~

状态盒从整个 [−1,1]² 开始覆盖。每个盒子必须满足下列一项：

1. 整盒 B>20，可以排除当前动态检查；
2. 所有后继 V≤1，因此后继 B=0≤当前 B；
3. 后继 V 上界≤当前 V 下界，因此 B 不增。

不能判定就二分；达到限额还不能判定，报告未知。只有所有相关盒子处理完、没有未解决区域，并通过覆盖面积核对，才判通过。

实际使用两种网络界：

| 方法 | 初始状态网格 | 每个误差分量的分段 | 结果 |
|---|---:|---:|---|
| 保留输入相关性的仿射界 | 60×60 | 2 | 三个曲率全部通过，未解决 0 |
| 普通逐层 IBP | 75×75 | 8 | 三个曲率全部通过，未解决 0 |

两次均设最大深度 16，实际最深到 8。普通 IBP 更保守，所以用了更细的误差划分。两种方法共享动力学和审计组织代码，不能写成两个完全独立、互不共享实现的形式验证器。

**输出：**[主证书](../../artical-F122/results/lane_keeping_20261106_neural_sbc_certificate_v1/certificate.json)与 [IBP 复核](../../artical-F122/results/lane_keeping_20261106_neural_sbc_certificate_v1/independent_ibp.json)。

### 4.11 步骤 L10：做允许误差范围内的轨迹回归

**输入：**正确重载的 float32 PPO、原初始集合、误差范围和车辆模型。

**具体做法：**各做 240 条、每条 80 步，显式包含初始角点和中心；曲率可以在三个注册值之间逐步切换。

| 误差方式 | 如何产生 | 越界 | 平均绝对横向偏差 |
|---|---|---:|---:|
| 均匀误差 | 每步在二维盒内随机取值 | 0/240 | 0.0268 米 |
| 贪心角点 | 每步比较四个误差角点，选使下一步 V 最大的一个 | 0/240 | 0.1514 米 |
| 交替角点 | 按固定规律交替取正负极值 | 0/240 | 0.0233 米 |

贪心角点是压力回归，不是穷尽所有多步最坏扰动的求解器；连续区间验证负责覆盖声明范围内的全部后继。

**输出：**720 条轨迹的状态、动作和统计文件。它们补充实际部署精度下的运行证据。

### 4.12 步骤 L11：用真实渲染图像运行闭环

**输入：**原初始集合、6 个测试场景编号、冻结 patch-DINO 和原 PPO。

**具体做法：**

1. 每个测试场景运行 2 次，共 12 条；
2. 根据当前真实车辆状态重新渲染图像；
3. 图像经过 DINO 和空间读出头，得到两个观测；
4. 拼接已知曲率，PPO 输出转向；
5. 更新车辆，再生成下一帧，运行 80 步；
6. 离线比较观测与真实状态，核对每一帧是否满足证书误差前提。

**输出与结果：**

| 指标 | 结果 |
|---|---:|
| 完成 80 步且无越界 | 12/12 |
| 平均绝对横向偏差 | 0.03502 米 |
| 在证书 ±0.08 盒内的帧 | 958/960 |
| 全程满足 ±0.08 的轨迹 | 10/12 |
| 最大归一化误差 | 0.09965 |
| 图像回归中的 B | 全部为 0 |

**如何理解剩余两条：**两条轨迹各有一帧超出误差盒，实际仍安全。这说明该回归没有发生越界，但证书的全程误差前提对这两条不成立，不能把它们的安全全部归因于 ±0.08 包络证书。

这也是为什么不能只报告“12/12 成功”而省略包络核对。

### 4.13 步骤 L12：保存可核查的模型与证据

**输入：**通过的区间报告、策略、SBC、视觉头、CP 文件和轨迹。

**具体做法：**保存权重、源码快照、环境版本、文件散列、测试记录和两种审计；核对原 actor 权重未变，主验证与复核使用同一策略及几何证书。

**输出：**[车道最终结果包](../../artical-F122/results/lane_keeping_20261106_neural_sbc_certificate_v1/README.md)。保存记录有 6 项针对性回归测试通过。

### 4.14 车道在线运行时每一步到底做什么

~~~text
当前道路图像
   ↓
冻结 DINO patch 特征
   ↓
空间读出 → 二维观测 (y_e,y_θ)
                              \
准确已知曲率 κ ----------------→ 原 PPO → 转向 φ
                                             ↓
                                  车辆更新、获取下一帧
~~~

真实 e、θ 不传给图像策略；它们只在仿真生成图像、离线计算误差和检查安全时可用。SBC 也没有在线替换或修正 PPO 动作。

### 4.15 车道最后得到了什么安全保证

对当前离散模型，假设：

1. 从原初始集合出发；
2. 使用与本包绑定、正确重载的原 PPO；
3. 速度 4 米/秒、步长 0.1 秒、轴距 2.6 米、动作限幅不变；
4. 无额外过程扰动；
5. 曲率准确已知，并只取三个注册值；
6. 每步两个归一化观测误差都在 ±0.08 内。

则数值连续区间审计支持：

$$
B(x_0)=0,\quad B(x_{t+1})\le B(x_t),\quad B\ge0,
$$

因此 B 始终为 0；而危险处 B≥28.0829，所以不会进入危险集合。

这是**包络条件下的模型不越界保证**，覆盖本次 80 步任务。同一个状态证书对三个曲率分别成立，因此允许它们逐步切换；没有验证任意连续曲率区间。

证书条件本身是无时钟的一步不变性条件，在模型及误差前提持续成立时可递推。当前实际图像试验只运行 80 步，不能据此宣称无限长真实图像过程都满足前提。

没有得到：实车保证、未知天气/相机保证、过程扰动保证、采样间完整车身安全、目标渐近收敛，或基于 CP 的整条轨迹无条件 95% 安全概率。当前实现也没有完成严格向外舍入与完整浮点程序形式证明。

## 5. 把两项实验最后得到的结论放在一起

### 5.1 已完成的东西

| 层次 | AEBS | 车道 |
|---|---|---|
| 感知模型 | DINO CLS→一维距离观测 | DINO patch→二维横向/航向观测 |
| 控制器 | 经 SBC 反馈改进的 PPO | 保留原权重、修复加载结构的 PPO |
| 误差描述 | 状态相关 Bernstein 尺度＋CP 参考倍率 | 二维最大范数 CP 分数；最终另验证 ±0.08 盒 |
| 神经证书 | 学习得到的非负 Tanh/ReLU 网络 | 构造得到的 32 面纯 ReLU 网络 |
| 初始/危险分离 | 0 / ≥24.9659 | 0 / ≥28.0829 |
| 连续域证据 | 包络和固定 400 图回放两条验证 | 仿射界和 IBP 两种数值审计 |
| 任务运行 | 三种观测模式各 1441/1441 成功 | 720 条误差轨迹、12 条图像轨迹零越界 |
| 在线安全过滤 | 当前主线没有 | 当前主线没有 |
| 独立现实安全概率 | 尚未建立 | 尚未建立 |

### 5.2 为什么车道比原 AEBS 更接近“当前状态生成当前图像”

AEBS 依据当前距离从旧图库选一张近邻图像，图片来自固定集合；车道依据当前状态用渲染器产生新帧。

车道因此具备更直接的状态—图像反馈连接，也把低维视觉从一个分量扩展到两个分量。但当前渲染条件仍简单、确定，不能把“重新渲染”解释成已经覆盖真实交通场景分布。

### 5.3 哪些改进可以归到 SPVC，哪些不能夸大

可以说：两项实验展示了替换视觉前端后，需要明确观测语义、误差进入闭环的方式、SBC 表达和验证范围；在具体任务上，已有能运行的控制器、实际神经证书和连续域数值验证证据。

AEBS 保留了“策略与神经屏障交替改进”的主线；车道展示了“冻结已有神经策略、构造神经证书并验证”的路线。两者共同采用非负屏障，但合成方式不同。

不能据此说：已经完整复现 VISION-SLS；原 SPVC 所有理论假设原样保持；CP 自动解决了闭环安全；或这份车道构造能保证任意 PPO 都有可行证书。

## 8. 术语与理论来源

### 8.1 容易混淆的词

| 术语 | 在本文中是什么意思 |
|---|---|
| 真实状态 | 仿真内部的物理量；用于标签和离线验证，不表示在线相机已经知道它 |
| 观测 | 策略真正拿到的数；可能存在误差 |
| latent / 低维向量 | 此处有明确物理语义：AEBS 是归一化距离，车道是归一化横向/航向 |
| 归一化 | 除以尺度改变数值大小；误差换回物理单位时须乘回尺度 |
| CLS | 整图摘要特征 |
| patch token | 对应图像局部块的特征，保留空间布局 |
| soft-argmax | 用平滑权重算位置均值，便于学习 |
| PPO / actor | 学习如何根据输入选动作的强化学习方法/动作网络 |
| SBC | 用于安全论证的非负屏障函数，不是 PPO 的回报估计 critic |
| 包络/误差盒 | 声明允许的观测误差集合，不表示所有实际误差天然都在其中 |
| CP | 根据校准分数排序确定集合大小的方法；保证依赖统计前提 |
| 可交换性 | 样本联合规律不因交换顺序改变；校准与目标新样本须符合所用 CP 的前提 |
| 图片复用 | 同一图片或其缓存被多次使用；缓存是正常工程行为，但不能把它算成新样本 |
| 边际覆盖 | 按样本分布平均后的覆盖，普通 split CP 还涉及校准集随机性 |
| 轨迹覆盖 | 一整条轨迹所需的每次误差都满足条件；比单帧覆盖要求不同 |
| 不变集 | 从集合内出发，所有允许转移之后仍在集合内 |
| 零值平台 | 一片区域 B 都等于 0；安全成立还必须验证该区域不会被允许转移带出去 |
| 区间外包络 | 给出覆盖整个输入范围的输出上下界，而不是只算几个点 |
| IBP | interval bound propagation，逐层传播上下界 |
| 反例 | 找到一个实际满足模型前提却违反待验证条件的点或转移 |
| 未解决 | 数值界太宽或预算不够，暂时无法证明；既不是已经安全，也不必然实际不安全 |
| 吸收终止 | 达到原终止事件后，分析中状态保持不变，不再模拟继续运动 |
| 条件模型安全 | 在明确模型、误差等前提成立时推出安全 |
| 严格浮点形式证明 | 还需包含实际浮点运算舍入和程序执行语义；当前两项数值审计均未完成这一层 |
