## 1. 研究目标：改进 SPVC，而不只是把某个任务跑安全

### 1.1 原 SPVC 的核心是什么

原 SPVC 的核心机制是：建立可验证的视觉闭环，学习神经随机屏障证书 SBC，利用验证产生的反例交替改进控制器与证书。本地论文正文称该框架为 SafePVC，项目沿用 SPVC 名称。原方法还涉及 cGAN 观测近似、蒸馏与随机扰动建模。[原 SPVC，第 2—4 节](../references/720_file_Paper.pdf)

先把三个角色分开：

- **控制器**决定车辆下一步做什么。
- **SBC**给状态一个证明分数，用来论证危险能否被到达，或约束到达危险的概率。
- **验证器**检查条件是否在整个声明范围成立；发现问题后，返回需要处理的状态或转移。

保留 SPVC 核心，不要求激活函数、超参数和原视觉网络永远不能改。关键是改动后有清楚的理论条件，最终神经证书确实支持部署控制器的安全结论。

### 1.2 建议保留什么，重点改什么

| 部分 | 建议定位 | 原因 |
|---|---|---|
| 神经控制器 | 保留，可改输入、结构和训练 | 部署策略仍是研究对象 |
| 神经 SBC | 保留为最终证书目标 | 不把几乎不影响证明的学习项当主要创新 |
| 反例驱动联合合成 | 保留并加强 | 发现危险后需要改变控制行为，而不只是分数 |
| cGAN 视觉路径 | 用 DINO＋低维观测替换并比较 | 检验感知抽象是否改善验证与控制 |
| 误差模型 | 显式建模视觉误差、独立校准 | 不把未经核查的简单扰动分布当成真实误差 |
| 连续域验证 | 保留，研究更紧的外包和划分 | 抽样成功不能代替整域检查 |
| 在线后备过滤器 | 保留为对照、教师或辅助分支 | 主实验需要说明无该过滤器时是否成立 |

低维观测和状态相关感知误差借鉴 VISION-SLS；其完整方法还包含 SLS 输出反馈求解器。本项目建议改进 SPVC 的视觉接口和合成环节，不声称已复现完整 VISION-SLS。[VISION-SLS](https://arxiv.org/abs/2604.24894v1)

### 1.3 当前停车场后备方案为什么不宜直接作为全部主线

当前停车场证明主要依赖：启动校准保留真实状态，区间传播保持包含，执行动作前保留安全后备，然后为该闭环构造结构化神经 SBC。

这是有价值的分支。但其有界学习头对证明的权重依赖很弱，图像轨迹上的输出接近零。去掉该学习项，不变性证明仍可能成立。因此，不能仅凭它主张“新的神经 SBC 学习方法解决了原 SPVC 的合成困难”。[停车场证书说明](./停车场神经SBC_构造证明与实验_20261103.md)

| 项目 | 改进 SPVC 的建议主线 | 当前后备分支 |
|---|---|---|
| 不安全动作怎样消除 | 离线改进策略，使它本身满足验证要求 | 在线检查并修改建议 |
| 神经 SBC 的职责 | 参与反馈，验证最终部署策略 | 描述已由后备不变性保护的闭环 |
| 主要困难 | 策略合成、证书表达和验证 | 集合传播、后备可行性与在线计算 |
| 潜在优势 | 控制阶段无需额外安全过滤求解 | 对错误建议有直接保护机制 |
| 主要代价 | 离线合成可能困难或失败 | 在线开销与保守性，学习贡献需另证 |

在线保护已有研究基础，不能仅把“增加后备检查”作为新的通用原理。[预测安全过滤器](https://arxiv.org/abs/1812.05506v4)

### 1.4 三类可以检验的贡献候选

**A：视觉误差与控制影响连接更明确。**从图像残差构造低维集合，再传播到动作和后继。需展示校准与包络效用，而不只是视觉均方误差变小。

**B：反例更有效地改进控制器。**区分感知歧义、动作错误、证书表达问题和验证外包过松，分别处理。需比较同预算下成功合成次数、迭代次数及任务退化。

**C：神经证书更容易验证。**通过非负参数化、划分或有依据的可达域限制改善效率。需排除“缩小任务范围”“换弱要求”带来的假提升。

这些是待实验支持的主张。反例驱动神经证书合成本身已有先行工作，贡献必须落到本项目特有的问题和可测改进。[Fossil 2.0](https://arxiv.org/abs/2311.09793)

## 2. 当前有什么，失败究竟说明什么

### 2.1 已有资产及范围

| 资产 | 已有事实 | 怎样使用 |
|---|---|---|
| AEBS 发布版 | CP 参考包络和固定图片回放的连续域数值检查通过 | 最先做公平比较与消融 |
| 旧停车场规划反馈控制器 | 有任务表现，原 CP 盒内有超速反例，神经 SBC 未通过 | 反例驱动策略改进的起点 |
| 新停车场后备版 | 注册初态盒子、模型、时域内的条件证明；30 次图像仿真成功 | 对照、诊断和教师，不冒充无保护策略证书 |
| VISION-SLS 源码 | 有 Light-Dark、停车场、无人机等入口 | 复用场景，重新接入 SPVC 后端 |
| 原 SPVC 代码与论文 | AEBS 路径和 taxi 模型代码；论文有跑道跟踪任务 | 恢复原方法比较协议 |

成绩与限制以[当前方案与验证结果](./当前方案与验证结果.md)和冻结包为准。后文的新设计不属于已完成结果。

### 2.2 旧停车场反例不否定整个路线

场景 0 第 4 步速度约 2.367292，超过 2.001 的判定值。若初始 SBC≤1、每个允许后继都不增，则第 4 步 SBC≤1；但危险状态又要求 SBC≥20。

这说明：**固定这个控制器、误差集合和逐后继条件，不存在满足条件的 SBC。**

联合合成会改变控制器。若它在相关观测下及时减速，旧路径可能不再是新闭环轨迹，原矛盾就不再适用于新控制器。但新控制器仍需整域验证，不能只检查这一条轨迹。[反例逐步解释](./停车场神经SBC_构造证明与实验_20261103.md#contradiction-explained)

它否定的是该鲁棒要求下的固定候选，不是否定所有其他控制器，也不直接否定另一有依据的概率模型下采用期望条件的可能性。

### 2.3 验证失败要先分类

| 现象 | 可能原因 | 合理处理 | 处理错误的后果 |
|---|---|---|---|
| 复核了真实危险路径 | 策略确实不安全 | 改策略、感知或观测器 | 只训练 SBC 反复遇到不存在性矛盾 |
| SBC 违例，无危险路径 | 证书没学好或条件过强 | 改表达、采样，查理论条件 | 误判整个任务不可行 |
| 未知或超时 | 界松、网络复杂、资源不足 | 改界、划分、可验证结构 | 把未知误写成失败或通过 |
| 相似观测需要冲突动作 | 信息或记忆不足 | 增加必要观测、状态估计 | 无限训练也恢复不了缺失信息 |
| 安全但不前进 | 安全损失与性能失衡 | 保留进度要求，检查性能退化 | 用零碰撞掩盖任务失败 |

“控制器不安全”“证书未满足”“验证器未决定”是三种不同结论。

## 3. 方法主线：每一步做什么，输入和输出是什么

### 3.1 完整流程

~~~mermaid
flowchart TD
    A["固定任务、初始域和观测权限"] --> B["采集并划分图像数据"]
    B --> C["训练并冻结低维视觉观测"]
    C --> D["开发误差包络"]
    D --> E["误差下的策略训练"]
    E --> F["神经 SBC 学习"]
    F --> G["完整闭环验证"]
    G --> H["复核与分类反例"]
    H --> E
    H --> F
    G --> I["固定候选、独立最终校准与验证"]
    I --> J["独立图像测试和公平比较"]
    J --> K["绑定策略、证书、数据与保证范围"]
~~~

开发循环可反复进行；最终校准和测试不能当成任意调参的数据池。最终验证失败应报告失败，或按预定的新一轮数据与统计协议重新开展。

### 3.2 操作表

| 步骤 | 输入 | 处理 | 输出与验收 |
|---|---|---|---|
| 0. 定义问题 | 原配置和代码 | 固定动力学、限幅、时域、初态、危险集和终止条件 | 共同实验协议 |
| 1. 数据划分 | 图像、真值标签、采集标识 | 按独立运行/采集单元划分训练、开发、最终校准、测试 | 可追踪样本清单 |
| 2. 视觉抽象 | 训练图像与标签 | 学低维观测，检查决策信息是否保留 | 冻结模型、理想观测映射、残差定义 |
| 3. 开发误差模型 | 拟合和开发数据 | 拟合尺度、检查尾部、设计联合评分 | 开发包络，不冒充最终统计证书 |
| 4. 策略预训练 | 动力学、开发误差、奖励 | 误差扰动训练，加入困难误差 | 有任务性能和误差响应余量的策略 |
| 5. SBC 学习 | 策略、区域和转移样本 | 学非负性、初始/危险分离、动态条件 | 候选证书与分类损失 |
| 6. 连续域验证 | 完整闭环、集合、证书 | 外包全部声明后继，区分通过、反例、未知 | 报告与失败区域 |
| 7. 联合更新 | 复核反例 | 行为问题改策略，表达问题改 SBC，界松改验证 | 新候选及历史反例/名义任务回归 |
| 8. 最终校准验证 | 固定候选、独立数据 | 得到最终包络，再验证对应闭环 | 接受或拒绝，明确保证范围 |
| 9. 测试交付 | 冻结候选、未用场景 | 统计性能、误覆盖和成本 | 模型、配置、失败轨迹、复现说明 |

### 3.3 怎样把反例反馈给控制器

一次停车场反例应保存：真实状态、观测或允许误差、观测器记忆、策略动作、后继以及 SBC 违例。

若策略持续给过大加速度，更新应推动它在这些情形下减速；同时保留正常停车轨迹，防止所有情况都过早停止。SBC 随新策略重新训练，验证器继续检查是否存在新违例。

**反例训练损失降低只说明样本改善。**背下几条轨迹但在邻近状态失败，仍不能交付证书。

### 3.4 可考虑的改动及副作用

| 改动 | 潜在收益 | 可能问题 | 怎样判断值得 |
|---|---|---|---|
| 限制策略对观测过度敏感 | 减少误差造成的动作放大 | 紧急制动/纠偏不够及时 | 查危险附近响应与整体性能 |
| 基础控制＋神经残差 | 从可用行为开始学习 | 基础控制可能完成全部工作 | 与基础控制单独运行比较 |
| 小型或分块 SBC | 界更紧、验证更快 | 表达不足，切换需证明 | 比较未知区域和覆盖范围 |
| 可验证替代模型 | 降低组合网络复杂度 | 新增替代误差 | 该误差必须外包，不只测 MSE |
| 后备控制生成示范 | 学习安全动作 | 危险边界出现蒸馏误差 | 去掉教师后独立验证学生 |
| 历史帧或观测器 | 改善部分可观测性 | 记忆状态增大验证对象 | 证明初始化和记忆可达性 |

学生模仿有证书的教师，不等于自动继承教师证书。

## 4. 理论需要补哪些环节

### 4.1 写清楚验证哪个闭环

设物理状态为 $x_t$，记忆为 $m_t$，完整验证状态为 $z_t=(x_t,m_t)$。目标、参考编号、时钟等影响转移的量也要计入。

$$
y_t=p_\phi(\psi(I_t))=h(x_t)+e_t,\qquad
z_{t+1}=F_\theta(z_t,e_t,w_t).
$$

$e_t$ 是视觉误差，$w_t$ 是过程或执行误差，不能随意混为一项。真实状态可以供离线验证使用，不因此成为在线策略额外输入。

### 4.2 第一阶段建议保留鲁棒集合条件

一种清楚、但可能保守的目标是：

$$
B_\omega(z)\ge0,\quad B_\omega(z_0)\le b,\quad
B_\omega(z)\ge\lambda\ (z\in\mathcal U),\qquad b<\lambda,
$$

$$
\sup_{e\in\mathcal E(x),\,w\in\mathcal W(z)}
B_\omega(F_\theta(z,e,w))\le B_\omega(z).
$$

条件必须覆盖实际安全前缀上的转移，包括首次进入危险的那一步。如果只验证可达域，需证明初始化在域内、后继闭合；终止后的停止规则也要明确。

直观上，从低分出发，在每一种允许误差下都不涨分，就无法进入高分危险区。因此**包络始终有效时是逐路径安全结论**；并非名称叫 SBC 就必须报告某个小于 1 的安全概率。

### 4.3 期望条件是另一条路线

若采用

$$
\mathbb E[B_\omega(z_{t+1})\mid\mathcal F_t]\le B_\omega(z_t),
$$

必须定义条件转移规律、可积性和停止过程等前提，才可用非负超鞅得到类似危险概率上界 $b/\lambda$。

它可能允许小概率危险分支；鲁棒集合条件则排除集合内全部危险分支。两者不能直接按“通过率”比较。CP 集合没有提供盒内每条误差路径的概率，不能擅自设成均匀分布。

建议先完善集合版本；若它明显过强，再单独研究有依据的概率模型。后者理论工作更重，应单独报告。

### 4.4 单帧 CP 没有自动解决整轨迹安全

单次观测 95% 覆盖，不意味着 400 步全部覆盖的概率也是 95%。直接相乘 $0.95^{400}$ 通常也没依据，因为各帧未必独立。并集界不需要独立，但每一时刻的误覆盖上界必须对实际闭环有效，且长时域时可能无用。

CP 的统计单元、可交换性和边缘保证必须先固定；更多数据和更低维投影不能替代这些前提。[CP 教程](https://arxiv.org/abs/2107.07511)

| 路线 | 可得到什么 | 好处 | 限制 |
|---|---|---|---|
| 声明每步观测属于包络 | 包络条件下模型安全 | 易沿用当前验证器 | 无真实图像尾部概率 |
| 完整独立运行作为校准单元 | 同协议下整轨迹边缘覆盖 | 允许轨迹内时间相关 | 新采集成本，最大误差可能很大 |
| 条件风险或有效序贯协议 | 有机会控制长期风险 | 可以利用持续观测 | 理论要求高，不能套普通 split CP |

一种**拟议设计**：冻结策略后，对每条完整运行定义

$$
R_i=\max_{0\le t<H}\max_j
\frac{|y_{i,t,j}-h_j(x_{i,t})|}{s_j(x_{i,t})},
$$

尺度 $s_j>0$ 在独立拟合集固定；$j$ 为观测分量。对同协议独立轨迹的分数进行 split CP，得到整轨迹倍率，再验证对应包络。

这是把一条轨迹当一个样本，不要求轨迹内部独立。提前终止与最大时域规则必须一致；不能只保留成功轨迹。该设计尚未在本项目完成。

### 4.5 校准之后又改策略，会有什么问题

用策略 A 的轨迹校准，再部署策略 B，会改变状态访问和误差序列分布，原结论不能自动搬过去。

建议：开发包络用于反复训练；最终候选冻结后，独立采集该策略轨迹做最终校准与验证，再用另一批数据测试。最终包络过大而验证失败，应记录失败，不能挑容易通过的校准集。

即使固定候选、单次校准后按验证结果接受或拒绝，普通边缘覆盖也不自动变成“条件于获准发布仍同样覆盖”。反复筛选、换种子直到通过，需要预先设计有效的选择与风险控制协议。新数据有助于隔离适应性，但不自动消除多次尝试的选择效应。

### 4.6 风险不能直接相乘

若已证明整轨迹误差事件 $E$ 成立就安全，则 $P(\text{危险})\le P(E^c)$。

若另有过程随机性，只有确实证明
$$
P(\text{危险且 }E)\le\beta,\qquad P(E^c)\le\alpha
$$
时，才可由事件分解得到 $P(\text{危险})\le\alpha+\beta$。

不能未经证明把另一截断/条件化系统的 $b/\lambda$ 直接作为这里的 $\beta$，更不能把两个“95%”随意相乘。

### 4.7 神经证书可以重点研究什么

- **验证划分：**按违例或区间松弛程度细分，最终仍覆盖全部声明区域。
- **动作敏感性：**抑制危险方向的误差放大，同时检查性能；局部梯度不能代替整区间界。
- **局部证书组合：**不同参考/区域使用不同证书，但切换必须验证。
- **可达增广域：**排除不可能的记忆组合，代价是证明包含和闭合。
- **安全与进度联合条件：**补 reach-avoid 或排名条件，避免只安全停住；研究范围会明显增大。

CP-NCBF 可启发校准、训练与违例评估分离，但不能替代本项目离散 SBC 后继证明。[CP-NCBF v2](https://arxiv.org/abs/2503.17395v2)

## 5. 挑选任务的标准

任务应该暴露待改进的问题，同时有机会在合理资源内验证。

| 标准 | 先问什么 | 不满足的后果 |
|---|---|---|
| 比较价值 | 原任务、明确扩展还是全新系统？ | 场景很多却不能归因于 SPVC 改进 |
| 感知必要性 | 不看图像、固定动作就能完成吗？ | 视觉可能只是展示 |
| 观测充分性 | 相同观测是否对应互相冲突的动作？ | 无记忆策略可能信息不足 |
| 控制余量 | 最坏误差下仍有安全动作序列吗？ | 不可行伪装成训练失败 |
| 可验证性 | 完整闭环有多少状态、记忆和切换？ | 物理低维但验证仍困难 |
| 数据资源 | 有独立图像与标签还是只有示意图？ | 时间耗在搭环境 |
| 性能定义 | 除不出事故还要求什么？ | 靠不动或提前刹停赢指标 |

低维观测不意味着完整验证系统低维；停车场加入观测器和参考后已超出四维物理状态。

## 7. 各任务的详细设计、优缺点与可能后果

### 7.1 E1：AEBS，最先做清楚的主实验

**任务与接口。**图像估计距离，拼接实测速度，输出单一制动动作；状态是距离与速度。目标、安全和终止保持原定义。

**步骤。**固定原任务与现版本；补独立采集；比较原 cGAN、只换视觉、固定半径、状态相关半径和完整联合更新；记录成功、提前停车、危险和超时；最后再分别加入速度误差、执行误差、时延。

**优点。**代码和证书基础齐全，容易解释改动作用，验证对象相对简单。

**缺点。**单一二维任务不能支持广泛可扩展性；提前制动容易安全却丢失任务性能。

**会造成什么。**误差训练可能使刹车提前；包络变宽可能降低到达率；加入时延就增加记忆，不能继续沿用原二维闭环。

**应测什么。**在可接受任务表现下，是否减少合成/验证成本、提高成功次数，或扩大可验证初始域。

依据：[AEBS 完整说明](./VISION-SLS_SPVC_SBC当前框架_步骤原理实验与安全保证_20261029.md)、[冻结包](../../artical-F122/results/vision_sls_spvc_sbc_pass_20261029/README.md)。

### 7.2 E2：原 SPVC 的 X-Plane 跑道中心线跟踪

**任务。**飞机在地面根据图像修正横向位置与航向，避免偏出允许范围。它不是高维飞机飞行动力学。

原文第 4.1 节使用横向偏差 $p$、航向偏差 $\theta$，固定速度，转向角 $\phi$：

$$
p_{k+1}=p_k+v\Delta t\sin\theta_k,\qquad
\theta_{k+1}=\theta_k+\Delta t\frac vL\tan\phi_k.
$$

原设置为 $v=5$ 米/秒、$\Delta t=0.05$ 秒、$L=5$ 米。应统一角度单位，明确离散模型与模拟器的差别。[原 SPVC，第 4.1 节](../references/720_file_Paper.pdf)

**输入输出。**图像投影为位置和航向相关二维观测，输出转向；采用联合误差评分，两个各 95% 不等于联合 95%。

**步骤。**清点模拟器版本、脚本、标签、相机和数据；恢复原任务与原方法；替换视觉；对比固定/状态相关联合误差；分别评估初始偏角和可见度，偏移分布另表报告。

**优点。**直接对比原 SPVC；二维状态却包含双变量感知、非线性和持续反馈，比再做一次制动有信息量。

**缺点。**模拟器与采集可能成为成本主体；把原极低分辨率图放大给 DINO 不会恢复信息。若增加分辨率，应分开数据收益和算法收益。

**会造成什么。**过度保守的转向会纠偏迟缓；角度误差累积为横向偏差；靠近 $\tan$ 奇异点会使界差，需物理合理的动作限幅。

**本地状态。**找到 taxi 模型定义，未确认完整 X-Plane 数据与运行链。本项是优先审计候选，不能当作现成可运行实验。

### 7.3 E3：停车场，回到控制器与 SBC 联合合成

**任务与接口。**保留地图、障碍和安全要求；三维视觉经延迟观测器进入参考反馈与神经残差，输出转向与加速度。主线不执行现有在线后备修改，旧后备证书因此不适用。

| 阶段 | 工作 | 能说明什么 |
|---|---|---|
| P1 诊断 | 研究场景 0 与已知反例，更新策略 | 旧失败行为能否修复，不代表全场景证书 |
| P2 同域 | 统一初始域、误差协议，比较有无后备 | 离线合成和在线保护的作用 |
| P3 扩域 | 逐级扩大初态、场景与扰动 | 覆盖能力和计算代价 |

小范围可用于诊断，最终要回到预定共同域。±0.02 与 ±0.04 必须单列。

**优点。**资产多、反例具体，能检验感知、记忆与耦合动作。

**缺点。**可能同时受信息不足、鲁棒任务不可行、验证高维影响；只加训练预算风险大。

**会造成什么。**降低加速度修复超速，却可能错过目标；抑制转向敏感性会影响避障；增加历史能改善估计，也扩大验证状态。

**先做的检查。**在困难状态检查是否存在短期安全动作，再看是否有可延续的安全动作序列。一步动作存在不代表整个停车任务可行。

**后备版怎样用。**提供困难状态的动作示范、作为性能对照、定位需要干预的时刻。无后备学生必须重新验证，不继承教师证书。

### 7.4 E4：Light-Dark，检验状态相关误差的机制实验

**直觉。**同一场地有些位置容易看清，有些位置误差大；控制器需要到达目标并满足状态约束。

VISION-SLS 有二维单积分器 Light-Dark。本地代码用位置相关系数放大观测扰动，现成版本不是 DINO 图像闭环。[原文实验](https://arxiv.org/html/2604.24894v1#S8.SS2)、[本地观测模型](../../VISION-SLS/dyn/light_dark_of.py)

**分开两个版本。**

- **L0 机制版：**直接使用解析观测误差，接策略与 SBC，隔离误差建模和合成算法作用。
- **L1 图像版：**新增相机、遮挡/可见度变化、图像位置预测和独立校准。只有这版能支持视觉编码收益。

**输入输出。**二维位置，带误差位置观测，二维速度指令；图像版的数据生成是新增工作。

**优点。**动力学简单，可清楚比较固定/状态相关误差，暴露“平均准确但危险处误差大”。

**缺点。**L0 不能证明 DINO 优势；L1 是改造基准，需公开生成规则，避免只对本方法有利。

**会造成什么。**策略可能绕远走可见度好的区域，但绕行不自动证明主动感知。需检查误差、记忆、路径与性能；无记忆策略不自动获得原 SLS 后端的信息收集能力。

**应测什么。**局部包络宽度、路径长度、到达、约束违反和证书成本。结论限定为该机制是否有效，不宣称全面超过 VISION-SLS。

### 7.5 E5：视觉 Cart-Pole，检验非车辆持续反馈

**任务。**小车在有限轨道内保持摆杆接近直立。状态通常为位置、速度、杆角、角速度，动作是水平力。

safe-control-gym 可提供模型、约束和扰动接口，但图像、CP、SPVC 验证链需自己接入，不直接提供本项目证书。[论文](https://arxiv.org/abs/2109.06325)、[官方代码](https://github.com/learnsyslab/safe-control-gym)

| 方案 | 在线输入 | 好处 | 代价 |
|---|---|---|---|
| C1 混合传感 | 图像位置/角度，速度/角速度实测 | 先隔离视觉与非线性控制 | 不是纯视觉 |
| C2 视觉序列 | 多帧图像与有限记忆 | 检验部分可观测控制 | 单帧缺速度，记忆增大验证对象 |

**优点。**无法靠不动作保持平衡，能检验真实反馈能力，区别于车辆特定结构。

**缺点。**不稳定系统放大延迟和误差；细摆杆图像中，DINO 未必胜过几何检测或小 CNN。

**会造成什么。**过强平滑/限幅损害纠偏；误差界太大可能使安全角度内无可行策略。扩大角度阈值属于换任务，不能藏起来。

**建议。**先做直立附近有限时域平衡，不同时加入大范围 swing-up。若研究无限时域平衡，不能照搬有限时钟严格下降项。

### 7.6 E6：ACC 跟驰与前车急刹

**任务。**既保持安全间距又跟随前车速度。不同于静止目标 AEBS，前车会变速。

**输入输出。**状态包括间距、本车/前车速度；图像提供距离，速度来自明确传感器或观测器；输出本车加减速度。前车加速度是独立建模的外部输入。

**步骤。**固定前车速度/加速度范围；比较无误差、仅视觉误差、仅动态扰动、二者共存；固定安全间距定义和动作限幅。

ACC 和车道保持有经典 CBF 控制研究，可参考任务与基线，但不继承其结论作为本项目 SBC 证明。[CBF-QP 原论文](https://arxiv.org/abs/1609.06408)

**优点。**直接检验视觉误差和过程扰动分离，比 AEBS 更丰富。

**缺点。**无界急刹或过小初始间距可能物理不可行；单帧图像距离不能自动给出相对速度。

**会造成什么。**鲁棒控制会增大间距、降低效率；随机前车模型可能较不保守，但需要新概率前提，不能与鲁棒保证混写。

**建议。**先把 AEBS 的理论连接做清楚，再作为扩展，不作为最先求通证书的任务。

### 7.7 E7：视觉高度控制，再到平面无人机

**阶段一。**竖直运动，状态为高度和垂直速度，动作为推力；在高度范围内悬停或到达目标。

**阶段二。**加入平面位置、姿态和角速度，重新处理姿态—推力—位置耦合。

**输入输出。**相机估计高度/位置；哪些速度和姿态传感器可用要说明。单张图像尺度歧义需已知标志或额外观测解决。

**优点。**有重力，不能零动作保持安全；可逐级增加复杂度。

**缺点。**二维高度版与 AEBS 同属低维单输入，对通用性支撑有限；平面模型可能与物理模拟器有差异。

**会造成什么。**理想推力假设忽略电机响应；加入滞后、电池或风，会增加状态/扰动，旧证书需重做。

**资源。**safe-control-gym 有相关模型，视觉和校准需新增。模拟器与验证模型同名不代表动力学完全一致。[官方环境](https://github.com/learnsyslab/safe-control-gym)

### 7.8 E8：VISION-SLS 原十维无人机，为何不优先

本地存在该实验与部分感知资产。[原文实验](https://arxiv.org/html/2604.24894v1#S8.SS4)、[本地入口](../../VISION-SLS/expe/quad_perception/main_quad10d_perception.py)

**改造。**保留场景/观测，重新训练 SPVC 策略与 SBC，明确记忆和动作。原 SLS 控制器运行成功，不等于改进 SPVC 成功。

**优点。**可研究高维和复杂视觉扩展，复用部分场景资产。

**缺点。**完整验证维度可能远超十维；区间松弛与细分成本会主导工作，训练难诊断。

**会造成什么。**大量投入后可能只有有限轨迹成功而无证书，论文主题被迫转向经验控制。

**启动条件。**先在 AEBS 和一个中等复杂任务得到可重复的无后备证书，再考虑它。人形机器人更不宜作为首批验证对象。

### 7.9 E9：视觉车道保持，X-Plane 资源不足时的替代

**任务与接口。**固定/有界速度下保持车道，先用横向与航向偏差模型，图像输出二维观测、策略输出转向。

**优点。**直观，可用曲率、遮挡和标线可见度考察误差。

**缺点。**CARLA 图像采集与模型连接未必比跑道便宜；两者同时做，任务信息可能重复。

**会造成什么。**把曲率视为已知输入需说明来自地图还是视觉；来自视觉则也有误差。真实车辆侧偏/横摆模型会增维。

**建议。**先查 E2 资源，再决定替代；新汽车模型不能称为严格复现原飞机跑道实验。

## 8. 比增加场景更重要的消融与压力测试

消融指只去掉或替换一个模块，判断改进来自哪里，而不是仅增加一些外观不同的图片。

### 8.1 最小方法比较矩阵

| 版本 | 改动 | 目的 |
|---|---|---|
| M0 原 SPVC | 保持原观测、扰动和合成设置 | 复现原方法，差异单列 |
| M1 视觉替换 | 在可比设置下只换视觉接口 | 检验前端收益 |
| M2 固定半径 | 新视觉＋独立校准固定半径 | 简单鲁棒误差基线 |
| M3 状态相关 | M2 改为状态相关尺度 | 检验局部误差建模 |
| M4 完整联合更新 | M3 加策略/SBC 反例联合更新 | 检验是否解决策略安全问题 |
| M5 固定策略 | 与 M4 同设置，只训练 SBC | 检验联合更新必要性 |
| M6 在线保护 | 同一建议策略加后备或过滤器 | 衡量在线保护收益与代价 |

M0 的原概率模型与 M2—M4 的鲁棒误差要求不同，不能把两个数字直接当同口径安全率。需要两张表：

1. **原协议复现表：**列各自前提、保证范围和实现差异。
2. **共同任务评估表：**同真实图像、初态、安全条件和预算比较性能；能适配同一验证模型的部分，再单独比较验证结果。

前端改变可能连带改变策略输入和误差模型。“只换视觉”应说明哪些接口适配不可避免，不能声称完全隔离了所有因素。

### 8.2 十项有论文价值的实验

| 实验 | 怎么做 | 可能的正面结果 | 负面结果说明什么、会造成什么 |
|---|---|---|---|
| A1 前端比较 | DINO、小 CNN、简单语义回归，匹配数据/输入 | 更适合控制和验证 | DINO 可能慢、低分辨率无优势；不应强行保留 |
| A2 观测维度 | 保留必要信息，比较维度与结构 | 性能和验证成本折中 | 过低维不可辨识，过高维界松 |
| A3 固定/状态相关半径 | 同数据与覆盖目标 | 较紧包络、较大可验证范围 | 平均变窄却危险区域更差 |
| A4 CP 样本量与风险水平 | 预定档位、多独立划分 | 展示有限数据代价 | 高覆盖小样本使界大甚至无有限阈值 |
| A5 固定策略/联合更新 | 同预算、初始化 | 消除危险，提高证书成功率 | 只靠降低任务性能换安全 |
| A6 随机/反例误差训练 | 匹配样本量和训练量 | 更快定位敏感区域 | 背下旧反例、邻域仍失败 |
| A7 验证方法 | 固定候选和域，改界或划分 | 少未知、低耗时 | 只是内存换时间，需报告两者 |
| A8 难度曲线 | 逐级扩大初始域或提高误差 | 明确能力边界 | 可能很早失效，不能只挑容易档位 |
| A9 模型误差/时延 | 分别加入声明过的误差 | 增强现实相关性 | 增维、保守性上升、旧证书失效 |
| A10 学习项作用 | 去掉、冻结、重训学习部分并重新核验 | 证实学习带来独立收益 | 无任何差异，则不宜作为核心贡献 |

**A8 限制。**把 CP 半径乘以 0.5 或 0.1 可做敏感性诊断，但原覆盖保证不会保留。应标为“缩放误差模型”，不能称同覆盖水平下的改进。

**A10 限制。**若策略在线不调用 SBC，部署时删掉证书文件不改变轨迹是正常的。检验 SBC 的训练贡献，要比较有无证书反馈训练出的策略；检验证书表达，要在同策略下比较不同证书的验证表现。

### 8.3 图像压力测试

分别改变亮度、遮挡、模糊、相机位置、渲染条件，并标明是否属于校准协议。

- 同协议扰动可讨论校准与验证；全新场景先作为分布外压力测试。
- 缓存特征可用于训练，但端到端耗时必须包含预处理、DINO 和策略。
- 复制或裁切同一帧不会自动产生多个独立采集样本。
- DINO 预训练资源是外部先验，公平比较时需披露。

### 8.4 对抗误差与真实图像分别报告

误差角点和搜索序列检验声明的鲁棒模型；真实图像运行检验感知与控制的实际表现。二者证据不同。

某条盒内反例未必能由真实图片产生，但若要求本来就是“盒内所有误差”，它仍能否定要求。反过来，没有找到盒内反例也不证明现实图像一定在盒内。

## 9. 公平比较、统计协议与结果记录

### 9.1 必须对齐的条件

| 项目 | 处理方式 |
|---|---|
| 物理任务 | 动力学、动作、安全/目标阈值固定；改动另表 |
| 初态 | 同集合与采样协议，报告所有失败 |
| 观测权限 | 真值、实测速度、参考编号权限明确且可比 |
| 数据 | 匹配分辨率与训练数据，披露预训练先验 |
| 预算 | 同硬件或报告差异，匹配训练/验证资源并保留超时 |
| 基础控制 | LQR、参考、教师单列，不能全部归功于 SBC |
| 在线保护 | 无保护主线与有保护对照分开 |
| 保证语义 | 区分鲁棒包络、指定随机模型、固定回放和真实图像 |

### 9.2 五组指标

1. **任务：**成功、失败原因、时间、跟踪误差、动作平滑性；安全未到达单列。
2. **感知：**误差分位数、包络宽度、组覆盖和轨迹覆盖；危险附近审计不冒称逐状态保证。
3. **合成：**训练种子、成功次数、更新轮数、训练/验证耗时、峰值内存。
4. **验证：**初始上界、危险下界、后继违例、未知区域、覆盖域与数值计算等级。
5. **部署：**视觉、观测器、策略、过滤器分项耗时，报告分位数和最大观测值；平均快不是硬实时保证。

训练种子和测试运行是不同统计层次。开发阶段应检查多个种子，正式比较预定种子集合与预算，不只报告最好的一次。重复次数按方差和资源决定，“五次训练”不是普适充分性标准。

### 9.3 经验零失败怎样理解

900 个相邻转移不等于 900 次独立安全实验。一次运行是否发生过违规，才是常用轨迹级二元结果。

**统计教学例子，不是当前数据的新结论：**若独立同分布 Bernoulli 运行 $N$ 次零失败，失败概率的单侧 95% 精确上界为

$$
p_{\rm upper}=1-0.05^{1/N}.
$$

$N=30$ 时约 9.5%；$N=300$ 时约 1.0%。现有 30 条轨迹包含固定中心和不同组启动，不能未经核查套此独立同分布计算。

因此，30/30 成功不等于证明失败概率低于 1%。模型证明、CP 边缘覆盖与经验频率分别报告。

### 9.4 CP 小样本会造成什么

标准 split CP 阶次：

$$
k=\lceil(n+1)(1-\alpha)\rceil.
$$

若 $k>n$，标准保守约定需要无穷阈值，不能把最大样本值硬当所需分位数。32 个校准单元可以用最大值支持不低于 95% 的标准边缘覆盖，但不能同样支持 99%。

要让 99% 阶次不超出样本数，至少需要 99 个校准单元；这仅是有限阈值最低条件，不代表界紧、任务可行或统计稳定。若单元是完整轨迹，就需要运行而不是相邻帧。推算依据为标准校准公式。[CP 教程](https://arxiv.org/abs/2107.07511)

### 9.5 失败也是交付内容

保存版本、任务参数、种子、真实状态与观测、允许误差、动作、终止原因、验证状态和耗时。最终至少区分：

- 通过声明的模型或数值验证；
- 找到真实反例；
- 无反例但验证未完成；
- 任务性能不达标；
- 模型或统计前提不适用。

这样才能决定是改方法、加资源，还是调整研究范围。

## 10. 推荐实施顺序与调整条件

### 10.1 第一阶段：AEBS 改进归因

**做什么：**恢复原版比较协议，建立最小方法矩阵，补独立数据，完成视觉、误差模型、联合更新三项核心消融。

**产物：**公平结果表、可复查证书、覆盖假设说明。

**进入后续阶段的依据：**至少一项可重复改善，例如相同性能下验证更快，或同预算下可验证域更大。若只换前端没有稳定收益，先查表示、数据与外包，不急着扩场景。

### 10.2 第二阶段：原跑道或 Light-Dark

先审计 X-Plane 资源；缺关键数据/采集条件时暂缓，先用本地 Light-Dark L0 隔离误差建模作用。

**产物：**状态相关误差的机制证据，或原第二基准的可比结果。L0 不计为完整视觉实验。

**调整依据：**若机制版也没有收益，查是任务无须状态相关建模，还是方法本身有问题，再决定是否搭图像版。

### 10.3 第三阶段：停车场无后备联合合成

保留冻结后备包，另建独立候选。从已知反例开始诊断，再回到共同初始域。

**产物：**无在线后备版本的完整验证报告；未通过则给出失败类型。

**调整依据：**策略不变、SBC 损失反复时，不再只训证书；观测歧义严重则改估计；外包明显松则改界和划分。不能预设训练够久一定通过。

### 10.4 第四阶段：只选一个新增困难

- 强调跨系统适用性：选视觉 Cart-Pole。
- 强调视觉误差与过程扰动分离：选 ACC。
- 强调逐级增加复杂度：选高度再到平面无人机。

每个新任务应对应一个尚未回答的研究主张，不建议全部同时开展。

### 10.5 三套可选实验组合

| 组合 | 内容 | 优点 | 代价与限制 |
|---|---|---|---|
| 最聚焦原方法 | AEBS＋原跑道＋消融 | 改进 SPVC 的归因直接 | 跑道资源依赖、跨系统有限 |
| 兼顾已有资产 | AEBS＋停车场＋Light-Dark 机制版 | 代码与反例可复用 | 停车场困难，机制版非视觉 |
| 更强通用性 | AEBS＋停车场/跑道＋视觉 Cart-Pole | 非车辆且持续反馈 | 图像和观测器成本高 |

**当前推荐：**先按第二套开发顺序推进，同时审计跑道；资源就绪后优先补原跑道比较。消融和统计协议在任何组合中都不能省。

### 10.6 改动会怎样改变论文主张

| 改动 | 后果 | 正确表述 |
|---|---|---|
| 增加在线后备 | 安全来源转向保护闭环 | 与在线保护结合，不再是同一直接策略 |
| 缩小初始域 | 任务更容易 | 子域成立，不是覆盖能力提高 |
| 放宽危险阈值 | 改变安全要求 | 新任务版本 |
| 增加速度/姿态测量 | 信息变多 | 混合传感，非纯视觉 |
| 改期望条件 | 可允许低概率危险 | 新概率模型下的保证 |
| 固定图片最近邻回放 | 观测变成已知规则 | 回放模型验证 |
| 只证明不碰撞 | 允许停住或不到达 | 安全，不是必达 |
| 加严格时钟下降 | 自然限定有限时域 | 不自动得到无限时域保证 |

## 11. 论文可以怎样组织

### 11.1 建议研究问题

> 在保持 SPVC 控制器—神经 SBC 反例驱动合成机制下，能否通过低维视觉抽象、校准感知误差和更有效的闭环验证，提高可验证性，同时保持任务表现？

这个问题可被实验否定，不预设 DINO 必胜，也不预设状态相关半径必然更好。

### 11.2 建议论文结构

1. 原方法的具体限制：感知近似、误差模型、验证复杂度。
2. 视觉抽象与数据/校准协议。
3. 完整闭环、后继集合与 SBC 安全条件。
4. 反例分类与策略/证书联合合成算法。
5. 包络条件安全，以及有前提的轨迹概率连接。
6. 原基准比较、停车场扩展、消融、难度与成本曲线。
7. 未知区间、分布偏移、模型误差、数值计算与到达限制。

### 11.3 想写什么，需要什么证据

| 主张 | 最低证据 |
|---|---|
| 更容易验证 | 同域同模型同预算的时间、内存、未知区域和成功次数 |
| 更不保守 | 同覆盖目标下的包络/可验证域与任务表现 |
| 联合训练有效 | 固定策略、反例更新对照及多种子结果 |
| 跨任务适用 | 至少两个有不同控制困难的完整实例，不只是换贴图 |
| 视觉闭环概率安全 | 采集协议、有效统计论证与对应动态条件 |
| 神经 SBC 有作用 | 支持实际部署策略证明，或反馈带来可测收益 |

### 11.4 暂时不能写的结论

- 所有新场景都至少 95% 安全。
- 单帧 CP 自动给整条轨迹同样概率。
- 低维 DINO 必然使验证更容易。
- 后备停车场 30/30 成功证明原无后备神经合成通过。
- 增加过滤器证明 SBC 学习更强。
- 没找到反例就是形式化证明。
- 首次结合视觉、CP 与安全控制。

已有感知 CP 安全控制、视觉生成模型验证、神经证书合成等相关研究。本次是针对性调查，不是穷尽文献的新颖性审查。[感知 CP 安全控制](https://arxiv.org/abs/2304.00194)、[视觉半概率安全](https://arxiv.org/abs/2503.00191)、[Fossil 2.0](https://arxiv.org/abs/2311.09793)

### 11.5 给导师讨论的表述

研究主线拟回到 SPVC 控制器与神经 SBC 联合合成。AEBS 提供已有基础，停车场反例说明单独训练证书不足，因此重点改进视觉误差建模和反例驱动策略更新。后备版本作为对照与教师。先做好原任务公平比较，再用停车场及机制或非车辆任务检验扩展性。贡献最终取决于同任务下的合成、验证和性能收益，以及统计覆盖与闭环安全的严格连接。

## 12. 术语、来源与调研边界

### 12.1 术语

| 术语 | 含义 |
|---|---|
| 联合合成 | 控制器和证书都可更新 |
| 消融 | 改一个模块以识别其作用 |
| 鲁棒包络 | 要求集合内全部误差成立，不保证集合覆盖现实 |
| 期望不增 | 给定历史的下一分数平均值不增，个别分支可增 |
| 可交换性 | 样本联合概率规律在重排后不变 |
| 边缘覆盖 | 对规定随机采样整体成立，非逐状态保证 |
| 增广状态 | 物理状态加影响未来的记忆、模式和时钟 |
| 可达域 | 合法初态按所声明闭环可到达的集合或可靠外包 |
| 证书成功率 | 多次训练中完成验证的比例，非车辆安全率 |
| 界松 | 外包包括很多不可能组合，未必真的危险 |
| 不可行 | 规定初态、观测、动作和扰动下无法满足要求 |
| 经验安全 | 有限测试未违规，不等于整域证明 |
| reach-avoid | 避险同时到达，需额外进度条件 |
| 分布偏移 | 部署采样规律不同于校准 |
