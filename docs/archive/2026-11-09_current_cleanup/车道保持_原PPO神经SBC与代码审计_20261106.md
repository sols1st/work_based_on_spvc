## 2. 为什么此前记录不能直接沿用

本地 11 月 5 日文档已经声称 LQR＋残差类证书通过，但本轮代码检查发现：

### 2.1 PPO 重载少了最后一个激活函数

训练时 SB3 的策略为：

~~~text
Linear → Tanh → Linear → Tanh → Action head → clip
~~~

旧加载函数重建成：

~~~text
Linear → Tanh → Linear → Action head → clip
~~~

Tanh 没有可训练权重，所以载入权重不会报错，但计算出来的动作已经不同。5000 个固定诊断样本中，归一化动作最大差约 0.09147。

已修复加载器，并将两个现有 PPO 的输出与 SB3 原模型逐项对照。对应测试通过。因此本轮求证对象是正确还原的原 ppo_image，而不是加载错误形成的另一个策略。

### 2.2 旧 LQR 区间计算把上下界写反

反馈动作含 −Kx，当前 K 分量为正。状态变大，负反馈动作变小。

教学例子：若动作是 −2x，x∈[0,0.1]，动作范围应为 [−0.2,0]，不能写成 [0,−0.2]。旧验证器恰好出现了这种次序错误，后续区间计算可能遗漏实际后继。

已改为按权重正负传播，并增加“下界不能大于上界”的检查。原报告的 passed=true 不能抵消这一错误，因此不再接受旧报告作为已成立证书证据。

### 2.3 初始上界、边界与平衡点处理也有问题

- 旧视觉脚本写死二次初始上界 0.99，但使用的矩阵实际缩放为 0.999，平底后初始值为 0.499，不是 0.49。
- 旧子水平集安全范围来自网格抽样，不能当连续集合的严格外包；已改成解析椭球坐标支撑界。
- 旧平衡点邻域允许 1e-8 正漂移。正漂移容差不能直接证明精确不增，现实现不再用它放行。

旧结果文件保留作为历史记录；本轮新包与当前文档给出更正。旧证书失效是证据问题，不能据此直接推定对应控制器一定不安全。

## 3. 新神经 SBC 怎样构造

使用归一化真实状态：

$$x=(e/0.85,\ \theta/0.30).$$

先由局部线性反馈的 Lyapunov 矩阵生成一组方向，作为几何模板；模板本身不等于原 PPO 已经安全。然后对模板对应的多面体证书，用原 PPO 的真实非线性网络做独立动态验证。

最终：

$$V(x)=\max_{i=1,\ldots,32} a_i^\top x,\qquad
B(x)=200\,\operatorname{ReLU}(V(x)-1).$$

每个最大值都可按

$$\max(a,b)=\operatorname{ReLU}(a-b)+b$$

计算，因此这是由仿射层和 ReLU 构成的神经网络，不需要二次乘法、时钟项或额外的指示函数。

**为什么留一个零值区域？**有持续观测误差时，车辆可以在中心附近小幅移动。若硬要求某个严格正定分数每步下降到原点，可能与扰动不相容。这里允许整个安全核心区域 B=0；但必须验证：从核心区域出发，所有允许观测下的下一状态仍在核心区域。不能靠把函数写成零就自动获得证明。

### 3.1 初态与危险分离

初态盒子四角的最大 V 约 0.99892643。V 是仿射函数的最大值，凸性保证盒内 V 不超过角点最大值，因此整个初态 B=0。

危险区分离不用抽样：通过非负的面系数组合，界定坐标绝对值。结果给出，只要任一归一化坐标绝对值达到 1，就有 V≥1.14041464，因此 B≥28.0829。组合系数及数值残差保存在 certificate.json。

需要动态验证的 B≤20 区域等价于 V≤1.1，其坐标外包约为：

- 横向偏差不超过 0.33881 米；
- 航向偏差不超过 0.28937 弧度。

这个集合严格位于原安全矩形中。没有把危险区域换成更宽的范围。

### 3.2 每一步的检查

对状态盒，加入所有 ±0.08 观测误差，再依次传播：

~~~text
真实状态盒＋观测误差盒
→ 原 PPO 网络动作区间
→ 原车辆离散动力学
→ 后继状态盒
→ 新神经 SBC 上界
~~~

每个可能相关状态盒必须满足下列一项：

1. 可靠证明它整个都在 B>20 区域，因此不属于当前动态检查范围；
2. 后继全部在 V≤1 核心区，故 B(next)=0≤B(current)；
3. 后继 V 上界不超过当前 V 下界，故 B 不增。

无法判断则细分，达到限额仍不能判断就报告未知，不按通过处理。曲率分别检查。初始网格完整覆盖归一化安全域 [−1,1]²；验证同时核对终止叶子面积，面积误差约 10⁻¹⁵。

主方法通过仿射界保留网络输入间的相关性；第二方法使用普通 IBP，并把误差划得更细。两种不同网络界和不同状态划分均通过，降低了仅依赖一种界实现的风险，但不是两个完全无共享代码的形式化验证器。

## 4. 得到什么安全保证

在声明的离散模型、零过程扰动、原初态、正确的原 PPO 网络、已知注册曲率下，**如果每步两个视觉误差都在 ±0.08 内**：

1. 初态 B=0。
2. 区间审计支持每个允许后继 B 不增。
3. 非负性意味着沿轨迹 B 一直为 0。
4. 危险处 B≥28.0829，不可能由该轨迹到达。

因此获得包络条件下的不越界模型保证，适用于本次 80 步任务。由于同一状态函数对三个曲率分别验证，模型也允许逐步在这三个值之间切换；不包含连续曲率区间。

这不是“初始≤1 / 危险≥20，所以现实 95% 安全”。CP 单帧边缘覆盖不自动给所有步同时覆盖，也没有完成实车、未知相机或模型偏差的连接。

## 5. 新实验及不应混淆的数字

三种误差回归各 240 条、每条 80 步，允许注册曲率切换：

| 回归 | 违规次数 | 平均绝对横向偏差 |
|---|---:|---:|
| 误差盒内均匀采样 | 0/240 | 0.0268 米 |
| 每步选使后继 V 最大的四角误差 | 0/240 | 0.1514 米 |
| 正负交替角点 | 0/240 | 0.0233 米 |
| 实际渲染＋patch-DINO | 0/12 | 0.0350 米 |

图像运行共有 960 帧。958 帧在证书 0.08 包络内；10/12 条轨迹全程在包络内；另外两条各有一帧超出，但实测仍未越界。最大归一化观测误差约 0.09965。因此这 12 次不能全称为“每帧满足证书前提”的实验。

旧 patch CP 文件的实际校准覆盖为 95.185%、测试覆盖为 93.611%，而非部分文档此前写的 96.7% / 95.6%。本轮不重新解释或替换该数据。

回归中 B 全为 0，说明它们落在已检验的零值核心；不表示整个函数恒为零。危险区域的分数由全局分离条件保证。它是安全证书，不是跟踪误差指标，也未证明渐近收敛到中心线。
