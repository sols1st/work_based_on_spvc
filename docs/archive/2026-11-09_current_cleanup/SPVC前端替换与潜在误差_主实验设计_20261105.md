# SPVC 前端替换与潜在误差：主实验怎么设计

更新：2026-11-05。**这是建议，不是新实验结果；数字来自已冻结的车道保持包和现有 AEBS/停车场记录。**

## 0. 建议先看这三句

1. **主目标不是"再证一个 PPO"，而是把"真实图像潜在向量 vs 代理潜在向量"的误差变成显式合同，并用同一套 CP+SBC+验证器比较新旧前端。**
2. **不要再追原始 PPO actor 的证书**；用 `LQR + 有界神经残差类` 作为已证安全骨架，PPO 只作性能基线。前端的贡献用"同覆盖率下更小的潜在误差/更好的性能"来证明，而不是"只有新前端能过证书"。
3. **AEBS 做原 SPVC 的前端对照（cGAN vs DINO），车道保持做二维潜在误差与视觉证书。**两个任务各回答一个问题，不要把所有主张压在一个任务上。

## 1. 潜在误差合同

设真实图像潜在向量 `z_real = φ_θ(I)`，代理潜在向量 `z_surrogate = C x`（车道的 `C=I`）。误差：

```
e = z_real - z_surrogate
```

CP 校准得到集合 `E(x)`，覆盖率 `1-α`。控制器只看 `z_real`；验证器用 `z_surrogate + δ`（`δ∈E`）检查：

```
B( F(x, π(z_surrogate+δ)) ) ≤ B(x)
```

这就是当前车道视觉证书的结构：`z=(e,θ)`、`C=I`、patch-DINO 前端、CP 盒 0.08、平底 SBC `B=relu(x^T P x-0.5)`、`LQR + 0.5·B·tanh` 残差类。**潜在误差不是训练损失里的一个正则项，而是验证对象的一部分。**

## 2. 当前已经能说明什么

| 实验 | 前端 | 潜在维 | 潜在误差/CP | 结果 |
|---|---|---|---:|---|
| AEBS | DINO-CLS | 1 | 1D CP 包络；连续域检查通过 | 原 SPVC 任务已有通过版；cGAN 公平对照未整理 |
| 车道保持 | DINO-CLS | 2 | 测试 MAE 0.044 m，CP95 0.134 | 视觉证书通过（平底 SBC）；图像闭环 6/6 |
| 车道保持 | DINO-patch | 2 | 测试 MAE 0.021 m，CP95 0.072 | 视觉证书通过；图像闭环 12/12，CP 覆盖 98.1–100% |

**关键发现：** 两个车道前端都能过视觉证书，认证集相同；patch 的贡献是**把 CP 半径从 0.134 降到 0.072**、把 patch 图像闭环从 6/6 提到 12/12。所以前端替换的正确主张是"同覆盖率下潜在误差更小、性能更好"，不是"旧前端过不了证书"。

这也意味着：**证书的可行性主要来自控制器/CP/SBC 结构，不单来自前端**；前端的价值必须用潜在误差和性能指标量化。

## 3. 真正要补的实验

### 3.1 AEBS：cGAN vs DINO（原 SPVC 前端替换的直接证据）

- 同一 AEBS 数据、同一初始域、同一 actor/SBC/验证器，只换前端。
- 指标：潜在误差 MAE/尾部、CP 半径与覆盖率、可证域/未知区间、任务成功/提前停车、验证耗时。
- 现有 AEBS 已有 DINO 版和 legacy cGAN 记录，但公平同预算对照还没整理；这是当前最值得补的一组。
- 不需要 CARLA；用冻结的 400 张图像与现有包。

### 3.2 车道：CLS vs patch（二维潜在误差与视觉证书）

- 已完成：CP 0.134 vs 0.072；视觉证书都通过；图像闭环 6/6 vs 12/12。
- 还缺：多种子/多场景统计；潜在误差按状态分箱（中心/边缘）；同一 certified set 下的性能对比。
- 这组回答"输入维数更多 + 潜在误差更大时，证书还能不能成立"。

### 3.3 神经 SBC（可选，不要当第一优先级）

- 当前证书用的是平底二次 SBC，不是学出来的神经 SBC。若论文必须主张"神经 SBC"，用有界残差：
  `B_θ = B_flat + δ·(1+tanh(s_θ))`，`δ` 小，证书覆盖任意 `s_θ`；或训练神经 SBC 并如实报告区间审计失败。
- 不要把"神经 SBC 候选点采样通过"写成证书。

## 4. 推荐路线

| 阶段 | 工作 | 产出 | 时间 |
|---|---|---|---|
| 1 | AEBS 前端公平对照：cGAN vs DINO，同 actor/SBC/验证器 | 潜在误差/CP/可证域/性能表 | 1–1.5 周 |
| 2 | 车道 CLS vs patch 的统计补强：多种子、状态分箱、同 certified set | 二维潜在误差表 + 视觉证书对照 | 1 周 |
| 3 | 论文主张：前端替换降低潜在误差、保持可验证性；PPO 仅作性能基线 | 主张-证据表 | 3–5 天 |
| 4（可选） | 有界神经 SBC 或原始 PPO 证书 | 扩展/失败分类 | 2–4 周 |

**不建议：** 先上 CARLA/X-Plane；先把 PPO 本体证出来；把"两个前端都过证书"说成"新前端才过"。

## 5. 论文/导师表述

> 我们把 SPVC 的 cGAN 前端替换为 DINO/patch 视觉前端，并把真实图像潜在向量与代理潜在向量的误差显式校准为 CP 集合；控制器只看真实潜在向量，验证器在代理潜在向量加误差盒上检查 SBC。AEBS 用于原任务的前端对照，车道保持用于二维潜在误差和视觉证书。当前结果是：同一 CP+SBC+验证器下，patch 前端把 CP 半径从 0.134 降到 0.072，图像闭环从 6/6 提到 12/12；两个前端都能通过视觉证书，因此我们不声称"只有新前端可证"，而声称"新前端在相同覆盖率下误差更小、性能更好"。

## 6. 风险

- cGAN 对照需要同预算训练；旧记录不能直接当公平基线。
- 图像闭环样本量小；需要多种子/多场景，不能只报 12/12。
- CP 是边缘覆盖；不是每个状态 95%，也不是整条轨迹 95%。
- 平底 SBC 的认证集只到 `|e|≤0.306 m, |θ|≤0.262 rad`；不覆盖全车道。
- 视觉证书是数值区间，不是形式化浮点证明；只验证三个注册曲率。
