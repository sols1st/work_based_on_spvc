可以。结合前面已经分析出的几个核心问题，我建议不要对 SafePVC 做零散修补，而是把它重构成一个更严谨的"**语义抽象 + 状态相关不确定性 + 分布鲁棒 SBC + 自适应反例驱动联合优化**"框架。原文的核心流程是：cGAN 近似视觉观测、MLP 蒸馏、PPO 预训练控制器、估计 $\Delta s$ 分布、学习 SBC，并通过反例交替更新 SBC 与 controller。原文还假设 $\Delta s$ 来自与当前状态无关的固定分布 $\mu$。

下面给出一个可以直接作为"改进方法章节"来写的详细过程。

### 一、先明确改进后的总体目标

原方法最终验证的是近似闭环

$$s_{t+1}=f\!\left(s_t,\pi(g(s_t,z_0))\right)+\Delta s_t,\qquad \Delta s_t\sim\mu.$$

我建议改成

$$s_{t+1}=f\!\left(s_t,\pi(\xi_t)\right)+w_t,$$

其中

$$\xi_t\in\mathcal C_\xi(s_t,z_t),\qquad w_t\sim Q(\cdot|s_t),\qquad Q(\cdot|s_t)\in\mathcal P(s_t).$$

这里有三个关键变化：

- 图像生成 $g$ → 语义集合 $\mathcal C_\xi$；
- $\mu(\Delta s)$ → $Q(\Delta s|s)$；
- 单一经验分布 → 分布不确定集合 $\mathcal P(s)$。

最终希望找到一对 $(\pi,B)$ 满足

$$B(s)\le1,\qquad s\in S_0,$$

$$B(s)\ge\frac1{1-p},\qquad s\in X_u,$$

并且

$$B(s)-\sup_{\xi\in\mathcal C_\xi(s)}\sup_{Q\in\mathcal P(s)}\mathbb E_{w\sim Q}\left[B\!\left(f(s,\pi(\xi))+w\right)\right]\ge\epsilon.$$

这就是改进版方法的核心安全条件。

### 二、第一阶段：删除 cGAN 图像生成模块

原文的第一阶段是：

$$(s,z)\rightarrow G_{\rm cGAN}(s,z)\rightarrow g_{\rm MLP}(s,z)\rightarrow o.$$

作者使用 cGAN 生成视觉观测，再蒸馏为 MLP，并通过 Lipschitz regularization 提高后续可验证性。这个模块存在两个误差源：

$$g_{\rm real}\rightarrow G_{\rm cGAN}\rightarrow g_{\rm MLP}.$$

因此第一项改进就是：**彻底取消"状态→图像"的生成过程**。不再要求模型重建 $8\times16$、$32\times32$ 甚至更高维视觉输入，而是直接学习控制真正需要的 semantic variable。

### 三、第二阶段：定义任务相关 semantic latent

定义

$$\xi=[\xi_1,\ldots,\xi_k]\in\Xi\subset\mathbb R^k,$$

这里 $k$ 应尽量小。例如 X-Plane：

$$\xi=(d,\theta,\kappa,c_v),$$

其中：

- $d$：跑道中心线横向偏差；
- $\theta$：heading deviation；
- $\kappa$：局部路径曲率；
- $c_v$：视觉置信度。

如果希望与原 benchmark 最大程度保持一致，可以直接：$\xi=(d,\theta)$。

CARLA emergency braking 可以定义：

$$\xi=(d_{\rm obs},v_{\rm rel},{\rm TTC},c_o),$$

其中

$${\rm TTC}=\frac{d_{\rm obs}}{\max(v_{\rm rel},\varepsilon)}.$$

选择原则是：**$\xi$ 必须保留控制和安全相关信息，而不是保留视觉外观。**

### 四、第三阶段：建立语义数据集

原文使用 $D=\{(s_i,o_i)\}$，改成：

$$D_{\rm sem}=\{(o_i,s_i,z_i,\xi_i)\}_{i=1}^{N}.$$

对于 simulator benchmark，$\xi_i$ 可以直接从 X-Plane/CARLA 的 ground-truth simulator state 中获得。例如 $(o_i,d_i,\theta_i)$ 或 $(o_i,d_i,v_i,{\rm TTC}_i)$。因此不需要昂贵人工标注。

把数据划分为 $D_{\rm train}$、$D_{\rm cal}$、$D_{\rm test}$。这里必须保留独立 calibration set，因为后面要构造 certified semantic abstraction。

### 五、第四阶段：训练 semantic encoder

定义 $E_\phi:O\rightarrow\Xi$。给定真实图像 $o_t$，输出 $\hat\xi_t=E_\phi(o_t)$。训练目标可以写为：

$$L_{\rm sem}=\sum_{j=1}^{k}w_j\ell_j\left(E_{\phi,j}(o),\xi_j\right).$$

对于连续 semantic variables：$\ell_j=|\hat\xi_j-\xi_j|^2$。因此不同于原文学习 $(s,z)\rightarrow\text{image}$，现在学习的是 **image → control-relevant semantics**。

### 六、第五阶段：检查 semantic latent 的"控制充分性"

这是非常重要的一步，否则容易只是把 cGAN 换成另一个 encoder。设原始视觉 policy 为 $\pi_{\rm img}(o)$，训练 semantic policy $\pi_\xi(\xi)$，要求

$$\pi_\xi(E_\phi(o))\approx\pi_{\rm img}(o).$$

定义：

$$L_{\rm suff}=\mathbb E_o\left[\|\pi_{\rm img}(o)-\pi_\xi(E_\phi(o))\|_2^2\right].$$

如果 $L_{\rm suff}$ 较小，则说明 $\xi$ 确实保留了主要控制信息。如果不希望保留原视觉 controller，则还可以采用 task-return criterion：$J(\pi_\xi)\approx J(\pi_{\rm img})$。

### 七、第六阶段：从 point estimate 升级为 certified semantic abstraction

这是整个改进方法的第一个理论核心。不能简单使用 $\xi=\hat\xi$，而应写成：

$$\xi^{\rm true}\in\mathcal C_\xi(o).$$

在 calibration dataset 上计算 residual $r_i=\|\xi_i-E_\phi(o_i)\|$，或者逐维 $r_{i,j}=|\xi_{i,j}-\hat\xi_{i,j}|$。利用 conformal calibration 得到 $q_{j,1-\alpha_j}$，构造：

$$\mathcal C_\xi(o)=\prod_{j=1}^{k}[\hat\xi_j-q_j,\hat\xi_j+q_j].$$

这样得到的不是 $\hat d=10m$，而是 $d\in[9.6,10.4]m$。这对形式验证更有意义。

### 八、第七阶段：进一步构造 state/environment-dependent semantic set

全局固定 $q_j$ 容易保守。更合理的是令 $\delta_\xi=\delta_\xi(s,z)$。例如在大雾、低光照、目标远距离情况下，semantic uncertainty 应更大。可以学习 uncertainty scale $\sigma_\omega(s,z)$，定义 normalized residual：

$$r_i=\frac{\|\xi_i-\hat\xi_i\|}{\sigma_\omega(s_i,z_i)},$$

再进行 conformal calibration，得到：

$$\mathcal C_\xi(s,z)=\left\{\xi:\|\xi-\hat\xi\|\le q_{1-\alpha}\sigma_\omega(s,z)\right\}.$$

于是 easy environment ⇒ small semantic set，hard environment ⇒ large semantic set。

### 九、第八阶段：训练 semantic controller

原文使用 PPO 预训练控制器 $\pi_0$。该设计可以保留，但输入改成 $\xi$，即 $\pi_0=\operatorname{PPO}(\pi,\xi)$，控制器为 $u_t=\pi_\theta(\xi_t)$。这样 RL 的搜索空间从视觉网络的高维输入变成 $\Xi\subset\mathbb R^k$。不仅训练更简单，后面的 verification 也明显更容易。

### 十、但训练阶段必须加入 semantic uncertainty augmentation

如果 PPO 只在精确 $\xi$ 上训练，而 verification 使用 $\xi\in\mathcal C_\xi$，会造成 train-verification mismatch。因此训练时应随机采样 $\tilde\xi=\xi+e_\xi$，其中 $e_\xi\in\mathcal E_\xi(s,z)$，PPO 改成 $\pi_\theta(a|\tilde\xi)$。甚至使用 worst-case robust loss：

$$\max_{e_\xi\in\mathcal E_\xi}L_{\rm RL}\left(\pi_\theta(\xi+e_\xi)\right).$$

这样 controller 在预训练阶段已经对 semantic uncertainty 有一定鲁棒性。

### 十一、第九阶段：重构闭环系统

原文闭环为 $F(s,z)=f(s,\pi(g(s,z)))$，现在变成：

$$F(s,\xi,w)=f(s,\pi(\xi))+w,$$

其中 $\xi\in\mathcal C_\xi(s,z)$。这里应明确区分两类 uncertainty：第一类是 perception uncertainty $\xi-\hat\xi$，第二类是 process/environment uncertainty $w$。这样就不再像原论文那样把所有视觉影响统一塞入 $\Delta s$。

### 十二、第十阶段：从 state-independent disturbance 改成 state-dependent disturbance

原文假设 $\Delta s\sim\mu$ 且与 $s$ 无关。改为：

$$w_t\sim\mu(\cdot|s_t,\xi_t).$$

如果希望控制复杂度，可以先采用 $w_t\sim\mu(\cdot|s_t)$。数据构造方式为：对每个 state region $C_i$，收集 $\{w_j:s_j\in C_i\}$，得到局部经验分布 $\hat\mu_i$。于是不同状态区域具有不同 disturbance characteristics。

### 十三、第十一阶段：不要直接把 $\hat\mu$ 当真实分布

这是第二个主要理论改进。用有限样本得到 $\hat\mu_s$ 后，不直接假设 $\mu_s=\hat\mu_s$，而定义 ambiguity set：

$$\mathcal P(s)=\{Q:W(Q,\hat\mu_s)\le\rho_s\}.$$

这里 $W$ 可以采用 Wasserstein distance。半径 $\rho_s$ 由 sample size 和 confidence level 确定。于是 $\mu_{\rm true}(\cdot|s)\in\mathcal P(s)$ 以高概率成立。

### 十四、第十二阶段：形成 distributionally robust closed-loop system

现在系统模型变成：

$$s_{t+1}=f(s_t,\pi(\xi_t))+w_t$$

subject to $\xi_t\in\mathcal C_\xi(s_t,z_t)$、$w_t\sim Q_t(\cdot|s_t)$、$Q_t\in\mathcal P(s_t)$。这样 uncertainty 被分为 **set-bounded perception uncertainty** + **distributionally uncertain process disturbance**。

### 十五、第十三阶段：定义改进后的 robust SBC

原文 Theorem 2.2 的核心是 $B(s)\ge E[B(s')]+\epsilon$。改进后定义：

$$B(s)-\sup_{\xi\in\mathcal C_\xi(s)}\sup_{Q\in\mathcal P(s)}E_{w\sim Q}\left[B(f(s,\pi(\xi))+w)\right]\ge\epsilon.$$

其意义是：对所有被 certified semantic abstraction 覆盖的感知结果，以及所有与有限数据一致的 disturbance distributions，都保证 barrier 在期望意义下下降。

### 十六、第十四阶段：保留原 SBC 的初始区和 unsafe 区约束

仍然使用 $B(s)\ge0$、$B(s)\le1,\ s\in S_0$、$B(s)\ge\frac{1}{1-p},\ s\in X_u$。因此原论文 probabilistic barrier 的理论骨架可以保留。真正改变的是 condition (iv)：原来 $E_{\Delta s\sim\mu}$，现在变为 $\sup_{\xi}\sup_Q E_Q$。

### 十七、第十五阶段：重新设计 SBC 网络 loss

原文使用 $L_L=L_{\rm dec}+\lambda_RL_{\rm region}+\lambda_LL_{\rm lip}$。建议改为：

$$L_B=L_{\rm Rdec}+\lambda_I L_{\rm init}+\lambda_U L_{\rm unsafe}+\lambda_L L_{\rm localLip},$$

其中

$$L_{\rm Rdec}=E_s\left[\operatorname{ReLU}\left(\mathcal R_B(s)-B(s)+\epsilon\right)\right],$$

定义

$$\mathcal R_B(s)=\sup_{\xi\in\mathcal C_\xi(s)}\sup_{Q\in\mathcal P(s)}E_Q[B(f(s,\pi(\xi))+w)].$$

这样训练目标和最终 theorem condition 完全对齐。

### 十八、第十六阶段：不要再使用单一 global Lipschitz bound

原文 Theorem 3.1 使用：

$$K=\tau L_B\left(1+L_f\sqrt{1+(L_\pi L_g)^2}\right).$$

这里 $L_g$ 与 perception MLP 有关。semantic abstraction 后可以删除这一复杂 visual surrogate 项。对每个 state cell $C_i$ 使用局部 $L_B^{(i)}$、$L_f^{(i)}$、$L_\pi^{(i)}$，得到 $K_i^{\rm state}$。perception uncertainty 单独处理：

$$K_i^{\rm sem}=L_B^{(i)}L_{f,u}^{(i)}L_\pi^{(i)}\delta_{\xi,i}.$$

于是 $K_i^{\rm total}=K_i^{\rm state}+K_i^{\rm sem}+K_i^{\rm stat}$。

### 十九、第十七阶段：显式加入 sampling/statistical error

假设 Monte Carlo estimate 为 $\hat E_N[B]$，则计算 statistical margin $\eta_i(N,\delta)$。例如 bounded case 下：

$$\eta_i=B_{\max}\sqrt{\frac{\log(2/\delta)}{2N_i}}.$$

最终 verification 不检查 $B(\tilde s_i)-\hat E[B]\ge\epsilon$，而检查：

$$B(\tilde s_i)-\hat{\mathcal R}_B(\tilde s_i)-K_i^{\rm state}-K_i^{\rm sem}-\eta_i\ge\epsilon.$$

这一步非常重要，因为现在所有主要误差都显式进入 certificate：state discretization error + semantic perception error + finite-sample error。

### 二十、第十八阶段：采用 adaptive state partition

不要像原论文那样简单固定 state discretization。定义某个 cell $C_i$，计算 certified margin：

$$M_i=\inf_{s\in C_i}B(s)-\sup_{\xi,Q}E_Q[B(s')].$$

如果 $M_i\ge\epsilon$，则整个 cell certified；如果 $M_i<0$ 并能找到明确 violating state，则产生 counterexample；如果 $0\le M_i<\epsilon$ 或 bound 太松，则 split $C_i$（例如 $C_i\rightarrow C_i^1\cup C_i^2$）。因此算法变为 verify → certify / counterexample / refine partition。这比 uniform grid 更 scalable。

### 二十一、第十九阶段：counterexample 从一个 state 升级成 joint counterexample

原文主要收集 $s_{\rm cex}$。改进后生成：

$$c^*=(s^*,\xi^*,Q^*,w^*),$$

其中 $\xi^*=\arg\max_{\xi\in\mathcal C_\xi(s^*)}\mathcal R_B$、$Q^*=\arg\max_{Q\in\mathcal P(s^*)}E_Q[B(s')]$。这意味着 counterexample 明确告诉我们：

- 哪个 system state 最危险；
- 哪个 semantic perception error 最危险；
- 哪类 disturbance distribution 最危险。

这比原文仅仅获得 state counterexample 更有信息量。

### 二十二、第二十阶段：用 counterexample 更新 SBC

固定 controller $\pi_k$，对 $(s^*,\xi^*,w^*)$ 加大训练权重：

$$L_B^{\rm cex}=\operatorname{ReLU}\left[B(s^{\prime *})-B(s^*)+\epsilon\right],$$

然后 $B_k\rightarrow B_{k+1}$。这里仍然保留原 SafePVC 的 verification-guided learning 思想。

### 二十三、第二十一阶段：用 counterexample 更新 controller

固定 $B_{k+1}$，更新 controller $\pi_k\rightarrow\pi_{k+1}$，目标是：

$$\min_\pi\sup_{\xi\in\mathcal C_\xi(s^*)}\sup_Q E_Q\left[B(f(s^*,\pi(\xi))+w)\right],$$

也就是说选择一个动作，使 worst-case next barrier value 尽可能低。

### 二十四、第二十二阶段：Controller update 加 trust region

不要只使用原文 $L_{\rm mse}=E\|\pi-\pi_0\|^2$（原文使用这一项保持 policy 接近 PPO baseline）。改进后建议：

$$D_{\rm KL}(\pi_{k+1}\|\pi_k)\le\rho,$$

或者 $\|\pi_{k+1}-\pi_k\|_\infty\le\rho$。最终 controller optimization：

$$\min_\pi L_{\rm robust\_safe}+\lambda_{\rm perf}L_{\rm performance},$$

subject to $D(\pi,\pi_k)\le\rho$。这样可以减少 $\pi\rightarrow\mu_\pi\rightarrow B$ 不断大幅变化引起的震荡。

### 二十五、第二十三阶段：对 controller 性能直接加约束

原文靠 $\|\pi-\pi_0\|^2$ 近似保持性能。更严格的方法是：

$$J(\pi)\ge J(\pi_0)-\delta_J.$$

于是 controller synthesis 变成 $\min_\pi L_{\rm safe}$ subject to $J(\pi)\ge J_{\min}$。这样 **performance + safety** 都成为明确优化目标。

### 二十六、第二十四阶段：Controller 更新后重新构造 ambiguity set

这一点继承原文的正确设计。原文在 controller 更新后会重新估计 $\Delta s$。改进后应做：$\pi_k\rightarrow\pi_{k+1}$，重新运行 simulator $(s,z,\xi)\rightarrow s'$，获得新的 disturbance samples $w^{k+1}$，重新构造 $\hat\mu^{k+1}(\cdot|s)$ 以及 $\mathcal P^{k+1}(s)$。所以闭环迭代变成：

$$\pi\rightarrow\mathcal P_\pi\rightarrow B\rightarrow\pi.$$

### 二十七、第二十五阶段：必要时再更新 semantic abstraction

这是比原 SafePVC 更进一步的地方。如果 counterexample 指出 $\xi^*$ 总出现在某种环境 $z^*$（例如 heavy fog、strong shadow、low illumination），则可以收集更多相关图像 $D_{\rm new}$，加入 $D_{\rm sem}$，重新训练 $E_\phi$，并重新 calibration $\mathcal C_\xi$。因此形成三层闭环：

$$E_\phi\leftrightarrow\pi\leftrightarrow B.$$

### 二十八、整个改进算法可以总结为

初始化 $D_{\rm sem}$、$E_\phi$、$\pi_0$、$B_0$，然后：

1. 训练 semantic encoder：$E_\phi(o)\rightarrow\hat\xi$。
2. Conformal calibration：$\hat\xi\rightarrow\mathcal C_\xi$。
3. PPO 训练：$\pi_0(\xi)$。
4. 采样 state-dependent disturbance：$w\sim\hat\mu(\cdot|s)$。
5. 建立 ambiguity set：$\mathcal P(s)$。
6. 训练 robust SBC：$B$。
7. Formal verification：$B(s)-\sup_{\xi\in C_\xi}\sup_{Q\in P(s)}E_Q[B(s')]\ge\epsilon$。
8. 若成立：return $(\pi,B)$。
9. 若失败：$(s^*,\xi^*,Q^*)$ 作为 counterexample。
10. 更新 $B$。
11. 每若干轮更新 $\pi$。
12. 重新估计 $\mathcal P_\pi$。
13. 必要时重新训练 $E_\phi$。

重复直到验证通过。

### 二十九、可以把改进版 Algorithm 1 写成如下逻辑

**Algorithm: Semantic-DR-SafePVC**

输入：$D_{\rm sem}$、$f$、$S_0$、$X_u$、$p$、$\alpha$、$\delta$。输出：$\pi$、$B$。

核心过程：

$$E_\phi\leftarrow\operatorname{TrainSemanticEncoder}(D_{\rm train})$$

$$\mathcal C_\xi\leftarrow\operatorname{ConformalCalibration}(E_\phi,D_{\rm cal},\alpha)$$

$$\pi_0\leftarrow\operatorname{RobustPPO}(f,\mathcal C_\xi)$$

$$\mathcal P\leftarrow\operatorname{StateDependentDisturbanceEstimation}(\pi_0,\mathcal C_\xi)$$

然后循环：

$$B\leftarrow\operatorname{TrainRobustSBC}(\pi,\mathcal C_\xi,\mathcal P)$$

$$r\leftarrow\operatorname{Verify}(B,\pi,\mathcal C_\xi,\mathcal P).$$

若 $r=\mathrm{SAT}$，结束。若 $r=\mathrm{UNKNOWN}$，执行 $\operatorname{AdaptiveSplit}$。若 $r=\mathrm{UNSAT}$，获得 $c^*=(s^*,\xi^*,Q^*)$，然后 $B\leftarrow\operatorname{UpdateB}(c^*)$、$\pi\leftarrow\operatorname{TrustRegionUpdate}(c^*,B)$，之后 $\mathcal P\leftarrow\operatorname{Reestimate}(\pi)$。

### 三十、改进后的理论保证应该怎么写

原文希望得到 $P_{s_0}(\mathrm{Safe})\ge p$。改进后建议分成两层。

第一层是 perception abstraction guarantee：

$$P_{\rm data}\left[\xi^{\rm true}\in\mathcal C_\xi\right]\ge 1-\alpha.$$

第二层是 distribution ambiguity guarantee：

$$P_{\rm data}\left[\mu_{\rm true}(\cdot|s)\in\mathcal P(s)\right]\ge 1-\delta.$$

在 abstraction contract 和 ambiguity contract 成立条件下，robust SBC 证明：

$$P_{\rm dyn}\left[\forall t,\,s_t\notin X_u\right]\ge p.$$

因此最终最好表述成类似：

$$P_{\rm data}\left[\inf_{\substack{Q\in\mathcal P\\ \xi\in\mathcal C_\xi}}P_Q(\mathrm{Safe})\ge p\right]\ge 1-\delta_{\rm total}.$$

这比原论文直接把 learned disturbance model 当真实模型更加严谨。

### 三十一、需要特别注意：无限时域的 conformal guarantee 不能简单处理

如果你希望保留原文 $t\rightarrow\infty$ 的安全主张，那么不能简单从 $P(\xi_t\in C_t)\ge1-\alpha$ 推到 $P(\forall t,\xi_t\in C_t)\ge1-\alpha$。普通 conformal 通常只是 marginal coverage。因此有两种选择。

第一种更稳妥：把 $\mathcal C_\xi$ 定义为一个工程上可接受的 robust perception contract，然后 SBC 对这个集合进行确定性 worst-case verification。

第二种：专门设计 sequence-level / online conformal guarantee，再把它和 stochastic barrier 理论结合。

如果以 DAC 论文的工作量考虑，我更推荐第一种，理论更干净。

### 三十二、改进后的实验设计也必须同步变化

否则方法改了，但实验仍无法支持贡献。至少做四组 ablation：

1. cGAN-SafePVC vs Semantic-SafePVC；
2. fixed $\mu$ vs state-dependent $\mu(\cdot|s)$；
3. empirical $\hat\mu$ vs distributionally robust $\mathcal P(s)$；
4. global grid/Lipschitz vs adaptive local verification。

指标包括：$p_{\rm certified}$、$T_{\rm verify}$、$N_{\rm cells}$、$N_{\rm cex}$、$J_{\rm task}$、empirical violation rate。

### 三十三、感知模块实验要增加什么？

需要直接比较 pixel reconstruction quality 和 semantic safety relevance。不再只展示原文 Figure 2 那种 Raw / Downsampled / Generated。原论文主要通过视觉生成图展示 perception approximation。改进后应报告：$\mathrm{MAE}(d)$、$\mathrm{MAE}(\theta)$、$\mathrm{Coverage}(\mathcal C_\xi)$、$\mathrm{Width}(\mathcal C_\xi)$，以及不同 fog、lighting、rain、blur 下的 coverage。这会更符合"certified abstraction"的论点。

### 三十四、整个改进方法最核心的变化可以压缩成一个表

| 原 SafePVC | 改进方法 |
|---|---|
| cGAN 生成图像 | semantic encoder |
| MLP 近似 cGAN | certified semantic set |
| image-level approximation | task-relevant abstraction |
| $\Delta s\sim\mu$ | $w\sim\mu(\cdot|s)$ |
| empirical distribution | ambiguity set $\mathcal P(s)$ |
| Monte Carlo expectation | confidence-corrected expectation |
| global Lipschitz | local/cell-wise bound |
| uniform discretization | adaptive partition |
| state counterexample | joint semantic-state counterexample |
| MSE-to-$\pi_0$ | trust-region + performance constraint |
| $\pi\leftrightarrow B$ | perception $\leftrightarrow\pi\leftrightarrow B$ |

### 三十五、最终形成的"新论文方法主线"

如果把它写成新的论文 contribution，最清楚的主线可以是：

**Step 1: Semantic Abstraction** — $o\rightarrow\hat\xi\rightarrow\mathcal C_\xi$

**Step 2: Robust Policy Learning** — $\xi\in\mathcal C_\xi\rightarrow\pi$

**Step 3: State-Dependent Uncertainty Learning** — $w\sim\mathcal P(\cdot|s)$

**Step 4: Distributionally Robust SBC** — $B(s)\ge\sup_{\xi,Q}E_Q[B(s')]+\epsilon$

**Step 5: Adaptive Formal Verification**

**Step 6: Trust-Region CEGIS Refinement** — $(s^*,\xi^*,Q^*)\rightarrow(\pi^*,B^*)$

最终，从本质上看，这个改进不是简单把 cGAN 换成 semantic encoder，而是把原 SafePVC 的证明对象从 **learned image surrogate** 升级成 **certified semantic abstraction + distributionally robust stochastic closed loop**。
