## 1. 总表

“低维观测/潜变量”是控制器实际使用的量；原始图像、LiDAR 等只列在“原始观测”列。**注意两类潜变量的区别：**

- SafePVC、SPVT 的 cGAN 是**状态+潜变量 → 图像**的生成器，潜变量是生成器的输入，不是图像编码器的输出；
- VISION-SLS、当前车道实验是**图像 → 低维观测**的编码器，低维观测是控制器输入。

## 2. 逐篇实验设计

### 2.1 SafePVC / Provably Probabilistic Safe Controller Synthesis（[PDF](720_file_Paper.pdf)）

这是当前项目“SPVC”的直接方法祖先，也是 `artical/` 代码对应的论文。

- **两个 benchmark**：X-Plane 滑行跑道跟踪（状态 2D `(p,θ)`，图像 8×16，潜变量 2）和 CARLA 紧急制动（状态 2D `(d,v)`，图像 32×32，潜变量 4）。
- **流程**：cGAN 近似状态→图像；蒸馏成 MLP；PPO 预训练控制器；数据驱动状态扰动分布；SBC（随机屏障）由 martingale 条件训练；α,β-CROWN 做区间验证；反例交替更新控制器和 SBC。
- **实验设计**：固定控制器、联合更新、交替更新三组；报告“可验证安全概率下界”和迭代次数。结果：X-Plane 84.9%（固定）→92.1%（交替，35 iters）；CARLA 72.6%→94.2%（100 iters）；联合更新不收敛（OT）。
- **扰动实验**：把状态扰动建模为人工指定均匀分布，按状态空间跨度的百分比扫描扰动强度，画最大可验证安全概率 vs 训练步数。
- **可迁移**：这是 AEBS 任务的原始协议；固定/联合/交替三组消融、扰动分布估计、α,β-CROWN 验证、反例回灌都可直接用。**注意**：它的“潜变量”是 cGAN 生成器输入，不是 DINO 编码器输出；换前端时不能把两者混为一谈。

### 2.2 SPVT：Learning Vision-Based NN Controllers with Semi-Probabilistic Safety（[PDF](<Learning Vision-Based Neural Network Controllers with Semi-Probabilistic.pdf>)，[代码](../../SPVT/README.md)）

- **四个任务**：X-Plane 跑道、CARLA 车道跟随、F1Tenth 实体小车、Airsim 无人机。
- **状态/观测**：前三个是 2D `(d,θ)`、8×16 灰度图、动作 1 维转向；无人机是 7D（位置+四元数）、64×64 图、连续控制。cGAN 用“状态+10 维潜变量”生成图像；潜变量消融 2/4/6/8/10/16/32/64，图像 MSE 随维数下降。
- **验证设计**：半概率 SPV：对 2000 个 i.i.d. 初态做 K 步可达性验证（α,β-CROWN），再用分布无关尾界给整个初态空间的安全概率下界；δ=0.05。报告 K 步安全概率曲线。
- **性能设计**：100 个随机初态 ×200 步，累计奖励；与 RESPO、SAC-RCBF、VSRL 比较；无人机任务额外比较扩散模型生成器。
- **可迁移**：SPV 的“采样初态 + 尾界 + 逐步可达”协议、K 步曲线、潜变量维数消融、hard-example buffer/课程学习，适合 AEBS/车道评估。**它的 cGAN 是生成器，不是编码器**；如果当前工作是“图像→潜变量”，应主要借它的验证协议，而不是前端结构。
- **代码限制**：`SPVT/` 只实现 CARLA（`exp=carla`），X-Plane 仍是 TODO；无人机不在本地代码中。

### 2.3 VISION-SLS（[PDF](<../../VISION-SLS- Safe Perception-Based Control from Learned Visual Representations via System Level Synthesis.pdf>)，[代码](../../VISION-SLS/README.md)）

- **方法**：冻结 DINOv2 → 学习低维观测 `y≈Cx` + 状态相关误差界；非线性 SLS 输出反馈 + SCP/Riccati；鲁棒约束收紧。
- **实验矩阵**：
  - Light-Dark 2D：状态 2、观测 2、动作 2；15 初态 ×50 rollouts；SR/CVR 对比 CE/NR：100%/0% vs 90.13%/9.87% vs 87.73%/12.27%。
  - 4D 车 + 俯视 RGB：状态 4、观测 3、动作 2；遮挡 0.97，诱导信息收集；SR 98.53%、CVR 1.6%；与 CE 93.47%/6.53%、NR 48.13%/55.87% 比较。
  - 10D 四旋翼 + 机载 RGB：状态 10、观测 5、动作 3；SR/CVR 100%/0%；NR 29.47%/92.8%。
  - 59D 人形（无视觉）：状态 59、观测 30、动作 23；后空翻跟踪；NR 2%/98%。
  - 实体 TurtleBot 4：状态 5、观测 3、动作 2；办公室 3 次运行；全部在 reachable tube 内。
  - 校准实验：500 个随机状态；校准点数 50/100/250/500/1500 对应覆盖 91.4/92.2/97.4/99/99%。
- **可迁移**：**状态相关误差界**（第 3 节详述）是当前“真实图像潜变量 vs 代理潜变量”误差的直接方法；4D 车/3D 观测是维度升级的自然下一站；SR/CVR、15×50、校准覆盖 vs 样本数都是现成实验协议。
- **不直接迁移**：SLS 求解器本身很重，且与 SPVC 的 SBC/PPO 后端不同；当前项目不需要复现 SLS 才能用它的误差界和评价协议。

### 2.4 Model-Free Safe RL through Neural Barrier Certificate（[PDF](<../../Model-Free_Safe_Reinforcement_Learning_Through_Neural_Barrier_Certificate.pdf>)，[代码](../../srlnbc/README.md)）

- **任务**：紧急制动（状态 2、动作 1）、独轮车 reach-avoid（状态 5、动作 2）、Safety Gym point/car/doggo（高维状态+目标+LiDAR）、MetaDrive（14 DOF 整车）。
- **方法**：无模型联合学习策略与神经屏障；把单步不变性扩展为**多步不变损失**；拉格朗日法约束策略。
- **实验设计**：与解析可行域比较；与 PPO-Lag/TRPO-Lag/CPO/FAC-SIS/PPO 比较；barrier step 消融（1 步不安全，5 步以上近零违例，20 步足够）；报告 episode cost/return、成功率。
- **可迁移**：多步不变损失可直接加入当前 SBC 训练（当前是一步/终止条件）；barrier step 消融可作为 SBC 训练的必做消融。**无视觉、无潜变量误差**，不解决前端问题。

### 2.5 CP-NCBF（[PDF](2503.17395v2.pdf)）

- **任务**：地面车避障（状态 3 `(x,y,θ)`，动作 2）、平面飞行器 geo-fencing（状态 6，动作 2）、四足动态避障（状态 8，动作 2）。
- **方法**：split conformal prediction 给 NCBF 的零水平集做概率修正；NCBF-QP 在线过滤；安全水平 99.5%/99.9%。
- **实验设计**：PyBullet + Crazyflie/四足；与 CP-CBF、robust NCBF 比较安全集大小；报告安全率/约束违反；附录给出状态空间、安全/不安全集、校准细节。
- **可迁移**：CP 与 NCBF-QP 的组合、按安全水平调 CP 分位数、与 robust 基线比较“安全集更大”。**无视觉**；适合当前 SBC 的 CP 校准或 QP 过滤分支，但不是前端替换。

### 2.6 BarrierNet（[PDF](BarrierNet_Differentiable_Control_Barrier_Functions_for_Learning_of_Safe_Robot_Control.pdf)）

- **任务**：交通汇入（每车状态 2 `(x,v)`，动作 1）、2D 机器人导航（状态 4，动作 2）、3D 机器人导航（状态 6，动作 3）、视觉端到端驾驶（状态 7 `(s,d,μ,v,a,δ,ω)`，动作 2；前视 960×600 + CNN/LSTM）。
- **方法**：可微 QP 层 + HOCBF；策略输出 QP 参数，QP 保证约束；端到端训练。
- **实验设计**：交通汇入与最优/OCBF/FC/DFB 比较；2D/3D 导航与 FC/DFB 比较，障碍尺寸泛化；视觉驾驶用 VISTA sim-to-real + 实车 Lexus，比较 FC/DFB/OCBF，报告车道偏离/碰撞/控制平滑。
- **可迁移**：如果要把当前 LQR+残差换成“神经策略 + QP 安全层”，这是最接近的模板；视觉驾驶 7D 状态 + 图像也是可参考的高维视觉任务。**它是 QP 过滤/可微层，不是 SBC 证书**；不能替代当前 CP+SBC 的证明链。

### 2.7 Opt-ODENet（[PDF](Opt-ODENet.pdf)）

- **任务**：单个独轮车避障（状态 3，动作 2），目标点 + 障碍。
- **方法**：Neural ODE + 可微 QP；CLF 损失保证稳定/收敛，CBF-QP 保证安全；学习 class-K 函数。
- **实验设计**：单个 case study；比较无 CBF-QP、仅推理时 QP、固定 κ、学习 κ；画轨迹和距离目标曲线。
- **可迁移**：可微 QP/CLF 思路可参考，但实验规模小、无视觉；优先级低。

### 2.8 Latent CBF + World Model（[PDF](<Safety Certification in the Latent space using Control Barrier Functions and.pdf>)）

- **任务**：倒立摆（状态 2 `(Θ,Θ̇)`，动作 1）、Dubins 车（状态 3，动作 1）；观测是 RGB 图 + 一个本体量（角速度/朝向）。
- **方法**：DINOv2 世界模型把图像编码到 latent，学习 latent 动力学；在 latent 空间学 control barrier certificate 和策略；半监督（少量安全/不安全标签）。
- **实验设计**：2 个 case study；约 250 条参考轨迹；可视化 latent 决策边界；作者明确说**没有形式保证**（limitation）。
- **可迁移**：这是“视觉 latent + CBF”的最接近工作，适合对照当前“latent + CP + SBC”；但它的 latent 误差没有校准，不能直接支持证书。可作为“无误差界 baseline”写进相关工作。

### 2.9 Training with Hard Constraints（[PDF](<Training with hard constraints- Learning neural certificates and controllers for sdes.pdf>)）

- **任务**：证书验证：2D 倒立摆、2D/3D/4D/5D/10D 几何布朗运动（GBM）；联合控制器-证书：2D 倒立摆、2D GBM、3D Lorenz、3D XV-15 倾转旋翼。
- **方法**：supermartingale 神经证书；bound-based 离散化训练（硬约束）到 5D；scenario-based PAC 到 10D。
- **实验设计**：6 个验证例子 + 4 个联合合成；与 Neustroev et al. 比较运行时间/划分大小/pRA；报告 ϵ 和置信度（δ=1e-9）；Monte Carlo 验证 pRA≈1。
- **可迁移**：高维证书训练和“硬约束/PAC”思路，适合将来把 SBC 扩展到 5D/10D；**无视觉、无控制任务的前端**，当前不优先。

### 2.10 状态相关误差界说明（[PDF](<../../VISION_SLS_状态相关误差界计算.pdf>)）

- 不是论文实验，而是 VISION-SLS 误差包络的技术说明：
  1. 残差 `r_i=||p_θ(ψ_DINO(I_i)) − C_r x_i||∞`；
  2. 多项式特征 `m(x)`；
  3. 凸优化拟合 `b0(x)=βᵀm(x)`，覆盖残差且不过度保守。
- **这是当前工作最该直接迁移的一页**：把当前的全局 CP 盒换成状态相关包络，可能缩小 CP 半径、扩大认证集；同时保留 CP 的覆盖率校准。

## 4. 哪些适合迁移到当前工作

### 4.1 高优先级

1. **VISION-SLS 的状态相关误差界**（第 2.10 节）
   - 当前车道实验用的是全局 CP 盒（patch 0.072/0.08）。改成 `b0(x)=βᵀm(x)` 的状态相关包络，可以直接减少保守性，并让“真实图像 latent vs 代理 latent”的误差进入验证器。
   - 做法：用 patch 观测的残差拟合 `m(x)=[1,|e|,|θ|,e²,θ²,...]` 的凸上界；在校准集上做分位数/覆盖检查；把 `b0(x)` 作为每个状态格的 CP 半径送入现有视觉证书。
   - 预期：同覆盖率下更小的平均半径；认证集可能扩大；需要防止边缘过拟合。

2. **SafePVC 的固定/联合/交替消融 + 扰动分布估计**
   - 直接用于 AEBS 的 cGAN vs DINO 公平对照：同一 α,β-CROWN、同一 SBC 条件、同一初态/扰动协议，只换前端。
   - 指标沿用它的“可验证安全概率下界 + 迭代次数”，再补潜在误差/CP 半径。

3. **SPVT 的半概率 SPV 协议**
   - 2000 个 i.i.d. 初态、K 步可达、δ=0.05、尾界下界；适合给 AEBS/车道做“K 步安全概率”曲线。
   - 潜变量维数消融（2–64）和 hard-example buffer 可用于“前端/潜变量维数”消融。

### 4.2 中优先级

4. **Model-Free NBC 的多步不变损失**
   - 当前 SBC 训练以一步/终止为主；把 `num_barrier_step`（5/20）加进 SBC 损失，做 barrier step 消融。可能改善训练稳定性，但不改变 CP/前端。
   - 注意：它是无模型、全状态；不能替代 CP 的感知误差处理。

5. **CP-NCBF 的“CP + NCBF-QP”**
   - 如果以后要在策略输出后加 QP 安全层，可参考它的 CP 分位数→NCBF 零水平集→QP 过滤；当前证书是离线 SBC，不需要 QP。
   - 它的 3D/6D/8D case study 可作为高维 CP 校准的参照。

6. **BarrierNet 的可微 QP + 视觉驾驶 7D**
   - 如果要把 LQR+残差换成“神经策略 + 可微 QP”，这是最接近的架构；视觉驾驶 7D 状态 + 图像也可参考。
   - 但它不是 SBC 证书；与当前 CP+SBC 的证明链是两条路线，不能混写。

### 4.3 低优先级/不直接迁移

7. **Latent CBF + World Model**
   - 概念最接近“视觉 latent + CBF”，但**没有形式保证**，latent 误差未校准；适合作为相关工作/无误差界 baseline，不适合直接替代 CP+SBC。
   - 它的倒立摆/Dubins 两个任务可以作为低维视觉补充例子，但当前车道已经覆盖 2D 视觉证书。

8. **Hard Constraints SDE**
   - 高维（5D/10D）证书训练和 PAC 思路值得将来扩展到 10D 无人机/人形；当前 2D 车道/AEBS 用不上。
   - 它的 GBM 例子不是控制任务，不能直接当 benchmark。

9. **Opt-ODENet**
   - 可微 QP/CLF 可参考；单 case study、无视觉，当前优先级最低。

## 5. 对当前工作的具体建议

1. **先做 VISION-SLS 状态相关误差界**：这是当前“真实图像 latent vs 代理 latent 误差”最直接、成本最低的改进；用现有 patch 观测/CP 数据即可，不需要新环境。
2. **AEBS 前端对照用 SafePVC 协议**：cGAN vs DINO，同 actor/SBC/αβ-CROWN/初态/扰动；这是“换前端”的直接证据。
3. **车道补 SPVT 式 SPV 曲线**：2000 初态、K 步、δ=0.05；把“视觉证书”从单步不变扩展成 K 步概率下界。
4. **SBC 训练加多步不变损失**（NBC），做 barrier step 消融；这是低成本、可解释的训练改进。
5. **暂不做**：59D 人形、10D 四旋翼、BarrierNet 实车、MetaDrive；它们不能更快回答“前端替换 + 潜在误差”的主问题。

## 6. 维数口径提醒

引用这些论文时，必须区分四个量，不能只写“状态几维”：

- **物理状态维**：验证对象；
- **原始观测维**：图像分辨率/LiDAR 点数；
- **低维观测/潜变量维**：控制器实际输入；
- **SBC/验证器输入维**：可能包含观测器记忆、时钟、误差盒。

例如 VISION-SLS 的 59D 人形是“状态 59、观测 30、无视觉”；SafePVC 的 CARLA 是“状态 2、图像 32×32、潜变量 4”；SPVT 的潜变量 10 是生成器输入，不是编码器输出。把这些混在一起，会得出错误的“高维视觉”结论。
