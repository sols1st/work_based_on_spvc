| 八维起重机搬运与消摆 | [完整实验、配对相机观测与鲁棒屏障](experiments/八维起重机/八维桥式起重机_视觉消摆与有限时域鲁棒屏障_20261117.md)。在同批初态与扰动下单独检验视觉摆移反馈对末段定位和消摆的作用。 |

| 三维移动机器人 | [实验和盒内越界反例](experiments/三维移动机器人/移动机器人_三维视觉实验_20261108.md)。图像闭环已跑通，当前控制器在允许误差下可以越界，完整鲁棒证书未通过。 |
