## 六 引用结果时的共同规则

1. 说明模型版本：PPO09、最小DINO-SPVC、新R2原生PPO不是同一个控制器。
2. 说明数据单位：图片数、图像/速度组合数、同步帧数、独立轨迹数不能互换。
3. 说明评估方式：精确配对、同步轨迹与最近图片近似闭环必须分开。
4. 说明误差单位及聚合：latent尺度、距离米、速度米/秒；按帧均值与轨迹等权均值不能混用。
5. 说明保证范围：开发误差、原代码代理读数、CP统计覆盖、图像闭环证书不是同一结论。
6. 最新日期增补优先解释后续状态，但不覆盖旧实验原始数据。相应结果文件和配置在`artical-F122/results/`保留。
